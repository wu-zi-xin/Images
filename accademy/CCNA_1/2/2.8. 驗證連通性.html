2.7.1 手動設定終端設備 IP (Manual IP Address Configuration)

網路通訊的基礎：IP 位址

如同你需要朋友的電話號碼才能打電話給他們一樣，網路上的設備也需要 IP 位址才能互相通訊。在此主題中，我們將學習如何透過設定交換器 (Switches) 和個人電腦 (PCs) 的 IP 位址來建立基本的連線能力。

通訊基礎 (Communication Basics)
Much like you need your friends' telephone numbers to text or call them, end devices in your network need an IP address so that they can communicate with other devices on your network. In this topic, you will implement basic connectivity by configuring IP addressing on switches and PCs.
中文解析
就像你需要朋友的電話號碼才能傳簡訊或打電話給他們一樣，你網路中的終端設備也需要 IP 位址，這樣它們才能與網路上的其他設備進行通訊。在這個主題中，您將透過設定交換器和 PC 的 IP 位址來實現基本的連線能力。
Windows 作業系統手動設定步驟

IPv4 位址資訊可以手動輸入終端設備，也可以使用動態主機設定協定 (DHCP) 自動獲取。

⚙️ Windows 手動設定路徑：
Control Panel (控制台) > Network and Sharing Center (網路和共用中心) > Change adapter settings (變更介面卡設定) > 右鍵點擊介面卡選擇 Properties (內容) > 選擇 Internet Protocol Version 4 (TCP/IPv4) > Properties (內容)
Required Fields for Manual Config:

• IP address: 192.168.1.10
• Subnet mask: 255.255.255.0
• Default gateway: 192.168.1.1
手動設定的必填欄位解析：

• IP 位址： 識別該設備在網路上的唯一位置。
• 子網路遮罩： 決定 IP 位址中哪部分是網段，哪部分是主機。
• 預設閘道： 讓設備能夠與「不同網段」通訊的路由器介面 IP。

2.7.2 自動設定終端設備 IP (Automatic IP Address Configuration)

為何 DHCP 如此重要？

終端設備通常預設使用 DHCP (Dynamic Host Configuration Protocol) 來進行自動的 IPv4 位址設定。這項技術幾乎在每一個網路環境中都會被使用。

DHCP 的必要性
In a network, DHCP enables automatic IPv4 address configuration for every end device that is DHCP-enabled. Imagine the amount of time it would take if every time you connected to the network, you had to manually enter the IPv4 address, the subnet mask, the default gateway, and the DNS server. Multiply that by every user and every device in an organization and you see the problem.

Manual configuration also increases the chance of misconfiguration by duplicating another device's IPv4 address.
中文解析
在網路中，DHCP 可以為每台啟用 DHCP 的終端設備自動設定 IPv4 位址。想像一下，如果每次連接網路時，都必須手動輸入 IPv4 位址、子網路遮罩、預設閘道和 DNS 伺服器，那將會花費多少時間。將這個情況乘上組織中的每位使用者和每台設備，你就會發現手動設定的難題。

手動設定還會增加因重複配置另一台設備的 IPv4 位址而導致「設定錯誤 (IP 衝突)」的機率。
💡 自動獲取設定選項：
在 Windows IPv4 設定頁面中，選擇 Obtain an IP address automatically (自動取得 IP 位址) 以及 Obtain DNS server address automatically (自動取得 DNS 伺服器位址)。

Note: IPv6 則使用 DHCPv6 和 SLAAC (Stateless Address Autoconfiguration) 來進行動態位址分配。

2.7.4 設定交換器虛擬介面 (Switch Virtual Interface Configuration)

什麼是 SVI？為何交換器需要 IP？

交換器 (Switch) 主要運作在 L2，本身不需要 IP 位址也能轉發封包。但為了讓我們能夠遠端管理 (Remote Access) 交換器（例如透過 SSH 或 Telnet），我們必須在 SVI 上設定 IP 位址和子網路遮罩。

SVI 設定概念
To access the switch remotely, an IP address and a subnet mask must be configured on the SVI. To configure an SVI on a switch, use the interface vlan 1 global configuration command. Vlan 1 is not an actual physical interface but a virtual one.
中文解析
要遠端存取交換器，必須在 SVI 上設定 IP 位址與子網路遮罩。若要在交換器上設定 SVI，請使用 interface vlan 1 全域設定指令。VLAN 1 並非實際的實體介面，而是一個虛擬介面。
SVI 與預設閘道設定指令解析

以下列出在交換器上設定 VLAN 1 SVI 以及預設閘道時所使用的重要指令。請仔細閱讀其詳細說明與解析。

interface vlan 1
進入 VLAN 1 的介面設定模式 (Interface Configuration Mode)。 VLAN 1 是 Cisco 交換器預設的管理 VLAN。
ip address [ip] [mask]
指派 IPv4 位址與子網路遮罩給此虛擬介面。 例如：ip address 192.168.1.20 255.255.255.0
no shutdown
啟用此虛擬介面 (Enable the interface)。 路由器或交換器的介面預設可能是關閉 (shutdown) 狀態，必須輸入此指令將其喚醒 (state to up)。
ip default-gateway [ip]
設定交換器的預設閘道 (在全域設定模式下執行)。 與 Windows PC 類似，如果我們需要從「另一個網段」遠端連線到這台交換器進行管理，交換器就必須知道預設閘道的 IP。
指令 (Command) 說明與解析 (Description)
interface vlan 1 進入 VLAN 1 的介面設定模式 (Interface Configuration Mode)。 VLAN 1 是 Cisco 交換器預設的管理 VLAN。
ip address [ip] [mask] 指派 IPv4 位址與子網路遮罩給此虛擬介面。 例如：ip address 192.168.1.20 255.255.255.0
no shutdown 啟用此虛擬介面 (Enable the interface)。 路由器或交換器的介面預設可能是關閉 (shutdown) 狀態，必須輸入此指令將其喚醒 (state to up)。
ip default-gateway [ip] 設定交換器的預設閘道 (在全域設定模式下執行)。 與 Windows PC 類似，如果我們需要從「另一個網段」遠端連線到這台交換器進行管理，交換器就必須知道預設閘道的 IP。

完整指令流程參考：

Switch# configure terminal
Switch(config)# interface vlan 1
Switch(config-if)# ip address 192.168.1.20 255.255.255.0
Switch(config-if)# no shutdown
%LINK-5-CHANGED: Interface Vlan1, changed state to up
Switch(config-if)# exit
Switch(config)# ip default-gateway 192.168.1.1

Q1. 自動位址分配協定

What protocol enables automatic IPv4 address configuration for end devices, helping to prevent duplicate IP misconfigurations?

(哪一種協定能夠為終端設備提供自動的 IPv4 設定，且有助於防止 IP 衝突與設定錯誤？)
👉 點擊翻開看解答
解答
DHCP
解析：Dynamic Host Configuration Protocol (動態主機設定協定) 能大幅減少網路管理員手動輸入 IP、子網路遮罩、閘道及 DNS 的時間與人為錯誤。
Q2. 終端機檢查指令

What command is used at the Windows command prompt to display the IP configuration settings (IPv4 address, subnet mask, gateway)?

(在 Windows 命令提示字元中，使用哪個指令可以顯示 IP 設定資訊？)
👉 點擊翻開看解答
解答
ipconfig
解析：ipconfig 是在 Windows 端最常用的指令，用來確認設備是否成功從 DHCP 伺服器拿到正確的網路參數。
Q3. 交換器管理介面

Vlan 1 is not an actual physical interface but a virtual one. What is the acronym for this type of interface used for remote switch management?

(Vlan 1 並非實體介面而是虛擬的。這種用於交換器遠端管理的介面，其英文縮寫為何？)
👉 點擊翻開看解答
解答
SVI (Switch Virtual Interface)
解析：由於 L2 交換器的實體 Port 不會直接設定 IP 位址，因此我們將 IP 設定在虛擬介面 (SVI) 上，通常預設為 VLAN 1，以便進行遠端存取。
Q4. 啟用介面指令

After assigning an IP address to interface vlan 1, which interface configuration command must you enter to enable the virtual interface?

(在為 vlan 1 介面指派 IP 位址後，您必須輸入哪個介面設定指令來「啟用」這個虛擬介面？)
👉 點擊翻開看解答
解答
no shutdown
解析：在 Cisco IOS 中，shutdown 代表關閉，因此 no shutdown 即代表取消關閉（啟用介面），此時系統會提示 changed state to up。
Q5. 跨網段遠端管理

To manage a switch remotely from a host on a different network, you must configure an SVI IP. What other global configuration parameter is required?

(若要從「不同網段」的主機遠端管理交換器，除了設定 SVI IP 外，還必須設定哪一個全域參數？)
👉 點擊翻開看解答
解答
Default Gateway (預設閘道)
解析：必須使用 ip default-gateway [ip位址] 指令。這樣交換器才知道要將回傳給外部網路的封包交給哪台路由器處理。
