2.9.3 模組學習總結 (What did I learn in this module?)

1. 作業系統與存取模式 (OS and Access Modes)
All end devices and network devices require an operating system (OS). The user can interact with the shell using a command-line interface (CLI) or a graphical user interface (GUI).

As a security feature, the Cisco IOS software separates management access into the following two command modes: User EXEC Mode and Privileged EXEC Mode.
所有終端設備和網路設備都需要作業系統 (OS)。使用者可以使用命令列介面 (CLI) 或圖形使用者介面 (GUI) 與 Shell 進行互動。

作為一項安全功能，Cisco IOS 軟體將管理存取權限分為以下兩種指令模式：使用者 EXEC 模式 和 特權 EXEC 模式。
2. 設定模式與輔助功能 (Configuration Modes & Help)
Global configuration mode is accessed before other specific configuration modes. From global config mode, the user can enter different subconfiguration modes: Line Configuration Mode and Interface Configuration Mode.

Each IOS command has a specific format or syntax and can only be executed in the appropriate mode. The IOS has two forms of help available: context-sensitive help and command syntax check.
在進入其他特定的設定模式之前，必須先進入全域設定模式 (Global Configuration Mode)。從全域設定模式中，使用者可以進入不同的子設定模式：線路設定模式 (Line Configuration Mode) 和介面設定模式 (Interface Configuration Mode)。

每個 IOS 指令都有特定的格式或語法，且只能在適當的模式下執行。IOS 提供兩種形式的輔助功能：上下文關聯輔助 (context-sensitive help，即 ? 鍵) 和 指令語法檢查。
3. 基本設定與系統檔案 (Basic Config & System Files)
The first configuration command on any device should be to give it a unique device name or hostname. Network devices should always have passwords configured to limit administrative access. Provide a method for declaring that only authorized personnel should attempt to access the device by adding a banner.

There are two system files that store the device configuration: startup-config (NVRAM) and running-config (RAM). Running configuration files can be altered if they have not been saved.
任何設備上的第一個設定指令，都應該是賦予其唯一的設備名稱或主機名稱 (hostname)。網路設備應始終設定密碼，以限制管理存取權限。透過新增登入警告訊息 (banner)，提供一種宣告僅允許授權人員嘗試存取設備的方法。

有兩個系統檔案負責儲存設備設定：startup-config (儲存於 NVRAM) 和 running-config (儲存於 RAM)。如果執行中的設定尚未儲存，則在設備重啟時將會遺失。
4. IP 尋址與連線驗證 (IP Addressing & Verification)
IP addresses enable devices to locate one another and establish end-to-end communication. IPv4 address information can be entered into end devices manually, or automatically using DHCP.

To access the switch remotely, an IP address and a subnet mask must be configured on the SVI (interface vlan 1).

The show ip interface brief command verifies the interfaces and address settings. The ping command can be used to test connectivity to another device.
IP 位址使設備能夠找到彼此並建立端對端通訊。IPv4 位址資訊可以手動輸入終端設備，也可以使用 DHCP 自動獲取。

要遠端存取交換器，必須在 SVI (虛擬介面，通常是 interface vlan 1) 上設定 IP 位址和子網路遮罩。

show ip interface brief 指令可驗證介面狀態和位址設定。ping 指令可用於測試與網路其他設備的連線能力。

📝 2.9.4 課後複習測驗 (Module Quiz)

自我檢測：Basic Switch and End Device Configuration

以下收錄模組測驗全 14 題，透過翻卡設計來強化記憶。這對釐清指令觀念以及熟悉網路底層邏輯非常有幫助！點擊卡片即可查看解答與詳細解析。

Question 1

Which statement is true about the running configuration file in a Cisco IOS device?

(關於 Cisco IOS 設備中的執行設定檔 (running-config)，下列哪項敘述是正確的？)
👉 點擊翻開看解答
解答 (Answer)
It affects the operation of the device immediately when modified.
解析：running-config 儲存在 RAM 中，它是設備當下正在執行的設定。任何你在設定模式下輸入並按下 Enter 的指令，都會立刻修改這個檔案並立即生效。
Question 2

Which two statements are true regarding the user EXEC mode? (Choose two.)

(關於使用者 EXEC 模式 (user EXEC mode)，哪兩個敘述是正確的？)
👉 點擊翻開看解答
解答 (Answer)
The device prompt for this mode ends with the ">" symbol.
Only some aspects of the router configuration can be viewed.
解析：User EXEC 模式的提示字元結尾是 ">"（例如 Switch>）。這是權限最低的模式，只能用來檢視部分的基礎設定，無法進行任何修改。
Question 3

Which type of access is secured on a Cisco router or switch with the enable secret command?

(使用 enable secret 指令，可以保護 Cisco 路由器或交換器的哪一種存取權限？)
👉 點擊翻開看解答
解答 (Answer)
Privileged EXEC
解析：從 User EXEC (>) 進入 Privileged EXEC (#) 時，需要輸入 `enable` 指令。`enable secret` 就是用來設定這道關卡的加密密碼，防止未經授權者進入特權模式。
Question 4

What is the default SVI on a Cisco switch?

(Cisco 交換器預設的交換器虛擬介面 (SVI) 是哪一個？)
👉 點擊翻開看解答
解答 (Answer)
VLAN1
解析：預設情況下，交換器的所有連接埠都屬於 VLAN 1。因此，用來做為遠端管理用的預設 SVI (Switch Virtual Interface) 就是 `interface vlan 1`。
Question 5

When a hostname is configured through the Cisco CLI, which three naming conventions are part of the guidelines? (Choose three.)

(透過 Cisco CLI 設定主機名稱時，哪三個命名規範是符合準則的？)
👉 點擊翻開看解答
解答 (Answer)
The hostname should be fewer than 64 characters in length.
The hostname should contain no spaces.
The hostname should begin with a letter.
解析：設備命名規則：開頭必須是字母、不能包含空格、總長度不能超過 64 個字元。
Question 6

What is the function of the shell in an OS?

(在作業系統中，Shell 的功能是什麼？)
👉 點擊翻開看解答
解答 (Answer)
It interfaces between the users and the kernel.
解析：OS 的結構中，使用者透過介面 (CLI/GUI) 操作 Shell。Shell 的責任是接收使用者的指令，並將其翻譯給核心 (Kernel) 處理，最後由 Kernel 去調動硬體 (Hardware)。
Question 7

A router with a valid operating system contains a configuration file stored in NVRAM. The configuration file has an enable secret password but no console password. When the router boots up, which mode will display?

(路由器儲存了設定檔。它有設定特權密碼，但沒有設定 Console (主控台) 密碼。開機時，會顯示哪個模式？)
👉 點擊翻開看解答
解答 (Answer)
User EXEC mode
解析：因為沒有設定 Console 登入密碼 (line con 0 內的 password)，開機後不需驗證就會直接進入預設的第一個模式：User EXEC 模式 (Router>)。要進一步提權才會遇到 enable secret 密碼。
Question 8

An administrator has just changed the IP address of an interface on an IOS device. What else must be done in order to apply those changes to the device?

(管理員剛更改了介面的 IP 位址。為了讓這些變更套用到設備上，還必須做些什麼？)
👉 點擊翻開看解答
解答 (Answer)
Nothing must be done. Changes to the configuration on an IOS device take effect as soon as the command is typed correctly and the Enter key has been pressed.
解析：這呼應了 Q1。因為你修改的是 RAM 中的 running-config，所以只要按下 Enter 鍵，IP 設定就會立刻生效，無需額外套用或重新啟動。
Question 9

Which memory location on a Cisco router or switch will lose all content when the device is restarted?

(Cisco 路由器或交換器重新啟動時，哪個記憶體位置會遺失所有內容？)
👉 點擊翻開看解答
解答 (Answer)
RAM
解析：RAM (隨機存取記憶體) 是揮發性記憶體，斷電或重啟後內容就會消失。running-config 就在此處。
Question 10

Why would a technician enter the command copy startup-config running-config?

(技師為何要輸入 `copy startup-config running-config` 這個指令？)
👉 點擊翻開看解答
解答 (Answer)
To copy an existing configuration into RAM
解析：copy 指令的格式是 `copy [來源] [目的地]`。此指令是將 NVRAM 中的開機設定檔 (startup-config) 複製並覆蓋到 RAM 中的執行設定檔 (running-config)，通常用於還原設定。
Question 11

Which functionality is provided by DHCP?

(DHCP 提供哪一項功能？)
👉 點擊翻開看解答
解答 (Answer)
Automatic assignment of an IP address to each host
解析：Dynamic Host Configuration Protocol (動態主機設定協定) 的主要功能就是自動分配 IP 位址及其他網路參數給連線的設備。
Question 12

Which two functions are provided to users by the context-sensitive help feature of the Cisco IOS CLI? (Choose two.)

(Cisco IOS CLI 的上下文關聯輔助功能 (輸入 ? 鍵) 提供使用者的哪兩項功能？)
👉 點擊翻開看解答
解答 (Answer)
Displaying a list of all available commands within the current mode
Determining which option, keyword, or argument is available for the entered command
解析：在空白處輸入 `?` 可以列出當前模式下所有可用的指令；在某個指令後輸入 `?`，則可以提示接下來可以接續哪些參數或關鍵字。
Question 13

Which memory location on a Cisco router or switch stores the startup configuration file?

(Cisco 路由器或交換器的哪個記憶體位置儲存了開機設定檔 (startup-config)？)
👉 點擊翻開看解答
解答 (Answer)
NVRAM
解析：NVRAM (非揮發性記憶體) 斷電後資料不會遺失，因此用來存放設備啟動時要讀取的 startup-config 檔案。
Question 14

To what subnet does the IP address 10.1.100.50 belong if a subnet mask of 255.255.0.0 is used?

(如果使用 255.255.0.0 的子網路遮罩，IP 位址 10.1.100.50 屬於哪一個子網路？)
👉 點擊翻開看解答
解答 (Answer)
10.1.0.0
解析：遮罩 255.255.0.0 表示前兩個八位元 (Octet) 是網路段，後兩個是主機段。因此 10.1 保留，主機段歸零，得出該 IP 所屬的網段位置為 10.1.0.0。
