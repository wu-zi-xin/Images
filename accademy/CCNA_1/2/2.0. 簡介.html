2.0.1 Why should I take this module? (我為什麼要修習這個模組？)

模組簡介 (Module Introduction)
English

Welcome to Basic Switch and End Device Configuration!


As part of your career in networking, you might have to set up a new network or maintain and upgrade an existing one. In either case, you'll configure switches and end devices so that they are secure and perform effectively based on your requirements.


Out of the box, switches and end devices come with some general configuration. But for your particular network, switches and end devices require your specific information and instructions. In this module, you will learn how to access Cisco IOS network devices. You will learn basic configuration commands and use them to configure and verify a Cisco IOS device and an end device with an IP address.


Of course, there is much more to network administration, but none of that can happen without first configuring switches and end devices.
Let's get started!

中文翻譯

歡迎來到「基本交換器與終端設備設定」！


作為網路職涯的一部分，您可能需要建立新網路，或維護並升級現有網路。無論哪種情況，您都需要根據需求來設定交換器與終端設備，以確保其安全且有效地運作。


交換器與終端設備在出廠時帶有一些通用設定。但針對您特定的網路，這些設備需要您提供特定的資訊與指示。在本模組中，您將學習如何存取 Cisco IOS 網路設備。您將學習基本設定指令，並使用它們來設定和驗證帶有 IP 位址的 Cisco IOS 設備與終端設備。


當然，網路管理還有很多內容，但如果不先設定交換器與終端設備，這一切都無法實現。
讓我們開始吧！

2.0.2 What will I learn to do in this module? (我將在這個模組中學到什麼？)

Module Title: Basic Switch and End Device Configuration (模組標題：基本交換器與終端設備設定)

Module Objective: Implement initial settings including passwords, IP addressing, and default gateway parameters on a network switch and end devices. (模組目標：在網路交換器和終端設備上實作初始設定，包含密碼、IP 位址和預設閘道參數。)

Cisco IOS Access
(存取 Cisco IOS)
Explain how to access a Cisco IOS device for configuration purposes. (說明如何為了設定目的存取 Cisco IOS 設備。)
IOS Navigation
(IOS 導覽)
Explain how to navigate Cisco IOS to configure network devices. (說明如何導覽 Cisco IOS 以設定網路設備。)
The Command Structure
(指令結構)
Describe the command structure of Cisco IOS software. (描述 Cisco IOS 軟體的指令結構。)
Basic Device Configuration
(基本設備設定)
Configure a Cisco IOS device using CLI. (使用命令列介面 CLI 設定 Cisco IOS 設備。)
Save Configurations
(儲存設定)
Use IOS commands to save the running configuration. (使用 IOS 指令儲存執行中的設定。)
Ports and Addresses
(連接埠與位址)
Explain how devices communicate across network media. (說明設備如何透過網路媒介進行通訊。)
Configure IP Addressing
(設定 IP 位址)
Configure a host device with an IP address. (為主機設備設定 IP 位址。)
Verify Connectivity
(驗證連線)
Verify connectivity between two end devices. (驗證兩個終端設備之間的連線能力。)
