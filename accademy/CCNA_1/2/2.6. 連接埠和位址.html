2.5.1 設定檔 (Configuration Files)

兩種主要設定檔系統

Cisco 設備有兩個負責儲存設備設定的系統檔案：

startup-config (啟動設定檔)
儲存在 NVRAM (非揮發性記憶體) 中。包含設備啟動或重新啟動時將使用的所有命令。當設備關閉電源時，Flash/NVRAM 不會遺失其內容。
running-config (執行設定檔)
儲存在 RAM (隨機存取記憶體) 中。反映目前的設定狀態。修改此檔案會立即影響設備運作。RAM 是揮發性記憶體，當設備關閉或重啟時，會遺失所有內容。
檢視與儲存設定指令

這些指令都必須在 特權 EXEC 模式 (Privileged EXEC mode) 下執行：

1. 檢視目前的執行設定 (RAM)：

Switch#
show running-config

2. 檢視儲存的啟動設定 (NVRAM)：

Switch#
show startup-config

3. 儲存設定 (將 RAM 的設定複製到 NVRAM)：

Switch#
copy running-config startup-config
這能確保下次重新啟動時載入完整的最新設定。

2.5.2 更改與清除設定 (Alter the Running Configuration)

還原未儲存的設定

如果對 running-config 所做的更改未達到預期效果且尚未儲存，可以使用 reload 指令將設備還原到先前的設定。

Switch#
reload
⚠️ 注意事項與影響：
使用 reload 指令的缺點是設備將會短暫離線，導致網路中斷。當 IOS 偵測到有未儲存的更改時，會出現提示詢問是否要儲存更改。若要放棄更改，請輸入 n 或 no。
清除已儲存的設定

如果不想要的更改已經儲存到 startup-config，則必須清除所有設定並重啟設備：

Switch#
erase startup-config

輸入指令後，交換器會提示確認，按 Enter 接受。

After removing the startup config from NVRAM, reload the device to remove the current running config file from RAM. On reload, a switch will load the default startup config that originally shipped with the device. 從 NVRAM 移除啟動設定檔後，必須重新載入 (reload) 設備，才能從 RAM 中移除目前的執行設定檔。重新載入後，交換器將載入隨設備出廠的預設啟動設定。

2.5.3 & 2.5.4 擷取與儲存為文字檔

2.5.3 影片重點：指令縮寫 (Command Shortening)

為了加快設定速度，只要指令縮寫不會與其他指令混淆 (具備唯一性)，就可以直接使用縮寫。例如，儲存設定的最常用縮寫為：

Switch#
copy run start
💡 注意：合併與覆蓋
若執行 copy startup-config running-config (將啟動檔複製到執行檔)，並不會完全清除當前的執行設定，而是會將設定合併 (merged) 到執行設定檔中。
2.5.4 將設定擷取到文字檔 (Capture Configuration)

可以透過終端機模擬軟體 (例如 PuTTY 或 Tera Term) 將設定檔保存並封存為文字檔。這能做為設備當前設定的備份記錄。

  • 步驟 1：打開 PuTTY，進入左側選單的 Session > Logging。
  • 步驟 2：選擇 "All session output" 選項，並在下方的 Log file name 指定存檔位置與名稱 (例如 MySwitchLogs.txt)。
  • 步驟 3：回到終端機視窗，執行 show running-config 或 show startup-config，畫面上印出的所有內容都會被記錄到該文字檔中。
  • 步驟 4：完成後，回到 Logging 設定，改回 "None" 以停止記錄。
💡 如何從文字檔還原設定？
將設備進入全域設定模式 (configure terminal)。接著將文字檔中的指令複製，並直接貼上到連接到交換器的終端機視窗中，讓指令依序套用。

📝 課後複習測驗 (Quiz)

自我檢測：Save Configurations

請試著回答以下問題來檢驗學習成果，點擊卡片即可查看解答！

Q1. 儲存設定指令

Which command is used to save the running configuration to NVRAM?

(哪個指令用於將執行設定儲存至 NVRAM？)
👉 點擊翻開看解答
解答
copy running-config startup-config
縮寫為 copy run start。
Q2. 檢視目前設定

Which command displays the configuration currently operating on the device?

(哪個指令可以顯示設備上目前正在運作的設定？)
👉 點擊翻開看解答
解答
show running-config
此檔案存放在 RAM 中，設備斷電後會消失。
Q3. 清除啟動設定

What is the command to remove the configuration stored in NVRAM?

(移除儲存在 NVRAM 中的設定的指令是什麼？)
👉 點擊翻開看解答
解答
erase startup-config
清除後必須再執行 reload，才能將 RAM 中的設定一併清除並恢復出廠預設。
Q4. RAM 與 NVRAM

If a switch loses power, which configuration file is lost?

(如果交換器斷電，哪一個設定檔會遺失？)
👉 點擊翻開看解答
解答
running-config
因為 running-config 儲存在揮發性的 RAM 記憶體中，斷電即消失；而 startup-config 在 NVRAM 中，會保留下來。
Q5. 重啟設備

Which command restarts the device to discard unsaved changes?

(哪個指令可重啟設備以放棄未儲存的更改？)
👉 點擊翻開看解答
解答
reload
系統詢問是否要保存修改過的配置時，選擇 n (no) 即可放棄更改。
