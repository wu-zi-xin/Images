2.1.1 & 2.1.2 作業系統架構與介面 (OS & Interfaces)

作業系統的三大核心組件 (Operating Systems Components)
English
All end devices and network devices require an operating system (OS). The OS interacts directly with hardware via the kernel, while the shell provides the user interface.
中文翻譯
所有終端設備和網路設備都需要作業系統 (OS)。作業系統透過核心(Kernel)與硬體直接互動，而殼層(Shell)則提供使用者介面。
Shell
(殼層 / 介面)
The user interface that allows users to request specific tasks from the computer. (CLI or GUI) (允許使用者向電腦要求執行特定任務的介面。可為命令列或圖形介面。)
Kernel
(核心)
Communicates between the hardware and software of a computer. (在電腦的硬體與軟體之間進行通訊。)
Hardware
(硬體)
The physical part of a computer including underlying electronics. (電腦的實體部分，包含底層電子元件。)

CLI vs GUI (命令列與圖形化介面)
CLI (Command-Line Interface)
(命令列介面)
Interacts directly with the system in a text-based environment. Requires less overhead but needs knowledge of underlying command structure. (在文字環境中直接與系統互動。佔用的系統資源較少，但需要了解底層指令結構。)
GUI (Graphical User Interface)
(圖形化使用者介面)
Interacts with the system using graphical icons, menus, and windows. More user-friendly, but can fail, crash, and is more resource-intensive. (使用圖形圖示、選單和視窗與系統互動。更易於使用，但可能當機且佔用較多系統資源。)

💡 額外補充 (Cisco IOS 簡介)：
Cisco 網路設備 (如路由器、交換器) 普遍使用 Cisco IOS (Internetwork Operating System)。雖然有提供部分的 GUI 介面，但網路工程師通常都依賴 CLI 來進行完整且高效的設備設定。除了傳統 IOS，還有 IOS XE, IOS XR, NX-OS 等不同版本的系統。

2.1.4 存取方法 (Access Methods)

連接並設定網路設備的常見方式

當我們拿到一台全新的 Cisco 交換器或路由器時，我們需要透過以下方法進入系統進行設定：

Console
(主控台連線 / 帶外管理)
A physical management port that provides out-of-band access. Used for initial configuration or when the device is inaccessible over the network. Requires a special console cable. (提供帶外存取的實體管理連接埠。用於「初始設定」或當設備無法透過網路存取時。需要使用專屬的 Console 線材連接。)
Secure Shell (SSH)
(帶內管理 / 推薦)
An in-band method for remotely establishing a secure CLI connection over a virtual interface. Provides encrypted connection. (在虛擬介面上遠端建立「安全 CLI 連線」的帶內管理方法。連線過程會加密，是最推薦的遠端管理方式。)
Telnet
(帶內管理 / 不推薦)
An insecure, in-band method of remotely establishing a CLI session. Passwords and commands are sent in plaintext. (一種不安全的遠端 CLI 連線方式。所有密碼與指令皆以「明文 (plaintext)」傳送，極易遭竊聽。)
Auxiliary (AUX)
(輔助埠 / 帶外)
Older routers support a legacy AUX port used to establish a CLI session remotely over a telephone connection using a modem. (較舊的路由器支援的連接埠，透過數據機與電話線路遠端建立 CLI 連線。用於網路斷線時的備用方案。)

💡 額外補充：什麼是 Out-of-band (帶外) 與 In-band (帶內)？
  • Out-of-band (帶外)： 不依賴當前網路基礎設施的連線方式 (例如直接插上 Console 線，或是打電話進 AUX port)。即使網路設備尚未設定 IP、或是整個網路癱瘓斷線，你還是能進行管理。
  • In-band (帶內)： 透過現有網路架構進行連線 (例如 SSH、Telnet)。前提是設備已經配置了 IP 位址，且網路是暢通的。

2.1.5 & 2.1.6 終端程式與測驗解析 (Terminal & Quiz)

2.1.5 終端機模擬程式 (Terminal Emulation Programs)

要透過 Console、SSH 或 Telnet 連接設備，我們需要在電腦上安裝終端機模擬程式。影片中列舉了以下幾款常見軟體：

  • PuTTY： 最知名且免費的開源終端機軟體。
  • Tera Term： 另一款老牌、輕量級的開源終端連線軟體。
  • SecureCRT： 功能強大的商業付費終端軟體，適合需要管理大量設備的專業工程師。
2.1.6 模組測驗解析 (Quiz Review)

以下整理了影片中完成的 4 題隨堂測驗，皆附有完整語音發音：

Q1

Which access method would be most appropriate if you were in the equipment room with a new switch that needs to be configured?

Console (主控台) 解析：新設備沒有 IP 位址，無法使用網路連線，必須使用實體 Console 線。
Q2

Which access method would be most appropriate if your manager gave you a special cable and told you to use it to configure the switch?

Console (主控台) 解析：指的就是淺藍色的 Cisco Console 纜線 (Rollover Cable)。
Q3

Which access method would be the most appropriate in-band access to the IOS over a network connection?

Telnet / SSH 解析：影片的選項將這兩者合為一項。實際上，基於安全性，強烈建議只使用 SSH。
Q4

Which access method would be the most appropriate if you call your manager to tell him you cannot access your router in another city over the internet and he provides you with the information to access the router through a telephone connection?

Aux (Auxiliary 輔助埠) 解析：AUX 埠搭配 Modem 數據機，可以透過傳統電話線進行 Out-of-band 管理。
