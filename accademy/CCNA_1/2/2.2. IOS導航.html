1. 命令模式與子組態模式 (Command Modes)

Cisco IOS uses different command modes to establish various privilege levels for users. (Cisco IOS 使用不同的命令模式為使用者建立各種權限等級。)

主要命令模式 (Primary Command Modes)
User EXEC Mode
(使用者 EXEC 模式)
Mode allows access to only a limited number of basic monitoring commands. It is often referred to as "view-only" mode. User EXEC mode has very little privileges. (此模式僅允許存取有限數量的基本監控命令。它通常被稱為「唯讀」模式。權限非常少。)

預設提示字元： Switch> 或 Router>
Privileged EXEC Mode
(特權 EXEC 模式)
Mode allows access to all commands and features. The user can use any monitoring commands and execute configuration and management commands. It offers a higher privilege level. (此模式允許存取所有命令和功能。使用者可以使用任何監控命令並執行設定和管理命令。提供更高的權限層級。)

預設提示字元： Switch# 或 Router#

組態模式與子組態模式 (Configuration and Subconfiguration Modes)
Global Configuration Mode
(全域組態模式)
Used to configure the device globally. Changes made affect the operation of the device as a whole. Must be accessed before other specific configuration modes. (用於對設備進行全域設定。所做的更改會影響設備的整體運作。必須在進入其他特定組態模式前進入此模式。)

提示字元： Switch(config)#
Line Configuration Mode
(線路組態模式)
Used to configure console, SSH, Telnet, or AUX access. (用於設定 console、SSH、Telnet 或 AUX 等連線存取。)

提示字元： Switch(config-line)#
Interface Configuration Mode
(介面組態模式)

2. 模式間的導覽指令 (Navigate Between Modes)

A common mistake made by users new to working with Cisco IOS is trying to use commands from within the wrong mode. Learning to navigate efficiently between the different command modes will save you a lot of time.
(Cisco IOS 新手常犯的錯誤是在錯誤的模式下輸入指令。學會有效率地在不同模式間切換可以節省大量時間。)

進入與返回模式的關鍵指令
  • enable: Moves from user EXEC mode to privileged EXEC mode. (從使用者 EXEC 模式進入特權 EXEC 模式。)
  • disable: Returns to user EXEC mode from privileged EXEC mode. (從特權 EXEC 模式返回使用者 EXEC 模式。)
  • configure terminal: Moves from privileged EXEC mode to global configuration mode. (從特權 EXEC 模式進入全域組態模式。)
  • exit: Exits a subconfiguration mode and returns to global configuration mode, or returns to privileged EXEC mode from global config mode. (Goes one step back). (退出子組態模式並返回全域組態模式，或從全域組態模式返回特權 EXEC 模式。也就是往回退一步。)
  • end (或 Ctrl+Z): Returns directly to privileged EXEC mode from any subconfiguration mode. (無論在哪個子組態模式或全域模式，直接跳回特權 EXEC 模式。)
進入特定子組態模式
  • line console 0: Enters line subconfiguration mode for the console port. (進入 console 0 埠的線路子組態模式。)
  • interface vlan 1 (或 interface FastEthernet 0/1): Enters interface subconfiguration mode. (進入特定介面的子組態模式。)
  • Tip: 直接切換 (Direct switching): You can also move directly from one sub-configuration mode to another. (For example, typing interface vlan 1 while inside Switch(config-line)#). (您可以直接從一個子組態模式切換到另一個，不必先 exit 退回全域模式。)

3. 語法檢查器與實作步驟 (Syntax Checker)

A Note About Syntax Checker Activities: When learning how to modify device configurations, you might want to start in a safe, non-production environment... These are simulation tools, they typically do not have all the functionality of real equipment. (關於語法檢查器活動：這是一個安全的非生產環境模擬工具，通常不具備真實設備的所有功能。請輸入完整的指令才能通過檢查。)

影片實作步驟完整紀錄 (Navigate Between IOS Modes)

請對照以下終端機畫面進行操作：

Switch>enable (Enter privileged EXEC mode)
Switch#disable (Return to user EXEC mode)
Switch>enable (Re-enter privileged EXEC mode)
Switch#configure terminal (Enter global configuration mode)
Switch(config)#exit (Exit global configuration mode)
Switch#configure terminal (Re-enter global configuration mode)
Switch(config)#line console 0 (Enter line subconfig for console 0)
Switch(config-line)#exit (Return to global config mode)
Switch(config)#line vty 0 15 (Enter VTY line subconfig mode)
Switch(config-line)#interface vlan 1 (Switch directly to interface subconfig mode)
Switch(config-if)#line console 0 (Switch directly to console subconfig mode)
Switch(config-line)#end (Return to privileged EXEC mode)
Switch# // You successfully navigated between the various IOS command line modes.

Which IOS mode allows access to all commands and features?

(哪一種 IOS 模式允許存取所有命令和功能？)

Which IOS mode are you in if the Switch(config)# prompt is displayed?

(如果顯示 Switch(config)# 提示字元，您處於哪一種 IOS 模式？)

Which IOS mode are you in if the Switch> prompt is displayed?

(如果顯示 Switch> 提示字元，您處於哪一種 IOS 模式？)
User EXEC mode (使用者 EXEC 模式)
