2.4.1 設備命名 (Device Names)

主機名稱命名原則 (Naming Guidelines)

如果網路中的所有交換器都保留預設名稱 (例如 Switch)，將很難識別特定設備。因此，請務必設定具有描述性的名稱。命名需遵循以下規則：

  • Start with a letter (以字母開頭)
  • Contain no spaces (不包含空格)
  • End with a letter or digit (以字母或數字結尾)
  • Use only letters, digits, and dashes (僅使用字母、數字和破折號)
  • Be less than 64 characters in length (長度少於 64 個字元)
Switch(config)#
hostname
Sw-Floor-1
💡 復原預設名稱：
若要將交換器恢復為預設的名稱 (Switch)，請在全域設定模式下使用 no hostname 指令。

2.4.2 & 2.4.3 設定密碼 (Configure Passwords)

2.4.2 密碼安全指南 (Password Guidelines)

使用弱密碼或容易猜測的密碼是企業最大的安全隱患。選擇密碼時應注意：

長度與複雜度
密碼應大於 8 個字元，並混合使用大小寫字母、數字與特殊符號。
避免重複與猜測
不要在所有設備上使用相同密碼。請勿使用常用詞彙，因為容易被輕易猜中。
2.4.3 實作：設定各層級密碼

網路設備必須透過分層模式來限制未授權存取：

存取通道 (Access Mode) 設定指令 (Configuration Commands)
Console 連線
保護 User EXEC 模式存取 		Switch(config)# line console 0
Switch(config-line)# password cisco
Switch(config-line)# login
Switch(config-line)# end

提供管理員權限 		Switch(config)# enable secret class

2.4.4 & 2.4.5 密碼加密與橫幅訊息 (Encrypt & Banner)

2.4.4 密碼加密 (Encrypt Passwords)

在預設情況下，startup-config 與 running-config 檔案中的密碼是以「明文 (plaintext)」顯示的，這會構成安全威脅。

Switch(config)#
service password-encryption
💡 驗證方式：
設定完成後，可以使用 show running-config 指令來檢視，此時所有的明文密碼都會轉換為加密格式顯示。
2.4.5 每日訊息橫幅 (Banner Messages)

在網路設備上建立橫幅 (Banner) 有助於宣告只有經過授權的人員才能嘗試存取該設備。在法庭程序中，這也是起訴惡意入侵者的重要依據。

Switch(config)#
banner motd
# Authorized Access Only #
The "#" in the command syntax is called the delimiting character. It is entered before and after the message. 指令中的 "#" 稱為分隔字元 (delimiting character)。它必須在訊息的最前方與最後方輸入。只要分隔字元沒有出現在您的訊息本文中，您也可以替換成其他字元 (例如 $ 符號)。

自我檢測：Basic Device Configuration

請試著回答以下來自影片中的 2.4.8 隨堂測驗，點擊卡片即可查看解答！

Q1. 設備命名指令

What is the command to assign the name "Sw-Floor-2" to a switch?

(哪個指令可以將交換器命名為 "Sw-Floor-2"？)
👉 點擊翻開看解答
解答
hostname Sw-Floor-2
解析：在全域設定模式 (Global Configuration mode) 下輸入。
Q2. 特權模式密碼

How is the privileged EXEC mode access secured on a switch?

(如何保護交換器的特權 EXEC 模式存取？)
👉 點擊翻開看解答
解答
enable secret class
解析：使用 enable secret 指令可以設定經過加密處理的高權限密碼，取代較不安全的 enable password。
Q3. 啟用身分驗證

Which command enables password authentication for user EXEC mode access on a switch?

(哪個指令能為 user EXEC 模式啟用密碼身分驗證？)
👉 點擊翻開看解答
解答
login
解析：在 line console 或 line vty 設定檔中，輸入 password 後，必須再輸入 login 才能強制要求使用者登入。
Q4. 加密明文密碼

Which command encrypts all plaintext passwords access on a switch?

(哪個指令可對交換器上所有明文密碼進行加密？)
👉 點擊翻開看解答
解答
service password-encryption
解析：這可以防止有人透過 show running-config 窺探設定檔中的密碼。
Q5. 設定橫幅訊息

Which is the command to configure a banner to be displayed when connecting to a switch?

(當連接到交換器時，用於配置顯示橫幅訊息的指令為何？)
👉 點擊翻開看解答
解答
banner motd $ Keep out $
解析：此處使用 "$" 作為分隔字元包夾訊息內容。
