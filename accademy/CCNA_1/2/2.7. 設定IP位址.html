2.6.1 IP Addresses (IP 位址)

The Role of IP Addresses (IP 位址的作用)

The use of IP addresses is the primary means of enabling devices to locate one another and establish end-to-end communication on the internet. Each end device on a network must be configured with an IP address.
(使用 IP 位址是讓設備能夠在網際網路上互相定位，並建立端到端通訊的主要方式。網路上每個終端設備都必須設定 IP 位址。)

  • Computers (work stations, laptops, file servers, web servers) (電腦：工作站、筆記型電腦、檔案伺服器、網頁伺服器)
  • Network printers (網路印表機)
  • VoIP phones (VoIP 網路電話)
  • Security cameras (安全監控攝影機)
  • Smart phones (智慧型手機)
  • Mobile handheld devices (such as wireless barcode scanners) (行動手持設備，例如無線條碼掃描器)
IPv4 Address Structure
The structure of an IPv4 address is called dotted decimal notation and is represented by four decimal numbers between 0 and 255. IPv4 位址的結構稱為「點分十進位表示法」，由四個介於 0 到 255 之間的十進位數字組成。(例如：192.168.1.10)
IPv6 Address Structure
IPv6 addresses are 128 bits in length and written as a string of hexadecimal values separated by a colon (:). IPv6 位址長度為 128 位元，並寫成由冒號 (:) 分隔的十六進位字串。(例如：2001:db8:acad:10::10)
💡 重要配置參數 (IPv4)：
• Subnet mask (子網路遮罩): A 32-bit value that differentiates the network portion of the address from the host portion. (一個 32 位元的值，用來區分位址中的網路部分與主機部分。)
• Default gateway (預設閘道): The IP address of the router that the host will use to access remote networks, including the internet. (主機用來存取遠端網路 (包含網際網路) 的路由器 IP 位址。)

2.6.2 Interfaces and Ports (介面與連接埠)

Network Media Types (網路媒介類型)

網路通訊依賴終端設備介面、網路設備介面以及連接它們的線材。常見的網路媒介包含：Copper (銅線)、Fiber-optics (光纖) 以及 Wireless (無線)。不同的媒介有不同的特性，選擇時需考慮以下差異：

考量因素 (Factors) 說明 (Description)
Distance The distance the media can successfully carry a signal. (媒介能成功傳輸訊號的距離。)
Environment The environment in which the media is to be installed. (安裝媒介的環境條件，如干擾、戶外/室內等。)
Amount of data / Speed Amount of data and the speed at which it must be transmitted. (需要傳輸的資料量以及傳輸速度。)
Cost Cost of the media and installation. (線材及安裝的成本。)

Switch Virtual Interfaces (SVI 虛擬交換介面)

關於 Layer 2 Switches (第二層交換器) 的介面特性：

  • 實體埠不支援 IP： Cisco IOS Layer 2 switches have physical ports for devices to connect. These ports do not support Layer 3 IP addresses. (Cisco IOS Layer 2 交換器的實體連接埠是用來連接設備的，這些連接埠不支援 Layer 3 的 IP 位址。)
  • SVI 的作用： Therefore, switches have one or more switch virtual interfaces (SVIs). These are virtual interfaces because there is no physical hardware on the device associated with it. An SVI is created in software. (因此，交換器擁有一個或多個 SVI。因為沒有對應的實體硬體，它們被稱為「虛擬」介面，SVI 是在軟體中建立的。)
  • 遠端管理： The virtual interface lets you remotely manage a switch over a network using IPv4 and IPv6. Each switch comes with one SVI appearing in the default configuration "out-of-the-box". The default SVI is interface VLAN1. (虛擬介面讓你可以透過網路使用 IPv4 和 IPv6 遠端管理交換器。每台交換器出廠時預設設定中就有一個 SVI，預設的 SVI 是介面 VLAN1。)
