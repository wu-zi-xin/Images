2.3.1 基本指令結構 (Basic IOS Command Structure)

Cisco IOS 指令的基本格式

Cisco IOS 支援許多指令。每個 IOS 指令都有特定的格式或語法 (Syntax)，並且只能在適當的模式下執行。通用語法如圖所示，包含：提示字元、指令、空格、關鍵字或參數。

Prompt
Command
Space
Keyword or Argument
Switch>
ping
192.168.10.5
Keyword (關鍵字)
This is a specific parameter defined in the operating system. (e.g., ip protocols) 在作業系統中預先定義的特定參數。(例如 show "ip protocols")
Argument (參數/引數)
This is not predefined; it is a value or variable defined by the user. (e.g., 192.168.10.5) 這不是預先定義的；它是使用者自行定義的值或變數。(例如 ping "192.168.10.5")
💡 執行指令：
輸入完整指令（包括任何關鍵字和參數）後，請按 Enter 鍵將指令提交給命令直譯器 (command interpreter)。

2.3.3 IOS Help Features (幫助與語法檢查)

Cisco IOS 提供了非常實用的幫助功能與語法錯誤提示：

  • Context-sensitive help (上下文敏感幫助)： 在 CLI 中輸入問號 ?，系統會列出當前模式下可用的指令，或是列出該指令後方可接續的關鍵字/參數。
  • Command syntax check (指令語法檢查)： 當輸入指令並按下 Enter 時，CLI 會由左至右評估指令。如果系統無法理解，會提供反饋說明：

    % Ambiguous command: "x" 不明確的指令。代表你輸入的字元太少，系統無法辨識出唯一的指令 (例如只打 'c'，可能是 clock 也可能是 configure)。
    % Incomplete command. 不完整的指令。代表你需要提供更多關鍵字或參數才能執行該指令 (例如只打 'clock set')。
    % Invalid input detected at '^' marker. 偵測到無效輸入。'^' 符號會指向系統開始無法辨識的地方，通常是因為拼寫錯誤。

2.3.5 快捷鍵與捷徑 (Hot Keys and Shortcuts)

指令縮寫 (Command Shortening)

在 IOS 中，只要輸入的字元足以與其他指令區分開來（具有唯一性），就可以使用指令和關鍵字的「縮寫」。

💡 例如：
configure 可以縮寫為 conf (因為它是唯一以 conf 開頭的指令)。
但 con 無法作用，因為還有 connect 等其他指令，系統會回應 % Ambiguous command。
常用快捷鍵與按鍵對應
按鍵 (Keystroke) 說明 (Description)
Tab Completes a partial command name entry. (自動補齊輸入了一部分的指令或關鍵字名稱。)
Ctrl-A Moves the cursor to the beginning of the line. (將游標移到行首。)
Ctrl-E Moves the cursor to the end of command line. (將游標移到行尾。)
Up Arrow (↑) / Ctrl-P Recalls the previous command in the history buffer. (呼叫出歷史紀錄中上一個輸入的指令。)
Ctrl-C When in any configuration mode, ends the configuration mode and returns to privileged EXEC mode. (在任何設定模式下，結束設定模式並退回到「特權 EXEC 模式」。)
Ctrl-Z Similar to Ctrl-C. Returns to privileged EXEC mode. (功能類似 Ctrl-C，直接退回到「特權 EXEC 模式」。)
Ctrl-Shift-6 All-purpose break sequence used to abort DNS lookups, traceroutes, pings, etc. (中斷序列快捷鍵。用來強制中止進行中的 DNS 查詢、ping 或 traceroute。)
Tab

Ctrl-A / Ctrl-E
Ctrl-A 移至行首；Ctrl-E 移至行尾。

💡 終端機顯示 "--More--" 時的按鍵：
當系統輸出的內容超過一個畫面時，底部會顯示 --More--：
• 按 Enter 鍵：顯示下一行 (Next line)。
• 按 Space (空白鍵)：顯示下一頁 (Next screen)。

自我檢測：The Command Structure (翻轉卡片)

請試著回答以下問題，點擊卡片即可查看解答！

Q1. 自動補齊指令

Which keystroke completes a partial command name entry?

(哪一個快捷鍵可以自動補齊輸入了一部分的指令？)
👉 點擊翻開看解答
解答
Tab 鍵
解析：只要輸入的字元具有唯一性，按下 Tab 鍵 IOS 就會幫你把單字拼完。
Q2. 求助功能

What character is used to access context-sensitive help in the Cisco IOS CLI?

(在 Cisco IOS CLI 中，使用什麼字元可以呼叫上下文敏感的幫助功能？)
👉 點擊翻開看解答
解答
? (問號)
解析：輸入 ? 可以列出當前模式下可用的所有指令，或該指令後續可接的參數。
Q3. 錯誤訊息判讀

If you enter only the letter "c" at the prompt and press Enter, what error message will the router display?

(如果你在提示字元下只輸入字母 "c" 並按 Enter，路由器會顯示什麼錯誤訊息？)
👉 點擊翻開看解答
解答
% Ambiguous command: "c"
解析：因為以 'c' 開頭的指令有很多 (如 configure, clock, connect)，系統覺得指令「不明確 (Ambiguous)」。
Q4. 強制中斷

You typed a wrong command and the router is stuck doing a DNS lookup. Which key combination should you press to abort the lookup?

(你打錯了指令導致路由器卡在 DNS 查詢。你應該按下哪一組快捷鍵來中斷查詢？)
👉 點擊翻開看解答
解答
Ctrl-Shift-6
解析：Ctrl-Shift-6 是一個萬用的中斷序列 (all-purpose break sequence)，用於中止 ping、traceroute 或錯誤的 DNS 查詢。
