網路表示方式和拓樸
Network Representations and Topologies

這段課程在教你如何「看懂網路圖」。先認識 Cisco 常用的網路符號：終端裝置、中介設備、網路媒體；接著分清實體拓樸圖與邏輯拓樸圖。這是之後看 Packet Tracer、排錯、讀交換器與路由器介面的基礎。

自製重點圖中英術語白話解說拓樸讀圖互動測驗

1. 本段在學什麼？

網路工程師會用標準化圖示與拓樸圖來描述網路。你要學會的是：看到圖，就能快速知道有哪些設備、怎麼連、在哪裡，以及邏輯上怎麼通訊。

辨識設備角色哪些是使用者直接操作的終端裝置？哪些是幫忙轉送流量的交換器、路由器與防火牆？
辨識連線媒體連線可能是無線、區域網路有線媒體，或跨站點的廣域網路媒體。
讀懂拓樸實體拓樸描述「位置與佈線」；邏輯拓樸描述「網段、介面與資料路徑」。

2. 1.3.1 網路表示方式（Network Representations）

這一節把網路圖常見元素整理成三類。重點不是背圖案，而是先判斷每個物件在網路中的角色。

自製精簡示意圖：用角色分類理解網路圖，不直接使用影片的大型截圖。
白話理解：把網路想成城市交通。終端裝置像「出發地與目的地」；中介設備像「路口、交流道、收費站」；網路媒體就是「道路本身」。封包要從一台主機到另一台主機，三者缺一不可。

3. 三大元素：終端裝置、中介設備、網路媒體

終端裝置（End Devices）影片圖示包含：桌上型電腦（Desktop Computer）、膝上型電腦（Laptop）、印表機（Printer）、IP 電話機（IP Phone）、無線平板電腦（Wireless Tablet）、視訊會議終端（Video Conferencing Endpoint）。

重點 通常是資料的來源或目的地。
中介設備（Intermediary Devices）影片圖示包含：無線路由器（Wireless Router）、LAN 交換器（LAN Switch）、路由器（Router）、多層交換器（Multilayer Switch）、防火牆設備（Firewall Appliance）。

重點 負責連接、轉送、選路、過濾或保護流量。
網路媒體（Network Media）影片分成：無線介質（Wireless Media）、區域網路媒體（LAN Media）、廣域網路媒體（WAN Media）。

重點 是訊號實際傳遞的通道。

4. 1.3.2 拓樸圖（Topology Diagrams）

拓樸圖是網路文件裡最重要的視覺工具之一。這裡把拓樸圖整理成兩個最重要的觀念：Physical Topology Diagrams 與 Logical Topology Diagrams。

自製比較圖：Physical 看「實際世界」；Logical 看「通訊關係」。

5. Physical vs Logical：最常考的差異

實體拓樸圖（Physical Topology Diagram）

回答：設備實際在哪裡？線實際怎麼拉？

常見資訊：建築物、樓層、房間、機櫃、配線間、設備擺放位置、實際纜線走向。

例：要派工程師去換 S3 交換器，Physical Topology 能協助找它實際的位置。

邏輯拓樸圖（Logical Topology Diagram）

回答：哪些設備邏輯上相連？使用哪些網段與介面？資料可能怎麼走？

常見資訊：IPv4/IPv6 網段、路由器與交換器介面名稱、邏輯連線與資料路徑。

例：要查 192.168.100.0 網段的通訊問題，Logical Topology 能協助追介面與上游路徑。

6. 如何讀一張 CCNA 拓樸圖？

建議固定用同一套順序。

  1. 先找 Internet / Cloud：確認外部網路在哪一側。
  2. 找 Router：通常是不同 IP 網路之間的邊界。
  3. 找 Switch：確認哪些端點接到同一台交換器。
  4. 看網段：例如 192.168.10.0 與 192.168.100.0。
  5. 看介面標籤：例如 G0/0、G0/1、Fa0/1。
  6. 最後追路徑：從來源沿線走到目的地。
來源主機 → Access Switch → Router / L3 Device → 其他網段 → Destination Host 讀圖時問自己： 1. Source / Destination 在哪？ 2. 是否跨網段？ 3. 若跨網段，預設閘道在哪？ 4. 中間經過哪些介面？ 5. Physical 問「位置」，Logical 問「通訊關係」。

8. CCNA 延伸重點

① G0/0、G0/1 是什麼？

G/Gi 常用來代表 GigabitEthernet；Fa 代表 FastEthernet。後面的數字是介面編號。不同 Cisco 平台命名格式可能不同。

② 一張圖可以同時有 Physical 與 Logical 資訊嗎？

實務文件可能混合呈現。考題若問分類，看到房間、樓層、機櫃，多半是 Physical；看到 IP 網段、介面、資料路徑，多半是 Logical。

③ 為什麼要畫拓樸圖？

建置、維護、擴充與故障排除都需要。沒有拓樸文件，大型網路很難快速定位設備與流量路徑。

④ 拓樸不等於拓樸型態

Topology 是廣義的排列與連線關係；Star、Bus、Ring、Mesh 是常見拓樸型態。這段影片主要先教你如何表示與閱讀網路。

9. 課後考題

共 10 題。作答後按「批改並看解析」。

1. 下列哪一個最符合「終端裝置（End Device）」？

解析：Laptop 是端點；其餘都是中介設備。

2. 哪一項屬於網路媒體（Network Media）？

解析：無線介質是承載訊號的媒體。

3. 要找某台交換器實際位於哪個房間，最應查看哪一種圖？

解析：實體拓樸看設備位置與佈線。

4. 哪個資訊最典型地出現在邏輯拓樸圖？

解析：網段與介面是典型 Logical 資訊。

5. Router 在拓樸圖裡通常代表什麼角色？

解析：路由器的核心工作是跨網路轉送 IP 封包。

6. 「Fa0/1」中的 Fa 通常代表？

解析：Fa = FastEthernet；G/Gi 常用於 GigabitEthernet。

7. 下列何者屬於影片列出的中介設備？

解析：多層交換器是中介設備。

8. 若你要追查「某網段的封包會經過哪些介面」，哪種圖最有幫助？

解析：邏輯拓樸會呈現網段、介面與邏輯連線。

9. 下列哪個敘述正確？

解析：Logical 重點是網段、介面、邏輯連線與資料路徑。

10. 最好的讀圖順序是哪一個？

解析：固定順序能快速建立整體架構，再追資料路徑。
