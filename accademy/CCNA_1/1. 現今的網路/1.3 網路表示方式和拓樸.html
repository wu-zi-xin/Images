CCNA MODULE 1 · 1.3 NETWORK REPRESENTATIONS AND TOPOLOGIES

網路表示方式和拓樸
Network Representations and Topologies

這支影片在訓練你「看懂網路圖」。你需要先認得終端裝置、中介設備與網路媒體的符號，再分清楚 實體拓樸 與 邏輯拓樸：一個回答設備實際在哪裡，另一個回答網路在邏輯上怎麼連、用哪些介面與定址。

1. 本段在學什麼？

影片可清楚分成兩段：1.3.1 網路表示方式與1.3.2 拓樸圖。

Symbols｜符號用一致圖示代表網路元件，不需要畫成真實照片。
End vs Intermediary先分清「使用網路的裝置」與「幫忙轉送的設備」。
Physical Topology看真實位置、房間、機架與實際線路。
Logical Topology看介面、網路位址、裝置間的邏輯連線。
影片內容
影片指出網路架構設計人員與系統管理員必須能夠顯示網路外觀，並能快速看出哪些元件彼此連接、位於哪裡、使用何種連接方式；網路圖通常用符號來表示裝置與連線。

2. 1.3.1 網路表示方式｜Network Representations

網路圖把複雜環境縮成一套可讀的「視覺語言」。影片畫面把符號分成三大群：終端裝置、中介設備、網路媒體。

教材圖解｜依影片出現的圖示分類重新繪製。手機上保持足夠寬度，可左右滑動閱讀。
圖解怎麼讀：
  • 藍色區：終端裝置（End Devices）代表使用者真正產生或接收資料的端點，例如電腦、印表機、IP 電話。
  • 橘色區：中介設備（Intermediary Devices）位於端點之間，負責連接、轉送、控制或保護流量，例如 Switch、Router、Firewall。
  • 綠色區：網路媒體（Network Media）代表訊號傳遞的路徑；影片以不同線型區分無線、LAN 與 WAN 媒體。
終端裝置｜End Device 影片示例：桌上型電腦、膝上型電腦、印表機、IP 電話機、無線平板電腦、視訊會議終端。
中介設備｜Intermediary Device 影片示例：無線路由器、LAN 交換器、路由器、多層交換器、防火牆設備。
網路媒體｜Network Media 影片圖示包含無線介質、區域網路媒體、廣域網路媒體。
考試觀念：看到 PC、Printer、IP Phone，多半先想到 End Device；看到 Switch、Router、Firewall，多半先想到 Intermediary Device。

3. NIC、實體埠、介面：三個術語怎麼分？

影片內容
影片在圖示說明後補充三個專業術語：網路介面卡（NIC）、實體埠（Physical Port）與介面（Interface），並提醒術語「連接埠」與「介面」在實務上有時會互換使用。
教材圖解｜從硬體「卡」→ 實體「孔」→ 系統邏輯「介面」的視角拆解。
  • NIC｜Network Interface Card ：終端裝置實際連接到網路的介面卡。
  • Physical Port ：網路設備上的實體介面或插座，網路媒體從這裡接入。
  • Interface ：常指網路設備上面向某個網路的連接點；在 Cisco 設定中常看到 GigabitEthernet、FastEthernet 等介面名稱。
易混淆：這裡的「Port」是實體連接埠，不是 TCP/UDP 的 Port Number。後者是傳輸層的邏輯編號，例如 TCP 443。

4. 1.3.2 拓樸圖｜Topology Diagrams

影片定義：拓樸圖是任何使用網路的人都必須理解的文件，它提供網路連線方式的視覺圖。影片接著分成兩種類型：實體（Physical）與邏輯（Logical）。

Physical｜實體

看「東西在哪裡、線怎麼裝」。重點是設備與纜線的實際位置。

Logical｜邏輯

看「誰跟誰連、介面叫什麼、屬於哪個網路」。重點是連線與定址關係。

5. 實體拓樸圖｜Physical Topology Diagram

影片內容
影片指出：實體拓樸圖（Physical Topology Diagram）主要描述中介裝置、終端設備與纜線實際安裝的位置。讀這類圖時，最重要的是先回答：設備在哪個房間？哪些設備實際接在一起？纜線實際延伸到哪個空間？
自製簡化圖：重點是「地點與安裝位置」，不是重畫影片每一個細節。圖中用房間、設備與實際連線，讓你一眼判斷 Physical Topology 在回答什麼。
圖中怎麼讀：
  • 伺服器房 Rm 2158：Web Server、Mail Server、File Server 與 S1 都被畫在同一個實體空間，表示這些設備實際位於同一房間。
  • R1：位於伺服器房與線路間之間的主要連接點。黑色實線只表示實體連線存在，不是單向資料流箭頭。
  • 線路間 Rm 2124：S3、S4、S5 集中在同一個房間，並分別連往三間教室。這就是典型的「設備安裝位置＋實際線路」資訊。
  • 教室 1～3：Rm 2125、2126、2127 是不同實體位置；各教室終端實際連回對應的交換器。
  • IT 辦公室 Rm 2159：S2 被標示在另一個實體房間，讓你看到 Physical Topology 不只描述「誰跟誰連」，還要記錄「設備究竟放在哪裡」。
Physical Location｜實體位置房號、機房、教室、辦公室、機架位置，都屬於 Physical Topology 的核心資訊。
Physical Link｜實體連線線條表示設備之間有實體纜線連接；重點是「線接到哪裡」，而不是封包的單向流向。
Exam Clue｜考題線索題目若出現 room、rack、floor、installed、cable location，通常就是在考 Physical Topology。
CCNA 易錯提醒：不要把實體拓樸圖看成 IP 圖。它主要回答的是設備在哪裡、怎麼安裝、實際線路怎麼接；IP 網段、介面名稱、定址方案則更偏向 Logical Topology。

6. 邏輯拓樸圖｜Logical Topology Diagram

影片內容
影片指出：邏輯拓樸圖會顯示設備、連接埠和網路的定址方案；你能看出哪些終端裝置連到哪些中介裝置，以及正在使用哪些媒體。影片示例標示 R1 的 G0/0、G0/1、G1/0、G1/1、G1/2，以及多個 192.168.x.0 網路。
教材圖解｜依影片邏輯拓樸的核心資訊重新繪製：網段、介面、交換器、端點與 Internet 的關係。
圖中的資訊層次：
  • 黃色網路區域：每一塊代表一個邏輯網路／網段，而不是房間。
  • R1 的 G0/1、G1/0、G1/1、G1/2：表示路由器用不同介面連往不同網路。
  • 交換器的 Fa0/1 等標記：讓你能追蹤端點從哪個交換器埠進入。
  • Internet 雲：表示 R1 還有一條面向外部網路的連線。

8. 額外補充｜把影片觀念接到 CCNA 實戰

額外補充
拓樸圖不是只有上課看圖用。在實務故障排除中，最有效的方式常是兩張一起用：先看 Physical 找到「哪個房間、哪台設備、哪條線」，再看 Logical 找到「哪個介面、哪個網段、上游是誰」。
補充 1｜Port 的兩種意思

Physical Port ：硬體插孔，例如交換器 Ethernet 埠。

Port Number ：TCP/UDP 的邏輯編號，例如 HTTPS 常用 TCP 443。兩者不可混為一談。

補充 2｜介面名稱是排錯關鍵

看到 G0/1、G1/0、Fa0/1 時，要知道它們是介面標識。CCNA 後續指令如 show ip interface brief、show interfaces 都會依賴這些名稱。

補充但不要過度延伸：本影片沒有在講 Bus、Ring、Star、Mesh 這些「拓樸型態」。它此處的重點是拓樸圖文件的兩種視角：Physical 與 Logical。

11. 課後複習測驗｜16 題

選一個答案後，該題會立刻顯示正誤、正確答案、解析、其他選項錯在哪裡，以及對應課程觀念。

1. 網路圖（Network Diagram）最主要的價值是什麼？

正確答案：B. 用一致符號快速呈現裝置與連線關係

詳細解析：影片指出網路架構設計人員與系統管理員需要能夠顯示網路外觀，網路圖使用符號表示裝置與連線，協助視覺化網路組織與運作。

其他選項為什麼不對：

  • A：真實照片不是網路圖的必要形式。
  • C：IP 可以出現在邏輯圖，但不是所有網路圖唯一內容。
  • D：價格不是拓樸圖的核心用途。

對應課程觀念：1.3.1 網路表示方式

2. 下列哪一項屬於終端裝置（End Device）？

正確答案：C. IP 電話機

詳細解析：影片圖示把桌上型電腦、膝上型電腦、印表機、IP 電話機、無線平板電腦、視訊會議終端列為終端裝置。

其他選項為什麼不對：

  • A：LAN 交換器是中介設備。
  • B：路由器是中介設備。
  • D：防火牆設備列在中介設備類別。

對應課程觀念：終端裝置 vs 中介設備

3. 下列哪一項屬於中介設備（Intermediary Device）？

正確答案：C. LAN 交換器

詳細解析：影片將無線路由器、LAN 交換器、路由器、多層交換器與防火牆設備列為中介設備。

其他選項為什麼不對：

  • A：膝上型電腦是終端裝置。
  • B：印表機是終端裝置。
  • D：無線平板電腦是終端裝置。

對應課程觀念：中介設備

4. 影片的網路媒體符號分類包含哪些？

正確答案：A. 無線介質、區域網路媒體、廣域網路媒體

詳細解析：畫面直接列出三種表示：無線介質、區域網路媒體、廣域網路媒體。

其他選項為什麼不對：

  • B：這些是一般裝置連接介面，不是影片的網路媒體符號分類。
  • C：這些是電腦元件。
  • D：這些是網路協定或服務。

對應課程觀念：網路媒體符號

5. NIC 的全名與角色何者正確？

正確答案：A. Network Interface Card；終端裝置實際連線到網路的介面卡

詳細解析：影片定義網路介面卡（NIC）是終端裝置實際連線到網路的元件。

其他選項為什麼不對：

  • B：名稱與用途皆不正確。
  • C：NIC 不是 IP 位址代碼。
  • D：NIC 不是雲端網路。

對應課程觀念：NIC

6. 「實體埠（Physical Port）」最精確的描述是？

正確答案：A. 設備上的介面或插座，媒體透過它連到主機或其他設備

詳細解析：影片將實體埠描述為網路設備上的介面或插座，網路媒體透過它連接到終端主機或其他網路設備。

其他選項為什麼不對：

  • B：TCP/UDP port 是傳輸層概念，與此處的實體埠不同。
  • C：VLAN ID 不是實體插座。
  • D：鄰居 ID 不是硬體連接點。

對應課程觀念：Physical Port

7. 影片對「介面（Interface）」的描述，最接近下列何者？

正確答案：A. 路由器上連接到個別網路的專用埠／連接點

詳細解析：影片說明網路設備上連接到個別網路的專用埠，由於路由器連接網路，因此路由器上的連接埠常稱為網路介面。

其他選項為什麼不對：

  • B：USB 不等於網路介面。
  • C：管理 IP 是位址設定，不是介面的定義。
  • D：SSID 不是介面。

對應課程觀念：Interface

8. 實體拓樸圖（Physical Topology Diagram）主要顯示什麼？

正確答案：A. 設備與纜線安裝的實際位置

詳細解析：影片明確說實體拓樸圖說明中介裝置和纜線安裝的實體位置，並可看出設備所在房間。

其他選項為什麼不對：

  • B：TCP 狀態不是實體拓樸圖的主題。
  • C：DNS 流程不是這類圖的主題。
  • D：VLAN 編號偏邏輯資訊。

對應課程觀念：Physical Topology

9. 邏輯拓樸圖（Logical Topology Diagram）主要顯示什麼？

正確答案：A. 設備、連接埠、編址方案與使用的媒體

詳細解析：影片指出邏輯拓樸圖說明設備、連接埠和網路的定址方案，並讓你看出終端裝置連到哪些中介裝置以及使用哪些媒體。

其他選項為什麼不對：

  • B：採購日期不屬於邏輯拓樸。
  • C：冷氣屬設施資訊，不是邏輯網路關係。
  • D：桌椅配置不是網路邏輯。

對應課程觀念：Logical Topology

10. 工程師想確認 S3 實際裝在哪個房間與哪個機架，最該看哪種圖？

正確答案：B. 實體拓樸圖

詳細解析：房間與機架是設備的實際安裝位置，因此應查實體拓樸圖。

其他選項為什麼不對：

  • A：邏輯圖著重網路、介面、位址與連線關係。
  • C：ARP 表對應 IP 與 MAC。
  • D：路由表描述目的網路與下一跳。

對應課程觀念：Physical vs Logical

11. 工程師想確認 R1 的 G1/1 連到哪個網段，最該看哪種圖？

正確答案：B. 邏輯拓樸圖

詳細解析：介面名稱與網路定址方案屬邏輯拓樸圖資訊。

其他選項為什麼不對：

  • A：實體圖可能顯示線路位置，但不以介面與 IP 網段為核心。
  • C：採購清單不是網路連線文件。
  • D：門禁紀錄與網路邏輯無關。

對應課程觀念：Physical vs Logical

12. 影片中的邏輯拓樸示例，192.168.100.0、192.168.101.0、192.168.102.0 最主要代表什麼？

正確答案：A. 不同的邏輯網路／網段

詳細解析：邏輯拓樸圖把不同裝置群組標示為不同的 IP 網路，這就是定址方案的視覺化。

其他選項為什麼不對：

  • B：房間號碼出現在實體拓樸圖。
  • C：不是序號。
  • D：不是線長。

對應課程觀念：Logical Addressing

13. 下列何者最容易混淆，但在 CCNA 必須分清楚？

正確答案：B. Physical Port 是設備插座；TCP/UDP Port Number 是傳輸層用來辨識應用程式／服務的邏輯號碼

詳細解析：本影片的 port 指的是實體連接埠。CCNA 其他章節還會遇到 TCP/UDP port number，兩者完全不同。

其他選項為什麼不對：

  • A：兩者層次與用途不同。
  • C：兩者並非只存在路由器。
  • D：兩者並非只存在伺服器。

對應課程觀念：額外補充：Port 名詞辨識

14. 哪個敘述最符合『拓樸圖是網路的地圖』？

正確答案：B. 實體圖像建築平面配置；邏輯圖像交通路線與地址關係，各自回答不同問題

詳細解析：把實體拓樸想成『設備住哪裡』，邏輯拓樸想成『誰透過哪條路與哪個地址互通』，是最有效的記憶方式。

其他選項為什麼不對：

  • A：拓樸圖的技術準確性最重要。
  • C：連線是網路圖核心資訊之一。
  • D：邏輯圖常需要介面名稱。

對應課程觀念：Physical vs Logical

15. 發生『某教室斷線』時，第一輪文件交叉檢查的最佳做法是？

正確答案：B. 先用實體圖定位房間、設備與線路，再用邏輯圖確認介面、網段與上游關係

詳細解析：實體與邏輯拓樸圖互補：前者協助找設備與線，後者協助追介面與網路關係。

其他選項為什麼不對：

  • A：只看一種圖可能缺少另一半資訊。
  • C：全面換設備不是合理第一步。
  • D：重開機可能有用，但不是文件化故障定位方法。
