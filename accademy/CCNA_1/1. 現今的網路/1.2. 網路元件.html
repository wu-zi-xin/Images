CCNA MODULE 1 · 1.2

網路元件
Network Components

影片依序介紹主機在網路中的角色、對等式連線、終端裝置、中介設備，以及承載資料的網路媒體。核心概念是：資料由端點產生與接收，中介設備負責轉送，而媒體提供實際的傳輸路徑。

影片重點整理中英術語白話解說裝置分類互動測驗

1. 本段在學什麼？

把一個網路拆開看，可以先分成三大部分：終端裝置、中介設備、網路媒體。影片再從主機角色與對等式連線補充端點之間如何提供與使用服務。

終端裝置 End Devices使用者直接操作或提供服務的裝置，是資料的來源或目的地，例如電腦、手機、印表機與伺服器。
中介設備 Intermediary Devices位在端點之間，連接不同裝置或網路並協助資料轉送，例如交換器、路由器與無線網路設備。
網路媒體 Network Media資料必須透過某種媒體傳送，包括銅纜、光纖與無線訊號。

2. 1.2.1 主機角色｜Host Roles

影片先用「用戶端 ↔ 網路 ↔ 伺服器」的圖示說明主機可依所扮演的服務角色分類。

用戶端 Client向其他主機提出服務請求。常見情境是使用瀏覽器讀取 Web 內容、收發電子郵件或存取共享資源。
伺服器 Server提供資料或服務給其他主機。伺服器通常持續等待用戶端提出請求，再回傳相對應的內容。
記法：Client「請求」服務，Server「提供」服務。兩者都是主機，只是角色不同。

3. 1.2.2 對等式｜Peer-to-Peer

影片以兩台直接分享資源的電腦說明對等式網路：同一台主機可以同時扮演用戶端與伺服器，不一定需要獨立的專用伺服器。

每台主機都可分享例如分享檔案、印表機或其他本機資源，同時也能存取另一台主機提供的資源。
適合規模較小的情境架構簡單、建置容易，但當使用者與資源增加時，集中管理與安全控管會變得較困難。
容易混淆：Peer-to-Peer 描述的是主機提供服務的方式；它不是「沒有網路設備」的意思，也不代表完全不需要網路媒體。

4. 1.2.3 終端裝置｜End Devices

終端裝置位在資料傳輸的兩端。影片的拓樸圖把 LAN 內的電腦、伺服器、電話與印表機等放在端點位置，並與中間的網路設備做區分。

資料來源終端裝置可以建立並送出資料，例如使用者從電腦傳送訊息。
資料目的地終端裝置也可以接收資料，例如伺服器接收請求或印表機接收列印工作。
使用者介面多數終端裝置是人與網路互動的入口，讓使用者實際使用網路服務。
判斷技巧：看到一個裝置時先問「它是在產生／接收使用者資料，還是在中間幫忙轉送？」前者通常就是 End Device。

5. 1.2.4 中介設備｜Intermediary Devices

中介設備位在終端裝置之間。影片展示多種常見圖示，重點不是背圖案，而是理解它們負責連接、轉送與控制網路流量。

Switch｜交換器主要用來連接區域網路中的多個裝置，並在 LAN 內轉送資料。
Router｜路由器負責連接不同網路，協助封包在不同網路之間找到下一段路徑。
Wireless Device｜無線設備讓終端裝置透過無線訊號加入網路，再與有線網路或其他網路設備連接。

6. 1.2.5 網路媒體｜Network Media

影片最後介紹承載訊號的媒體，畫面分成銅纜、光纖與無線三類。不同媒體使用不同方式傳遞資料。

銅纜 Copper以電訊號傳送資料，常見於區域網路的乙太網路連接。
光纖 Fiber-Optic以光脈衝傳送資料，適合高速率與較長距離的連線。
無線 Wireless透過電磁波在空間中傳送訊號，讓裝置不必依賴實體纜線連接。
1
端點產生資料
來源裝置建立要傳送的資料。
2
中介設備轉送
交換器或路由器依網路資訊轉送。
3
媒體承載訊號
電、光或無線訊號承載資料。
4
目的端接收
另一個終端裝置收到資料。

8. 課後考題｜Quiz

先作答，再按批改。題目針對影片中的元件分類與角色觀念。

Q1. 在 Client / Server 模型中，Client 的主要角色是？

答案 B。Client 是提出服務請求的一方。

Q2. Peer-to-Peer 網路的特徵是？

答案 C。同一台主機可以同時扮演 Client 與 Server。

Q3. 下列哪個最符合「終端裝置」？

答案 A。電腦是資料來源或目的地，因此屬於 End Device。

Q4. 下列哪一個屬於中介設備？

答案 D。Router 位在端點之間，負責連接與轉送。

Q5. 光纖主要利用什麼方式承載資料？

答案 C。Fiber-Optic Cable 透過光來傳輸資料。

Q6. 哪一組最完整地描述影片中的網路元件分類？

答案 B。這三類能幫助你快速判斷各種網路元素扮演的功能。
