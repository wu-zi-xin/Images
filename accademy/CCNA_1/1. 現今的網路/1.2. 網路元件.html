1. 本段在學什麼？

先把整支影片濃縮成一張心智圖：網路中的裝置不是只有「電腦、交換器、路由器」而已，更重要的是理解它們在通訊流程中的角色。

Host｜主機直接參與網路通訊的裝置；可以扮演 Client 或 Server。
End Device｜終端裝置資料的來源或目的地；每個終端裝置都需要可識別的位址。
Intermediary Device｜中介設備在來源與目的地之間協助連接、轉送、選路、過濾。
Network Media｜網路媒體資料真正「走過去」的通道：銅纜、光纖、無線。
影片內容
影片依序介紹 1.2.1 主機角色、1.2.2 對等、1.2.3 終端裝置、1.2.4 中介設備、1.2.5 網路媒體，並以最後的小測驗確認你能辨認中介設備。
一口氣記住：終端裝置是「人與應用程式接觸資料的地方」；中介設備是「資料途中經過的設備」；媒體是「訊號真正行進的物理／無線通道」。

2. 1.2.1 主機角色｜Host Roles

影片內容 影片先建立主機、用戶端與伺服器的角色觀念。

主機 Host 所有直接連接到網路並直接參與網路通訊的裝置，都可稱為主機。影片也指出「主機」有時會被稱為終端裝置。
用戶端 Client 執行用戶端軟體，向伺服器提出要求，並把伺服器回傳的資訊呈現給使用者。Web Browser 是典型例子。
伺服器 Server 安裝特定伺服器軟體，向其他主機提供服務，例如電子郵件、Web 或檔案服務。
資訊圖：Client 先送出 Request，Server 提供對應服務後回傳 Response；中間的網路只負責把資料送達。
圖解逐區說明
  • 左側 Client：代表瀏覽器、郵件用戶端等程式，主動要求內容。
  • 中央 Network：資料會經過交換器、路由器等中介設備，不是 Client 直接「瞬間到達」Server。
  • 右側 Server：提供 Web、Email、File 等服務；不同服務需要對應的伺服器軟體。
  • 藍色箭頭：用戶端請求；綠色箭頭：伺服器回覆。
伺服器類型影片中的說明對應用戶端概念
電子郵件伺服器 Email Server 執行電子郵件伺服器軟體，保存並提供郵件。郵件用戶端例如 Outlook 類型程式向伺服器存取郵件。
Web 伺服器 Web Server 執行 Web 伺服器軟體，保存並提供網頁。瀏覽器是 Web 用戶端軟體。
檔案伺服器 File Server 把公司或使用者檔案集中保存。用戶端透過檔案管理／共享機制存取檔案。
額外補充
CCNA 要抓的是「角色」而不是外型。同一台實體電腦可以同時是多個服務的 Client，也可能在某些情境扮演 Server。考題若問「誰提出服務請求？」通常看 Client；問「誰提供服務？」通常看 Server。

3. 1.2.2 對等｜Peer-to-Peer

影片內容 在家庭或小型企業裡，一台電腦可以同時是用戶端又是伺服器，這類網路稱為對等式網路。

資訊圖：影片的例子是一台電腦分享印表機、另一台分享檔案；兩端都能同時扮演 Client 與 Server。
影片列出的優點
  • 易於設定。
  • 複雜度較低。
  • 可能不需要專用伺服器與額外網路設備，因此成本較低。
  • 適合檔案共享、印表機共享等簡單工作。
影片列出的缺點
  • 沒有集中管理。
  • 安全性較弱。
  • 不容易擴充。
  • 主機同時當 Client 與 Server 可能拖慢效能。
考試易錯：Peer-to-Peer 不是「兩台電腦直接用一條線接起來」的同義詞；它描述的是服務角色沒有中央專用伺服器、各節點可彼此提供資源的架構。

4. 1.2.3 終端裝置｜End Devices

影片內容 終端裝置是使用者最直接接觸的網路裝置，也是資料通訊的來源或目的地。

影片內容
影片明確指出：為了區分不同終端裝置，網路上的每個終端裝置都有一個位址；當終端裝置開始通訊時，會使用目的地終端裝置的位址，指定訊息要送到哪裡。終端裝置是透過網路傳輸訊息的來源 (Source) 或目的地 (Destination) 。
資訊圖：來源裝置產生資料，資料經過中介設備，最後抵達有對應目的地位址的終端裝置。
箭頭的意義：藍色單向箭頭表示這一筆資料的傳送方向；若對方回覆，會產生另一筆反向資料流，來源與目的地角色也會交換。
額外補充
在 CCNA 後續章節，這個「位址」會被拆成不同層次，例如第 2 層常看 MAC Address ，第 3 層看 IP Address 。這支影片還沒深入封包格式，因此這裡只先建立「端點需要可識別位址」的概念。

5. 1.2.4 中介設備｜Intermediary Devices

影片內容 中介設備把個別終端裝置接進網路，也能把多個獨立網路連成互聯網路，並讓資料在網路上持續流動。

無線路由器 Wireless Router 把無線終端接入網路，常同時提供多種家用／小型辦公室功能。
LAN 交換器 LAN Switch 把同一區域網路內的多個終端裝置連接起來。
路由器 Router 連接不同網路，並根據路徑資訊轉送資料。
多層交換器 Multilayer Switch 結合交換與部分路由能力。
防火牆設備 Firewall Appliance 依安全設定允許或拒絕資料流。
資訊圖：終端裝置先接到 LAN 交換器，跨網路時會經過路由器等設備；不同中介設備負責的功能不同。
圖解逐區說明
  • LAN 交換器：把同一 LAN 的端點連起來。
  • 路由器：把不同網路連起來，讓資料跨網路前進。
  • 防火牆／多層交換器等：可能加入安全、分類、路由或策略功能。
  • 影片特別提醒：列出的六種功能是「可能執行的功能」，不是每台設備全部都有。
影片小測驗對應考點：「哪兩個設備是中介設備？」答案類型是 Router 與 Switch；Host 與 Server 屬於端點／主機角色，不是中介設備。

6. 1.2.5 網路媒體｜Network Media

影片內容 通訊會在媒體上透過網路傳輸；媒體就是訊息從來源到目的地所走的通道。

銅纜 Copper Cabling 纜線中的金屬線，以電氣脈衝形式編碼資料。
光纖 Fiber-Optic Cabling 玻璃或塑膠纖維，以光脈衝形式編碼資料。
無線 Wireless Transmission 使用特定頻率的無線電波來編碼資料。
資訊圖：同樣都是傳輸資料，銅纜、光纖、無線使用的訊號形式不同；選擇媒體不能只看「能不能接」，還要看距離、環境、流量／速度與成本。
媒體資料如何表示影片直接提到／畫面顯示額外 CCNA 提醒
銅纜 Copper電氣脈衝畫面呈現銅纜類型。容易受電磁干擾的程度與線材種類有關。
光纖 Fiber光脈衝畫面呈現多芯光纖與光纖接頭。通常適合較長距離與高頻寬情境，且不受電磁干擾。
無線 Wireless無線電波畫面呈現無線路由器／無線攝影機。彈性高，但會受環境、干擾與安全設計影響。
考試易錯：「媒體」不是只指網路線。無線也屬於 Network Media，因為它同樣提供訊息從來源到目的地的傳輸通道。

7. CCNA 額外補充｜把五個概念串成一條資料路徑

額外補充 下面內容不是影片逐字出現，但能把 1.2 的角色關係接到後續 Switching / Routing 學習。

額外補充圖：把本支影片的五個概念串成一條完整資料路徑，方便銜接後續 CCNA。
額外補充
Switch 與 Router 的基本分工：這支影片只把它們列為中介設備；後續 CCNA 會進一步學到交換器主要處理同一 Layer 2 網路內的訊框轉送，而路由器負責不同 IP 網路之間的封包轉送。
額外補充
「端點」與「伺服器」不衝突：Server 仍然是終端裝置／Host 的一種角色。它雖然提供服務，但通常不是用來幫其他主機「中途轉送」資料的設備。

8. 重點速記

主題一句話重點常見陷阱
Host直接參與網路通訊的裝置。Host 不等於只指桌上型電腦。
Client / ServerClient 要服務；Server 提供服務。它們是角色，同一主機可能同時扮演多種角色。
Peer-to-Peer節點可直接互相分享資源。不是「兩台電腦直連」的同義詞。
End Device資料的來源或目的地。Server 也可以是 End Device。
Intermediary Device在端點之間連接、轉送、選路或過濾資料。Switch / Router 是中介設備；一般 Host / Server 不是。
Network Media承載訊號的通道。無線也算媒體。
Media Selection看距離、環境、流量／速度、成本。不要只用「線材價格」單一條件判斷。
