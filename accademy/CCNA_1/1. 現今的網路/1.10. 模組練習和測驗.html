2. Network Affect our Lives｜網路如何影響生活

網路的真正價值不是「有網路線」，而是讓人與資訊可以即時連結。

Communication｜溝通即時訊息、語音、視訊會議，把地理距離壓縮成網路延遲。
Collaboration｜協作多人可以共同編輯、分享資料與完成工作。
Access to Information｜資訊存取使用者可從各種終端存取遠端服務與內容。
白話：網路不是只把電腦接起來，而是把「人、裝置、應用程式與資訊」接成一個可互動的系統。

3. Network Components｜網路元件

基本分類要非常熟：終端裝置、中介裝置、網路媒體。

優化圖解：終端裝置是封包的來源或目的地；中介設備負責交換、選路與控制；Copper、Fiber、Wireless 則是承載訊號的三種媒體。
End Devices｜終端裝置
PC、手機、伺服器、IP Phone、印表機等。封包真正的來源或目的地。
Intermediary Devices｜中介裝置
Switch、Router、Firewall、Wireless AP 等。負責連接、轉送、控制流量。
Network Media｜網路媒體
Copper、Fiber、Wireless。決定訊號用電、光或無線方式傳遞。

4. Network Representations and Topologies｜網路表示法與拓撲

拓撲是「網路長什麼樣、資料怎麼走」的模型。CCNA 很常分成 Physical 與 Logical 兩種視角。

Physical Topology｜實體拓撲看設備真的放在哪裡、線路真的怎麼接。像看機房平面圖。
Logical Topology｜邏輯拓撲看資料在網路中如何流動、介面與網段如何相連，不一定等於實際線路位置。
考試陷阱：題目問「cabling / physical location」多半是實體拓撲；問「data path / addressing / logical relationship」則偏邏輯拓撲。

5. Common Types of Networks｜常見網路類型

LAN｜Local Area Network｜區域網路涵蓋較小地理範圍，通常由單一組織管理，例如家庭、辦公室、校園中的一個區域。
WAN｜Wide Area Network｜廣域網路跨越較大地理範圍，把多個 LAN 串在一起，通常會使用電信商／服務供應商提供的連線。
優化圖解：每個辦公據點內部各自是一個 LAN；兩地路由器再透過服務供應商的 WAN 互連，形成跨城市通訊。

6. Internet Connections｜Internet 連線

不同環境選不同接取技術。重點不是只背名字，而是理解媒介、速度、可用範圍與使用情境。

DSL｜數位用戶線路
透過電話銅線提供寬頻服務。
Cable｜纜線寬頻
利用有線電視同軸網路提供 Internet。
Fiber｜光纖
高頻寬、低衰減，常用於高速寬頻與骨幹。
Cellular｜行動網路
透過電信基地台連線，適合行動裝置。
Satellite｜衛星
適合偏遠地區，但通常延遲較高。
Dedicated / Metro Ethernet
企業可使用專線或都會乙太網路取得較穩定的服務。
補充
企業連線通常更在意 SLA、可用性、對稱頻寬、固定 IP 與備援；家庭環境則更常在成本與下載速度間取平衡。

7. Reliable Networks｜可靠網路的四個核心特性

這四個字幾乎是 Module 1 的必考：Fault Tolerance、Scalability、QoS、Security。

Fault Tolerance｜容錯一條路徑或設備失效時，網路仍可透過其他路徑繼續服務。
Scalability｜可擴充性增加使用者與設備時，不必整個重建網路，也不應嚴重影響現有服務。
QoS｜Quality of Service｜服務品質對時間敏感流量（語音、視訊）提供較高優先權，降低延遲、抖動與丟包影響。
Security｜安全性同時保護網路基礎設施與傳輸中的資料，避免未授權存取與攻擊。

8. Network Trends｜網路趨勢

影片的回顧頁列出現代網路的重要趨勢；這些概念會改變網路的流量型態與安全需求。

BYOD｜Bring Your Own Device
自攜裝置使用者用自己的手機、平板、筆電存取組織資源。
Online Collaboration｜線上協作共享文件、聊天、專案平台與即時共同工作。
Video Communications｜視訊通訊需要較穩定的頻寬、低延遲與 QoS。
Cloud Computing｜雲端運算應用與資料不一定在本地，網路本身成為存取服務的關鍵路徑。

9. Network Security｜網路安全

影片回顧安全威脅與解決方案；測驗中也出現「間諜軟體」的情境題：電腦上的軟體偷偷收集使用者瀏覽網站的資料，正確類型是 Spyware。

Malware｜惡意軟體Virus、Worm、Trojan、Spyware 等，可能破壞、控制或竊取資料。
External / Internal Threats威脅可能來自 Internet，也可能來自內部人員、誤操作或被感染的裝置。
Layered Security｜多層防護端點防護、防火牆、ACL、IPS、VPN 等各自負責不同層次。
影片測驗畫面
問題 1 的情境指出軟體在電腦上偷偷蒐集使用者造訪網站的資料，畫面標示的正確答案為「間諜軟體」。

10. The IT Professional｜IT 專業人員

影片回顧頁提到 Cisco Certified Network Associate（CCNA）與 Cisco Networking Academy 的相關學習／職涯路徑。

CCNA｜Cisco Certified Network Associate
證明具備網路基礎、IP 連線、網路存取、安全基礎與自動化等入門能力的一項 Cisco 認證。
Professional Skills｜專業能力
不只會背指令，也要能讀拓撲、定位故障、理解需求、紀錄變更，並把技術概念說清楚。
補充
真正的 CCNA 解題習慣是：先辨識題目層級（端點、二層、三層、WAN、安全），再找「題目要解決的問題」，最後才選技術。

12. 課後考題｜互動複習

共 25 題。前半聚焦影片 Module 1 回顧內容，後半加入情境題，讓你用 CCNA 的方式判斷而不是死背。

1. 某軟體偷偷記錄使用者瀏覽哪些網站，最可能是哪一種威脅？

Spyware 的典型行為就是秘密蒐集使用者活動或資料；這也是影片測驗畫面出現的情境。

2. 哪一項最符合 End Device？

終端裝置是資料真正的來源或目的地，例如 PC、手機、伺服器。

3. 哪一項屬於 Intermediary Device？

Switch 是典型中介設備，負責轉送流量。

4. 光纖、銅線與無線電波在網路元件分類中屬於？

它們是承載訊號的媒體。

5. 題目描述『設備實際擺放位置與線路如何連接』，指的是？

實體拓撲看的是實際設備與纜線布局。

6. 一間辦公室內由公司自行管理的小範圍網路通常是？

LAN 通常涵蓋小地理範圍並由單一組織管理。

7. 公司要把台北與高雄兩個辦公室的 LAN 互連，最符合哪種網路？

跨城市連接多個 LAN 是典型 WAN 情境。

8. 某條連線故障後，流量可以自動改走另一條路徑，這主要展現？

容錯的重點是局部故障不應造成整體服務中斷。

9. 公司增加大量新員工與裝置，但原網路不必整個重做，表示具備？

Scalability 指能平順擴充。

10. 語音與視訊會議在壅塞時需要比一般下載更優先，應使用？

QoS 用來對時間敏感或重要流量分類與優先處理。

11. BYOD 的全名是？

BYOD = Bring Your Own Device。

12. 雲端運算最核心的概念是？

Cloud Computing 讓使用者透過網路取得遠端 IT 資源。

13. 下列何者最常用於家庭寬頻，並利用電話銅線？

DSL 使用電話線路提供數位寬頻服務。

14. 哪種接取方式通常具有高頻寬、低衰減的特性？

光纖以光訊號傳輸，適合高速與較長距離。

15. 偏遠地區沒有有線基礎設施時，哪種 Internet 接取可能較常見？

衛星可涵蓋偏遠區域，但通常延遲較高。

16. 以下何者不是可靠網路的四大核心特性？

畫面解析度不是網路可靠性設計特性。

17. DoS 攻擊主要破壞哪個目標？

DoS 的重點就是降低或破壞服務可用性。

18. 遠端員工需要透過 Internet 安全存取公司內部資源，最適合？

VPN 用於建立受保護的遠端連線。

19. 依 IP 位址與協定規則允許或拒絕流量，最接近哪個概念？

Access Control List 可根據條件篩選流量。

20. 哪個系統的定位是偵測惡意流量並主動阻擋？

IPS = Intrusion Prevention System。

21. 為什麼企業安全不能只靠一個設備？

多層防護的原因就是任何單一控制都不可能涵蓋所有風險。

22. 一間公司導入視訊會議後，使用者抱怨通話卡頓但檔案下載正常，優先應檢查？

即時影音對延遲、抖動與丟包敏感，QoS 是核心考點。

23. 題目說『資料實際走哪一條邏輯路徑』，較偏向？

Logical Topology 關注資料流與邏輯連接關係。

24. WAN 最常見的核心用途是？

WAN 的典型用途就是跨區域串接多個 LAN。

25. 面對 CCNA 情境題，最好的解題順序是？

先辨識問題層級與目標，才不容易被干擾選項帶走。
