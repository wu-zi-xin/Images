CCNA MODULE 1 · 1.5 INTERNET CONNECTIONS

網際網路連線
Internet Connections

這段課程的核心問題是：家庭、小型辦公室與企業，應該用什麼方式連到網際網路？ 影片依序介紹常見存取技術、家庭與企業選項，接著說明為什麼現代網路會把資料、語音與視訊整合到同一個網路架構中。

影片畫面逐段整理影片／補充分流標示教材級 SVG 圖解中英術語發音響應式與手機橫滑18 題互動測驗

1. 本段在學什麼？

先建立一個總框架：不同使用情境需要不同的網際網路存取方式，而「頻寬、可用性、地理位置、成本、對稱性與延遲」會影響選擇。

家庭 / SOHO常見 Cable、DSL、行動通訊、衛星、撥接。
企業通常需要更高可靠性與更高頻寬，常見專屬租用電路、Metro Ethernet、商務 DSL。
統合網路讓資料、語音、視訊可共用同一個 IP 網路基礎架構。
Packet Tracer用標準化圖示和連線表示法協助建立與理解拓樸。
影片內容
影片明確指出家庭使用者、遠端工作者與小型辦公室通常透過 ISP 連線；企業則通常需要更快的連線支援商務服務，例如 IP 電話、視訊會議與資料中心儲存。
額外補充
ISP（Internet Service Provider）偏向提供終端客戶的網際網路存取；SP（Service Provider）是更廣義的服務供應商概念，可包含企業 WAN、專線、Metro Ethernet 等服務。CCNA 題目常透過「使用情境」來判斷較合適的存取方案。

2. 1.5.1 網際網路存取技術

課程先問：已經知道網路由哪些元件組成之後，實際上要怎麼把使用者與組織接到 Internet？答案不是只有一種。

影片內容
家庭使用者、遠端工作者與小型辦公室通常需要連到 網際網路服務供應商（Internet Service Provider, ISP） 才能存取 Internet。各地 ISP 可提供的技術不同，常見選項包括有線電視纜線、寬頻 DSL、無線 WAN／行動服務。企業則可能由 服務供應商（Service Provider, SP） 提供商務級連線。
圖 1｜家庭／SOHO 與企業常見網際網路接取方式總覽。
  1. 左側是影片列出的家庭／小型辦公室常見方案；它們都先經過服務供應商網路再進入 Internet。
  2. 右側是影片列出的企業方案，重點在更高可用性、較高頻寬、跨據點連線與商務需求。
  3. 箭頭表示「接取路徑」，不是說所有技術都會同時使用；實際方案取決於地理位置與服務可用性。

3. 1.5.2 家庭與小型辦公室網際網路連線

影片逐一比較 Cable、DSL、行動通訊、衛星與撥接。這是本段最容易出「依情境選技術」的地方。

有線電視纜線｜Cable Internet影片內容

通常由有線電視服務供應商提供，網際網路資料與有線電視可共用同一條纜線。影片強調其高頻寬、高可用性、持續連線的特性。

DSL / ADSL｜數位用戶線路影片內容

DSL 在電話線上運作，也提供高頻寬與高可用性。家庭／小型辦公室常見 非對稱數位用戶線路（Asymmetric DSL, ADSL），下載通常比上傳快。

行動通訊｜Cellular影片內容

只要有行動電話訊號就能連線；效能會受到終端裝置能力與所連基地台等因素限制。

衛星｜Satellite影片內容

適合缺乏其他網際網路連線的地區，但碟型天線需要與衛星之間有清楚的視線（line of sight）。

撥接電話｜Dial-up影片內容

使用電話線與撥號數據機，頻寬很低，不足以進行大型資料傳輸；影片提到在特定行動／旅行存取情境仍可能有用。

選擇依據影片內容

影片直接總結：連線選擇取決於地理位置以及服務供應商的可用性。

圖 2｜家庭／SOHO 五種連線技術的傳輸媒介與限制。
  1. Cable 與 DSL 都是固定式有線接取，但媒介不同：Cable 走有線電視纜線，DSL 走電話線。
  2. Cellular 的關鍵是「有行動訊號即可接取」；Satellite 的關鍵是「遠端地區可用，但需要視線條件」。
  3. Dial-up 在現代網路屬低速方案；在 CCNA 題目裡看到「大型資料傳輸」通常不是合適選擇。
額外補充｜理解考題用
ADSL 的 A = Asymmetric（非對稱）：下載與上傳速率不同，常見是下載較快。這與影片內容一致。相對地，企業常見的 SDSL（Symmetric DSL） 強調上傳與下載採相同或對稱速率。另請注意：實際 Cable、DSL、5G 或衛星服務速度與延遲會因服務方案與網路狀況而異，不要把「某技術一定比另一技術快」當成永遠成立的規則。

4. 1.5.3 企業網際網路連線

企業比家庭更重視高頻寬、可用性與可預測性。影片列出四類常見選擇。

影片內容
公司連線選項通常不同於家庭使用者；企業可能需要更高頻寬、專屬頻寬與受管理的服務。影片列出專屬租用電路、都會乙太網路、商務 DSL 與衛星。
企業方案影片重點你要抓的考點
專屬租用電路
Leased Line		服務供應商網路中的保留電路，連接地理上分離的辦公室，供私人語音及／或資料網路使用；按月或按年租用。跨據點、專屬／保留、企業級。
都會乙太網路
Metro Ethernet		也可視為 Ethernet WAN；把乙太網路 LAN 存取技術延伸到 WAN。看到「Ethernet 延伸到都會／WAN」就想到 Metro Ethernet。
商務 DSL / SDSL商務 DSL 有多種形式，常見 SDSL；與消費型 DSL 類似，但可提供上傳和下載相同的高速頻寬。S = Symmetric，強調對稱。
衛星
Satellite		無法使用有線解決方案時，可提供連線。地理位置偏遠／沒有有線基礎設施。
圖 3｜企業需求如何對應到企業級存取方案。
  1. 企業的「商務需求」不是另一種傳輸媒介，而是選擇連線方案的理由。
  2. Leased Line 的核心是保留／專屬；Metro Ethernet 的核心是 Ethernet 技術延伸到 WAN。
  3. SDSL 的核心是 symmetric（對稱）；Satellite 則是缺乏有線方案時的替代手段。

5. 1.5.4 統合網路

這一節不是在比較 ISP 方案，而是在說明企業內部網路從「各自獨立」走向「共用同一個 IP 基礎架構」的演變。

影片內容
影片先用 Traditional Separate Networks 說明早期資料、電話與視訊網路常各自獨立，彼此無法直接溝通，每一個網路需要自己的規則與標準；接著以單一網路承載多種服務的圖示呈現統合網路概念。
圖 4｜傳統分離網路與統合網路的架構差異。
  1. 左側三條獨立路徑代表早期資料、電話、視訊各有自己的網路。
  2. 右側三種流量都進入同一個 IP Network，表示「共用基礎架構」，不是說資料類型變成一模一樣。
  3. 統合後仍要處理不同應用需求；例如即時語音／視訊比一般檔案傳輸更怕延遲與抖動。這點是理解統合網路的重要延伸。
額外補充｜CCNA 延伸
統合網路常與 服務品質（Quality of Service, QoS） 一起理解：同一個網路承載多種流量後，網路必須能辨識並適當優先處理延遲敏感的語音與視訊。QoS 的細節不屬於這支影片畫面，但它能解釋「為什麼統合網路需要更好的流量管理」。

7. 連線選擇與 CCNA 考點

影片說「取決於地理位置與服務可用性」，考題則常再加上頻寬、對稱性、可靠度與成本需求。

圖 5｜把影片的「地理位置／可用性」延伸成 CCNA 常見情境判斷流程。
  1. 第一層先分家庭／SOHO 或企業，因為服務需求與預算通常不同。
  2. 家庭方案重點多落在「媒介與覆蓋」；企業方案重點則常落在專屬性、對稱性與 WAN 整合。
  3. 此流程是輔助記憶，不代表實務採購只能照單一路徑決策。
考試易錯：「ADSL = 下載比上傳快」是方向性的定義；不要把「Cable 一定比 DSL 快」當成固定真理。實際效能取決於服務方案、線路條件、共享程度與當地網路。

8. 重點速記

主題一句話重點最容易錯在哪裡
ISP / SP家庭常經 ISP；企業可由 SP 提供商務級服務。不要把 ISP 與所有 WAN 服務完全畫上等號。
Cable有線電視纜線承載 Internet 存取。是接取技術，不等同 Ethernet。
ADSLAsymmetric：下載與上傳不對稱，常見下載較快。A 不是 Advanced，而是 Asymmetric。
Cellular有行動訊號的地方可使用。效能會受裝置與基地台／無線環境影響。
Satellite偏遠地區可用；需要適當視線條件。可用性高於某些有線方案，不代表延遲一定低。
Dial-up電話線＋撥號數據機，低頻寬。不適合大型資料傳輸。
Leased LineSP 保留的專屬電路，可連接分散據點。重點是專屬／保留與企業用途。
Metro Ethernet把 Ethernet LAN 技術延伸到 WAN。名稱有 Ethernet，但服務範圍可跨都會／WAN。
SDSLSymmetric：上下行對稱。不要和 ADSL 的非對稱搞反。
Converged Network資料、語音、視訊共用同一 IP 網路。共用基礎架構 ≠ 所有流量需求完全相同。

10. 課後測驗｜18 題

每題選一個答案後按「檢查答案」。系統會顯示正誤、正確答案、其他選項為什麼不對，以及對應觀念。

1. 基礎觀念｜家庭使用者通常要先連到什麼，才能存取 Internet？

正確答案：ISP（Internet Service Provider）。
詳細解析：影片指出家庭、遠端工作者與小型辦公室通常需要連線到 ISP 才能存取 Internet。
其他選項為什麼不對：STP Root Bridge 是交換網路生成樹角色；DNS Zone 是名稱解析管理範圍；VLAN Trunk 是交換器間承載多 VLAN 的鏈路。
對應課程觀念：1.5.1 網際網路存取技術

2. 基礎觀念｜ADSL 的 A 代表什麼？

正確答案：Asymmetric。
詳細解析：ADSL 是 Asymmetric Digital Subscriber Line，重點是上下行不對稱，常見下載比上傳快。
其他選項為什麼不對：其他三個字都不是 ADSL 名稱中的 A。
對應課程觀念：1.5.2 DSL / ADSL

3. 情境題｜偏遠地區沒有可用的 Cable 或 DSL，有清楚天空視線。影片中的哪個方案最符合？

正確答案：Satellite。
詳細解析：影片指出衛星在沒有其他網際網路連線的地方特別有用，但需要到衛星的清楚視線。
其他選項為什麼不對：Dial-up 低頻寬；Metro Ethernet 與 Leased Line 是企業型服務，且題目強調沒有有線接取。
對應課程觀念：1.5.2 衛星

4. 比較題｜下列何者最能描述 ADSL 與 SDSL 的差異？

正確答案：ADSL 常見下載較快；SDSL 強調上下行對稱。
詳細解析：影片分別把 ADSL 描述為非對稱、把商務 SDSL 描述為上傳和下載可採相同高速頻寬。
其他選項為什麼不對：其他選項把使用對象、媒介或技術名稱混淆。
對應課程觀念：1.5.2 + 1.5.3

5. CCNA 類型｜公司要連接兩個地理上分離的辦公室，希望使用服務供應商網路中的保留電路。應選哪一種？

正確答案：Leased Line。
詳細解析：影片直接定義專屬租用電路為服務供應商網路內的保留電路，可連接地理上分離的辦公室。
其他選項為什麼不對：其餘選項不是題目描述的保留企業跨據點電路。
對應課程觀念：1.5.3 專屬租用電路

6. 基礎觀念｜Metro Ethernet 的核心概念是什麼？

正確答案：將 Ethernet LAN 技術延伸到 WAN。
詳細解析：影片指出 Metro Ethernet 可視為 Ethernet WAN，將 Ethernet 的 LAN 存取技術延伸至 WAN。
其他選項為什麼不對：其他選項都不是 Metro Ethernet 的定義。
對應課程觀念：1.5.3 Metro Ethernet

7. 情境題｜一家小型辦公室主要下載大型檔案，上傳需求較少，現場有可用電話線。哪個影片方案最符合典型描述？

正確答案：ADSL。
詳細解析：ADSL 的非對稱特性常見下載比上傳快，與題目需求吻合。
其他選項為什麼不對：SDSL 偏對稱；Leased Line 是企業專屬電路；Satellite 不是因為有電話線就必須選。
對應課程觀念：1.5.2 DSL / ADSL

8. 基礎觀念｜哪一種家庭連線方式的效能會受到手機功能與所連基地台等因素限制？

正確答案：Cellular。
詳細解析：影片描述行動網路效能會受到手機功能與所連基地台等因素限制。
其他選項為什麼不對：其餘選項不依賴行動基地台。
對應課程觀念：1.5.2 行動通訊

9. 易混淆｜下列哪句最正確？

正確答案：實際連線選擇會受地理位置與服務供應商可用性影響。
詳細解析：這是影片的直接總結。
其他選項為什麼不對：Cable 與 Ethernet 不是同義詞；不同服務的實際速度不可一概而論；衛星也不能一概說最低延遲。
對應課程觀念：1.5.2 方案選擇

10. CCNA 類型｜企業需要上傳與下載都維持相同等級頻寬，哪個影片選項最直接符合？

正確答案：SDSL。
詳細解析：商務 SDSL 的重點是 symmetric，影片說明可提供上傳與下載相同的高速頻寬。
其他選項為什麼不對：ADSL 是非對稱；Dial-up 低頻寬；Cellular 未以對稱頻寬為核心特徵。
對應課程觀念：1.5.3 商務 DSL

11. 基礎觀念｜Traditional Separate Networks 的主要特徵是什麼？

正確答案：不同服務各自使用分離網路。
詳細解析：影片的傳統分離網路示意把資料、電話與視訊放在不同網路中，每個網路有自己的規則與標準。
其他選項為什麼不對：其他選項與影片圖示相反或無關。
對應課程觀念：1.5.4 統合網路

12. 比較題｜Converged Network 最準確的描述是？

正確答案：資料、語音與視訊共用同一 IP 網路基礎架構。
詳細解析：統合網路的核心是多種服務共用一套 IP 網路基礎架構。
其他選項為什麼不對：其他選項不是 convergence 的定義。
對應課程觀念：1.5.4 統合網路

13. 額外補充｜統合網路中，為何 QoS 常被提到？

正確答案：因為即時語音／視訊對延遲等更敏感。
詳細解析：這是額外補充：統合網路讓多種流量共享同一基礎架構，因此常需 QoS 依需求管理優先順序。
其他選項為什麼不對：其他選項都不是 QoS 的主要作用。
對應課程觀念：額外補充：QoS

14. 情境題｜公司希望使用熟悉的 Ethernet 技術來提供都會範圍 WAN 服務，哪個最符合？

正確答案：Metro Ethernet。
詳細解析：Metro Ethernet 的核心就是把 Ethernet 存取技術延伸到 WAN／都會範圍。
其他選項為什麼不對：其他選項不是 Ethernet WAN 服務。
對應課程觀念：1.5.3 Metro Ethernet

15. 基礎觀念｜撥接電話（Dial-up）最大的影片限制是？

正確答案：低頻寬，不適合大型資料傳輸。
詳細解析：影片明確指出撥接數據機的低頻寬不足以進行大型資料傳輸。
其他選項為什麼不對：其餘選項都不是撥接的主要描述。
對應課程觀念：1.5.2 Dial-up

16. 情境題｜下列哪個需求最像影片提到企業需要快速連線來支援的商務服務？

正確答案：IP 電話、視訊會議與資料中心儲存。
詳細解析：這三項是影片在 1.5.1 直接列出的企業商務需求範例。
其他選項為什麼不對：其他選項不需要企業級 Internet／WAN 連線支援。
對應課程觀念：1.5.1 企業商務需求

17. Packet Tracer｜影片最後的活動主要在探索什麼？
