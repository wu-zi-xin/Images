1. 為什麼要學 Cisco Packet Tracer？

Cisco Packet Tracer 是用來模擬網路環境的學習工具。你可以在沒有實體路由器、交換器與大量網路線的情況下，先在虛擬環境建立拓樸（Topology）、接線、設定裝置，再觀察封包如何傳送。

先做再懂用拖拉與連線把抽象的網路概念變成可視化操作，適合剛接觸 CCNA 的學習者。
低風險練習設定錯了可以重來，不會真的把公司網路弄斷；很適合練 IP、介面、VLAN、路由與 ACL。
建立「網路感」你會慢慢知道哪種裝置該放哪裡、哪個介面要接哪條線，以及封包為何能或不能到達目的地。
影片核心：Packet Tracer 允許你建立或編輯網路、操作網路中的元件，並開啟既有或範例網路來學習。影片接著示範如何從介面開始建立第一個 Packet Tracer 網路。
影片畫面示例：課程頁面介紹 Packet Tracer 的用途，並展示底部的裝置類型與 WAN Emulation 等工具。

2. Packet Tracer 的三大主要選項

1
新增／連線
新增裝置（Device），並加入網路線或其他連線（Connection）。
2
操作元件
選取（Select）、刪除（Delete）、查看（Inspect）、標示（Label）、群組（Group）。
3
管理專案
開啟既有或範例網路、儲存網路，並透過使用者設定與偏好設定管理環境。
4
觀察結果
完成拓樸後，用即時或模擬方式驗證裝置之間能否通訊。
白話理解：Packet Tracer 就像「網路版的積木＋實驗室」。先放設備，再用線接起來，最後打開設備做設定並測試通不通。

3. 認識介面：Logical、Physical 與裝置選單

影片示範時會在工作區與底部裝置選單之間切換。初學時最重要的是先知道「你現在在哪個工作區」與「你選到哪一類設備」。

Logical Workspace｜邏輯工作區

用來看「網路關係」。你會看到 Router、Switch、PC 等圖示，以及它們彼此之間的連線。大多數 CCNA 拓樸規劃與基本設定都會在這裡完成。

Physical Workspace｜實體工作區

用來看「設備實際放在哪裡」。例如城市、建築、配線間（Wiring Closet）、機架（Rack）。影片中也示範把路由器放到網路機架上。

Physical 工作區：可用較接近真實機房的方式理解裝置位置、機架與實體連線。
Network Devices｜網路設備

常見子類別包含 Routers、Switches、Wireless Devices、Security、WAN Emulation。

End Devices｜終端裝置

PC、Laptop、Server、Printer、IP Phone 等。它們通常是「使用網路的人或服務」。

Connections｜連線

銅纜、光纖、Console 等不同線材。Packet Tracer 可自動選線，也可以手動挑選。

4. 建立第一個 Packet Tracer 網路

影片的操作重點是：從裝置類別挑選設備、拖曳到工作區，然後放到適當位置，最後建立連線。下面用一個最小型 LAN 範例把流程講清楚。

操作順序

  1. 選擇裝置大類，例如 Network Devices。
  2. 再選細分類，例如 Routers 或 Switches。
  3. 點選特定型號，把設備拖曳到工作區。
  4. 加入 PC 等 End Devices。
  5. 切到 Connections 選擇線材並連接介面。
  6. 點開設備進行設定，最後測試連通性。

最重要的判斷

「線要接哪裡？」不是看圖示漂亮，而是看設備上的介面（Interface）。例如 PC 的 FastEthernet/GigabitEthernet 介面接到 Switch 的 Ethernet 埠；Router 再用 Ethernet 介面接到 Switch。

「為什麼不通？」通常要依序檢查：線材／介面是否連好 → 介面是否啟用 → IP 與遮罩是否正確 → 是否需要 Default Gateway → 路由是否存在。

Logical 工作區示例：路由器、交換器與終端裝置形成簡單拓樸，是最常見的練習方式。
影片示範在實體視圖中放置設備並觀察機架介面，幫助理解真實網路設備的外觀與位置。

5. File 選單、Open Samples 與 Exit and Logout

一般檔案操作

  • Open｜開啟：讀取既有 Packet Tracer 專案。
  • Save｜儲存：保存目前網路。
  • Save As｜另存新檔：保留舊版，同時建立新版本。
  • Exit｜結束：關閉程式；操作方式和其他桌面應用程式相近。

Packet Tracer 特有／常用項目

  • Open Samples｜開啟範例：瀏覽內建的範例拓樸與預先建置的實作。
  • Exit and Logout｜退出並登出：移除 Packet Tracer 軟體的註冊／登入資訊，下一位使用者需要重新登入。
  • User Profile｜使用者設定檔：與個人資訊或使用環境有關。
  • Preferences｜偏好設定：調整軟體顯示與操作習慣。
實務建議：每完成一個重要步驟就另存版本，例如 lab01-start.pkt、lab01-ip-configured.pkt、lab01-done.pkt。設定錯誤時比較容易回頭。

7. 這段影片之外，CCNA 初學者一定要補上的觀念

Real-Time vs Simulation

Real-Time｜即時模式像真實網路一樣讓事件自然發生。Simulation｜模擬模式則可以逐步觀察 PDU／封包經過哪些設備、被哪一層處理。學協定時非常重要。

CLI vs GUI

Packet Tracer 可以用視窗介面操作，但 CCNA 不能只會點 GUI。Router/Switch 的大量考點仍然來自 CLI（Command-Line Interface，命令列介面）。

Link Light 不等於一定能通

線路顯示綠燈只代表實體／資料鏈路層多半已建立，不代表 IP 設定、預設閘道與路由一定正確。

先畫簡單，再加複雜

先用 2 台 PC + 1 台 Switch 驗證同網段，再加入 Router 驗證跨網段。一次只多加一個變因，排錯最快。

常用驗證思路： PC > ipconfig PC > ping 192.168.1.1 Switch# show interfaces status Switch# show mac address-table Router# show ip interface brief Router# show ip route
注意：Packet Tracer 是學習模擬器，不會 100% 支援所有真實 Cisco IOS / IOS XE 指令與硬體行為。遇到「真機有、PT 沒有」的情況不一定是你操作錯。
影片中的實體設備視圖有助於把「抽象圖示」對應到真實機房裡的設備、埠與線路。

8. 課後考題｜Quiz

先自己作答再按「批改答案」。每題都附解釋，答錯時重點是知道錯在哪裡。

Q1. Packet Tracer 最主要的用途是什麼？

答案 C。Packet Tracer 的價值在於「可操作的網路模擬」，不只是畫圖。

Q2. 想看設備實際放在哪個機房／機架，最適合使用哪個工作區？

答案 B。Physical Workspace 用來呈現城市、建築、配線間與機架等實體位置。

Q3. 「Open Samples」最合理的用途是？

答案 A。Open Samples 是很好的練習入口，可查看已完成或預先建立的範例。

Q4. 建立一個簡單 LAN 時，最常見的合理順序是？

答案 D。這是最清楚、最容易排錯的工作流程。

Q5. 線路已經變綠，但兩台不同網段 PC 仍 Ping 不通，最合理的判斷是？

答案 B。Link up 只代表底層連線條件多半成立，Layer 3 還有多個設定需要驗證。

Q6. 哪一個最接近 WAN（Wide Area Network）的概念？

答案 C。WAN 典型特徵是覆蓋較大的地理範圍並連接不同地點的網路。
