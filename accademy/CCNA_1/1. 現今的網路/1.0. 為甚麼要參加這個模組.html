影片示範時，最常碰到的是中央工作區、下方裝置／連線選擇區，以及 Logical / Physical 分頁。

補充｜先把圖排整齊非常重要
學 CCNA 時，拓撲圖越清楚，你越容易辨認「哪台設備連到哪個介面」。亂放設備不是功能性錯誤，但會大幅增加你自己排錯的難度。

5. 建立連線：選線 → 選第一端 → 選第二端

影片示範切到連線工具，並可看到 Copper Straight-Through（銅質直通線）。接線時不是只點兩台設備而已，你還要在兩端各選一個可用介面／連接埠。

自製圖解：Packet Tracer 接線最容易忘的是「兩端都要選介面」。不是選完線後隨便點兩台設備就結束。
常見錯誤：線材選對了，但介面選錯；或設備本身根本沒有該類型介面。遇到不能接、接了不通時，先檢查「線材類型、兩端介面、介面狀態」三件事。
補充｜Straight-Through 怎麼理解？
在基礎乙太網路教材裡，直通線常用在「不同類型」的乙太網路設備之間，例如終端主機連交換器、路由器連交換器。現代實體設備常支援自動 MDI/MDIX，因此真實世界不一定還要死背交叉線／直通線；但在 CCNA 基礎學習與模擬器操作時，理解線材類型仍然很重要。

6. Logical 與 Physical：同一個網路，兩種看法

影片中先在 Logical 視圖放置與連接設備，之後切換到 Physical 視圖，畫面可看到機櫃、設備與實體線路。

Logical｜邏輯視圖重點是「誰跟誰相連」以及拓撲結構。很適合做配置、看網路關係、整理封包路徑。
Physical｜實體視圖重點是「設備實際放在哪裡、線怎麼走、機櫃與位置怎麼呈現」。影片畫面可見設備位於機櫃中，並顯示連接線。
自製比較圖：Logical 在意「關係」，Physical 在意「位置與實體」。兩者不是不同網路，而是同一個網路的不同呈現方式。
考試思路：看到 topology、path、connection relationship，比較偏 Logical；看到 rack、wiring closet、building、physical cable，通常比較偏 Physical。

7. 一次做對的操作流程

把影片操作整理成一個你之後每次做 Packet Tracer Lab 都能直接套用的順序。

  1. 先看題目要你建什麼拓撲：有哪些 Router、Switch、End Devices？
  2. 在裝置分類中找設備：先選類別，再選具體設備。
  3. 把設備放進工作區並排整齊：不要一開始就亂接。
  4. 開啟 Connections：選題目需要的線材。
  5. 選兩端設備與介面：記下或確認哪一端接哪個 port/interface。
  6. 檢查連線是否建立：若不正常，先排除線材與介面錯誤。
  7. 需要時切換 Logical / Physical：用不同視角確認拓撲與實體配置。
  8. 常存檔：完成一個階段就 Save，避免操作失誤後全部重做。
不要把「接上線」誤認成「網路一定會通」：實際 CCNA Lab 還可能需要設定 IP Address、Subnet Mask、Default Gateway、Router Interface、VLAN、Routing 等。這支影片主要是在教你 Packet Tracer 的起手式，不代表完成接線就完成整個網路設定。

8. CCNA 補充重點：這些觀念跟後面課程會一直連在一起

以下是額外補充，不是把它假裝成影片逐字內容，而是幫你把這支入門影片跟後續 CCNA 實作接起來。

補充 1｜Device ≠ Interface
設備（Device）是一整台 Router/Switch/PC；介面（Interface）是設備上拿來送收資料的連接點。你連線時真正選的是「設備上的某個介面」。
補充 2｜Link ≠ Connectivity
有線路（Link）只代表有連接關係；能不能互通（Connectivity）還要看位址、介面狀態與協定設定。
補充 3｜Physical 與 Data Link 不一樣
接線主要先碰到 OSI Layer 1 的物理媒介問題；交換器轉送乙太網路框架則主要是 Layer 2。後面你會開始把「線、MAC、IP」分層理解。
補充 4｜先命名再排錯
大型拓撲建議把裝置名稱、介面、IP 設定記清楚。當拓撲一複雜，清楚標示會比靠記憶可靠得多。

9. 重點速記

主題一句話重點你要記得
Packet Tracer用來建立與模擬網路的學習工具。很適合練習拓撲、接線、設定與排錯。
Workspace主要放置與操作設備的區域。先把拓撲排整齊，再接線。
Device Categories用分類快速找到 Network Devices / End Devices。先類別、再型號。
Connections選擇線材並指定兩端介面。兩端介面都要選。
Logical看設備之間的邏輯拓撲關係。適合看「誰跟誰連」。
Physical看設備位置、機櫃與實體線路。適合看「設備在哪、線怎麼走」。
Save保存目前 Lab 進度。養成階段性存檔習慣。
