IOS 導航
Navigating the Cisco IOS

本頁依你錄下的 2.2 課程影片整理。影片依序介紹主要命令模式、全域設定與子設定模式，以及如何用 enable、disable、configure terminal、exit、end、Ctrl+Z 在 IOS CLI 模式之間移動。下面將影片內容改寫成容易記憶的白話講義，並補上可互動測驗與英文發音。

影片畫面整理中英對照自製 SVG 圖解英文發音20 題互動測驗手機自適應

1. 本段到底在學什麼？

你可以把 IOS CLI 想成一棟有很多樓層與房間的大樓。不同模式就是不同房間；每個房間可以使用的命令不一樣。

> User EXEC先進門，只能做較有限的基本監看。
# Privileged EXEC取得較高權限，可做更多監看、管理並進入設定。
(config)# Global Config開始改整台裝置的設定。
(config-...)# 子模式針對 console、VTY、介面等特定項目設定。
影片內容
影片 2.2 的核心是：辨認 IOS CLI 的主要模式與設定模式，並學會在它們之間有效率地導航。影片畫面明確示範 User EXEC、Privileged EXEC、Global Configuration、Line Configuration 與 Interface Configuration，以及 mode switching 的命令。

2. 2.2.1 主要命令模式｜Primary Command Modes

影片先把安全與權限切成兩個主要 EXEC 層級。

User EXEC Mode｜使用者 EXEC 模式

只能存取數量有限的基本監視命令，通常也稱為「僅檢視」模式。提示字元通常以 > 結尾。

Switch>
Router>
Privileged EXEC Mode｜特權 EXEC 模式

允許存取更多命令與功能，可以使用監視、管理命令，也是進入更高設定模式的入口。提示字元通常以 # 結尾。

Switch#
Router#
白話：Switch> 像一般使用者帳號；Switch# 像管理員權限。你要改設定，通常先得從 > 進到 #。

3. 2.2.2 設定模式與子設定模式

當你真的要「改」設備，就要從 Privileged EXEC 進入 Global Configuration Mode。全域設定再往下分成多種子設定模式。

自製圖解：所有文字與箭頭分區放置，讓手機縮放時仍能看清楚模式、提示字元與切換命令。
Global Configuration Mode｜全域設定模式影響整台裝置的設定。典型提示字元是 Switch(config)#。
Subconfiguration Mode｜子設定模式用來設定特定元件。影片舉出兩種常見類型：Line Configuration（SSH、Telnet、AUX 等管理線路）與 Interface Configuration（交換器埠、路由器介面等）。
看括號就能猜用途：(config-line)# 是 line；(config-if)# 是 interface。這些字串比背畫面位置可靠得多。

4. 2.2.3 影片：IOS CLI 主要命令模式

影片中的英文投影片列出三個主要學習項目：User EXEC mode、Privileged EXEC mode、Global config mode。

Step 1｜User EXEC登入 CLI 後常先看到 Switch>。這裡適合基本查看。
Step 2｜Privileged EXEC輸入 enable 後進到 Switch#，取得更多權限。
Step 3｜Global Config輸入 configure terminal 後進到 Switch(config)#。
Switch> enable
Switch# configure terminal
Switch(config)#

5. 2.2.4 在 IOS 模式之間瀏覽

這一頁是整段最值得背熟的地方：怎麼進、怎麼退、怎麼直接跳。

目的命令典型變化白話
升級到特權 EXECenableSwitch> → Switch#拿到管理員層級。
返回 User EXECdisableSwitch# → Switch>放下特權。
進全域設定configure terminalSwitch# → Switch(config)#開始改設備設定。
進 Line 子模式line console 0(config)# → (config-line)#設定 console 線路。
退回上一層exit(config-line)# → (config)#只退一層。
快速回特權 EXECend 或 Ctrl+Z(config-...)# → Switch#直接離開設定模式。
白話記憶：exit 是樓梯、end / Ctrl+Z 是電梯、直接輸入另一個子模式命令則像從一個房間直接走去另一個房間。
Switch(config)# line console 0
Switch(config-line)# exit
Switch(config)#

Switch(config-line)# end
Switch#

Switch(config-line)# interface FastEthernet 0/1
Switch(config-if)#

6. 2.2.5 影片：IOS 模式之間導航

影片示範把前面的規則真的打進 CLI。畫面中可看到 console、VTY、VLAN 介面與 FastEthernet 介面的切換。

影片畫面可辨識到的示範
line console 0、exit、line vty 0 15、interface vlan 1、interface fastethernet 0/1、end，以及 config t 和 Ctrl+Z。
Line console 0進到 console 的 line 設定模式。
Line vty 0 15切到 VTY 虛擬終端線路設定。
Interface VLAN / FastEthernet切到介面設定模式，提示字元改為 (config-if)#。
重要補充
config t 是縮寫，不是另一個新命令。 Cisco IOS 常允許把命令縮寫到「足以唯一辨識」的程度。學習初期建議先熟完整命令，再逐漸使用縮寫，這樣比較不容易混亂。

7. 2.2.6～2.2.7 語法檢查器練習

影片後段進入互動式 Syntax Checker，讓你實際練習在交換器的 IOS 命令列之間導航。

2.2.6 練習注意事項

這類練習的目的不是只看答案，而是讓你親自輸入命令。若練習環境同時開著課程頁與模擬器，要以題目要求的 prompt 為準，逐步確認自己所在模式。

2.2.7 Syntax Checker

畫面中的題目從 Switch> 開始，要求用 enable 進入 Privileged EXEC，之後繼續進行模式切換。重點是「你輸入的命令是否符合當下 prompt」。

練習方法：不要只抄命令。每打一行之後，都先看新的提示字元，口頭說出「我現在在哪個模式」。這個動作會讓導航觀念很快變成直覺。

10. 課後考題｜20 題

前 15 題以影片內容為主；後 5 題加入理解型補充。按「檢查答案」後會顯示正確選項與逐題解析。

1. User EXEC 模式的典型提示字元是哪一個？

影片表格指出 User EXEC 常以 > 結尾，例如 Switch>。

2. Privileged EXEC 模式與 User EXEC 相比，最重要的差別是？

特權 EXEC 允許存取更多監看、管理命令，也是進入設定模式的入口。

3. 從 User EXEC 進入 Privileged EXEC，使用哪個命令？

enable 會把 Switch> 提升為 Switch#。

4. 從 Privileged EXEC 回到 User EXEC，使用哪個命令？

disable 會離開特權 EXEC，返回 User EXEC。

5. 要進入 Global Configuration Mode，常用哪個命令？

在 Switch# 下輸入 configure terminal，提示字元會變為 Switch(config)#。

6. 哪個提示字元代表 Global Configuration Mode？

(config)# 是全域設定模式的典型識別。

7. 下列何者是影片提到的常見子設定模式？

影片 2.2.2 介紹 line 與 interface 兩種常見子設定模式。

8. 從 Switch(config)# 輸入 line console 0 後，通常會進入？

line console 0 進入 line configuration mode。

9. 在 Switch(config-line)# 輸入 exit，最合理的結果是？

exit 通常只回到上一層設定模式。

10. 若想從任何設定模式快速回到 Privileged EXEC，可使用？

影片明確示範 end 與 Ctrl+Z 都能直接回 Switch#。

11. 影片示範可從 (config-line)# 直接輸入 interface FastEthernet 0/1，這表示？

IOS 可直接根據新命令切到對應子設定模式，不必先逐層退出。

12. line vty 0 15 最接近哪一類設定？

VTY 是 virtual terminal lines，常用於遠端 CLI 存取的 line 設定。

13. interface vlan 1 會把 CLI 帶入哪種模式？

interface ... 命令會進入介面子設定模式，提示字元常是 (config-if)#。

14. 下列哪個是影片示範中的命令縮寫？

影片示範 config t 作為 configure terminal 的常見縮寫。

15. 為什麼要先學會辨認 prompt（提示字元）？

命令是否可用，常取決於目前 IOS mode；看 prompt 能先確認自己在哪一層。

16. 【補充】在實務排錯時，輸入命令出現 invalid input，第一個合理檢查是？

常見原因不是命令本身完全錯，而是目前模式不接受該命令。

17. 【補充】Ctrl+Z 的效果最接近哪個命令？

在設定模式中，Ctrl+Z 常用來快速結束設定並回 Privileged EXEC。

18. 【補充】若只是想從 (config-if)# 回到 (config)#，較合適的是？

exit 回上一層；end / Ctrl+Z 則通常直接回 Switch#。

19. 【補充】哪一種記憶方式最不容易搞混？

提示字元直接揭示所在模式，是最可靠的導航線索。

20. 影片 2.2 這段的核心能力最接近哪一句？

本段集中在主要命令模式、設定/子設定模式與模式間導航。
