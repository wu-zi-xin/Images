Configure IP Addressing

1. 這堂課到底在學什麼？

把「IP 位址是什麼」進一步變成「我知道去哪裡設定、怎麼驗證、出問題怎麼查」。

Manual｜手動自己輸入 IP、遮罩、閘道與 DNS，適合需要固定位址的裝置。
Automatic｜自動由 DHCP 伺服器自動提供網路參數，日常用戶端最常見。
Verify｜驗證Windows 用 ipconfig；Cisco IOS 用 show；最後用 ping 測連通。
Manage｜管理Layer 2 交換器透過 SVI 取得管理 IP，方便遠端管理。
一句話記住：「設定」不是目的，驗證設定正確、確認真的能通才是網路工程工作完成的標準。

2. 2.7.1 手動設定終端裝置的 IP 位址

影片以 Windows 乙太網路介面為例：進入網路介面卡內容，選取 Internet Protocol Version 4 (TCP/IPv4)，再開啟 Properties 填入固定網路參數。

Windows 操作路徑
  1. 開啟 Control Panel（控制台）。
  2. 進入 Network and Sharing Center（網路和共用中心）。
  3. 選擇 Change adapter settings（變更介面卡設定）。
  4. 在網路介面上按右鍵 → Properties。
  5. 選 Internet Protocol Version 4 (TCP/IPv4) → Properties。
  6. 選 Use the following IP address 並輸入網路參數。
影片中的手動設定範例
欄位範例值
IP Address192.168.1.10
Subnet Mask255.255.255.0
Default Gateway192.168.1.1
DNS依網路需求設定；影片畫面可保持空白
自製圖解：四個欄位各司其職。最常見的初學錯誤是只輸入 IP，卻忽略遮罩或閘道。
重要：「預設閘道」要是同一個本地子網路中可到達的路由介面，不是隨便填一個 IP。若主機只需要跟同網段設備通訊，即使沒有閘道仍可能互通；但要前往其他網路就需要路由。

3. 2.7.2 終端裝置的自動 IP 位址設定

影片指出，終端裝置通常預設使用 DHCP 自動取得 IPv4 設定。Windows 中勾選 Obtain an IP address automatically 與 Obtain DNS server address automatically 即可。

DHCP｜Dynamic Host Configuration Protocol自動發放 IPv4 位址、子網路遮罩、預設閘道，以及可選的 DNS 等參數。
為什麼方便？不用每台電腦手動輸入，能降低輸入錯誤與重複 IP 的機會，也方便大量用戶端集中管理。
IPv6 怎麼辦？影片備註 IPv6 可使用 DHCPv6 與 SLAAC（Stateless Address Autoconfiguration）進行動態位址設定。
延伸必懂｜DHCP 的 DORA 流程
1. Discover
用戶端：「網路上有 DHCP 伺服器嗎？」
→
2. Offer
伺服器：「我可以提供這組 IP。」
→
3. Request
用戶端：「我要使用這個租約。」
→
4. Acknowledge
伺服器：「確認，這個位址暫時租給你。」

DORA 是常見的 DHCPv4 初始租用記憶法。這是延伸知識，不是影片畫面逐字內容。

4. 2.7.3 語法檢查：驗證 Windows 電腦 IP 設定

設定完不要用「看起來有填」當作驗收。Windows 可在 Command Prompt 執行 ipconfig 檢查目前介面實際使用的參數。

C:\> ipconfig Windows IP Configuration Ethernet adapter Local Area Connection: Connection-specific DNS Suffix . : cisco.com Link-local IPv6 Address . . . . . : fe80::... IPv4 Address. . . . . . . . . . . : 192.168.1.10 Subnet Mask . . . . . . . . . . . : 255.255.255.0 Default Gateway . . . . . . . . . : 192.168.1.1
你要核對三件事：IP 是否在預期網段、Subnet Mask 是否正確、Default Gateway 是否正確。DHCP 環境還要確認取得的 DNS 是否合理。
延伸
ipconfig /all 可看到更完整資訊，例如 DHCP 是否啟用、實體位址（MAC）、DHCP Server、DNS Server 等。

5. 2.7.4～2.7.5 交換器虛擬介面設定與語法檢查

第 2 層交換器可以不用 IP 就做基本的 MAC 位址轉送；但是若要從網路上遠端管理交換器，就需要管理 IP。這個 IP 通常配置在 SVI（Switch Virtual Interface），而不是一般 Layer 2 實體埠。

自製圖解：實體交換埠與 SVI 的角色不同。SVI 是邏輯介面，用來承載管理 IP。
影片示範的 IOS 設定
Sw-Floor-1# configure terminal Sw-Floor-1(config)# interface vlan 1 Sw-Floor-1(config-if)# ip address 192.168.1.20 255.255.255.0 Sw-Floor-1(config-if)# no shutdown Sw-Floor-1(config-if)# exit Sw-Floor-1(config)# ip default-gateway 192.168.1.1

逐行解釋：
interface vlan 1：進入 VLAN 1 的 SVI。
ip address ...：指定管理 IP 與遮罩。
no shutdown：管理上啟用此介面。
ip default-gateway ...：讓此 Layer 2 交換器需要回覆其他網段的管理流量時，知道送往哪個路由出口。

容易漏掉：SVI 要變成 up/up，除了 no shutdown 外，該 VLAN 通常還需要存在，並且至少有一個與該 VLAN 關聯的實體埠處於可運作狀態（實際行為依平台與拓撲而定）。

Part 1｜S1 / S2 基本設定

PDF 要求設定 hostname、console password（cisco）、encrypted privileged EXEC password（class）、MOTD banner，最後儲存到 NVRAM。

! 以下為符合實作要求的參考命令（以 S1 為例） Switch> enable Switch# configure terminal Switch(config)# hostname S1 S1(config)# line console 0 S1(config-line)# password cisco S1(config-line)# login S1(config-line)# exit S1(config)# enable secret class S1(config)# banner motd #Authorized access only.# S1(config)# end S1# copy running-config startup-config

對 S2 重複相同步驟，hostname 改為 S2。

Part 2｜設定 PC
  1. PC1 → Desktop → IP Configuration。
  2. PC1 設 192.168.1.1 / 255.255.255.0。
  3. PC2 設 192.168.1.2 / 255.255.255.0。
  4. PC1 → Command Prompt → ping 192.168.1.253。
為什麼這時可能不成功？因為 Part 3 才替 S1 的 VLAN 1 SVI 設定 192.168.1.253。若 S1 還沒有這個管理 IP，就沒有對應的 L3 介面可回覆該 ping。
Part 3｜交換器管理介面
! S1 S1# configure terminal S1(config)# interface vlan 1 S1(config-if)# ip address 192.168.1.253 255.255.255.0 S1(config-if)# no shutdown S1(config-if)# end S1# show ip interface brief S1# show running-config S1# copy running-config startup-config
! S2 S2# configure terminal S2(config)# interface vlan 1 S2(config-if)# ip address 192.168.1.254 255.255.255.0 S2(config-if)# no shutdown S2(config-if)# end S2# show ip interface brief S2# show running-config S2# copy running-config startup-config

最後從 PC1 / PC2 對 PC2、S1、S2 執行 ping。PDF 說所有 ping 應成功；若第一次只有 80%，再試一次通常會變成 100%。常見原因是第一次通訊前需先完成位址解析等前置動作。

PDF 實作問題答案整理
怎麼驗證 console / enable 密碼？離開或重新開啟 console 連線，確認登入需 console 密碼；再進入 privileged EXEC 模式確認 enable secret 生效。
如何存到 NVRAM？copy running-config startup-config（常用縮寫：copy run start）。
交換器既然不需 IP 就能交換，為何要設 IP？為了遠端管理與監控交換器本身，不是為了讓基本 Layer 2 轉送開始運作。
為什麼要 no shutdown？把 SVI 從 administratively down 狀態啟用；但 SVI 實際 line protocol 是否 up 還受 VLAN / 實體埠狀態影響。

8. 延伸必懂：考 CCNA 很值得補上的觀念

Running-config vs Startup-config

running-config 是設備目前正在使用的設定，主要存在 RAM；startup-config 是開機時載入的設定，存於 NVRAM。你只改 running-config 卻沒儲存，設備重開後可能遺失變更。

管理 IP ≠ 交換資料所必需

Layer 2 switch 的資料轉送核心依據是 MAC address table。SVI 管理 IP 是讓管理者「能找到交換器、登入交換器」，不是讓每一個 Ethernet frame 都先經過這個 IP。

/24 的快速理解

255.255.255.0 等價於 /24。在 192.168.1.0/24 中，典型主機位址範圍是 192.168.1.1～192.168.1.254；192.168.1.0 是 network address，192.168.1.255 是 broadcast address。

第一次 ping 可能掉一包

同一乙太網路中，主機在真正送 ICMP Echo 前可能先需要透過 ARP 得知目的端（或下一跳）的 MAC 位址；在模擬器或設備上，這可能讓第一次 ping 顯示部分遺失。這也是 PDF 提醒第一次可能 80% 的實務背景之一。

10. 課後考題｜22 題互動複習

先自己作答，再按「檢查答案」。每題會顯示正確選項與解釋。

1. Windows 手動設定 IPv4 時，應進入哪個項目的 Properties？

影片示範在網路介面內容中選 TCP/IPv4，再開啟 Properties。

2. 影片手動設定範例的 IPv4 位址是？

影片 Windows 畫面中的手動 IP 範例是 192.168.1.10。

3. 255.255.255.0 等價於哪個前綴長度？

255.255.255.0 的前 24 個位元為 1，因此是 /24。

4. Default Gateway 最主要的用途是？

預設閘道就是主機前往非本地網路時常用的出口。

5. Windows 選「Obtain an IP address automatically」通常代表使用？

DHCP 自動提供 IPv4 相關網路參數。

6. 下列哪一項不是 DHCP 常見提供的參數？

DHCP 提供網路設定，不負責發放使用者作業系統登入密碼。

7. DHCPv4 初始租約常用的 DORA 順序是？

DORA 是 DHCPv4 常見的四步記憶法。

8. 影片提到 IPv6 可用哪兩類機制進行動態位址設定？

影片備註 IPv6 使用 DHCPv6 與 SLAAC 等機制。

9. Windows 要快速查看目前 IP、遮罩、閘道，可用？

影片 2.7.3 就用 ipconfig 驗證 Windows IP 設定。

10. Layer 2 交換器為什麼要設定管理 IP？

基本 Layer 2 轉送不依賴管理 IP；管理 IP 是給管理平面使用。

11. SVI 的完整英文是？

SVI = Switch Virtual Interface。

12. 影片設定 VLAN 1 SVI 的第一個介面命令是？

先進入 interface vlan 1，再設定 ip address。

13. 在 SVI 下輸入 no shutdown 的目的為？

no shutdown 是啟用介面的標準 IOS 命令。

14. PDF 中 S1 VLAN 1 的 IP 是？

Packet Tracer PDF Addressing Table 指定 S1 VLAN 1 為 192.168.1.253/24。

15. PDF 中 PC2 的 IP 是？

PDF 指定 PC2 NIC = 192.168.1.2/24。

16. Cisco IOS 查看所有介面 IP 與簡要狀態，PDF 建議哪個命令？

PDF 明確要求用 show ip interface brief 顯示 IP 與狀態。

17. 把目前 running-config 保存成下次開機設定，常用命令是？

此命令把目前設定從 RAM 複製到 NVRAM 中的 startup-config。

18. PDF 的 console password 是？

PDF Part 1 Step 2 指定 console password 使用 cisco。

19. PDF 的 encrypted privileged EXEC password 是？

PDF 指定 privileged EXEC password 使用 class；實務上用 enable secret 設定。

20. 若同網段的兩台主機都設成 192.168.1.10，最可能造成？

同一 Layer 3 子網路中一般主機 IP 必須唯一。

21. 第一次 ping 80%，再次可能 100%，常見背景原因之一是？

先解析下一跳 MAC 後再送 ICMP，是常見造成首次 ping 少一包的原因。

22. 最好的故障排除順序是哪一個？

由底層到上層、由本地到遠端，能最快縮小問題範圍。
