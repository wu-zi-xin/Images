CCNA MODULE 2 · 2.6 PORTS AND ADDRESSES

連接埠和位址
Ports and Addresses

這段課程在講一個很基礎、但非常重要的觀念：裝置要怎麼透過正確的位址、介面、連接埠與網路介質彼此通訊。白話說，單靠「把線插上」還不夠，你還要知道主機的 IP 位址 (IP Address)、子網路遮罩 (Subnet Mask)、預設閘道 (Default Gateway) 是做什麼的；同時也要知道裝置上的 介面 (Interface)、連接埠 (Port)、以及各種 網路介質 (Network Media) 為什麼要互相配合。

影片畫面整理詳細白話解說中英對照按鈕英文發音自製圖解手機友善18 題測驗

1. 本段在學什麼？

影片畫面主要分成兩塊：2.6.1 IP 位址 與 2.6.2 介面和連接埠。前半段教你裝置怎麼被「找到」，後半段教你裝置怎麼被「接起來」。

IP Address｜IP 位址像網路世界中的門牌號碼，讓裝置知道「你是誰」。
Subnet Mask｜子網路遮罩幫你判斷「對方是不是跟我在同一個網段」。
Default Gateway｜預設閘道若對方不在同一網段，就把封包交給它幫忙轉送。
Interface / Port / Media介面、連接埠與網路介質一起決定「怎麼接、能不能通」。
影片內容
影片先說明終端裝置若要彼此通訊，必須具備適當的 IP 位址與正確連線；接著再進入介面、連接埠、網路媒體，以及第 2 層交換器的 SVI 觀念。
白話總結：「位址」回答的是 資料要送去哪裡；「連接埠／介面／介質」回答的是 資料要怎麼送出去。兩邊都對，網路才真的通。

2. 2.6.1 IP 位址

在網路上，裝置之所以能互相找到，是因為每一台主機都有自己的位址。影片強調：如果你希望終端裝置彼此通訊，就必須幫每個裝置設定合適的 IP 位址，而且線路也要接對。

為什麼需要 IP 位址？ IP 位址 IP Address 是裝置在網路中的邏輯位址。它的角色很像「門牌號碼」，沒有它，其他裝置就不知道資料應該送到哪裡。
哪些是終端裝置？ 影片列出的範例包含：電腦、網路印表機、VoIP 電話、保全攝影機、智慧型手機、以及各種 行動手持裝置。
重點一｜IPv4 的樣子長什麼樣

影片指出 IPv4 位址 常見的表示法是 點分隔十進位制表示法 (dotted decimal notation)，也就是用四組 0 到 255 之間的數字來表示，例如：192.168.1.10。課程也特別提醒，本課程裡講的 IP，包含 IPv4 與 IPv6 兩種通訊協定；其中 IPv6 是較新的版本，正在逐漸取代 IPv4。

🧠
不要死背，先理解：IPv4 像是目前仍大量使用的舊式地址系統；IPv6 則像是因應裝置數量爆增而推出的新地址系統，位址空間更大。
重點二｜IPv4 不是只有 IP，還要配子網路遮罩

影片提到，使用 IPv4 位址時，子網路遮罩 (Subnet Mask) 也很重要。它是一個 32 位元的值，用來區分 IP 位址中的 網路部分 (Network Portion) 與 主機部分 (Host Portion)。當你把 IP 位址和子網路遮罩搭配起來，裝置才能知道自己屬於哪一個子網路。

例如影片畫面上的主機設定是：

  • IP 位址：192.168.1.10
  • 子網路遮罩：255.255.255.0
  • 預設閘道：192.168.1.1

這個 /24 代表前 24 位元是網路部分，最後 8 位元是主機部分。

圖解 1：IP 位址、子網路遮罩與預設閘道的關係。圖中同時示範 192.168.1.10/24 的網路部分與主機部分怎麼切開來看。
影片重點補一句：主機若要去遠端網路（包含 Internet），通常要把封包交給 預設閘道 (Default Gateway)，而這個位址通常就是路由器的 IP 位址。

3. IP、遮罩與閘道怎麼配合？

很多初學者會把這三個欄位背起來，卻不知道彼此關係。下面用最白話的方式把它串起來。

步驟 1：先看自己的 IP
例如主機是 192.168.1.10。
→
步驟 2：配合子網路遮罩
例如 255.255.255.0，表示前 24 位是網路部分。
→
步驟 3：判斷對方是否同網段
若對方也是 192.168.1.x，很可能在同一個本地網段。
→
步驟 4：不同網段就交給預設閘道
例如目的地不在本地網段時，封包送給 192.168.1.1。
同網段通訊若來源與目的地在同一個子網路，主機通常可以直接和對方通訊，不必先送到預設閘道。
跨網段通訊若目的地在別的網路，主機就先把資料交給預設閘道，再由路由設備幫忙轉送到其他網路。
額外補充
預設閘道和 DNS 不一樣。預設閘道是幫你「把封包送出去」；DNS 是幫你「把網址翻譯成 IP 位址」。兩者都常出現在主機設定裡，但工作完全不同。
一個超實用的小檢查
看到的問題最可能先檢查什麼
同辦公室兩台主機互 ping 不通IP 是否重複、遮罩是否一致、線路是否插對。
能連本地設備，但上不了網預設閘道是否正確、路由器是否正常。
網址打得開但速度慢不一定是 IP 問題，也可能是頻寬、DNS 或伺服器端問題。

4. 2.6.2 介面和連接埠

影片接著把焦點轉到「裝置怎麼接起來」。網路通訊不只靠位址，還取決於使用者裝置介面、網路裝置介面，以及把它們接起來的線材或無線媒介。

介面 (Interface)是裝置上提供連線能力的地方。它可以是實體的，也可以是虛擬的。
連接埠 (Port)通常指設備上讓你把線接上的地方，例如交換器上的乙太網路孔位。
網路介質 (Network Media)是資料實際傳輸所依附的媒介，例如雙絞線、光纖、同軸或無線。
影片內容
影片強調：每個實體介面都有自己的規格與標準，連接到這些介面的纜線或媒介，也必須符合對應的實體標準；否則就算插上去，也可能無法正常通訊。
圖解 2：從裝置介面、連接埠到網路介質的一次整理。除了影片提到的概念，我也把常見媒體特性一併做成對照，方便複習。
影片直接提到的四種網路媒體
  • 雙絞線銅纜 (Twisted-Pair Copper)：最常見，乙太網路非常常用。
  • 光纖 (Fiber-Optic)：常用於高速、長距離、抗干擾需求較高的環境。
  • 同軸電纜 (Coaxial Cable)：在特定情境仍會看到，例如有線電視或某些舊型網路環境。
  • 無線 (Wireless)：不靠實體纜線，使用電波傳送資料。
白話提醒：介面標準和媒介標準要對得上。像是 RJ-45 的網路孔通常對應雙絞線銅纜；SFP 模組常見於光纖或高速上行鏈路。不是所有線都能插到所有孔，也不是插得進去就代表標準正確。

5. 網路介質比較：怎麼選？

影片明講：不同的網路介質有不同特性，不是每一種都適合所有用途。選擇時至少要考慮下面幾點。

距離 (Distance)能傳多遠？例如一般銅纜常見建議長度約 100 公尺，光纖則可更遠。
環境 (Environment)現場是否有電磁干擾、潮濕、高溫、戶外等條件？
速度／資料量 (Speed / Data Volume)要跑一般辦公流量，還是高頻寬骨幹流量？
成本 (Cost)媒材本身、安裝難度、維護成本，都要算進去。
再往前一步：網路技術也要搭配

影片也提到，網際網路上的每一條連結，不只要使用特定網路媒體，還需要對應的網路技術。最常見的例子就是 乙太網路 (Ethernet)，它是目前最普遍的區域網路 LAN (Local Area Network) 技術。你在電腦、交換器、路由器等裝置上看到的很多乙太網路孔，都是為了這類連線而設計的。

📌
考試常考點：媒介是「用什麼傳」，技術是「依照什麼規則傳」。雙絞線是一種媒介；乙太網路是一種常見 LAN 技術。

6. Layer 2 交換器與 SVI

這一段是影片非常關鍵、也很容易讓初學者卡住的地方：第 2 層交換器有很多實體連接埠，但這些埠本身通常不拿來設定 Layer 3 的 IP 位址。那交換器若要被遠端管理，IP 要設在哪？答案就是 SVI。

圖解 3：Layer 2 交換器的實體連接埠與 SVI。實體埠負責連接設備並進行 Layer 2 轉送；管理 IP 則通常配置在 SVI（例如 VLAN 1）上，用於遠端管理。
實體連接埠 (Physical Ports)這些埠主要是讓電腦、電話、AP、伺服器等設備接上來，交換器靠 MAC 位址 進行第 2 層轉送，不需要在每個實體埠上各自設定 IP。
交換器虛擬介面 (SVI, Switch Virtual Interface)這是邏輯上的介面，用來讓你透過 IPv4 或 IPv6 遠端管理交換器。影片指出：每台交換器的預設 SVI 通常是 VLAN 1。
影片中的關鍵句：第 2 層交換器本身不需要 IP 位址就能執行交換工作；指派給 SVI 的 IP，主要是為了遠端存取與管理，而不是為了讓交換器完成基本的第 2 層轉送。
額外補充
如果你想從別的網段遠端連到交換器，除了設定 SVI 的 IP，通常還會設定交換器的 ip default-gateway，讓管理流量知道該往哪裡送。
常見管理設定範例（補充）
! 設定交換器管理 SVI（範例）
Switch(config)# interface vlan 1
Switch(config-if)# ip address 192.168.1.2 255.255.255.0
Switch(config-if)# no shutdown
Switch(config)# ip default-gateway 192.168.1.1

這段不是影片逐字內容，而是根據影片觀念補上的典型管理設定，方便你把「SVI 的用途」跟實際操作對起來。

7. 重點速記

考前或複習前只剩 3 分鐘時，看這裡最快。

主題一句話重點你要記得什麼
IP 位址裝置在網路中的邏輯位址。沒有 IP，裝置就很難被其他設備正確找到。
子網路遮罩用來切分網路部分與主機部分。它決定主機如何判斷「同網段 or 不同網段」。
預設閘道前往其他網路時先交給它。通常就是路由器在本地網段上的位址。
介面與連接埠提供連線點，讓媒介接上去。標準要相符，才能正常連線。
網路介質雙絞線、光纖、同軸、無線，各有特性。挑選時要看距離、環境、速度／資料量、成本。
Layer 2 交換器實體埠主要做第 2 層交換，不必每埠設 IP。管理 IP 通常設在 SVI，例如 VLAN 1。
最容易混淆的點：「實體連接埠」不是「TCP/UDP 連接埠號碼」的那種 port。這支課程裡講的 port，主要是在講設備上的實體或邏輯連線埠，例如交換器上的乙太網路埠。

9. 課後考題

共 18 題。作答後按「檢查答案」會顯示正確選項與每題說明。

1. IP 位址最主要的用途是什麼？

IP 位址是裝置的邏輯位址，用來讓其他裝置找到它並傳送資料。

2. 下列哪一項是影片列出的終端裝置範例？

影片明列了多種終端裝置範例，包含電腦、印表機、VoIP 電話、攝影機、手機等。

3. IPv4 點分隔十進位制表示法，通常是幾組數字？

IPv4 常見寫法像 192.168.1.10，由四組十進位數字組成。

4. 子網路遮罩的主要用途是？

子網路遮罩幫主機判斷 IP 的哪一部分代表網路、哪一部分代表主機。

5. 當目的地不在本地網段時，主機通常先把封包交給誰？

預設閘道通常是本地路由設備，用來幫主機把封包轉送到其他網路。

6. 影片提到本課程中的 IP，包含哪兩種協定？

影片特別註明，課程中的 IP 是指 IPv4 與 IPv6。

7. 網路通訊取決於下列哪個組合？

影片 2.6.2 一開始就指出，介面與網路媒介共同決定連線是否成立。

8. 下列哪一個不是影片提到的網路介質類型？

影片列出的媒體有雙絞線、光纖、同軸與無線。

9. 影片說明選擇網路媒介時，可以比較哪些面向？

影片逐條列出不同介質之間的幾種差異，這些都是設計網路時的重要考量。

10. 目前最常見的 LAN 技術之一是？

影片提到乙太網路（Ethernet）是目前最常用的區域網路技術。

11. Cisco IOS 第 2 層交換器的實體連接埠，通常如何看待？

第 2 層交換器靠實體埠轉送乙太網路訊框，但管理 IP 不是設在每個實體埠上。

12. SVI 是什麼？

SVI 的全名是 Switch Virtual Interface，中文常譯為交換器虛擬介面。

13. 影片指出每台交換器預設就帶有一個 SVI，通常是哪一個？

影片明講：預設 SVI 是介面 VLAN 1。

14. 指派給 SVI 的 IP 位址，主要用途是什麼？

Layer 2 交換器本身不靠這個 IP 來做交換，而是用來讓管理者遠端登入管理。

15. 第 2 層交換器若沒有設定管理 IP，是否仍可進行基本的 Layer 2 交換？

這題就是影片的核心：L2 交換器不需要 IP 才能做基本交換，但若要遠端管理，就常會配置 SVI 的 IP。

16. 下列哪個敘述最能說明「介面標準必須與媒介標準相符」？

標準要相符是物理層與資料連結層的基本概念，不是「插得進去」就一定表示可用。

17. 下列哪一個比較接近「同網段時可直接通訊」的情境？

前兩者網段不同，通常要透過閘道；只有同一個 192.168.1.0/24 網段的主機較可能直接互通。

18. 哪一句話最能當作這堂課的總結？

這就是整支影片最核心的理解：位址與連線條件缺一不可。
