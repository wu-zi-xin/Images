3.3.1 - 3.3.3 網路協定套件與演進

3.3.1 Network Protocol Suites (網路協定套件)

在多數情況下，協定必須與其他協定協同運作，才能提供您網路通訊所需的完整體驗。這些設計用來無縫合作的協定組合，稱為「協定套件 (Protocol Suite)」。

Protocol Suite
A protocol suite is a group of inter-related protocols necessary to perform a communication function. 協定套件是一組相互關聯的協定，是執行通訊功能所必需的。
通訊堆疊 (Stack)
可以將協定套件想像成一個堆疊 (Stack)。較高層 (Higher layers) 關注正在傳送的訊息內容與服務；較低層 (Lower layers) 則關注如何透過網路移動資料。
3.3.2 Evolution of Protocol Suites (協定套件的演進)

自 1970 年代以來，發展了幾種不同的協定套件。如今，TCP/IP 是最普遍的標準。

協定套件 說明 (Description)
TCP/IP Internet Protocol Suite or TCP/IP: The most common and relevant protocol suite used today. It is an open standard protocol suite maintained by the IETF. (今日最常見且相關的協定套件。它是由網際網路工程任務組 (IETF) 維護的開放標準。)
OSI Open Systems Interconnection (OSI) protocols: Developed by ISO and ITU. Largely replaced by TCP/IP. (由國際標準化組織 (ISO) 和國際電信聯盟 (ITU) 開發。現已大多被 TCP/IP 取代。)
AppleTalk & Novell NetWare Proprietary protocol suites developed by Apple and Novell. Both have adopted TCP/IP. (過去由 Apple 和 Novell 開發的專有協定。現在兩者皆已改用 TCP/IP。)
TCP/IP
今日最常見、由 IETF 維護的開放標準協定套件。
The most common open standard protocol suite.
OSI
由 ISO 和 ITU 開發，雖然概念重要，但實務上已被 TCP/IP 取代。
3.3.3 TCP/IP Protocol Example (TCP/IP 運作範例)

當網頁伺服器傳送資料給客戶端時，會使用不同層級的協定組合：

  • Application (應用層): Hypertext Transfer Protocol (HTTP) - 定義網頁資料格式。
  • Transport (傳輸層): Transmission Control Protocol (TCP) - 負責將資料分段與可靠傳輸。
  • Internet (網際網路層): Internet Protocol (IP) - 負責定址與路由尋徑。
  • Network Access (網路存取層): Ethernet - 負責在實體媒體上傳輸訊框。

3.3.4 TCP/IP Protocol Suite

各層級的重要協定

TCP/IP 協定套件包含許多協定。以下列出四個層級中最關鍵的幾個：

層級 (Layer) 重要協定與功能 (Protocols)
Application
(應用層)		 DNS (Domain Name System): Translates domain names into IP addresses. (將網域名稱解析為 IP 位址，例如 www.cisco.com -> 192.168.1.1)

DHCPv4 (Dynamic Host Configuration Protocol): Dynamically assigns IPv4 addressing information to DHCPv4 clients. (動態分配 IPv4 位址資訊給客戶端。)

HTTP (Hypertext Transfer Protocol): Rules for exchanging text, graphic, video on the WWW. (在網際網路上交換文字、圖片等網頁資源的規則。)
Transport
(傳輸層)		 TCP (Transmission Control Protocol): Enables reliable communication, provides acknowledged transmissions. (提供可靠的通訊，具備確認回傳機制，確保資料成功送達。)

UDP (User Datagram Protocol): Enables process sending packets to another host, unacknowledged, best-effort. (無確認機制、盡力傳送，速度快但不保證送達，常用於影音串流。)
Internet
(網際網路層)		 IPv4 / IPv6 (Internet Protocol): Receives segments, packages into packets, routes end-to-end using IP addresses. (將資料分段打包成封包，並使用 IP 位址進行端對端路由。)

ICMPv4 / ICMPv6 (Internet Control Message Protocol): Provides feedback about errors in packet delivery. (提供封包傳遞過程中的錯誤回報與診斷，例如 ping 工具底層就是用 ICMP。)

OSPF (Open Shortest Path First): Link-state routing protocol. (一種開放標準的鏈路狀態路由協定。)
Network Access
(網路存取層)		 ARP (Address Resolution Protocol): Provides dynamic address mapping between an IPv4 address and a hardware address (MAC). (將已知的 IP 位址對應解析成實體硬體 MAC 位址。)

Ethernet: Defines rules for wiring and signaling standards. (定義有線網路的佈線與訊號標準。)

WLAN: Defines rules for wireless signaling (Wi-Fi). (定義無線網路通訊的規則。)
Application (應用層)
• DNS: 網域轉 IP。
• DHCP: 動態分配 IP。
• HTTP: 網頁傳輸。
• SMTP/POP3: 電子郵件收發。
Transport (傳輸層)
• TCP: 連線導向，可靠傳輸 (有確認機制)。
• UDP: 非連線導向，盡力傳送 (速度快)。
Internet (網際網路層)
• IP (IPv4/IPv6): 邏輯定址與路由。
• ICMP: 錯誤回報與診斷 (如 ping)。
• OSPF/EIGRP: 路由協定。
Network Access (網路存取層)
• ARP: 透過 IP 尋找 MAC 位址。
• Ethernet: 乙太網路有線標準。
• WLAN: 無線網路 (Wi-Fi) 標準。

3.3.5 TCP/IP Communication Process

封裝過程 (Encapsulation Process)

當網頁伺服器準備傳送資料給客戶端時，資料必須由上往下經過各層的「封裝 (Encapsulation)」，每一層都會加上自己的標頭 (Header) 資訊：

發送端 (Web Server) 的封裝順序：
1. User Data (網頁內容)
⬇️ 加上 TCP 標頭
2. TCP Segment (資料段)
⬇️ 加上 IP 標頭
3. IP Packet (封包)
⬇️ 加上 Ethernet 標頭與標尾
4. Ethernet Frame (訊框)
⬇️ 轉換為位元流
01010110100101... (Bits 在網路上傳輸)
💡 接收端的解封裝 (De-encapsulation)：
當客戶端收到 0101... 的訊號後，會執行反向的動作。從 Ethernet Frame 中剝離標頭，交給 IP 層處理；接著剝離 IP 標頭交給 TCP 層，最後重組出 User Data 交給瀏覽器顯示。

📝 課後複習測驗 (Check Your Understanding)

Protocol Suites 隨堂測驗

依據課程內容，點擊卡片查看正確解答與詳細解析！

Q1. 協定層級

UDP and TCP belong to which layer of the TCP/IP protocol?

(UDP 和 TCP 屬於 TCP/IP 協定套件中的哪一層？)
👉 點擊翻開看解答
解答
Transport (傳輸層)
解析：TCP (提供可靠連線) 與 UDP (提供快速非連線傳輸) 皆為傳輸層的核心協定。注意：影片中測驗選擇 Internet 是錯誤的示範。
Q2. 應用層協定

Which two protocols belong in the TCP/IP model application layer?

(下列哪兩個協定屬於 TCP/IP 模型的應用層？
選項：ICMP, DNS, OSPF, EIGRP, DHCP)
👉 點擊翻開看解答
解答
DNS, DHCP
解析：DNS (網域解析) 與 DHCP (動態 IP 分配) 皆為應用層服務。ICMP 和 OSPF/EIGRP 屬於 Internet 層。
Q3. 網路存取層

Which protocol operates at the network access layer of the TCP/IP model?

(哪一個協定運作在 TCP/IP 模型的網路存取層？
選項：IP, DNS, HTTP, Ethernet)
👉 點擊翻開看解答
解答
Ethernet (乙太網路)
解析：Ethernet 與 WLAN 負責底層實體連線與資料連結，屬於網路存取層 (Network Access Layer)。
Q4. 錯誤回報機制

Which protocols provide feedback from the destination to the source regarding errors in packet delivery?

(哪兩個協定會將封包傳遞錯誤的資訊，從目的端回報給來源端？)
👉 點擊翻開看解答
解答
ICMPv4, ICMPv6
解析：ICMP (Internet Control Message Protocol) 是網際網路層專門用來回報網路不可達、超時等錯誤訊息的控制協定。
Q5. 解封裝順序

A device receives a frame and removes Ethernet info. What info is processed next?

(接收端設備移除了 Ethernet 訊框資訊後，下一步要處理什麼層級的資訊？)
👉 點擊翻開看解答
解答
IP at the internet layer
解析：資料由下往上解封裝。剝去最低層的 Ethernet (Network Access) 標頭後，露出的就是上一層的 IP 封包 (Internet layer)。
Q6. Internet 層服務

Which services are provided by the internet layer? (Choose three.)

(Internet 層提供哪些服務？請選三項
選項：Ethernet, Internet Protocol, File Transfer, Address Resolution, Routing Protocols, Messaging)
👉 點擊翻開看解答
解答
Internet Protocol, Routing Protocols, Messaging
解析：Internet 層主要包含 IP (Internet Protocol)、路由協定 (如 OSPF/EIGRP) 以及訊息傳遞 (Messaging，即 ICMP)。
