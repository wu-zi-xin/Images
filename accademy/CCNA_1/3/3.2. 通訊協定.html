3.2.1 網路通訊協定概觀 (Network Protocol Overview)

什麼是通訊協定？ (What are Protocols?)

你知道為了讓終端裝置能夠在網路上進行通訊，每個裝置都必須遵守同一套規則。這些規則被稱為「通訊協定 (Protocols)」，它們在網路中具有許多功能。

網路通訊協定定義了裝置之間交換訊息的共通格式和規則集。通訊協定可由終端裝置與中介裝置透過軟體、硬體或兩者結合來實作。每一個網路通訊協定都有其專屬的通訊功能、格式與規則。

Protocol Type (協定類型) Description (說明)
Network Communications (網路通訊) Protocols enable two or more devices to communicate over one or more networks. The Ethernet family of technologies involves a variety of protocols such as IP, Transmission Control Protocol (TCP), HyperText Transfer Protocol (HTTP), and many more. (通訊協定使兩個或多個裝置能夠在一個或多個網路上進行通訊。乙太網路技術系列包含各種通訊協定，例如 IP、TCP、HTTP 等等。)
Network Security (網路安全) Protocols secure data to provide authentication, data integrity, and data encryption. Examples of secure protocols include Secure Shell (SSH), Secure Sockets Layer (SSL), and Transport Layer Security (TLS). (通訊協定保護資料以提供身分驗證、資料完整性和資料加密。安全通訊協定的範例包括 SSH、SSL 和 TLS。)
Routing Protocols (路由協定) Protocols enable routers to exchange route information, compare path information, and then to select the best path to the destination network. Examples of routing protocols include Open Shortest Path First (OSPF) and Border Gateway Protocol (BGP). (通訊協定使路由器能夠交換路由資訊、比較路徑資訊，然後選擇通往目的地網路的最佳路徑。路由協定的範例包括 OSPF 和 BGP。)
Service Discovery (服務探索) Protocols are used for the automatic detection of devices or services. Examples of service discovery protocols include Dynamic Host Configuration Protocol (DHCP) which discovers services for IP address allocation, and Domain Name System (DNS) which is used to perform name-to-IP address translation. (通訊協定用於自動偵測裝置或服務。服務探索協定的範例包括用於 IP 位址分配的 DHCP，以及用於執行名稱對應 IP 位址轉換的 DNS。)

3.2.2 網路通訊協定功能 (Network Protocol Functions)

通訊協定的重要功能

網路通訊協定負責終端裝置間進行網路通訊所需的各種功能。例如：電腦如何透過多個網路裝置將訊息傳送到伺服器？
裝置在傳遞資料時，皆須使用共同認可的通訊協定 (如圖中的 IPv4 Header) 才能溝通。

Function (功能) Description (說明)
Addressing
(定址)		 This identifies the sender and the intended receiver of the message using a defined addressing scheme. Examples of protocols that provide addressing include Ethernet, IPv4, and IPv6. (使用定義好的定址方案來識別訊息的發送者和預期接收者。提供定址的協定範例包括乙太網路 (Ethernet)、IPv4 和 IPv6。)
Reliability
(可靠性)		 This function provides guaranteed delivery mechanisms in case messages are lost or corrupted in transit. TCP provides guaranteed delivery. (此功能提供「保證交付機制」，以防訊息在傳輸過程中遺失或損壞。TCP 提供保證交付功能。)
Flow control
(流量控制)		 This function ensures that data flows at an efficient rate between two communicating devices. TCP provides flow control services. (此功能確保資料在兩個通訊裝置之間以有效率的速率流動。TCP 提供流量控制服務。)
Sequencing
(排序)		 This function uniquely labels each transmitted segment of data. The receiving device uses the sequencing information to reassemble the information correctly. This is useful if the data segments are lost, delayed or received out-of-order. TCP provides sequencing services. (此功能為每個傳輸的資料片段(Segment)加上唯一的標籤。接收裝置利用排序資訊來正確重組資料。當資料片段遺失、延遲或未按順序到達時非常有用。TCP 提供排序服務。)
Error Detection
(錯誤偵測)		 This function is used to determine if data became corrupted during transmission. Various protocols that provide error detection include Ethernet, IPv4, IPv6, and TCP. (此功能用於判斷資料在傳輸過程中是否損壞。提供錯誤偵測的各種協定包括乙太網路、IPv4、IPv6 和 TCP。)
Application Interface
(應用程式介面)		 This function contains information used for process-to-process communications between network applications. For example, when accessing a web page, HTTP or HTTPS protocols are used to communicate between the client and server web processes. (此功能包含用於網路應用程式之間「行程對行程 (process-to-process)」通訊的資訊。例如，存取網頁時，會使用 HTTP 或 HTTPS 來進行客戶端與伺服器網頁行程間的通訊。)
Addressing (定址)
識別訊息發送者和接收者。例如：Ethernet, IPv4, IPv6.
Reliability (可靠性)
提供保證交付機制，防止資料遺失。例如：TCP.
Flow control (流量控制)
確保資料在通訊裝置之間以高效率流動。例如：TCP.
Sequencing (排序)
為資料片段加上獨特標籤，讓接收端正確重組。可處理遺失或亂序問題。例如：TCP.
Error Detection (錯誤偵測)
判斷資料在傳輸中是否損壞。例如：Ethernet, IPv4, IPv6, TCP.
Application Interface (應用程式介面)
用於網路應用程式的行程對行程通訊。例如：網頁存取使用的 HTTP/HTTPS.

3.2.3 協定互動 (Protocol Interaction)

網路堆疊 (Protocol Stack) 運作範例

透過電腦網路傳送訊息，通常需要使用「多種」通訊協定，每個協定都有自己的功能和格式。
當裝置向網頁伺服器請求網頁時，會使用以下常見的網路通訊協定堆疊：

HTTP
TCP
IP
Ethernet
  • Hypertext Transfer Protocol (HTTP)： This protocol governs the way a web server and a web client interact. HTTP defines the content and formatting of the requests and responses... HTTP relies on other protocols to govern how the messages are transported.
    (控制網頁伺服器和網頁客戶端互動的方式。定義請求和回應的內容與格式。HTTP 依賴其他協定來負責訊息的實際傳輸。)
  • Transmission Control Protocol (TCP)： This protocol manages the individual conversations. TCP is responsible for guaranteeing the reliable delivery of the information and managing flow control between the end devices.
    (管理個別對話。TCP 負責保證資訊的「可靠傳遞」，並管理終端裝置之間的「流量控制」。)
  • Internet Protocol (IP)： This protocol is responsible for delivering messages from the sender to the receiver. IP is used by routers to forward the messages across multiple networks.
    (負責將訊息從發送端傳遞至接收端。路由器使用 IP 在多個網路之間轉發訊息。)
  • Ethernet (乙太網路)： This protocol is responsible for the delivery of messages from one NIC to another NIC on the same Ethernet local area network (LAN).
    (負責在「同一個乙太區域網路 (LAN)」上，將訊息從一張網路卡 (NIC) 傳送到另一張網路卡。)

Question 1

BGP and OSPF are examples of which type of protocol?

(BGP 和 OSPF 是哪種類型的通訊協定範例？)
👉 點擊翻開看解答
解答
Routing (路由協定)
解析：Routing protocols 使路由器能夠交換路由資訊並選擇抵達目標網路的最佳路徑。
Question 2

Which two protocols are service discovery protocols? (Choose two.)

(哪兩個通訊協定屬於「服務探索協定」？請選兩項)
👉 點擊翻開看解答
解答
DNS 與 DHCP
解析：Service Discovery Protocols 用於自動偵測設備或服務。DNS 提供名稱轉換 IP 服務，DHCP 則提供 IP 位址自動分配服務。
Question 3

What is the purpose of the sequencing function in network communication?

(在網路通訊中，「排序」功能的目的是什麼？)
👉 點擊翻開看解答
解答
To uniquely label transmitted segments of data for proper reassembly by the receiver.
解析：(為傳輸的資料片段貼上唯一標籤，以便接收方正確重組)。這對於處理封包遺失或亂序的情況非常重要。
Question 4

This protocol is responsible for guaranteeing the reliable delivery of information.

(哪一個通訊協定負責「保證資訊的可靠傳遞」？)
👉 點擊翻開看解答
解答
TCP (傳輸控制協定)
解析：TCP 提供了確認機制 (Reliability) 以及流量控制，以確保資料在傳輸過程中若遺失能夠被重新發送。
