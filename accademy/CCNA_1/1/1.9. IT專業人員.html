1. 本段在學什麼？

影片 1.9 的重點可以濃縮成三句：先理解 CCNA 與 IT 技能的關係，再知道去哪裡找網路工作，最後透過實驗真正研究職缺與職涯方向。

Certification｜認證用考試與標準化目標證明你具備某一範圍的知識與技能。
Skills｜技能網路不只 IP 與設備，還會碰到安全、無線、自動化與可程式化。
Jobs｜工作可以從 NetAcad 職涯資源、人才媒合與一般求職平台找職缺。
Evidence｜證據履歷不只寫「學過」，最好能用 Lab、Packet Tracer、設定檔與故障排除紀錄證明。
影片來源
影片 1.9.1～1.9.3 依序談 CCNA、網路工作與「研究資訊科技 IT 及網路就業機會」實驗。

2. 1.9.1 CCNA：它代表什麼？

影片強調，網路工程師的角色與所需技能正在演進；CCNA（Cisco Certified Network Associate）用來證明學習者具備基礎網路技術知識，以及採用下一代網路技術所需的技能組合。

CCNA｜Cisco Certified Network Associate

白話來說：它不是「你已經是資深工程師」的保證，而是用一套共同標準證明你具備進入網路領域的重要基礎。

技能會演進，不只會接線

影片點出新的網路技能已涵蓋 IP、資訊安全、無線、自動化與網路可程式化等方向。這代表網路工程師越來越需要理解「系統如何自動管理」與「如何安全地運作」。

不要把認證和實力畫上等號：認證能證明你達到一套知識標準；真正工作能力還需要實作、故障排除、溝通、文件紀錄與持續學習。

2026 官方更新
目前 Cisco 官方的 CCNA 200-301 v1.1 考試仍涵蓋 Network Fundamentals、Network Access、IP Connectivity、IP Services、Security Fundamentals，以及 Automation and Programmability；這與影片強調的「基礎 + 安全 + 自動化」方向一致。

4. 認證與職涯路徑：影片內容 vs. 2026 現況

影片介紹 associate、specialist、professional、expert 等級，也提到 DevNet 認證。這段最容易因時間而變動，所以要分開看。

自製示意：層級越高通常代表更深的技術範圍與實作要求；實際認證名稱與考試規則應以 Cisco 當期官方頁面為準。
影片來源
影片提到新的 DevNet 認證包含 associate、specialist、professional 等級，也說可依工作角色與專業選擇 Specialist 認證；並強調不同認證路徑可依個人目標開始。
2026 官方更新
自 2026-02-03 起，Cisco 將既有 DevNet Associate / Professional / Expert 的有效持有人分別對應為 CCNA Automation / CCNP Automation / CCIE Automation。也就是說，影片中的「DevNet」概念仍值得理解，但現行品牌與命名已更新。考試與認證名稱屬於會變動的資訊，準備報考時一定要回 Cisco 官方確認。

5. 1.9.2 網路工作（Networking Jobs）

影片的核心不是指定你只能做哪一個職稱，而是教你「去哪裡找機會」與「用什麼關鍵字找」。

Cisco Networking Academy / NetAcad

影片示範從 NetAcad 的 Careers / Employment Opportunities 找職涯與工作資源，並提到 Talent Bridge Matching Engine，用技能與雇主需求做媒合。

一般求職搜尋引擎

影片舉例可使用 Indeed、Glassdoor、Monster 等求職網站，並用 IT 與網路相關職稱或「Cisco CCNA」當搜尋關鍵字。

2026 官方更新
Cisco Networking Academy 目前仍提供 Career Prep、職缺資源與 Talent Bridge；官方描述 Talent Bridge 的用途就是把 Networking Academy 學生與全球雇主連結起來。

6. 常見工作職稱：看到名稱要先看「工作內容」

Network Technician
網路技術員
偏向安裝、基本設定、佈線、設備檢查、現場支援與第一線故障排除。適合累積實務經驗。
Network Administrator
網路管理員
日常維運 LAN/WAN、IP、交換器／路由器、帳號權限、監控、備份與故障處理。不同公司職責差異可能很大。
Network Engineer
網路工程師
通常比「管理員」更著重設計、建置、擴充、效能、路由交換、安全與跨系統整合；但職稱沒有全球統一標準。
Network Support
網路支援
處理使用者連線、設備、VPN、Wi‑Fi、DNS/DHCP 等問題，並把複雜問題升級給二、三線工程師。
Systems / IT Administrator
系統／IT 管理員
常同時管伺服器、端點、身分、雲端與網路。中小企業裡，一個人可能同時兼多個領域。
重要延伸
不要只用職稱判斷適不適合。同樣叫 Network Engineer，有的職缺偏 NOC 監控，有的偏路由交換，有的偏雲端與自動化。真正要比的是 Job Description（職務說明）裡的技能、責任、值班、經驗與工具。

8. 1.9.3 實驗：研究資訊科技 IT 及網路就業機會

影片最後不是再塞一堆理論，而是要你實際研究工作機會。畫面列出兩個部分：尋找工作機會，以及進一步研究 IT 職涯／職缺。

第 1 部分｜尋找工作機會

使用 NetAcad 職涯資源或求職網站，搜尋與 networking、CCNA、IT support、network administrator 等關鍵字相關的職缺。

第 2 部分｜研究職缺與職涯

不要只記公司名稱；要整理職缺要求、工作內容、地點、經驗、學歷、認證、技術工具與軟技能，最後比較自己還缺什麼。

9. 延伸：CCNA 初學者最值得做的作品集

這不是影片逐字內容，而是把「認證 → 工作」中間最容易缺的一塊補起來：讓雇主看到你能把知識做出來。

Campus Network Lab｜校園網路實驗VLAN、Trunk、Inter-VLAN Routing、DHCP、IPv4/IPv6。附拓樸圖、IP 規劃表與驗證指令。
Troubleshooting Log｜故障排除紀錄故意做錯 VLAN、gateway、ACL 或 routing，記錄症狀 → 假設 → 指令 → 根因 → 修復。
Secure Remote Access｜安全遠端存取用概念圖說明 VPN、AAA、ACL 與最小權限如何搭配；若沒有真設備，可用模擬與文件呈現。
面試加分點
作品集最有價值的不是「圖很漂亮」，而是你能說清楚：需求是什麼 → 為什麼這樣設計 → 怎麼驗證 → 出錯怎麼查 → 還能怎麼改進。
