CCNA 1 - Module 1: Network Components (1.2 網路元件)

1.2.1 主機角色 (Host Roles)
English
All computers that are connected to a network and participate directly in network communication are classified as hosts. Hosts can be called end devices.

Servers are computers with software that allow them to provide information, like email or web pages, to other end devices on the network.
中文翻譯
所有連接到網路並直接參與網路通訊的電腦都被歸類為主機。主機也可以稱為終端設備。

伺服器是配備軟體的電腦，允許它們提供資訊給網路上的其他終端設備，例如電子郵件或網頁。
💡 補充：常見的伺服器類型
  • Email (電子郵件伺服器): 執行電子郵件伺服器軟體，客戶端使用電子郵件客戶端軟體來存取電子郵件。
  • Web (網頁伺服器): 執行網頁伺服器軟體，客戶端使用瀏覽器來存取伺服器上的網頁。
  • File (檔案伺服器): 儲存企業與使用者檔案在一個集中的位置。
1.2.2 對等網路 (Peer-to-Peer)
English
Client and server software usually run on separate computers, but it is also possible for one computer to be used for both roles at the same time. This type of network is called a peer-to-peer network.
中文翻譯
客戶端與伺服器軟體通常在不同的電腦上執行，但也可能有一台電腦同時扮演這兩種角色。這種類型的網路被稱為對等網路。
Advantages
(優點)
  • Easy to set up (易於設定)
  • Less complex (較不複雜)
  • Lower cost (成本較低)
Disadvantages
(缺點)
  • No centralized administration (沒有集中管理)
  • Not as secure (較不安全)
  • Not scalable (不可擴展)

CCNA 1 - 1.2.3 ~ 1.2.5 設備與傳輸媒體

1.2.3 終端設備 (End Devices) 與 1.2.4 中間設備 (Intermediary Devices)
English
The network devices that people are most familiar with are end devices. To distinguish one end device from another, each end device on a network has an address.

Intermediary devices connect the individual end devices to the network. They can connect multiple individual networks to form an internetwork.
中文翻譯
人們最熟悉的網路設備是終端設備。為了區分不同的終端設備，網路上的每個終端設備都有一個位址。

中間設備將各個終端設備連接到網路。它們可以連接多個獨立的網路以形成一個互聯網。
💡 實務補充：常見的中間設備
影片中提到的常見中間設備範例包含：Wireless Router (無線路由器)、LAN Switch (區域網路交換器)、Router (路由器)、Multilayer Switch (多層交換器) 以及 Firewall Appliance (防火牆設備)。
1.2.5 網路媒體 (Network Media)
English
Communication transmits across a network on media. The media provides the channel over which the message travels from source to destination. Modern networks primarily use three types of media to interconnect devices.
中文翻譯
通訊在網路上透過媒體傳輸。媒體提供了訊息從來源傳遞到目的地的通道。現代網路主要使用三種媒體來互連設備。
Metal wires within cables
(Copper / 銅線)
Data is encoded into electrical impulses. (資料被編碼為電脈衝。)
Glass or plastic fibers
(Fiber-optic / 光纖)
Data is encoded into pulses of light. (資料被編碼為光脈衝。)
Wireless transmission
(無線傳輸)
Data is encoded via modulation of specific frequencies of electromagnetic waves. (資料透過特定頻率的電磁波調變進行編碼。)
Media Type (媒體類型) Description (描述與編碼方式)
Metal wires within cables (Copper / 銅線) Data is encoded into electrical impulses. (資料被編碼為電脈衝。)
Glass or plastic fibers (Fiber-optic / 光纖) Data is encoded into pulses of light. (資料被編碼為光脈衝。)
Wireless transmission (無線傳輸) Data is encoded via modulation of specific frequencies of electromagnetic waves. (資料透過特定頻率的電磁波調變進行編碼。)
