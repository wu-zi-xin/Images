網路趨勢
Network Trends

這一段把「網路正在怎麼改變我們使用裝置、工作、溝通與上網」串在一起。重點包括 BYOD、線上協作、視訊通訊、雲端運算、智慧家庭，以及在不同環境中提供連線的電力線網路與無線寬頻。

1. 本段在學什麼？

影片從「近期趨勢」切入，指出網路會持續改變，而組織與使用者必須跟著適應。後續依序介紹裝置使用方式、協作與視訊、雲端服務、智慧家庭，以及家庭／偏遠地區可能採用的替代連線方式。

BYOD把「我的裝置」安全地接入組織網路。
Collaboration + Video讓不同地點的人可以一起工作與溝通。
Cloud Computing把儲存、應用與 IT 功能延伸到遠端資料中心。
Alternative Access電力線與無線寬頻提供不同的「最後一段連線」方法。
影片來源
1.7.1 列出的近期網路趨勢包括：自攜裝置（BYOD）、線上協同合作、視訊通訊、雲端運算。

2. 1.7.1 近期趨勢（Recent Trends）

網路不是建好就永遠不變。新技術與新裝置會改變使用方式，企業與消費者都必須持續適應。

BYOD｜自攜裝置個人擁有的裝置進入工作或學習網路。
Online Collaboration｜線上協同合作透過網路讓多人共同工作、分享與溝通。
Video Communications｜視訊通訊利用即時影音跨越距離進行會議與互動。
Cloud Computing｜雲端運算把資料、應用或 IT 功能放到網路上的資料中心來提供。
白話記法：裝置變多 → BYOD；人不在同一地點 → Collaboration / Video；服務不一定放在本機 → Cloud。

3. 1.7.2 自攜裝置（Bring Your Own Device, BYOD）

影片把 BYOD 描述為一個全球趨勢：使用者把自己擁有的裝置安全連接到組織網路，從企業或學校資源中取得資訊與通訊服務。

Own Device｜自己的裝置可能包含桌上型電腦、筆記型電腦、平板、智慧型手機、電子閱讀器等。
Access Anywhere｜彈性使用使用者可在不同地方用熟悉的個人裝置完成工作與學習。
Secure Connection｜安全連線「能接」只是第一步；影片明確強調要安全地連到網路。
自製示意：BYOD 的核心不是特定品牌，而是「個人擁有的多種裝置」可安全接入組織網路。
CCNA 延伸
安全與管理是 BYOD 的代價。實務上常需要身分驗證、存取控制、端點合規與來賓網路等機制。這些是用來補足「個人裝置不完全由組織控制」的風險，並非影片本頁逐項列出。

4. 1.7.3 線上協同合作（Online Collaboration）

協作不只是「一起聊天」，而是多人在共同專案中一起工作。影片指出，這對組織競爭力與教育都很重要，學生也需要培養團隊合作能力。

協同合作在做什麼？

讓員工、學生、教師、客戶與合作夥伴能立即連線、互動、交換資訊並共同完成目標。

影片中的工具範例

Cisco Webex / Webex Teams 被用來示範多人溝通與協作。影片畫面提到可傳送即時訊息、張貼圖片與影片／連結，並保留團隊空間的歷史紀錄。

自製示意：協作平台把不同角色連進共同工作空間，重點是「共同完成工作」而不只是一對一通訊。

5. 1.7.4 視訊通訊（Video Communications）

影片指出，視訊是網路中溝通與協作的重要面向，可用於通訊、協作與娛樂；有網路連線的人即使身處不同地方，也能進行視訊通話。

Remote Presence｜遠端在場感影音讓彼此看到表情與動作，比只靠文字或聲音有更多溝通線索。
Cross-location｜跨地點可在本地或全球不同位置間進行視訊會議。
Collaboration Enabler｜協作促進器當組織跨越地理與文化界線，視訊成為有效協作的重要工具。
容易混淆：「線上協同合作」是較大的概念；「視訊通訊」是其中一種溝通媒介。協作平台還可以包含訊息、檔案與其他共享功能。

7. 1.7.6 雲端運算（Cloud Computing）

雲端運算讓使用者透過網路儲存、存取資料與使用服務。影片也從企業角度說明：組織不一定要自行投資所有新基礎架構、訓練與軟體，可以透過雲端服務延伸 IT 功能。

Remote Storage｜遠端儲存個人檔案甚至伺服器磁碟備份，可透過網際網路存放在雲端。
Data Center｜資料中心雲端背後仍是實體基礎設施：伺服器、儲存、網路、電力與環境控制。
Distributed Facilities｜分散式設施供應商通常會把資料／服務分散在多個資料中心，以支援安全性、可靠性與容錯能力。
自製示意：雲端服務由實際資料中心承載，且可分散在多個位置，而不是所有資料都放在一棟建築中。

影片列出的四種雲端類型

Cloud Type中文影片重點
Public Cloud公有雲以雲端為基礎的應用與服務提供給一般使用者，可採免費或按使用量付費等方式，由服務供應商透過網際網路提供。
Private Cloud私有雲應用與服務提供給特定組織或實體；可使用組織私有網路，也可能由外部組織管理，以符合存取與安全需求。
Hybrid Cloud混合雲由兩個或多個雲組成，例如部分私有雲、部分公有雲；各部分仍保持獨立但透過共同架構連接。
Community Cloud社群雲為有共同需求的特定組織／實體建立，例如需要共同遵循特定安全、隱私或法規要求的社群。
CCNA 延伸
雲端部署模型 ≠ 雲端服務模型。公有／私有／混合／社群是在講「誰使用、怎麼部署」；IaaS、PaaS、SaaS 則是在講「供應商提供到哪一層」。影片本節畫面列出的是前者。

8. 1.7.7 家中的技術趨勢（Technology Trends in the Home）

網路趨勢不只影響工作與學校，也進入家庭。影片以智慧家庭為例：日常電器與其他設備連上網路後，可以變得更自動化、可遠端控制，也能依時間或條件做動作。

Smart Appliances｜智慧家電傳統電器加入連網與控制能力，例如依排程或感測狀態運作。
Remote Control｜遠端控制使用智慧型手機或平板從外部查看或控制家中設備。
Automation｜自動化設備可依日曆、時間、溫度或其他條件觸發動作。
自製示意：智慧家庭的概念是把家庭設備、行動裝置與雲端服務連成可控制、可自動化的系統。
安全提醒（延伸）：連網設備越多，代表可被管理與攻擊的端點也越多。實務上智慧家庭需特別注意預設密碼、韌體更新、分段網路與不必要的遠端存取。

9. 1.7.8 電力線網路（Powerline Networking）

影片說明：家庭電力線網路利用既有的電力佈線來連接裝置。把電力線轉接器插入電源插座後，就能利用屋內電線承載資料，不需要另外拉一條新的網路線。

自製示意：兩端都插上電力線轉接器，資料訊號利用既有的室內電線跨房間傳送。

適合什麼時候？

當無線 AP 難以涵蓋某些區域，且不方便重新拉資料網路線時，電力線網路可成為另一種選擇。

不能把它想成什麼？

影片明確提醒，電力線網路不能取代資料網路中的專用纜線；它是在特定條件下提供連線的替代方案。

CCNA 延伸
實際效能會受家庭電力迴路、雜訊、插座／延長線環境與設備規格影響，因此「插上就一定跟乙太網路一樣快」不是正確理解。

10. 1.7.9 無線寬頻（Wireless Broadband）

在某些無法使用有線網路或 DSL 的區域，可能採用無線方式連接到網際網路。影片特別介紹 WISP，以及給家庭與小型企業使用的無線寬頻服務。

WISP｜Wireless Internet Service Provider無線網際網路服務供應商使用類似 WLAN 的無線技術，把訂戶連到指定 AP／熱點或供應商網路；常見於有線或 DSL 難以到達的農村／偏遠環境。
Wireless Broadband Service｜無線寬頻服務透過無線「最後一哩」把家庭或小型企業連到網路，不必讓 ISP 線路直接實體進入每一戶。
自製示意：WISP 以無線鏈路連接用戶端與供應商端，特別適合不易鋪設有線基礎設施的地區。
不要混淆 WLAN 與 WISP：WLAN 通常是在家裡、學校、辦公室內提供區域無線網路；WISP 是「網際網路服務供應商」，把無線技術用在用戶與 ISP 之間的接入。

14. 課後考題

共 25 題。作答後按「檢查答案」，會標示正確選項並顯示逐題解析。

1. 1.7.1 列出的近期網路趨勢中，下列哪一項不在影片列出的四個項目內？

答案 D。影片列出 BYOD、線上協同合作、視訊通訊、雲端運算。

2. BYOD 的全名是什麼？

答案 A。BYOD = Bring Your Own Device，自攜裝置。

3. 下列哪個情境最符合 BYOD？

答案 B。BYOD 的重點是使用者自己擁有的裝置接入組織網路。

4. 影片的 BYOD 例子包含哪些裝置？

答案 C。影片列舉多種消費性裝置，不限某一種。

5. 線上協同合作的核心是什麼？

答案 B。協作是與其他人在共同專案中一起工作的行為。

6. 影片提到 Webex 團隊空間可協助保存什麼？

答案 B。影片提到團隊空間會保留歷史紀錄並支援訊息、圖片、影片／連結等內容。

7. 視訊通訊的主要價值之一是？

答案 B。影片強調跨地點／全球溝通與協作。

8. 線上協作與視訊通訊的關係，哪個敘述較正確？

答案 B。協作概念較廣，視訊是其中一種可用媒介。

9. 1.7.5 的 Cisco Webex 片段主要在做什麼？

答案 B。影片 1.7.5 以 Webex 示範前述協作／視訊概念。

10. 雲端運算可以讓使用者做什麼？

答案 B。雲端是透過網路使用遠端資源與服務。

11. 雲端背後的實體設施通常稱為？

答案 A。資料中心承載伺服器、儲存、網路等雲端基礎設施。

12. 下列哪個不是影片列出的四種雲端類型？

答案 D。影片列出公有雲、私有雲、混合雲、社群雲。

13. 只為特定組織或實體提供的雲端環境最符合？

答案 B。Private Cloud 主要供特定組織使用。

14. 將公有雲與私有雲等兩種以上環境組合，最符合？

答案 A。Hybrid Cloud 是兩種或多種雲的組合。

15. 針對有共同安全、隱私或法規需求的一群組織建立的雲，最符合？

答案 A。Community Cloud 服務具有共同需求的特定社群。

16. 智慧家庭的典型特徵是？

答案 B。影片以智慧家電、排程、遠端控制與自動化說明智慧家庭。

17. 電力線網路利用什麼來傳送資料？

答案 A。Powerline Networking 利用既有電線承載資料訊號。

18. 使用電力線網路時，最典型的設備是？

答案 A。影片展示把電力線轉接器插入電源插座。

19. 影片對電力線網路的定位，哪個較正確？

答案 B。影片把它定位為特定情況下的替代連線方式，並非完全取代專用纜線。

20. WISP 的全名是？

答案 A。WISP = Wireless Internet Service Provider。

21. WISP 特別常見於什麼環境？

答案 B。影片明確提到 WISP 常見於 DSL 或有線服務無法使用的農村環境。

22. WISP 與一般家中 WLAN 最大的概念差異是？

答案 A。WISP 是服務供應商型態的 Internet 接入；WLAN 通常是局部區域網路。

23. 「最後一哩」在網路接入中指什麼？

答案 B。Last Mile 是供應商網路到訂戶端的最後一段。

24. 下列哪個配對正確？

答案 B。Cloud Computing 對應遠端資料中心提供的資料、應用與 IT 服務。

25. 哪個敘述最完整地總結本單元？

答案 B。本單元涵蓋使用裝置、合作溝通、服務交付、家庭應用與不同接入方法。
