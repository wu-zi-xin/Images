CCNA 1 - Module 1: Reliable Networks (1.6.1 網路架構)

1.6.1 網路架構 (Network Architecture)
English
As networks evolve, we have learned that there are four basic characteristics that network architects must address to meet user expectations:
  • Fault Tolerance
  • Scalability
  • Quality of Service (QoS)
  • Security
中文翻譯
隨著網路的發展，我們了解到網路架構師必須解決四個基本特性，以滿足使用者的期望：
  • 容錯 (Fault Tolerance)
  • 可擴展性 (Scalability)
  • 服務品質 (Quality of Service, QoS)
  • 安全性 (Security)

CCNA 1 - 1.6.2 容錯 (Fault Tolerance)

1.6.2 容錯簡介
English
A fault tolerant network is one that limits the number of affected devices during a failure. It is built to allow quick recovery when such a failure occurs. These networks depend on multiple paths between the source and destination of a message. If one path fails, the messages are instantly sent over a different link.
中文翻譯
容錯網路是在發生故障時能限制受影響設備數量的網路。它的建構是為了在發生此類故障時允許快速復原。這些網路依賴於訊息來源和目的地之間的多條路徑。如果一條路徑失敗，訊息會立即透過不同的連結發送。
💡 補充：備援機制 (Redundancy)

Redundant connections allow for alternative paths if a device or a link fails. The user experience is unaffected. (備援連線允許在設備或連結故障時提供替代路徑。使用者的體驗將不受影響。)

CCNA 1 - 1.6.3 可擴展性 (Scalability)

1.6.3 可擴展性簡介
English
A scalable network expands quickly to support new users and applications. It does this without degrading the performance of services that are being accessed by existing users.
中文翻譯
可擴展的網路能快速擴展以支援新的使用者和應用程式。它在不降低現有使用者正在存取的服務效能的情況下做到這一點。
💡 拓撲擴充說明

Additional users and whole networks can be connected to the internet without degrading performance for existing users. (即使是額外的使用者甚至是整個網路，也可以連接到網際網路，而不會降低現有使用者的效能。)

CCNA 1 - 1.6.4 服務品質 (Quality of Service)

1.6.4 服務品質簡介 (QoS)
English
Quality of Service (QoS) is an increasing requirement of networks today. New applications available to users over networks, such as voice and live video transmissions, create higher expectations for the quality of the delivered services.
中文翻譯
服務品質 (QoS) 是當今網路日益增長的需求。透過網路提供給使用者的新應用程式（例如語音和即時視訊傳輸）對所提供的服務品質產生了更高的期望。

(網路語音通話)
Will need priority to maintain a smooth, uninterrupted user experience. (需要較高優先權以維持流暢、不中斷的使用者體驗。)
Web Pages
(網頁瀏覽)
Can usually receive a lower priority. (通常可以接收較低的優先權，因為對延遲容忍度較高。)

CCNA 1 - 1.6.5 網路安全 (Network Security)

1.6.5 網路安全簡介
English
The network infrastructure, services, and the data contained on network-attached devices are crucial personal and business assets. Network administrators must address two types of network security concerns: network infrastructure security and information security.
中文翻譯
網路基礎設施、服務以及連接網路的設備中包含的資料是重要的個人和商業資產。網路管理員必須解決兩種類型的網路安全問題：網路基礎設施安全和資訊安全。
Confidentiality
(機密性)
Data confidentiality means that only the intended and authorized recipients can access and read data. (資料機密性意味著只有預期和授權的接收者才能存取和讀取資料。)
Integrity
(完整性)
Data integrity assures users that the information has not been altered in transmission, from origin to destination. (資料完整性向使用者保證資訊從來源到目的地在傳輸過程中未被更改。)
Availability
(可用性)
Data availability assures users of timely and reliable access to data services for authorized users. (資料可用性向授權使用者保證能夠及時且可靠地存取資料服務。)
