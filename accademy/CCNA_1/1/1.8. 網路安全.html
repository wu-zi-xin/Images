CCNA MODULE 1 · 1.8

網路安全
Network Security

本段影片聚焦兩件事：第一，網路面臨哪些常見的外部與內部安全威脅；第二，家用、小型辦公室與企業如何用多層安全措施降低風險。重點不是背一個「萬能安全設備」，而是理解威脅類型、控制措施，以及它們各自負責防守哪一層。

1. 本段在學什麼？

影片先說明網路安全是系統管理員的重要優先事項，因為無論家庭或大型企業，只要連上網路，就可能受到外部與內部威脅。接著介紹常見攻擊，再說明家用／SOHO 與企業網路應採用的不同層級安全措施。

Threats｜威脅病毒、蠕蟲、木馬、間諜軟體、零日攻擊、DoS、資料竊取、身分盜竊。
Internal｜內部威脅不只來自 Internet，也可能來自員工、裝置遺失或誤操作。
Home / SOHO終端防毒／反間諜軟體 + 防火牆過濾是基本防護。
Enterprise專用防火牆、ACL、IPS、VPN 等共同形成多層防線。
影片來源
影片 1.8.1 與 1.8.2 強調：網路安全必須考慮環境、威脅來源與多個安全層；沒有任何單一安全元件可以辨識並阻擋所有威脅。

2. 1.8.1 安全性威脅（Security Threats）

網路安全不是只在「公司被駭」時才需要。只要資料、帳號、服務與設備有價值，就需要用技術、設備、工具、技能與政策保護它們。

External Threat

外部威脅

從組織或家庭網路外部發動，例如 Internet 上的攻擊者、惡意網站或被感染的外部系統。

Internal Threat

內部威脅

由內部人員、內部裝置或操作錯誤造成。來源可能是無心失誤，也可能是惡意行為。

中等模式重製：以左右雙路徑呈現「外部攻擊須穿越邊界、內部風險已在信任範圍」，並把共同保護目標放在視覺中心。

3. 影片列出的常見外部威脅

以下八類是影片 1.8.1 的核心清單。考題常用「情境描述」而不是直接給英文名稱，所以要能從行為判斷是哪一種威脅。

Virus / Worm / Trojan
病毒／蠕蟲／木馬
在使用者裝置上執行惡意軟體或程式碼。白話：把有害程式帶進端點，可能破壞、控制、偷資料或繼續散播。
Spyware / Adware
間諜軟體／廣告軟體
安裝在裝置上的軟體類型，可能偷偷蒐集使用者相關資訊。考點：不一定立刻把系統弄壞，但會侵害隱私或導致資料外洩。
Zero-day / Zero-hour
零日／零時攻擊
利用剛發現、尚未建立完善防禦或修補的弱點。記法：「防守方還沒時間補，攻擊已經開始」。
Hacker Attacks
駭客攻擊
由攻擊者針對使用者裝置或網路發動的攻擊，可結合漏洞利用、惡意程式、憑證竊取等手法。
DoS
阻斷服務攻擊
降低設備、程式或網路服務的速度，甚至造成當機或無法使用。核心：破壞「可用性（Availability）」。
Data Interception & Theft
資料攔截與盜竊
未授權取得組織內部資料，包括在傳輸中攔截或進入系統後竊取。
Identity Theft
身分盜竊
竊取使用者的登入認證或個人資料，進而冒用身分、存取帳號或取得私密資訊。
影片用語提醒：零日攻擊（Zero-day Attack）與零時攻擊（Zero-hour Attack）在這個基礎單元中是同一類型的核心概念：利用防守方尚未準備好的新弱點。

4. 內部威脅（Internal Threats）為什麼不能忽略？

影片特別提醒，許多資料外洩事件與內部使用者有關。內部威脅不等於「員工都是壞人」；它包含意外、管理疏忽、裝置遺失，以及真正的惡意行為。

Lost Device｜裝置遺失筆電、手機、儲存媒體遺失後，如果沒有鎖定或加密，資料可能直接暴露。
Accidental Misuse｜意外誤用例如把敏感檔案寄錯人、使用弱密碼、誤點惡意連結、設定權限錯誤。
Malicious Insider｜惡意內部人員擁有合法存取權的人故意竊取、刪除、洩露或破壞資料。
和 BYOD 的連結：影片指出隨著 BYOD 策略普及，企業資料更容易受到攻擊，因此安全政策必須同時涵蓋個人裝置、內部存取與外部攻擊。

5. 1.8.2 安全解決方案（Security Solutions）

影片的核心觀念是：沒有任何單一安全解決方案可以保護網路免於所有現有威脅。安全必須在多個層面運作，讓不同元件互相補位。

中等模式重製：把原本的直線設備串接改成重疊盾牌，直接表達「縱深防禦」；下方保留每一層的功能速查。

6. 家用／小型辦公室的基本安全（Home / SOHO Security）

影片把家用網路安全定位為相對基本，但「基本」不代表只靠密碼。最核心的兩類控制是終端防護與防火牆過濾。

Antivirus & Antispyware｜防毒與反間諜軟體

安裝在終端裝置上，協助保護裝置免受惡意軟體感染，並偵測或移除已知惡意程式。

白話：敵人如果已經靠近「電腦本身」，這層就是端點守門員。

Firewall Filtering｜防火牆過濾

根據規則控制進出網路的流量，阻擋未經授權的存取。可以是主機型防火牆，也可以是家用路由器提供的基本過濾功能。

白話：不是每個封包都能自由進出，先看規則再決定放行。

影片來源
影片 1.8.2 明確列出「防毒和反間諜軟體」與「防火牆過濾」作為家用或小型辦公室網路的基本安全元件。

7. 企業網路的多層防護（Enterprise Security）

企業網路規模較大、服務較多、使用者與資料更複雜，因此需要多個安全元件一起工作，以提高防護完整性。

Dedicated Firewall｜專用防火牆比一般家用設備提供更完整的流量檢查、政策與日誌功能，用來控制網路邊界或重要區域間的流量。
ACL｜Access Control List
存取控制清單依 IP 位址、協定與其他條件允許或拒絕流量。CCNA 之後會深入學標準／延伸 ACL 與放置位置。
IPS｜Intrusion Prevention System
入侵防禦系統辨識惡意或異常流量，並採取阻擋措施。影片舉例包括零時差或快速散播的攻擊。
VPN｜Virtual Private Network
虛擬私有網路讓遠端工作者透過不受信任網路建立安全通道，存取企業內部資源。
最重要一句：防火牆、ACL、IPS、VPN 不是互相取代，而是解決不同問題。考 CCNA 時，要先問「題目要保護的是什麼？流量在哪裡？需要的是過濾、偵測、阻擋，還是安全遠端連線？」

8. CCNA 延伸：CIA Triad 三大安全目標

這不是影片 1.8 畫面逐項列出的清單，但它是理解所有安全威脅與控制措施非常重要的框架。

Confidentiality｜機密性只有被授權的人能看到資料。
常見手段：加密、權限控制、VPN。
Integrity｜完整性資料不能被未授權竄改，而且應能偵測不當變更。
常見手段：雜湊、數位簽章、權限與稽核。
Availability｜可用性合法使用者需要時能取得服務。
DoS 就是典型針對可用性的攻擊。
CCNA 延伸
把影片威脅套進 CIA：資料竊取主要傷害機密性；未授權修改傷害完整性；DoS 主要傷害可用性。很多攻擊會同時破壞不只一項。

9. CCNA 延伸：Defense in Depth｜縱深防禦

影片說「安全應該在多個層面中實作」；在資安領域常用 Defense in Depth 表達這種多層防護思維。

① User / Identity
帳號驗證、最小權限、MFA（延伸）
→
② Endpoint
防毒、反惡意程式、更新修補
→
③ Network
Firewall、ACL、Segmentation
→
④ Detection
IPS、日誌、監控
→
⑤ Remote Access
VPN 與安全管理連線
CCNA 延伸
Least Privilege｜最小權限：使用者與服務只拿到完成工作必要的最低權限。Network Segmentation｜網路分段：把不同用途或信任層級的裝置分區，並控制區域之間的流量，降低攻擊橫向移動的機會。

10. 用一個情境把整章串起來

情境：員工在家用自己的筆電遠端工作

第一層：端點。筆電需要防毒／反間諜軟體與更新，降低惡意程式風險。
第二層：網路邊界。家用路由器與企業防火牆負責基本流量過濾。
第三層：遠端連線。員工用 VPN 建立安全通道進企業網路。
第四層：企業內部。路由器／防火牆上的 ACL 限制他能去哪些網段與服務。
第五層：威脅阻擋。IPS 偵測並阻止已知或可識別的攻擊行為。

這就是影片「多層安全」的實際樣子：每一層都不是完美，但一起工作能大幅降低單點失守的風險。

12. 課後考題

共 25 題，包含影片原始概念、影片出現的題型，以及本頁標示為「CCNA 延伸」的觀念。作答後按「檢查答案」，會標示正確答案並顯示逐題解析。

1. 影片指出，網路安全威脅的來源可能是？

影片明確指出威脅可能來自外部或內部，因此安全政策不能只防 Internet 端。

2. 哪一類惡意程式會在使用者裝置上執行惡意軟體或程式碼？

病毒（virus）、蠕蟲（worm）與木馬（Trojan horse）都屬於影片列出的常見外部威脅。

3. 間諜軟體與廣告軟體（Spyware and Adware）的主要風險是？

影片指出這些軟體可能秘密蒐集與使用者有關的資訊。

4. 哪個情境最符合 Zero-day / Zero-hour attack？

零日／零時攻擊的核心是利用剛被發現、尚無防護或修補可用的弱點。

5. 阻斷服務（DoS）攻擊的目標通常是？

影片將 DoS 描述為降低設備和程式速度或造成當機的攻擊。

6. 哪一項屬於影片列出的『資料攔截和盜竊』？

Data interception and theft 指資料被未授權取得、攔截或竊取。

7. 身分盜竊（Identity Theft）最接近哪個描述？

影片指出攻擊者可能竊取登入憑證以存取私密資料。

8. 影片特別提醒，資料外洩最常見的來源之一是？

影片強調內部威脅同樣重要，可能來自裝置遺失、員工意外誤用，甚至惡意員工。

9. 家用／小型辦公室網路的基本安全元件，影片列出哪兩類？

影片把終端防護與防火牆過濾列為家用與小型辦公室的基本安全元件。

10. 防火牆過濾（Firewall Filtering）的核心作用是？

防火牆的角色是依規則允許或拒絕流量，降低未授權存取。

11. 企業網路中，影片列出的專用安全系統之一是？

企業通常需要比家用環境更完整的多層防護，例如專用防火牆。

12. ACL 的全名是？

ACL = Access Control List，中文常譯為存取控制清單。

13. ACL 可以依什麼條件做流量過濾？

影片指出 ACL 可依 IP 位址與應用程式等條件進一步過濾存取與流量轉送。

14. IPS 的主要角色是？

Intrusion Prevention System（入侵防禦系統）可辨識並阻擋惡意流量，例如零時差或快速散播類攻擊。

15. 哪個選項會為遠端工作者建立安全連線？

影片課後題的正確答案是 VPN；它可在不受信任網路上建立受保護的遠端連線。

16. VPN 的全名是？

VPN = Virtual Private Network，虛擬私有網路。

17. 影片說明企業安全應採取什麼策略？

影片明確說沒有任何單一解決方案可以阻擋現有的所有威脅，因此安全應在多個層面運作。

18. 為什麼單一安全元件不夠？

這就是 Layered Security / Defense in Depth 的概念：即使某一層失守，仍有其他層可以降低風險。

19. 『最小權限（Least Privilege）』屬於哪一種延伸安全觀念？

這是本頁的 CCNA 延伸：降低帳號被濫用或遭入侵後的影響範圍。

20. CIA Triad 中的 Confidentiality 是？

Confidentiality = 機密性，目標是避免未授權的人看到資料。

21. CIA Triad 中的 Integrity 是？

Integrity = 完整性，目標是確保資料未被未授權竄改。

22. CIA Triad 中的 Availability 是？

Availability = 可用性，目標是讓合法使用者在需要時能取得服務與資料。

23. 哪個最符合『網路分段（Network Segmentation）』的安全目的？

這是重要延伸：將不同信任等級或用途的裝置分區，搭配 ACL/防火牆控管跨區流量。

24. 影片問：哪種攻擊描述已知弱點的第一天發生？

影片課後題的正確答案是『零日攻擊或零時攻擊』。

25. 下列哪個組合最能代表本單元的完整防護思維？

安全不是單一設備，而是技術、設定、政策與使用者行為共同形成的多層防護。
