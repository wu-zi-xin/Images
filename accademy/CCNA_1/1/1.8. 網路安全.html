CCNA 1 - Module 1: Network Security (1.8.1 安全威脅)

1.8.1 安全威脅簡介 (Security Threats)
English
Network security is an integral part of computer networking, regardless of whether the network is in a home with a single connection to the internet or is a corporation with thousands of users. Network security must consider the environment, as well as the tools and requirements of the network. It must be able to secure data while still allowing for the quality of service that users expect of the network.
中文翻譯
網路安全是電腦網路不可或缺的一部分，無論是擁有單一網際網路連線的家庭網路，還是擁有數千名使用者的企業網路。網路安全必須考慮環境以及網路的工具和需求。它必須能夠保護資料，同時仍能提供使用者所期望的網路服務品質。
常見的外部威脅 (External Threats)
Viruses, worms, and Trojan horses
(病毒、蠕蟲與木馬)
These contain malicious software or code running on a user device. (這些包含在使用者設備上運行的惡意軟體或程式碼。)
Spyware and adware
(間諜軟體與廣告軟體)
These are types of software which are installed on a user's device. The software then secretly collects information about the user. (這些是安裝在使用者設備上的軟體類型。然後該軟體會秘密收集有關使用者的資訊。)
Zero-day attacks
(零日攻擊 / 零時差攻擊)
Also called zero-hour attacks, these occur on the first day that a vulnerability becomes known. (也稱為零時差攻擊，發生在漏洞被發現的第一天。)
Threat actor attacks
(威脅發動者攻擊)
A malicious person attacks user devices or network resources. (惡意人士攻擊使用者設備或網路資源。)
Denial of service attacks (DoS)
(阻斷服務攻擊)
These attacks slow or crash applications and processes on a network device. (這些攻擊會減慢或使網路設備上的應用程式和進程崩潰。)
Data interception and theft
(資料攔截與竊取)
This attack captures private information from an organization's network. (此攻擊從組織的網路擷取私人資訊。)
Identity theft
(身分竊取)
This attack steals the login credentials of a user in order to access private data. (此攻擊竊取使用者的登入憑證以存取私人資料。)

內部威脅 (Internal Threats)
English
It is equally important to consider internal threats. There have been many studies that show that the most common data breaches happen because of internal users of the network. This can be attributed to lost or stolen devices, accidental misuse by employees, and in the business environment, even malicious employees. With the evolving BYOD strategies, corporate data is much more vulnerable.
中文翻譯
考慮內部威脅同樣重要。許多研究顯示，最常見的資料外洩是因為網路的內部使用者而發生的。這可歸咎於設備遺失或被盜、員工的意外誤用，在商業環境中，甚至有惡意員工。隨著自攜設備 (BYOD) 策略的發展，企業資料變得更加脆弱。

CCNA 1 - 1.8.2 安全解決方案 (Security Solutions)

多層次安全防護 (Multiple Layers of Security)
English
No single solution can protect the network from the variety of threats that exist. For this reason, security should be implemented in multiple layers, using more than one security solution. If one security component fails to identify and protect the network, others may succeed.
中文翻譯
沒有單一的解決方案可以保護網路免受存在的各種威脅。因此，應實施多層安全，使用超過一種的安全解決方案。如果一個安全元件無法識別並保護網路，其他元件可能會成功。
基本安全元件 (家庭或小型辦公室)
Antivirus and antispyware
(防毒與反間諜軟體)
These applications help to protect end devices from becoming infected with malicious software. (這些應用程式幫助保護終端設備免受惡意軟體感染。)
Firewall filtering
(防火牆過濾)
Firewall filtering blocks unauthorized access into and out of the network. This may include a host-based firewall system or a basic filtering service on the home router. (防火牆過濾阻止未經授權存取網路的進出。這可能包含主機型防火牆系統或家庭路由器上的基本過濾服務。)
安全元件 (Security Component) 說明 (Description)

企業網路安全需求 (Corporate Network Security)

Larger networks and corporate networks use antivirus, antispyware, and firewall filtering, but they also have other security requirements:
(大型網路和企業網路除了使用防毒、反間諜軟體和防火牆過濾外，還有其他安全需求：)

Dedicated firewall systems
(專用防火牆系統)
These provide more advanced firewall capabilities that can filter large amounts of traffic with more granularity. (這些提供更進階的防火牆功能，可以更精細地過濾大量流量。)
Access control lists (ACL)
(存取控制清單)
These further filter access and traffic forwarding based on IP addresses and applications. (這些根據 IP 位址和應用程式進一步過濾存取和流量轉發。)
Intrusion prevention systems (IPS)
(入侵防禦系統)
These identify fast-spreading threats, such as zero-day or zero-hour attacks. (這些識別快速傳播的威脅，例如零日或零時差攻擊。)
Virtual private networks (VPN)
(虛擬私人網路)
These provide secure access into an organization for remote workers. (這些為遠端工作人員提供進入組織的安全存取。)
