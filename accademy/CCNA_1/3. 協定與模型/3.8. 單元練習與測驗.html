2. 通訊規則｜The Rules

任何通訊都至少牽涉三個共同元素：訊息來源（sender）、訊息目的地（receiver）與通道（channel）。

誰在傳？來源端負責產生與送出訊息。
傳給誰？接收端必須能識別、接收並理解訊息。
走哪裡？通道可以是有線、無線或其他傳輸媒介。
通訊協定常見要求

影片列出的共同規則包含：已識別的寄件者與接收者、共同語言與文法、速度與時間、編碼／解碼與確認要求。此外，訊息也會受到編碼、格式與封裝、大小、時間、傳遞選項等因素影響。

白話比喻：打電話時，雙方不只要「接通」，還要使用彼此懂的語言、輪流說話、知道何時開始與結束。

3. Protocols 與 Protocol Suites

Protocol（通訊協定）就是設備之間對話時共同遵循的規則。多個協定一起完成一件工作，就形成 Protocol Suite（協定套件）。

Protocols｜通訊協定

影片列舉 IP、TCP、HTTP 等協定，並說明不同協定各自負責不同功能，例如資料格式、可靠性、流量控制、錯誤偵測或服務存取。

也提到常見功能型協定：OSPF、BGP（路由）、DHCP、DNS（自動化／服務）。

Protocol Suites｜協定套件

一個完整的網路任務通常不是靠單一協定完成，而是多個協定協作。影片指出 TCP/IP 是今天網際網路與許多網路中廣泛使用的協定套件。

白話：瀏覽網頁時不是「HTTP 一個人做完全部」。HTTP 處理應用層內容，TCP 可能負責可靠傳輸，IP 負責跨網路尋址與轉送，下層再用乙太網路或 Wi‑Fi 把資料送出去。
補充理解（非影片逐字內容）：同一層也可能有不同協定可選，例如傳輸層可用 TCP 或 UDP。選哪一個取決於應用需求，不代表某一個永遠「比較好」。

4. 標準組織｜Standards Organizations

開放式標準讓不同廠商的設備能互通，促進互操作性、競爭與創新。

組織英文影片中的角色
網際網路協會ISOC 推動網際網路開放發展的重要組織。
網際網路架構委員會IAB 參與網際網路架構與標準方向。
網際網路工程任務組IETF 發展與推進網際網路技術標準。
網際網路研究任務組IRTF 聚焦較長期的網際網路研究。
ICANN / IANAICANN / IANA影片將其列為與 TCP/IP 運作與網際網路命名／號碼資源相關的組織。
電氣電子工程師學會IEEE 常見區域網路與實體／資料連結技術標準。
電子工業聯盟EIA電子與介面相關標準。
電信產業協會TIA電信與布線等標準。

考試觀念：標準組織的價值不是「一定由某家公司制定」，而是讓不同廠商可以照共同規範做出可互通的產品。

5. OSI 與 TCP/IP 參考模型

影片列出兩個參考模型：OSI 七層與TCP/IP 四層。它們的用途是幫助人們描述、設計與排錯網路功能。

OSI Model｜7 層

7 Application｜應用層
6 Presentation｜表示層
5 Session｜會議層
4 Transport｜傳輸層
3 Network｜網路層
2 Data Link｜資料連結層
1 Physical｜實體層

TCP/IP Model｜4 層

4 Application｜應用層
對應 OSI 7～5
3 Transport｜傳輸層
對應 OSI 4
2 Internet｜網際網路層
對應 OSI 3
1 Network Access｜網路存取層
大致涵蓋 OSI 2～1
記憶重點：OSI 比較細，常用來教學與排錯；TCP/IP 比較貼近實際網際網路協定族的分層方式。考題常會問「某功能屬於哪一層」或兩個模型如何對應。

6. 資料封裝｜Data Encapsulation

影片說明：資料在往下層傳送時，會逐層加入該層需要的控制資訊；接收端則反方向逐層移除，這就是封裝與解封裝。

Segmentation｜分割

把較大的資料分成較小部分。影片提到兩個好處：不同對話能在網路上交錯傳送（multiplexing），而且若一部分遺失，只需重傳遺失部分。

PDU｜Protocol Data Unit

每一層在處理資料時，都可把該層接收到或產生的資料單位稱為 PDU。資料往下走時封裝，往上走時解封裝。

圖解是概念示意：不同課程／技術會使用不同 PDU 名稱，但「往下封裝、往上解封裝」的方向不變。

7. Data Access 與位址

影片強調：網路層與資料連結層都有「來源位址」和「目的位址」，但它們扮演的角色不一樣。

層級位址主要用途白話
Network LayerIP Address將封包從原始來源送到最終目的地，可能跨越多個網路。像「最終收件地址」。
Data Link LayerMAC Address把資料連結層訊框從一個 NIC 傳到同一鏈路／區段上的下一個 NIC。像「這一站要交給哪個鄰居」。

影片內容：IP 位址會包含可辨識網路與主機／介面的部分；當來源與目的地在同一個網路時，資料連結層會直接使用相對應的本地 MAC 位址。若目的地位於不同網路，乙太網路訊框的目的 MAC 會指向路由器／預設閘道等「下一跳」設備，而 IP 的最終目的地仍保持指向遠端主機。

這張圖特別用來避免常見混淆：跨路由器時，Layer 2 的 MAC 位址會依每一跳改變；Layer 3 的來源／目的 IP 通常代表端到端主機。

8. 考前速記

規則先於傳送沒有共同規則，就算線路通了也無法正確理解資料。
協定各司其職HTTP、TCP、IP、Ethernet 等不是互相取代，而是分工合作。
標準帶來互通開放式標準讓不同廠商設備可以互操作。
OSI 7、TCP/IP 4要會層級名稱與大致對應。
往下封裝、往上解封裝每一層添加／移除該層控制資訊。
IP 看遠端，MAC 看本地鏈路跨網路時目的 MAC 常指下一跳，目的 IP 仍指最終主機。

10. 課後考題

共 20 題，包含影片核心概念與少量延伸理解。按「檢查答案」後會顯示正確答案與逐題解析。

1. 網路通訊最基本的三個共同元素是？

影片的 The Rules 先指出所有通訊都有來源、目的地與通道。

2. Protocol 最接近下列哪個意思？

Protocol 就是正式定義裝置如何交換訊息的共同規則。

3. 下列哪一組都是影片提到的協定？

影片在 Protocols 段落列出 IP、TCP、HTTP 等。

4. Protocol Suite 的概念是？

完整的網路工作通常需要多個協定合作，這就是協定套件。

5. 哪一個協定套件是影片指出今日廣泛使用於網際網路的核心？

影片把 TCP/IP 作為目前網路與網際網路最重要的協定套件。

6. 開放式標準最大的好處之一是？

標準化的核心目的之一是互操作性，也能促進競爭與創新。

7. 下列哪一個是影片列出的網路標準相關組織？

影片列出 ISOC、IAB、IETF、IRTF、ICANN、IANA、IEEE、EIA、TIA、ITU‑T 等。

8. OSI 模型共有幾層？

OSI 是七層模型：Application 到 Physical。

9. TCP/IP 模型在影片中列為幾層？

影片列出 Application、Transport、Internet、Network Access 四層。

10. OSI 第 4 層是？

OSI Layer 4 是 Transport Layer。

11. OSI 的 Network Layer 大致對應 TCP/IP 哪一層？

OSI Layer 3 Network 與 TCP/IP Internet Layer 大致對應。

12. Segmentation 的其中一個好處是？

影片指出分割能提高效率；遺失時不必重送整個大型資料。

13. PDU 的全名是？

PDU = Protocol Data Unit，協定資料單元。

14. 資料由應用程式往網路媒介方向傳送時，通常發生什麼？

往下層時逐層加入控制資訊，稱為 encapsulation。

15. 接收端資料由實體／資料連結層往應用層上移時，通常稱為？

接收端逐層移除標頭／尾碼，稱為解封裝。

16. 哪一種位址主要用來表示來源主機與最終目的主機，並可跨越多個網路？

網路層的 IP 位址用來識別端到端來源與最終目的地。

17. MAC Address 在影片的 Data Access 內容中主要扮演什麼角色？

MAC 位址是資料連結層位址，負責本地鏈路上的訊框傳遞。

18. 當目的地主機位於不同網路時，乙太網路 Frame 的目的 MAC 通常指向？

跨網路時 Layer 2 先送到下一跳；最終目的 IP 則仍是遠端主機。

19. 下列哪句最能描述「協定分層」？

參考模型與協定分層的價值就是把複雜系統拆成可管理的功能區塊。
