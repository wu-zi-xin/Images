網路概論與應用 (第26-29題)

主題：DHCP 伺服器功能
26. 下列何者為 DHCP 伺服器之功能？
① 提供網路資料庫的管理功能
② 提供檔案傳輸的服務
③ 提供網頁連結的服務
④ 動態的分配 IP 給使用者使用
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

DHCP (Dynamic Host Configuration Protocol，動態主機設定協定) 是一個用於區域網路的網路協定。其核心功能是「自動且動態地分配 IP 位址、子網路遮罩、預設閘道與 DNS 伺服器」等網路參數給客戶端裝置，可以省去網路管理員逐一為電腦設定 IP 的麻煩，並能有效避免 IP 發生衝突。

【各選項解析】
  • ① 提供網路資料庫的管理功能：錯誤，此為資料庫系統 (如 MySQL, SQL Server) 的功能。
  • ② 提供檔案傳輸的服務：錯誤，此為 FTP (File Transfer Protocol) 伺服器的功能。
  • ③ 提供網頁連結的服務：錯誤，此為 Web 網頁伺服器 (透過 HTTP/HTTPS) 的功能。
  • ④ 動態的分配 IP 給使用者使用：正確，此正是 DHCP 伺服器的最主要用途。
主題：乙太網路 (Ethernet) 特性
27. 有關乙太網路(Ethernet)之敘述，下列何者「不正確」？
① 是一種區域網路
② 採用 CSMA／CD 的通訊協定
③ 網路長度可至 2500 公尺
④ 傳送時不保證服務品質
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

乙太網路 (Ethernet) 是目前最普遍的區域網路技術 (IEEE 802.3)。傳統乙太網路採用 CSMA/CD 來控制存取，且為「盡力傳送」(Best-effort) 的服務，本身不保證傳輸的服務品質 (QoS)。在實體線路限制上，常見的雙絞線單段最長距離為 100 公尺；即便是早期的粗同軸電纜 (10Base5)，透過中繼器串接極限雖剛好為 2500 公尺，但這不能概括為現代乙太網路的「可達長度特性」(現代光纖網路早已遠超此距離)。因此單純表述「長度可至 2500 公尺」做為其代表特性是不正確的敘述。

【各選項解析】
  • ① 是一種區域網路：敘述正確，Ethernet 是最常見的 LAN (區域網路) 技術。
  • ② 採用 CSMA／CD 的通訊協定：敘述正確，這是傳統半雙工乙太網路的載波感測多重存取/碰撞偵測協定。
  • ③ 網路長度可至 2500 公尺：錯誤敘述，網路長度因實體媒介而異，常見雙絞線為 100 公尺，光纖可達數十公里，2500 公尺僅為早期 10Base5 透過特定規則串連的極限，不可視為乙太網路的通用規範長度。
  • ④ 傳送時不保證服務品質：敘述正確，傳統乙太網路不保證封包必定抵達或不延遲 (Best-effort 機制)。
主題：IPv4 網路位址計算
28. 一個 Class C 類型網路可用的主機位址有多少個？
① 254
② 256
③ 128
④ 524
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在標準的 IPv4 網路中，Class C 網路會將最後 8 個位元 (1 Byte) 保留給主機 ID 使用。8 個位元可以產生 2的8次方 (即 256) 個數字組合。但依據規定，主機 ID 全為 0 的位址必須保留給「網路位址 (Network Address)」使用，而主機 ID 全為 1 的位址必須保留給「廣播位址 (Broadcast Address)」使用，因此實際可分配給電腦的有效 IP 位址數量為：256 - 2 = 254 個。

【各選項解析】
  • ① 254：正確，256 減去頭尾 2 個保留位址，剩下 254 個可用主機位址。
  • ② 256：錯誤，這是未扣除「網路位址」與「廣播位址」的總數。
  • ③ 128：錯誤。
  • ④ 524：錯誤。
主題：網際網路服務與通訊埠 (Port)
29. 下列何者為正確的 Internet 服務及相對應的預設通訊埠？
① TELNET：21
② FTP：23
③ SMTP：25
④ HTTP：82
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

在 TCP/IP 協定模型中，各種常見的網路應用程式都會有 IANA 組織統一指派的「知名預設通訊埠 (Well-Known Ports)」，以便客戶端連線。常見的預設埠號包含：HTTP為 80，FTP為 20 及 21，TELNET為 23，SMTP為 25。

【各選項解析】
  • ① TELNET：21：錯誤，TELNET (遠端登入) 的預設通訊埠為 23。
  • ② FTP：23：錯誤，FTP (檔案傳輸協定) 的預設通訊埠通常為 20 (資料) 與 21 (控制)。
  • ③ SMTP：25：正確，SMTP (簡單郵件傳輸協定) 用於寄送電子郵件，預設通訊埠即為 25。
  • ④ HTTP：82：錯誤，HTTP (網頁傳輸協定) 的預設通訊埠為 80。
