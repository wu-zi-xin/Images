1. 先判斷 AAA 三個角色

這題右側只給 Accounting 與 Authentication。因此除了要找出這兩類的敘述，還要辨認哪一句其實屬於 Authorization，所以不使用。

Authentication

你是誰？

驗證身分與登入資格。常見線索：login、username/password、local、RADIUS、TACACS+、PPP authentication。

Authorization

你能做什麼？

指派權限與屬性。若句子在說「給使用者什麼權限／屬性」，通常屬於授權。

Accounting

你做了什麼？

追蹤服務、使用量、資源消耗與工作階段紀錄。常見線索：track、record、usage、resources consumed。

Authentication = 登入驗證 ｜ Authorization = 權限／屬性 ｜ Accounting = 使用紀錄

2. 正確答案

Accounting

應拖入 Accounting

  • It tracks the services that a user is using.
  • It records the amount of network resources consumed by the user.
Authentication

應拖入 Authentication

  • It supports local, PPP, RADIUS, and TACACS+ options.
  • It permits and denies login attempts.
不使用： It assigns per-user attributes. 這是在指定使用者的屬性／權限，因此屬於 Authorization。

3. 五個選項逐句翻譯、判斷原因與詳解

每一個選項都用同樣的方式判斷：先看句子正在描述「登入驗證」、「登入後的權限」，還是「使用後的紀錄」。下面每句都有翻譯、判斷關鍵，以及為什麼屬於該 AAA 服務的完整說明。

It supports local, PPP, RADIUS, and TACACS+ options.

Authentication

翻譯：它支援 local、PPP、RADIUS 與 TACACS+ 等選項。

判斷重點：這句在說設備可以使用哪些方式來處理使用者的登入／身分驗證，因此歸類為 Authentication。

為什麼是 Authentication？

Authentication 的核心問題是「你是誰？你能不能通過登入驗證？」。在 AAA 架構中，設備可以使用不同來源或協定來驗證使用者，例如本機資料庫（local），或把驗證要求交給 RADIUS、TACACS+ 等集中式 AAA 伺服器。

這句最容易混淆的地方，是 RADIUS 與 TACACS+ 本身都不只可以做 Authentication；它們也能參與 Authorization 或 Accounting。因此考題不能只看到協定名稱就判斷，而要看整句在描述什麼功能。這裡的重點是「支援哪些登入驗證選項」，所以答案是 Authentication。

考試判斷技巧：看到 local、login、username/password、RADIUS、TACACS+ 等字眼時，先問自己：句子是不是在描述「用什麼方式確認使用者身分」。如果是，就優先想到 Authentication。

簡單例子：使用者登入 Router 時，Router 可以先查本機帳號，也可以把帳號密碼交給 RADIUS 或 TACACS+ Server 驗證。驗證成功才允許進入設備。

It tracks the services that a user is using.

Accounting

翻譯：它會追蹤使用者正在使用哪些服務。

判斷重點：tracks 是非常明顯的 Accounting 線索。句子不是在決定能不能登入，也不是在決定權限，而是在留下使用紀錄。

為什麼是 Accounting？

Accounting 的工作是回答「使用者做了什麼？使用了哪些服務？用了多久？」。因此只要句子出現 track、record、log、usage、session 等「追蹤／記錄」概念，就非常接近 Accounting。

這句使用 tracks the services，表示系統會記錄某位使用者實際使用了哪些網路服務。這些資料可以拿來做稽核、問題追查、安全事件分析或使用量統計。

它和 Authentication 的差別是：Authentication 發生在「進入之前」，用來判斷是否能登入；Accounting 則是在使用過程中或使用之後，留下活動紀錄。

簡單例子：使用者登入後使用 VPN、網路連線或某項服務，AAA Server 記下他使用了哪一種服務與工作階段資訊，這就是 Accounting。

It records the amount of network resources consumed by the user.

Accounting

翻譯：它會記錄使用者所消耗的網路資源數量。

判斷重點：records 與 resources consumed 都是在描述「使用量紀錄」，因此是 Accounting。

為什麼是 Accounting？

Accounting 不只是記錄「有沒有登入」，也可以記錄使用者實際消耗了多少資源，例如連線時間、傳輸量、封包量、使用的服務或其他 session 統計資料。

這句的核心動詞是 records，而被記錄的內容是 the amount of network resources consumed。也就是系統正在做「用量追蹤」，這正是 Accounting 的典型用途。

如果是 Authorization，句子會比較像「允許使用多少資源」或「使用者可以存取哪些資源」；但這裡不是在設定限制，而是在記錄已經消耗了多少，所以不能選 Authorization。

簡單例子：某位遠端使用者連線 60 分鐘、傳輸 500 MB，系統把這些資料寫進 AAA accounting 紀錄，方便之後稽核或統計。

It assigns per-user attributes.

Authorization｜本題不使用

翻譯：它會為每位使用者指派個別屬性。

判斷重點：assigns 與 per-user attributes 表示系統正在決定「這個使用者登入後會得到哪些屬性／權限」，所以是 Authorization。

為什麼是 Authorization？為什麼本題不使用？

Authorization 的核心問題是「你已經登入成功了，接下來你可以做什麼？你會得到什麼權限或屬性？」。per-user attributes 就是針對特定使用者回傳或套用的授權參數。

例如同樣都已經通過身分驗證，不同使用者可能會得到不同的 privilege level、可用服務、存取範圍或其他 AAA attributes。這些都不是在確認身分，而是在登入後決定權限與行為範圍。

本題右側目標只有 Accounting 和 Authentication，沒有 Authorization，而且題目明確說 Not all options are used。因此這一句正是那個應該保留、不拖入任何目標的選項。

考試判斷技巧：看到 assign attributes、permission、privilege、permit specific commands、access level 等概念，通常要想到 Authorization。

It permits and denies login attempts.

Authentication

翻譯：它會允許或拒絕登入嘗試。

判斷重點：最重要的字不是 permit / deny，而是 login attempts。它正在判斷登入是否成功，所以是 Authentication。

為什麼是 Authentication？

Authentication 會驗證使用者提供的身分資訊，例如帳號、密碼或其他 credentials。驗證成功，登入要求被接受；驗證失敗，登入要求就會被拒絕。

這一句很容易因為看到 permits and denies 而誤選 Authorization。Authorization 確實也會出現 permit / deny，但它通常是在說「登入後允許或禁止哪些資源、命令或服務」。這句後面明確接的是 login attempts，所以焦點仍是身分驗證。

判斷時要看 permit / deny 的「對象」：如果是 login，通常是 Authentication；如果是 commands / resources / privileges，才比較像 Authorization。

簡單例子：輸入正確帳號密碼 → login permitted；密碼錯誤 → login denied。這就是 Authentication 的成功或失敗結果。

4. 專有名詞＋🔊發音

PPP

Point-to-Point Protocol

點對點通訊協定。可搭配 PAP、CHAP 等方式做連線驗證。

RADIUS

Remote Authentication Dial-In User Service

集中式 AAA 常見協定，常見於網路存取、VPN、Wi‑Fi 與 802.1X。

TACACS+

TACACS plus

常用於網路設備管理的 AAA 協定，可支援驗證、授權與稽核。

Per-user attributes

per-user attributes

針對個別使用者指派的屬性或權限參數，這題用來辨識 Authorization。
