1. AAA 到底是什麼？

AAA 是網路存取控制最常見的三個核心服務。判斷題目時，不要只背中文，而是問自己：這句話是在確認「你是誰」、決定「你能做什麼」，還是記錄「你做了什麼」。

A — Authentication

Authentication

你是誰？

身分驗證。常見線索：username、password、verify、login。

A — Authorization

Authorization

你能做什麼？

授權。決定使用者或群組可以存取哪些資源、執行哪些命令。

A — Accounting

Accounting

你做了什麼？

稽核／記帳。記錄登入時間、使用時間、執行過的指令等。

你是誰 → 你能做什麼 → 你做了什麼

3. 六個選項逐句翻譯與判斷

It enables the device to allow user- or group-based access.

Authorization

翻譯：它讓設備可以依「使用者」或「群組」來授予存取權限。

判斷重點：是在決定誰被允許使用哪些資源，因此屬於「授權」。

為什麼是 Authorization？

這句話的核心不是在確認「你是誰」，也不是在記錄「你做了什麼」，而是在決定某個使用者或某個群組是否被允許存取特定資源。這就是 Authorization（授權）的典型功能。

user-based access 表示依個別使用者設定權限；group-based access 則表示依群組設定權限。企業通常會把多人放進同一個群組，例如 Network-Admins、Helpdesk，再一次套用共同的存取權限。

判斷關鍵：看到 allow、deny、permission、privilege、user/group access，通常要先想到 Authorization。

例子：Alice 屬於 Network-Admins，可以進入設定模式；Bob 屬於 Helpdesk，只能查看狀態。兩人都已經登入成功，但能做的事情不同，這就是 Authorization。

It leverages a RADIUS server to grant user access to a reverse Telnet session.

Authentication

翻譯：它利用 RADIUS 伺服器，讓使用者經驗證後取得 reverse Telnet session 的存取權。

本題將重點放在利用 RADIUS 驗證使用者後取得存取，因此屬於 Authentication；不是右側兩個目標之一。

為什麼這題歸在 Authentication？

這個敘述強調的是透過 RADIUS server 驗證遠端使用者，讓通過驗證的人取得 reverse Telnet session 的存取。雖然句中出現 grant access，看起來像授權，但題目是在描述「使用 RADIUS 驗證後才能進入工作階段」的流程，因此本題把它視為 Authentication。

RADIUS 是集中式 AAA 服務常見協定，尤其常用於 VPN、Wi‑Fi、802.1X 與遠端網路存取。設備可以把使用者帳號密碼送到 RADIUS server，由伺服器回覆接受或拒絕。

reverse Telnet 通常是先連到 terminal server / access server，再透過它的連線埠進入其他 Router 或 Switch 的 console。

判斷提醒：考題若同時出現 grant access 與 RADIUS，要看整句焦點。如果焦點是驗證帳號後讓使用者登入，通常偏 Authentication；若焦點是登入後「允許做哪些事」，才是 Authorization。

It records the amount of time for which a user accesses the network on a remote server.

Accounting

翻譯：它會記錄使用者透過遠端伺服器存取網路的時間長度。

關鍵字：records、amount of time。只要是記錄使用時間／使用量，通常就是 Accounting。

為什麼是 Accounting？

這句話明確出現 records（記錄）與 amount of time（使用時間長度）。Accounting 的工作就是記錄使用行為，例如誰登入、何時登入、何時登出、使用多久、執行了哪些操作。

這些資料可用於稽核、安全事件調查、管理報表，甚至某些環境中的計費。它不是在決定能不能登入，也不是在控制登入後的權限。

判斷關鍵：record、log、track、usage、session duration、login time、logout time 幾乎都指向 Accounting。

例子：Kevin 18:00 登入 VPN，19:15 登出，系統記錄本次連線 75 分鐘。這就是 Accounting。

It restricts the CLI commands that a user can perform.

Authorization

翻譯：它會限制使用者能夠執行哪些 CLI 指令。

關鍵字：restricts。這是在決定使用者「可以做什麼」，因此是 Authorization。

為什麼是 Authorization？

這句話的核心是 restricts（限制）以及「使用者能執行哪些 CLI commands」。使用者已經通過 Authentication 之後，系統還要決定他是否有權執行特定命令，這就是 Authorization。

例如同樣登入一台 Cisco Router，某位工程師可以執行 show ip route，但不允許執行 reload 或 erase startup-config。這種命令層級的權限控制就是典型的授權。

CLI 是 Command-Line Interface，指透過文字命令操作設備的介面。

判斷關鍵：restrict、permit、deny、command privilege、what commands can be executed → Authorization。

It uses TACACS+ to log the configuration commands entered by a network administrator.

Accounting

翻譯：它使用 TACACS+ 記錄網路管理員所輸入的組態設定指令。

關鍵字：log。是在留下管理者執行命令的紀錄，因此是 Accounting。

為什麼是 Accounting？

這句最重要的字是 log。它不是在阻止管理員輸入命令，而是在把管理員「已經輸入過的 configuration commands」記錄下來，因此屬於 Accounting。

TACACS+ 常用於網路設備管理。它可以支援 Authentication、Authorization、Accounting，所以不能只看到 TACACS+ 就直接判斷類別，必須看後面的動作。

這裡後面的動作是 log the configuration commands，也就是留下稽核紀錄。日後若設備設定被改壞，管理者可以回頭查「誰在什麼時間輸入了哪些指令」。

判斷關鍵：TACACS+ + log / record / command history → Accounting。

It verifies the user and password before granting access to the device.

Authentication

翻譯：它會在授予設備存取權之前，驗證使用者與密碼。

關鍵字：verifies、user、password。典型的 Authentication 身分驗證。

為什麼是 Authentication？

這句話直接寫出 verifies the user and password，也就是驗證使用者身分與密碼。Authentication 的目的就是確認「你是不是你所聲稱的那個人」。

在登入流程中，Authentication 通常發生在最前面。先驗證身分成功，接著才進入 Authorization，決定這個人登入後擁有哪些權限。

granting access to the device 在這裡是驗證成功後的結果；真正的判斷重點仍然是前面的 verifies user and password。

判斷關鍵：username、password、credentials、verify identity、login → Authentication。

5. VPN 是什麼？

VPN

Virtual Private Network｜虛擬私人網路

VPN 的全名是 Virtual Private Network，中文通常翻成「虛擬私人網路」。它的主要用途，是讓使用者透過公用網路（例如 Internet）建立一條受保護的連線，就像把自己的裝置安全地「接進公司內部網路」一樣。

你的電腦 / 手機
→
加密的 VPN Tunnel
→
公司 VPN Gateway / Server
→
公司內部資源

VPN 最重要的概念：Tunnel（隧道）

VPN 會在你的裝置和 VPN Gateway 之間建立一條邏輯上的「隧道」。資料在這條隧道中傳送時，通常會受到加密保護，因此即使資料經過 Internet，中間的人也比較難直接看懂內容。

你可以把它想成：Internet 是公開道路，而 VPN Tunnel 像是在公開道路裡建立一條有保護措施的專用通道。

VPN 常見用途

  • 員工在家安全連回公司內部系統
  • 遠端存取公司檔案、伺服器或內部網站
  • 保護公共 Wi‑Fi 環境中的連線
  • 讓兩個辦公室之間建立安全的站點對站點連線

常見類型

Remote-Access VPN：單一使用者從外部連回公司。

Site-to-Site VPN：兩個辦公室或兩個網路彼此建立安全連線。

VPN 和這題的 RADIUS 有什麼關係？

企業的 Remote-Access VPN 常需要先驗證登入者的身分。這時 VPN Gateway 可以把帳號密碼交給 RADIUS Server 驗證。RADIUS 回覆接受或拒絕後，VPN 系統再決定是否讓使用者建立連線。

所以在考題中，看到 VPN + username/password + RADIUS，通常要優先想到 Authentication（身分驗證）。
