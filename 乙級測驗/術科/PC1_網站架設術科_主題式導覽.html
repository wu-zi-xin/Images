Step 01

USB 安裝

先完成 BIOS / UEFI 與系統安裝，確認開機順序與磁碟配置。

關鍵：舊版關閉、開 UEFI；開機順序選 USB / STATA2。
安裝

依序完成

  1. 1進 BIOS。
  2. 2舊版關閉，開 UEFI。
  3. 3開機順序：USB / STATA2。
  4. 4設定 root。
  5. 5磁碟空間配置選：自動 / 全部刪除 / 取回空間。
  6. 6安裝完成。

Step 03

套件與 Repo

先調整 centos.repo，確認 USB 掛載來源，再安裝 HTTP / SSL / FTP / Firewall 相關套件。

A

改 centos.repo

cd /etc/yum.repos.d
ll
mkdir backup
cp * backup
ll backup
rm centos-addons.repo -y
vim centos.repo
  • 1留下 【baseos】 與 【appstream】 區塊。
  • 2連用 2 次：先按 9，再按 dd。
  • 3最下面不要的區塊：先按 d，再按住 shift 後按 g 變大寫，從游標開始刪到最後。
  • 4【baseos】註解 metalink=......，新增 baseurl=file:///media/BaseOS。
  • 5【appstream】註解 metalink=......，新增 baseurl=file:///media/AppStream。
B

確認 USB / 媒體

df -h

查看 USB 是否在 /dev/sr0，確認位置並掛到 /media 上。

要有看到 read-only。
C

安裝套件

dnf install httpd -y
dnf install mod_ssl -y
dnf install ftp -y
dnf install firewall-config -y

setenforce 0

原筆記註記：setenforce 0 為暫時關閉 Linux 系統防火牆相關限制的操作。

Step 04

IP、Firewall 與 Ping

先把兩張網卡的 IP 與 MAC 身分設定正確，再開服務、啟動 HTTPD，最後依順序 Ping。

IP

網卡設定

提醒：設定 IP 記得勾「自動連線」；MAC 身分要選對。enp1s0 的 MAC 是橋接的，也就是 2 號環。

enp1s0

IP200.100.X.254
MASK255.255.255.0
GTW0.0.0.0

enp1s2

IP110.1.X.1 / 255.255.255.0
GTW10.1.X.254
IP210.1.X.2 / 255.255.255.0
Firewall

防火牆與 HTTPD

firewall-cmd --add-service=http --per
firewall-cmd --add-service=https --per
firewall-cmd --add-service=ftp --per
firewall-cmd --add-masquerade --per
firewall-cmd --reload

systemctl stop httpd
systemctl start httpd
Ping

測試順序

先 Ping 自己，再 Ping 別台。

ping 10.1.X.1
ping 10.1.X.2
ping 10.1.X.254
ping 10.1.200.200
ping 200.100.X.254
ping 200.100.X.2
ping 200.100.X.1

Step 05

帳密與權限

建立 WebX-1、WebX-2 兩個帳號，確認 Home 目錄存在，再開放其他使用者可進入目錄。

檢查點：到 /home 看是否有 WebX-1 與 WebX-2 目錄。
Account

建立帳號

useradd WebX-1
passwd WebX-1
# 輸入 WebX-1

useradd WebX-2
passwd WebX-2
# 輸入 WebX-2

cd /home

chmod o+x WebX-1
chmod o+x WebX-2

Step 06

網站與存取設定

這一段是核心：建立兩個使用者網站、準備 index.html，再修改 userdir、.htaccess 與 .htpasswd。

1

建立 www 與首頁

cd /home

# 各自建立 www
mkdir /home/WebX-1/www
mkdir /home/WebX-2/www

cd /home/WebX-1/www
vim index.html
# 輸入：網站架設術科—WebX-1號XXX的第1個網站

cp index.html ../../WebX-2/www/

cd /home/WebX-2/www
vim index.html
# 輸入：網站架設術科—WebX-2號XXX的第2個網站
2

主要 3 個設定檔

userdir
原筆記位置 /etc/httpd/conf.d/userdir.conf
用途 把 UserDir 從 public_html 改為 www。
.htaccess
原筆記位置 /home/Web-2/www/.htaccess
用途 Basic Auth 與有效使用者限制。
.htpasswd
原筆記位置 /home/Web-2/www/.htpasswd
用途 WebX-2 驗證帳密檔。

以上路徑依原筆記文字呈現。

3

修改 userdir.conf

  • 1UserDir public_html → 註解掉 → 複製一個在下面。
  • 2改成 UserDir www。
  • 3<Directory "/home/*/public_html"> 把 public 改成 www，然後複製一整大段到下面。
vim //etc/httpd/conf.d/userdir.conf

<Directory "/home/Web-2/www">
AllowOverride all
Order deny,allow
Deny from all
Allow from 200.100.X.1
</Directory>
4

.htaccess / .htpasswd

cd /home/Web-2/www/
vim .htaccess

AuthType Basic
AuthNAme "WebX-2 only"
AuthUserFile /home/Web-2/www/.htpasswd
Require valid-user

htpasswd - c .htpasswd WebX-2
5

重新啟動伺服器

systemctl restart_httpd
firewall-cmd --list-service
要看到：httpd mod_ssl ftp firewall

up1

大小700 KB

up2

大小700 KB
完成後：繼續往 PC2 去設定囉。

Step 08

FTP 測試

這一步要先等 PC2 做完再測試。依新版筆記分成兩段：先測 200.100.X.1，再測 200.100.X.2。

注意：測試可以等 PC2 部分做完後，再回來完成這一段。
1

測試 200.100.X.1

ftp>200.100.X.1
ftp>123
# 出現 anonymous only

dir
# 看一下有沒有 FtpX-1.txt 跟 FtpX-2.txt

ftp>get FtpX-1.txt
ftp>!cat FtpX-1.txt
ftp>!rm FtpX-1.txt
ftp>bye
檢查點：輸入 123 後要出現 anonymous only，並用 dir 確認 FtpX-1.txt 與 FtpX-2.txt。
2

測試 200.100.X.2

登入前：一樣先在 /hoem 下確認有 up1 跟 up2，再登入。
ftp>200.100.X.2
ftp>anonymous
# 要看到 Login failed

ftp>user FtpX-2
passwd:
# Login successful

ftp>dir
# 或 ls，確定目錄是空的

put up1
# 看到 Transfer complete

ftp>put up2
# 看到 Failure writing to local file

ftp>dir
# 或 ls
# Here comes the directory listing
716800 up1
319448 up2
結果

確認上傳結果

  • 1up1 顯示 716800。
  • 2up2 是 30 幾萬就對了；新版筆記範例為 319448。
  • 3看到這個結果表示上傳成功且完成。
清理

最後刪除測試檔

刪除上傳檔案，以備監考人員測試。

ftp>del up1
ftp>del up2
ftp>bye
完成：FTP 測試流程結束。
