工作項目03：網路架設佈線 (第76 - 100題)

主題：ARP 協定功能
76. 下列何者為 ARP 協定功能？
① 搜尋 Layer 3 目的位址
② 用以開發 Layer 4 資源表的快取
③ 用以對應 IP 位址與 MAC 位址
④ 送出廣播訊息尋找路由器 IP 位址
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

ARP (Address Resolution Protocol，位址解析協定) 的主要功能是在區域網路中，將已知的第三層邏輯位址（IP 位址）對應並轉換成第二層實體位址（MAC 位址），以便讓資料封包能夠準確地在實體網路線上傳遞給目標設備。

【各選項解析】
  • ① 搜尋 Layer 3 目的位址：尋找 IP 路徑是路由（Routing）協定的工作。
  • ② 用以開發 Layer 4 資源表的快取：與第四層（TCP/UDP）無關。
  • ③ 用以對應 IP 位址與 MAC 位址：正確。ARP 負責 IP 與 MAC 的轉換對應。
  • ④ 送出廣播訊息尋找路由器 IP 位址：ARP 廣播是尋找特定 IP 的 MAC 位址，不是專門尋找路由器的 IP。
主題：網路測試與除錯原則
77. 當進行網路測試時，下列何者正確？
① 應依序從 OSI 參考模型之第一層到第二層，依此類推
② 應直接處理 OSI 層中之特定層
③ 應與管理階層共同處理
④ 應以隨機方式測試 OSI 參考模型中的任一層
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在進行網路除錯（Troubleshooting）或測試時，最標準且具邏輯性的做法是「由下而上法（Bottom-Up）」。也就是先確認實體層（Layer 1：線路有無插好、電源、燈號）是否正常，再檢查資料鏈路層（Layer 2：MAC、Switch），接著才是網路層（Layer 3：IP、Routing）等，依此類推，這樣能避免白費力氣去查軟體設定，結果發現只是網路線沒插好。

【各選項解析】
  • ① 應依序從 OSI 第一層到第二層依此類推：正確。為標準的 Bottom-Up 測試法則。
  • ② 應直接處理 OSI 層中之特定層：直接跳層可能忽略底層的硬體故障。
  • ③ 應與管理階層共同處理：技術測試通常由工程師進行，不一定需要管理階層參與。
  • ④ 應以隨機方式測試：隨機測試缺乏邏輯，會降低除錯效率。
主題：網路連線問題排查
78. 在處理網路連線問題時，下列何者正確？
① 從 Layer 1 開始
② 從 Layer 2 開始
③ 從 Layer 3 開始
④ 從 Layer 7 開始
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

承上題的概念，處理連線故障最基本也是最快速的起手式，就是從實體層（Layer 1）開始檢查。確認網路線是否脫落、網路卡燈號是否有亮、電源是否開啟等硬體物理狀態，確認無誤後才往上層（IP 設定或應用程式）進行排查。

【各選項解析】
  • ① 從 Layer 1 開始：正確。底層是上層運作的基礎，應優先排查。
  • ② 從 Layer 2 開始：若線沒接好，看 MAC 狀態也無用。
  • ③ 從 Layer 3 開始：若網卡斷線，檢查 IP 設定也是枉然。
  • ④ 從 Layer 7 開始：這是 Top-Down 策略，較適用於確認網頁軟體邏輯，但在「連線問題」上，Layer 1 是更根本的出發點。
主題：網路通訊協定縮寫
79. ICMP 為下列何者之縮寫？
① Internet Control Message Parameter
② Internal Control Message Protocol
③ Internet Control Message Protocol
④ Internet Control Message Performance
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

ICMP 全名為 Internet Control Message Protocol（網際網路控制訊息協定）。它是 TCP/IP 協定族中一個核心的協定，運作於網路層（Layer 3），主要用於傳遞網路連線的錯誤訊息與控制資訊（例如 Destination Unreachable 或是 Ping 使用的 Echo Request / Reply）。

【各選項解析】
  • ① Internet Control Message Parameter：P 代表協定 Protocol，而非 Parameter。
  • ② Internal Control Message Protocol：I 代表 Internet，而非 Internal。
  • ③ Internet Control Message Protocol：正確。
  • ④ Internet Control Message Performance：P 代表協定 Protocol，而非 Performance。
主題：OSI 模型與協定對應
80. Telnet 為 OSI 參考模型中的哪一層協定？
① Layer 1
② Layer 5
③ Layer 6
④ Layer 7
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

Telnet 是一種透過終端機連線（Terminal Emulation）進行遠端登入與操作的網路協定。它直接提供網路服務給使用者操作的軟體介面，因此在 OSI 七層參考模型中，它被歸類於最高層的「應用層（Application Layer，即 Layer 7）」。

【各選項解析】
  • ① Layer 1：實體層，負責電氣與物理傳輸。
  • ② Layer 5：會議層，負責建立及管理連線交談。
  • ③ Layer 6：表示層，負責資料格式轉換或加解密。
  • ④ Layer 7：正確。Telnet、HTTP、FTP 等皆屬於應用層協定。
主題：數位調變技術比較
81. 比較二進位相位鍵控（Binary Phase-Shift Keying, BPSK）和四相相位鍵控（Quadrature Phase-Shift Keying, QPSK）的敘述，下列何者錯誤？
① QPSK 的傳輸速度比較快
② QPSK 所需要的傳輸頻寬較大
③ BPSK 抗雜訊的能力較高
④ BPSK 較容易實作
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

BPSK 每次狀態改變只傳送 1 個位元 (0或1)；QPSK 每次狀態改變傳送 2 個位元 (00,01,10,11)。
在維持相同的符元傳輸率（Symbol rate）與佔用「相同傳輸頻寬」的情況下，QPSK 的資料吞吐量是 BPSK 的兩倍，這稱為頻寬使用效率較高。因此選項指出「QPSK 所需頻寬較大」是錯誤的描述。

【各選項解析】
  • ① QPSK 的傳輸速度比較快：正確描述，因為每次傳的位元數是 BPSK 兩倍。
  • ② QPSK 所需要的傳輸頻寬較大：錯誤描述（即為本題答案）。同符元率下頻寬需求是相同的。
  • ③ BPSK 抗雜訊的能力較高：正確描述。相位只有兩種(差180度)，接收端較不容易誤判。
  • ④ BPSK 較容易實作：正確描述。調變邏輯最為單純。
主題：網路設備功能區分
82. 下列何種設備提供 LAN 的邏輯區隔？
① 路由器（Router）
② 橋接器（Bridge）
③ 交換器（Switch）
④ 集線器（Hub）
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

「邏輯區隔（Logical separation）」是指在網路架構上利用 IP 網段（Network ID）將網路切分成不同的廣播網域（Broadcast Domain）。能讀懂第三層 IP 位址並執行這項邏輯區隔任務的設備，就是路由器（Router）。

【各選項解析】
  • ① 路由器（Router）：正確。提供第三層的邏輯子網路區隔。
  • ② 橋接器（Bridge）：僅提供第二層實體區隔，分割碰撞網域，但無法阻隔廣播。
  • ③ 交換器（Switch）：為第二層設備，功能同橋接器（進階可設 VLAN，但傳統定義上選路由器最精確）。
  • ④ 集線器（Hub）：為第一層設備，無法提供任何有效的分隔。
主題：Layer 3 設備應用目的
83. 區域網路中，下列何者不是採用 Layer 3 設備的目的？
① 允許 LAN 區隔出子網路
② 允許與 WAN 連接
③ 提供網路的邏輯結構
④ 增加 LAN 的大小
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

Layer 3 設備（如路由器、L3 交換器）的主要目的是為了「路由」，也就是切分廣播網域（劃分子網路）、連接異質網路（連外網 WAN），以及建立清晰的邏輯拓樸結構。如果要單純「增加區域網路 (LAN) 可連接的電腦數量或實體覆蓋範圍」，通常是使用 Layer 2 交換器或集線器來串接擴充。

【各選項解析】
  • ① 允許 LAN 區隔出子網路：這是 Layer 3 設備的核心功能。
  • ② 允許與 WAN 連接：對外連線需要靠路由器的 Layer 3 轉發。
  • ③ 提供網路的邏輯結構：將網路以 IP 切段管理即為邏輯結構的建立。
  • ④ 增加 LAN 的大小：正確（這不是它的主要目的）。擴大單一 LAN 通常靠 L2 交換器。
主題：廣播網域阻隔
84. 下列何種設備可阻隔網路廣播（Broadcast）？
① 集線器（Hub）
② 橋接器（Bridge）
③ Layer 2 交換器
④ 路由器（Router）
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

廣播封包（目的 MAC 為 FF:FF:FF:FF:FF:FF）在區域網路內傳播時，所有的 Layer 1 與 Layer 2 設備（Hub, Bridge, L2 Switch）都會將其複製並轉發出去。唯有 Layer 3 設備「路由器（Router）」會阻擋這些廣播封包跨越介面，藉此將網路劃分為多個獨立的廣播網域，有效防止廣播風暴。

【各選項解析】
  • ① 集線器（Hub）：會放大並轉發廣播。
  • ② 橋接器（Bridge）：會轉發廣播。
  • ③ Layer 2 交換器：會轉發廣播。
  • ④ 路由器（Router）：正確。預設不轉發廣播封包。
主題：碰撞網域特性
85. 下到何種設備無法劃分不同碰撞區（Collision domain）？
① 路由器（Router）
② Layer 2 交換器
③ 集線器（Hub）
④ 橋接器（Bridge）
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

碰撞區（Collision domain）是指網路上多台設備同時發送資料會產生訊號碰撞的區域範圍。運作於 OSI 第一層的「集線器（Hub）」只是單純的電氣訊號放大器，所有連接在 Hub 上的設備都處於同一個碰撞區。而 Bridge、Switch、Router 都可以學習或過濾位址，能將不同的連接埠劃分為獨立的碰撞區。

【各選項解析】
  • ① 路由器（Router）：可區隔碰撞區與廣播區。
  • ② Layer 2 交換器：每個 Port 都是獨立的碰撞區。
  • ③ 集線器（Hub）：正確。它是共享媒介，所有 Port 在同一碰撞區。
  • ④ 橋接器（Bridge）：可將網路分割為較小的碰撞區。
主題：IP 類別與網路 ID
86. IP 位址為 172.16.30.56 時，預設網路 ID（Network ID）為何？
① 172
② 172.16
③ 172.16.30
④ 172.16.30.56
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

IPv4 的分類標準中，Class B 的 IP 位址範圍是 128 ~ 191 開頭。因此 `172.16.30.56` 是一個標準的 Class B 位址。
Class B 的預設子網路遮罩是 `255.255.0.0`，這意味著前兩個位元組（Bytes）是代表網路的部分（Network ID），後兩個位元組是主機部分。因此其預設網路 ID 就是 `172.16`。

【各選項解析】
  • ① 172：這是 Class A 網路的 Network ID 取法。
  • ② 172.16：正確。符合 Class B 取前兩組數字的規則。
  • ③ 172.16.30：這是 Class C 網路的 Network ID 取法。
  • ④ 172.16.30.56：這是完整的主機 IP 位址。
主題：IP 類別與節點 ID
87. IP 位址為 172.16.30.56 時，預設節點 ID（Node ID）為何？
① 172.16.30.56
② 16.30.56
③ 30.56
④ 56
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

如同上題所述，`172.16.30.56` 屬於 Class B 網路，其網路部分佔用前兩組（172.16）。而剩下的後兩個位元組，就是用來識別該網段內單一電腦或設備的主機識別碼（Host ID / Node ID），因此節點 ID 為 `30.56`。

【各選項解析】
  • ① 172.16.30.56：這代表整個 IP 位址。
  • ② 16.30.56：這是若為 Class A 網路時的主機 ID。
  • ③ 30.56：正確。符合 Class B 網路的 Node ID 範圍。
  • ④ 56：這是若為 Class C 網路時的主機 ID。
主題：IP 類別二進位判定
88. IP 位址第 1 個位元組為 11010111 時，屬於下列哪個級別（Class）？
① Class A
② Class B
③ Class C
④ Class D
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

我們可以透過第一個位元組（Byte）的二進位特徵或換算十進位來判斷網路類別：
二進位 `11010111` 換算為十進位：128 + 64 + 0 + 16 + 0 + 4 + 2 + 1 = 215。
或者直接看二進位開頭的特徵碼：`110` 開頭就固定是 Class C 網路。
(Class A=0..., Class B=10..., Class C=110..., Class D=1110...)
215 落在 192~223 的區間內，因此屬於 Class C。

【各選項解析】
  • ① Class A：範圍是 1~126，二進位開頭為 `0`。
  • ② Class B：範圍是 128~191，二進位開頭為 `10`。
  • ③ Class C：正確。範圍是 192~223，二進位開頭為 `110`。
  • ④ Class D：範圍是 224~239，二進位開頭為 `1110`。
主題：Class B 位址二進位特徵
89. IP 位址第 1 個位元組為下列何者時，屬於 Class B 網路位址？
① 01XXXXXX
② 0XXXXXXX
③ 10XXXXXX
④ 110XXXXX
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

早期 IPv4 設計分類時，在硬體底層直接規定了每個類別第一個位元組的高位元（High-order bits）特徵碼以便快速辨識：
• Class A 必須以 `0` 開頭 (0~127)
• Class B 必須以 `10` 開頭 (128~191)
• Class C 必須以 `110` 開頭 (192~223)
• Class D 必須以 `1110` 開頭 (224~239)
因此，Class B 的二進位表示式必為 `10XXXXXX`。

【各選項解析】
  • ① 01XXXXXX：這屬於 Class A 的子集範圍內。
  • ② 0XXXXXXX：這是 Class A 網路的標準特徵碼。
  • ③ 10XXXXXX：正確。這就是 Class B 網路的標準特徵碼。
  • ④ 110XXXXX：這是 Class C 網路的標準特徵碼。
主題：子網路數量計算
90. 網路位址為 172.160.0.0，子網路遮罩為 255.255.255.128，可切割出多少個子網路（Subnets）？
① 1024
② 64
③ 128
④ 512
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

首先判斷 `172.160.0.0` 屬於 Class B 位址（128~191）。Class B 預設的子網路遮罩是 `255.255.0.0`（/16）。
現行的子網路遮罩被設定為 `255.255.255.128`。換算成二進位，前三個 255 是 24 個位元，最後的 128 是 `10000000`（1 個位元），總共借位到了 /25。
從原本的 /16 到目前的 /25，網路位元向主機端借了 25 - 16 = 9 個位元。
計算切割出的子網路數量公式為：2 的 9 次方（2⁹）= 512 個子網路。

【各選項解析】
  • ① 1024：若借用 10 個位元（遮罩結尾為192）才會有此數量。
  • ② 64：若借用 6 個位元（遮罩第三碼為252）才會有此數量。
  • ③ 128：這只是遮罩最後一個數字的十進位，並非切割網段的數量。
  • ④ 512：正確。2⁹ = 512 個網段。
主題：P2P 點對點 IP 設定
91. 兩個路由器之 WAN 端介面對接，其個別 IP 可設定為
① 192.168.1.32/27 , 192.168.1.33/27
② 172.16.18.255/22 , 172.16.19.1/22
③ 192.168.3.6/30 , 192.168.3.7/30
④ 172.16.19.255/22 , 172.16.20.1/22
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

路由器互相對接必須具備兩個條件：1. IP在同一網段，2. 不能設定為該網段的網路位址或廣播位址。
• 選項①：/27 網段大小為 32。192.168.1.32 剛好是網段的「網路位址」，不能給主機用。
• 選項②：/22 網段大小為 4 (第三碼)。172.16.16.0 網段範圍是 16.0 ~ 19.255。因此 18.255 與 19.1 都是中間的一般可用主機 IP，完美對接！
• 選項③：/30 網段大小為 4。192.168.3.4 是網路位址，5 和 6 是主機，.7 則是廣播位址，不能給主機用。
• 選項④：172.16.19.255 是 16.0/22 網段的廣播位址，不能用。且 .20.1 落在下一個網段（20.0/22）。

【各選項解析】
  • ① 192.168.1.32 是網路位址無法設定。
  • ② 正確。兩者皆為 172.16.16.0/22 網段中的有效主機 IP。
  • ③ 192.168.3.7 是廣播位址無法設定。
  • ④ 172.16.19.255 是廣播位址，且兩者不在同一網段。
主題：RIP 協定更新頻率
92. RIP（Routing Information Protocol）路由協定，預設每隔多久會送出完整的路由表給所有介面？
① 10 秒
② 20 秒
③ 30 秒
④ 40 秒
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

RIP 是一種典型的距離向量（Distance Vector）路由協定。為了保持網路拓樸的更新與確認鄰居是否存活，它的預設運作機制是「每隔 30 秒」，就會從所有啟動 RIP 的介面廣播一次自己完整的路由表給鄰居路由器。

【各選項解析】
  • ① 10 秒：此為 OSPF 協定發送 Hello 封包的預設時間。
  • ② 20 秒：無特別代表性路由協定使用此預設值。
  • ③ 30 秒：正確。此為 RIP 的基礎更新計時器（Update Timer）時間。
  • ④ 40 秒：此為 OSPF 認定鄰居失效的預設 Dead Timer 時間。
主題：RIP 協定跳數限制
93. RIP（Routing Information Protocol）路由協定，定義最長的 Hop count 為
① 5
② 10
③ 15
④ 20
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

RIP 協定使用經過的路由器數量（Hop count，跳數）來作為計算路徑好壞的成本。為了防止網路發生故障時出現「無窮迴圈（Routing loop，封包在兩台路由器間無限互傳）」，RIP 強制規定了一條路徑的最大有效跳數為 15 跳。如果一條路由的成本累積到 16 跳，則該網路會被標記為「不可達（Unreachable）」。

【各選項解析】
  • ① 5：太小，不足以應付一般中型網路。
  • ② 10：非標準限制。
  • ③ 15：正確。這是 RIP 所能支援的最大有效直徑網路跳數。
  • ④ 20：超出 RIP 能辨識的 16 跳上限。
主題：防迴圈協定 (STP)
94. 為防止網路產生迴圈（Loop），網路交換器（Switch）應採用下列何種 IEEE 標準？
① 802.1D
② 802.1Q
③ 802.1G
④ 802.1X
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在 Layer 2 區域網路中若連接了備援實體線路，很容易形成廣播風暴與無窮迴圈，導致交換器癱瘓。為此，IEEE 定義了 802.1D 標準，也就是「跨距樹協定（Spanning Tree Protocol, STP）」。它會自動計算網路拓樸並邏輯性地阻塞（Block）部分多餘的連接埠，來維持一個無迴圈的樹狀結構。

【各選項解析】
  • ① 802.1D：正確。為 Spanning Tree Protocol (STP) 的官方標準編號。
  • ② 802.1Q：這是虛擬區域網路 (VLAN) 的標籤標準。
  • ③ 802.1G：為遠端 MAC 橋接標準，非防迴圈主流應用。
  • ④ 802.1X：這是網路存取控制與身分認證（Port-based Network Access Control）的安全標準。
主題：VLAN 標籤標準
95. 為限制網路廣播封包範圍，可在網路交換器（Switch）採用 VLAN（Virtual LAN）阻隔廣播封包，其 IEEE 標準為下列何者？
① 802.1D
② 802.1Q
③ 802.1G
④ 802.1X
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

要將一台實體交換器劃分成多個邏輯上的虛擬區域網路（VLAN），以有效切割廣播網域並提升安全性，且讓不同品牌的交換器能彼此辨識 VLAN 資訊，就需要依靠 IEEE 制定的國際標準協定：802.1Q。它會在一般乙太網路訊框中插入帶有 VLAN ID 的標籤（Tag）。

【各選項解析】
  • ① 802.1D：STP 防迴圈協定標準。
  • ② 802.1Q：正確。VLAN 標籤（Tagging）標準。
  • ③ 802.1G：橋接協定的一種，與 VLAN 無直接關聯。
  • ④ 802.1X：基於連接埠的身分認證協定（搭配 RADIUS 伺服器使用）。
主題：多模光纖衰減值(850nm)
96. 依 ANSI/TIA/EIA-568-B3 規範，62.5/125 μm 多模光纖在 850nm 波長下，最大衰減值為何？
① 3.5 dB/km
② 1.5 dB/km
③ 1 dB/km
④ 2.5 dB/km
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

依據國際電信基礎設施配線標準 ANSI/TIA/EIA-568-B.3，規範了光纖線材的物理傳輸特性。針對傳統 62.5/125 μm 的多模光纖（Multimode Fiber），當使用 850nm（奈米）波長的光源進行傳輸時，其容許的最大信號衰減值（Attenuation）為 3.5 dB/km。

【各選項解析】
  • ① 3.5 dB/km：正確。為標準規範 850nm 波長下多模光纖的上限值。
  • ② 1.5 dB/km：這是該規格多模光纖在另一常用波長 1300nm 下的最大衰減值。
  • ③ 1 dB/km：針對單模光纖（1310nm或1550nm）的標準通常遠低於此數字(約0.5~1.0)，多模則較高。
  • ④ 2.5 dB/km：非標準文件定義之對應波長衰減值。
主題：多模光纖衰減值(1300nm)
97. 依 ANSI/TIA/EIA-568-B3 規範，62.5/125 μm 多模光纖在 1300nm 波長下，最大衰減值為何？
① 3.5 dB/km
② 1.5 dB/km
③ 1 dB/km
④ 2.5 dB/km
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

與上一題屬於同一份 ANSI/TIA/EIA-568-B.3 的規範內容。光在光纖中傳輸時，較長的波長通常受到材料散射與吸收的影響較小。因此同樣是 62.5/125 μm 的多模光纖，改使用 1300nm 的波長傳輸時，其容許的最大衰減值就會降到更優的 1.5 dB/km。

【各選項解析】
  • ① 3.5 dB/km：這是波長 850nm 下的最大衰減值。
  • ② 1.5 dB/km：正確。為標準規範 1300nm 波長下的容許上限。
  • ③ 1 dB/km：單模光纖的室外纜線標準數字。
  • ④ 2.5 dB/km：非此規範對應之數據。
主題：光資訊插座彎曲半徑
98. 依據「建築物屋內外電信設備設置技術規範」規定，光資訊插座盒所收容之光纖，其彎曲半徑應依製造廠之規定，如無建議值時，不得少於多少距離？
① 25mm
② 35 mm
③ 50 mm
④ 60 mm
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

光纖因為是利用全反射原理導光且材質為玻璃纖維，若過度彎折會導致嚴重的光能耗損（光斑洩漏），甚至折斷。台灣的建築物電信法規中明確規範，末端牆面上的「光資訊插座盒（Outlet）」內部空間有限，在整理盤繞光纖餘線時，其彎曲半徑絕對不得小於 25mm，以確保傳輸品質。

【各選項解析】
  • ① 25mm：正確。這是終端資訊插座盒內收容的最小安全彎曲半徑。
  • ② 35 mm：非法規針對「插座盒內光纖」的下限規範。
  • ③ 50 mm：空間需求太大，無法實作於一般牆面插座盒內。
  • ④ 60 mm：距離錯誤。
主題：屋內光纜彎曲半徑 (無拉力)
99. 依據「建築物屋內外電信設備設置技術規範」規定，屋內光纜之彎曲半徑應符合製造廠之規定，如無建議值時，在施工完畢後，於使用時或在無拉力狀態時，須保持不可小於光纜外徑的幾倍？
① 10 倍
② 15 倍
③ 20 倍
④ 25 倍
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

佈放整把的屋內光纜（Fiber Cable）時，針對彎曲半徑有兩種狀況的規範：
第一種是「靜態（無拉力）狀態」：也就是線已經佈放完畢、固定在線槽內日常使用時，因為沒有外力拉扯，稍微彎一點是可以容忍的。法規規定此時的彎曲半徑不可小於光纜本體外徑的 10 倍。

【各選項解析】
  • ① 10 倍：正確。此為「無拉力/施工後」狀態下的規範。
  • ② 15 倍：此為「有拉力/施工中」狀態下的規範。
  • ③ 20 倍：一般為屋外重型直埋光纜施工或特殊規範下的倍數。
  • ④ 25 倍：數字錯誤，非法規預設。
主題：屋內光纜彎曲半徑 (施工中)
100. 依據「建築物屋內外電信設備設置技術規範」規定，屋內光纜之彎曲半徑應符合製造廠之規定，如無建議值時，佈放施工時不可小於光纜外徑的幾倍？
① 10 倍
② 15 倍
③ 20 倍
④ 25 倍
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

承上題的延伸。當工程人員正在「佈放施工（拉線、牽引）」光纜時，這是處於第二種「動態（有拉力）狀態」。在拉扯光纜過彎時，內部的光纖會承受極大的應力，更容易斷裂受損。因此法規要求施工當下經過轉角時的彎曲弧度必須更為平緩，彎曲半徑不可小於光纜本體外徑的 15 倍，以保障線材安全。

【各選項解析】
  • ① 10 倍：這是施工完畢、放開拉力（靜態）後的容許值。
  • ② 15 倍：正確。施工拉線過程中要求更嚴格的 15 倍。
  • ③ 20 倍：室內輕型光纜無須要求至 20 倍。
  • ④ 25 倍：數字過大。
