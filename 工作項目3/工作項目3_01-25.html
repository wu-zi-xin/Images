1. 一 Class C 網路以網路遮罩 255.255.255.224 切割成子網路，可切成幾個網路區段？
①16
②8
③4
④2
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 Class C 預設遮罩為 255.255.255.0。遮罩 224 換算為二進位是 11100000，代表向主機區段借了 3 個位元 (bits) 來做子網路切割。2 的 3 次方為 8，因此可切割出 8 個網路區段。 【各選項解析】
  • ❌ ①16：若要切出 16 個區段，需借用 4 bits (2^4=16)，遮罩會是 240。
  • ⭕ ②8：正確。借用 3 bits (2^3=8)，遮罩即為 224。
  • ❌ ③4：若要切出 4 個區段，需借用 2 bits (2^2=4)，遮罩會是 192。
  • ❌ ④2：若要切出 2 個區段，需借用 1 bit (2^1=2)，遮罩會是 128。
2. 下列何者為 216.35.12.98/26 所處之子網路的可用 IP 範圍？
①216.35.12.1~216.35.12.127
②216.35.12.66~216.35.12.127
③216.35.12.65~216.35.12.126
④216.35.12.129~216.35.12.254
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 /26 的遮罩代表向 Class C 借了 2 bits，將網段切分為 4 塊，每塊大小為 64 (256-192=64)。網段依序為 0~63、64~127、128~191 等。IP 98 落在 64~127 這個區間。每個網段需扣除頭 (網路位址) 與尾 (廣播位址)，因此可用 IP 範圍為 65~126。 【各選項解析】
  • ❌ ①1~127：這跨越了兩個不同的網段 (0~63 與 64~127)。
  • ❌ ②66~127：起點少算了 65，且包含了不可分配的主機廣播位址 127。
  • ⭕ ③65~126：正確。扣除網路位址(64)與廣播位址(127)後的有效範圍。
  • ❌ ④129~254：這是下一個網段 (128~191) 及更後面網段的可用範圍。
3. Cat 5e UTP 線中有幾對雙絞線？
①1
②2
③4
④8
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 UTP (無遮蔽雙絞線) Cat 5e 網路線的內部標準結構是由 4 對（共 8 芯）互相纏繞的銅線所組成，兩兩絞在一起以抵銷電磁干擾。 【各選項解析】
  • ❌ ①1：電話線(RJ-11)內部通常是 1 對或 2 對。
  • ❌ ②2：早期的 10Base-T 網路或部分電話線實務上只用到 2 對線，但標準 Cat 5e 實體線材仍是 4 對。
  • ⭕ ③4：正確。標準 Cat 5/5e/6 網路線內皆為 4 對線 (橙、綠、藍、棕)。
  • ❌ ④8：是 8「芯」單線，而非 8「對」。
4. 下列何者為 221.35.12.200/26 所處之子網路的網路位址？
①221.35.12.192
②221.35.12.128
③221.35.12.40
④221.35.12.0
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 /26 遮罩會將網段切為區塊大小 64 (0, 64, 128, 192)。IP 200 位於 192 到 255 的區間，因此該子網段的起點 (Network ID) 為 192。 【各選項解析】
  • ⭕ ①192：正確。這是 IP 200 所落入網段 (192~255) 的網路位址。
  • ❌ ②128：這是前一個網段 (128~191) 的網路位址。
  • ❌ ③40：這只是一個普通的有效主機 IP。
  • ❌ ④0：這是第一個網段 (0~63) 的網路位址。
5. IEEE 802.11 未定義哪個傳輸技術？
①紅外線
②藍牙
③跳頻式展頻
④直接序列展頻
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 IEEE 802.11 是無線區域網路 (WLAN/Wi-Fi) 的標準。早期的 802.11 標準中定義了三種實體層傳輸技術：紅外線 (IR)、跳頻 (FHSS) 以及直接序列展頻 (DSSS)。藍牙則不屬於此標準。 【各選項解析】
  • ❌ ①紅外線：早期 802.11 標準確實有定義紅外線傳輸，但後來未成為主流。
  • ⭕ ②藍牙：正確。藍牙 (Bluetooth) 是屬於 IEEE 802.15 (個人區域網路 PAN) 的標準，並非 802.11。
  • ❌ ③跳頻式展頻 (FHSS)：早期 802.11 定義的無線電傳輸技術之一。
  • ❌ ④直接序列展頻 (DSSS)：802.11 (特別是 802.11b) 使用的核心傳輸技術。
6. 能濾除高頻載波訊號，再透過低通濾波器平滑訊號，以提取出原始調變訊號的峰值，是下列哪一種裝置？
①路由器
②交換器
③包絡檢波器
④數據機
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 這題考的是電子通訊原理。將含有資訊的高頻類比載波訊號，透過電路擷取其邊緣 (包絡線) 並濾除高頻以還原原始訊號的裝置，稱為「包絡檢波器」。 【各選項解析】
  • ❌ ①路由器：運作在第三層，處理 IP 封包選路，不管類比載波。
  • ❌ ②交換器：運作在第二層，處理 MAC 訊框交換。
  • ⭕ ③包絡檢波器：正確。此為 AM (調幅) 訊號解調的經典硬體電路。
  • ❌ ④數據機：(Modem) 廣義上包含調變與解調功能，但「提取峰值、平滑訊號」是特指其內部「包絡檢波」這項特定單元技術，因此選 ③ 最精確。
7. 下列何者不可能是網路遮罩值？
①255.255.240.0
②255.255.242.0
③255.255.255.128
④255.255.255.192
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 合法的子網路遮罩轉換為二進位時，必須遵守「左邊是連續的 1，右邊接著連續的 0」的嚴格規則，1 和 0 中間絕不能交錯。 【各選項解析】
  • ❌ ①240：二進位為 11110000 (合法)。
  • ⭕ ②242：正確。二進位為 11110010。出現了 1 與 0 的交錯，因此絕對不可能是網路遮罩。
  • ❌ ③128：二進位為 10000000 (合法)。
  • ❌ ④192：二進位為 11000000 (合法)。
8. 下列何種 IEEE 標準協定使用 CSMA/CD？
①802.3
②802.4
③802.5
④802.11
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 CSMA/CD (載波感測多重存取/碰撞偵測) 是早期半雙工「有線乙太網路 (Ethernet)」用來解決封包碰撞衝突的核心機制。 【各選項解析】
  • ⭕ ①802.3：正確。這是有線乙太網路的 IEEE 標準，採用 CSMA/CD。
  • ❌ ②802.4：這是 Token Bus (權杖匯流排) 網路標準。
  • ❌ ③802.5：這是 Token Ring (權杖環) 網路標準。
  • ❌ ④802.11：這是無線區域網路 (Wi-Fi)，採用的是 CSMA/CA (碰撞「避免」)。
9. 乙太網路封包位址的長度是多少位元？
①128
②32
③48
④可變動
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 乙太網路封包位址指的是網路卡出廠時燒錄的「實體 MAC 位址」，它的長度是固定不變的。 【各選項解析】
  • ❌ ①128：這是 IPv6 位址的長度。
  • ❌ ②32：這是 IPv4 位址的長度。
  • ⭕ ③48：正確。MAC 位址長度固定為 48 位元 (通常以 6 組 16 進位數表示，如 00:1A:2B...)。
  • ❌ ④可變動：MAC 位址長度是固定規格，不可變動。
10. 路由表中，預設路由之網路位址及遮罩各為何？
①0.0.0.0 及 0.0.0.0
②0.0.0.0 及 255.255.255.255
③255.255.255.255 及 0.0.0.0
④255.255.255.255 及 255.255.255.255
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 預設路由 (Default Route) 的作用是「當路由器找不到任何一條匹配的目的地紀錄時，就把封包全都丟往這裡」。在 IPv4 中，代表「所有未知網段」的表示法就是全 0。 【各選項解析】
  • ⭕ ①0.0.0.0 及 0.0.0.0：正確。常被簡寫為 0.0.0.0/0。
  • ❌ ②0.0.0.0 及 255.255.255.255：遮罩 255.255.255.255 代表「嚴格匹配單一主機」，與預設路由本意不符。
  • ❌ ③/④ 255.255.255.255：這是受限廣播位址，不會用作路由表的網段位址。
11. 若要使用 CIDR 整合 16 組 Class C 之 IP 位址 199.1.16.0~199.1.31.0 成單一網路，則超網路遮罩（Supernet Mask）為何？
①255.255.248.0
②255.255.252.0
③255.255.240.0
④255.255.255.248
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 Class C 預設遮罩為 /24。要將 16 個連續網段合併，需要將遮罩向左退縮 (減少) 4 個位元 (因為 2^4 = 16)。/24 退縮 4 位元變成 /20。/20 對應的十進位遮罩為 255.255.240.0。 【各選項解析】
  • ❌ ①248.0：這是 /21，只能合併 8 個 Class C 網段。
  • ❌ ②252.0：這是 /22，只能合併 4 個 Class C 網段。
  • ⭕ ③240.0：正確。這是 /20，剛好可以合併 16 個 Class C 網段。
  • ❌ ④255.248：這是 /29，用來把「單一個」網段切得很小，而非合併。
12. 由網路外要送封包給 Class C 200.119.101.0 中所有 host，則封包之目的地位址應為何？
①255.255.255.255
②200.119.101.255
③200.119.101.0
④0.0.0.0
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 從外部網路發送廣播給「某個特定網段」的所有設備，這種行為稱為「直接廣播 (Directed Broadcast)」。做法是保留該網段的網路 ID，將主機 ID 部分全部填滿 1。 【各選項解析】
  • ❌ ①255.255.255.255：這是受限廣播位址，路由器不會轉發，外部無法送達。
  • ⭕ ②200.119.101.255：正確。這是該 Class C 網段的直接廣播位址。
  • ❌ ③200.119.101.0：這是該網段的網路位址 (Network ID)，代表網段本身，不作為傳送目標。
  • ❌ ④0.0.0.0：通常用於預設路由或未知來源 IP，非目的地位址。
13. 200.119.101.5 要送封包給同一網路中所有 host，則封包之目的地位址應為何？
①200.119.101.255
②255.255.255.255
③0.0.0.0
④200.119.101.0
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 當主機要在「自己身處的區域網路內部」發送廣播，且不希望封包跨越路由器跑到外面去時，會使用「受限廣播位址 (Limited Broadcast)」。 【各選項解析】
  • ❌ ①200.119.101.255：這是直接廣播，雖然在區網內也會通，但標準上本機內網廣播以 255.255.255.255 為主考點答案。
  • ⭕ ②255.255.255.255：正確。所有主機 IP 不論為何，對內網發送廣播時皆可統一使用此位址，路由器絕對不會轉發。
  • ❌ ③0.0.0.0：代表預設或未知，不作廣播用。
  • ❌ ④200.119.101.0：為網路 ID，不可用作目的位址。
14. 就傳播方式（單播、群播、廣播）而言，ARP request 及 ARP reply 分別使用何種方式？
①廣播，單播
②單播，廣播
③廣播，廣播
④單播，單播
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 ARP (位址解析協定) 的運作流程：發問者不知道目標在哪，所以大喊 (廣播)「請問誰是這個 IP？」；目標設備聽到後，因為已經知道發問者是誰，就私下悄悄回傳 (單播)「這是我，我的 MAC 是...」。 【各選項解析】
  • ⭕ ①廣播，單播：正確。Request = Broadcast，Reply = Unicast。
  • ❌ ②單播，廣播：完全相反了。
  • ❌ ③廣播，廣播：Reply 不需要浪費頻寬廣播給大家聽。
  • ❌ ④單播，單播：一開始根本不知道對方的 MAC，無法使用單播發問。
15. 在 Gigabit 乙太網路規格定義訊框與訊框之間的間隔時間為何？
①96 Bit Time
②128 Bit Time
③86 Bit Time
④48 Bit Time
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 在乙太網路 (Ethernet) 標準中，為了讓網路設備的接收端晶片有足夠的復原、準備與處理時間，規定連續發送的兩個訊框 (Frame) 之間必須保留一段最小間隔，稱為 Inter-Frame Gap (IFG)。 【各選項解析】
  • ⭕ ①96 Bit Time：正確。無論是 10M, 100M 還是 1000M (Gigabit)，標準的 IFG 皆固定為 96 個位元時間。
  • ❌ ②128 / ③86 / ④48：皆非 IEEE 802.3 規範所定義的訊框間隔時間標準。
16. 「建築物屋內外電信設備設置技術規範」關於宅內配線箱之設置規定，下列何者不正確？
①應離地面 30 ㎝以上
②箱門應具備空氣對流功能之通風設計
③箱內須有 110V 電源裝置
④從宅內配線箱至宅內各廳室出線匣之配線方式應以環狀為之，並設置資訊插座
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 法規考題，要求選出「不正確」的選項。通訊配線為了確保訊號品質與日後維修方便，必須採用「星狀」拓樸拉線。 【各選項解析】
  • ❌ ①應離地面 30 ㎝以上：正確規定，避免淹水潮濕。
  • ❌ ②箱門應具備空氣對流功能之通風設計：正確規定，因內部會有分享器或數據機等發熱設備。
  • ❌ ③箱內須有 110V 電源裝置：正確規定，提供主動式網路設備電力。
  • ⭕ ④應以環狀為之：錯誤敘述！法規明定必須以「星狀 (Star)」配線 (每一出線匣獨立拉一條線回到配線箱)，不可串聯成環狀。
17. 當與 MAC 位址運作時屬於 OSI 中哪一層？
①資料鏈路層
②網路層
③表示層
④應用層
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 OSI 模型中，各層負責的尋址機制不同：MAC 位址負責區域網路內的實體尋址，IP 位址負責跨網段的邏輯尋址。 【各選項解析】
  • ⭕ ①資料鏈路層 (Layer 2)：正確。負責 MAC (Media Access Control) 位址的讀取與訊框交換。
  • ❌ ②網路層 (Layer 3)：運作 IP 位址。
  • ❌ ③表示層 (Layer 6)：負責資料格式、壓縮、加密。
  • ❌ ④應用層 (Layer 7)：運作高階協定如 HTTP、FTP。
18. 使用兩個相位狀態表示二進位資料中的 0 和 1 的調變技術是下列哪一種？
①二進位相位鍵控（BPSK）
②四相相位鍵控（QPSK）
③偏移四相相移鍵控（Offset-QPSK）
④八相相位鍵控（8PSK）
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 數位調變技術中，利用「相位 (Phase)」的改變來代表資料 0 與 1，稱為相位鍵控 (PSK)。 【各選項解析】
  • ⭕ ①BPSK (Binary PSK)：正確。Binary 意即「二進位 / 兩種」，使用 0 度與 180 度兩種相位，剛好代表位元 0 和 1。
  • ❌ ②QPSK (Quadrature PSK)：使用 4 種相位狀態，可表示 2 bits (00, 01, 10, 11)。
  • ❌ ③Offset-QPSK：QPSK 的改良版，一樣是 4 種狀態。
  • ❌ ④8PSK：使用 8 種相位狀態，可表示 3 bits。

①實體層
②傳輸層
③資料鏈路層
④應用層
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 雖然傳輸層 (TCP) 也會對「封包(Segment)」進行定序，但在 OSI 模型的原始嚴格定義中，針對「訊框 (Frame)」在相鄰節點間的流量控制與定序，是第二層中 LLC (邏輯鏈路控制) 子層的職責。 【各選項解析】
  • ❌ ①實體層：只負責傳送 0 與 1 的電氣訊號，不管順序。
  • ❌ ②傳輸層：雖然做端對端定序，但在名詞定義上它處理的是 Segments(區段) 而非 Frames(訊框)。
  • ⭕ ③資料鏈路層：正確。負責 Frame 的偵錯、流量控制及定序。
  • ❌ ④應用層：提供應用程式網路介面。
20. POP3 在 TCP/IP 的埠號為何？
①UDP Port 21
②TCP Port 23
③UDP Port 25
④TCP Port 110
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 POP3 (Post Office Protocol version 3) 是收信端用來從郵件伺服器「下載接收」電子郵件的標準通訊協定。 【各選項解析】
  • ❌ ①UDP Port 21：Port 21 是 FTP (檔案傳輸協定) 控制埠，且使用 TCP。
  • ❌ ②TCP Port 23：Port 23 是 Telnet (遠端登入協定)。
  • ❌ ③UDP Port 25：Port 25 是 SMTP (發送郵件協定)，且使用 TCP。
  • ⭕ ④TCP Port 110：正確。POP3 預設使用 TCP 110 埠。
21. CSMA/CD 是屬於 IEEE 802 中哪一項標準？
①802.1
②802.2
③802.3
④802.5
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 CSMA/CD (載波感測多重存取/碰撞偵測) 是有線乙太網路 (Ethernet) 解決封包碰撞的基礎規範。 【各選項解析】
  • ❌ ①802.1：網路橋接、VLAN (802.1Q) 與網路管理的高階標準。
  • ❌ ②802.2：定義資料鏈路層的上半部 LLC (邏輯鏈路控制)。
  • ⭕ ③802.3：正確。此為乙太網路 (Ethernet) 的標準，定義了 CSMA/CD。
  • ❌ ④802.5：定義 Token Ring (權杖環) 網路，無碰撞問題不需 CSMA/CD。
22. 路由器採用以下哪種資訊判斷封包之目的地網路 ID？
①IP 標頭長度
②子網路遮罩
③位址類別
④MAC 位址
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 路由器在收到封包時，必須判斷該封包要送往哪一個網段。它的做法是將封包的「目的 IP 位址」與路由表內的「子網路遮罩」進行邏輯 AND (及) 運算，計算出最終的 Network ID (網路位址)。 【各選項解析】
  • ❌ ①IP 標頭長度：只用來確認封包標頭大小，無關路由判斷。
  • ⭕ ②子網路遮罩：正確。遮罩(Mask)是唯一能用來界定網路 ID 長度的關鍵參數。
  • ❌ ③位址類別：現代網路已全面採用無類別 (Classless/CIDR) 路由，不再單純依靠 ABC Class 判斷。
  • ❌ ④MAC 位址：這是 Layer 2 交換器轉發的依據，路由器尋路看的是 IP。
23. 下列哪個 IP 位址是 Class C 位址？
①10.20.30.40
②140.30.50.65
③230.20.35.14
④200.17.45.15
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 背誦 IPv4 類別的「第一組數字」範圍：Class A (1~126)、Class B (128~191)、Class C (192~223)、Class D (224~239)。 【各選項解析】
  • ❌ ①10.20.30.40：10 開頭屬於 Class A。
  • ❌ ②140.30.50.65：140 開頭屬於 Class B。
  • ❌ ③230.20.35.14：230 開頭屬於 Class D (多播專用)。
  • ⭕ ④200.17.45.15：正確。200 開頭落在 192~223 的 Class C 範圍內。
24. 哪個 Class 的 IP 位址可進行多播（Multicast）傳輸？
①Class A
②Class E
③Class B
④Class D
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 多播/群播 (Multicast) 是指「一對多」的傳輸模式，用來將單一封包同時派發給有訂閱該群組的多台主機。IANA 特別保留了一個 IP 區段供此功能專用。 【各選項解析】
  • ❌ ①Class A / ③Class B：這兩者與 Class C 皆為供一般主機使用的單播 (Unicast) 位址。
  • ❌ ②Class E：網段 (240~255)，保留給未來的實驗或研究用途。
  • ⭕ ④Class D：正確。網段 (224~239) 為群播/多播的專用保留位址。
25. 從主機 IP 位址之 hostid 部分使用多少位元可建立 40 個 subnet？
①10bit
②6bit
③4bit
④8bit
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 要建立 n 個子網路 (Subnet)，必須向主機區段借用位元。借用位元數與子網路數量的關係為 `2 的借用位元數次方 ≥ 需求數量`。本題需求為 40。 【各選項解析】
  • ❌ ①10bit：2^10 = 1024 個 (遠超過需求，浪費主機 IP 空間)。
  • ⭕ ②6bit：正確。2^6 = 64。64 大於 40，是最精準滿足需求且最少浪費的借位數量。
  • ❌ ③4bit：2^4 = 16 個 (不夠 40 個)。
  • ❌ ④8bit：2^8 = 256 個 (超過太多)。
