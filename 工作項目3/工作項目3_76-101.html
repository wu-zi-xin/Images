76. 下列何者為 ARP 協定功能？
①搜尋 Layer 3 目的位址
②用以開發 Layer 4 資源表的快取
③用以對應 IP 位址與 MAC 位址
④送出廣播訊息尋找路由器 IP 位址
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 ARP (Address Resolution Protocol，位址解析協定) 的核心功能，就是在區域網路內，透過已知的 IP 位址 (Layer 3) 廣播詢問，以取得對應的硬體 MAC 位址 (Layer 2)，藉此建立實體連線。 【各選項解析】
  • ❌ ①搜尋 Layer 3 目的位址：尋找網路層(Layer 3)路徑是路由協定 (如 OSPF, RIP) 的功能。
  • ❌ ②用以開發 Layer 4 資源表的快取：ARP 運作在 Layer 2 與 Layer 3 之間，與傳輸層 (Layer 4) 無關。
  • ⭕ ③用以對應 IP 位址與 MAC 位址：完全正確，此為 ARP 的唯一核心作用。
  • ❌ ④送出廣播訊息尋找路由器 IP 位址：尋找路由器 IP 通常透過 DHCP、BOOTP 或 ICMP Router Discovery，ARP 是拿「已知 IP」找 MAC。
77. 當進行網路測試時，下列何者正確？
①應依序從 OSI 參考模型之第一層到第二層，依此類推
②應直接處理 OSI 層中之特定層
③應與管理階層共同處理
④應以隨機方式測試 OSI 參考模型中的任一層
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 網路除錯與測試的標準且最有效的流程，是採用「由下而上 (Bottom-Up) 排查法」。必須先確認基礎硬體沒問題，才能排除上層軟體的錯誤。 【各選項解析】
  • ⭕ ①應依序從 OSI 參考模型之第一層到第二層：正確，先查實體層(網路線、燈號)，再查資料鏈路層(MAC、Switch)，依序往上。
  • ❌ ②應直接處理 OSI 層中之特定層：直接瞎猜特定層容易漏掉底層的基礎錯誤。
  • ❌ ③應與管理階層共同處理：網路連線為技術問題，首要由工程/網管技術人員處理。
  • ❌ ④應以隨機方式測試：隨機測試缺乏邏輯，會大幅浪費除錯時間。
78. 在處理網路連線問題時，下列何者正確？
①從 Layer 1 開始
②從 Layer 2 開始
③從 Layer 3 開始
④從 Layer 7 開始
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 承上題觀念，實務上處理網路不通的第一步，永遠是「檢查網路線有沒有插好」、「設備電源有沒有開」、「網卡燈號有沒有亮」。這些都屬於第一層 (Layer 1) 實體層的範疇。 【各選項解析】
  • ⭕ ①從 Layer 1 開始：正確。確保硬體與線路暢通是網路通訊的基礎。
  • ❌ ②從 Layer 2 開始：若實體線路斷了，查 MAC 或 Switch 設定也沒用。
  • ❌ ③從 Layer 3 開始：若線沒接好，直接查 IP 位址或路由是本末倒置。
  • ❌ ④從 Layer 7 開始：從應用程式層(如瀏覽器)往下查(Top-Down)雖有此理論，但在「基礎連線問題」上效率極差。
79. ICMP 為下列何者之縮寫？
①Internet Control Message Parameter
②Internal Control Message Protocol
③Internet Control Message Protocol
④Internet Control Message Performance
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 ICMP 是網路層的重要協定，專門用來在 IP 網路上傳送控制訊息、回報錯誤狀態，以及進行網路診斷 (例如最知名的 Ping 和 Traceroute 都是使用它)。 【各選項解析】
  • ❌ ① Parameter：字尾錯誤，P 是 Protocol (協定)。
  • ❌ ② Internal：字首錯誤，I 是 Internet (網際網路)。
  • ⭕ ③ Internet Control Message Protocol：全名完全正確。
  • ❌ ④ Performance：字尾錯誤，與效能單字無關。
80. Telnet 為 OSI 參考模型中的哪一層協定？
①Layer 1
②Layer 5
③Layer 6
④Layer 7
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 Telnet 是一種讓使用者能透過遠端終端機連線至伺服器的網路協定。因為它直接提供介面與服務給終端使用者(或應用程式)操作，因此歸類於 OSI 模型的最上層。 【各選項解析】
  • ❌ ①Layer 1 (實體層)：負責傳輸電氣訊號。
  • ❌ ②Layer 5 (會談層)：負責建立、管理通訊對話。
  • ❌ ③Layer 6 (表示層)：負責資料格式轉換、加解密。
  • ⭕ ④Layer 7 (應用層)：直接提供網路服務給使用者，如 HTTP, FTP, Telnet 皆屬此層。
81. 比較二進位相位鍵控（BPSK）和四相相位鍵控（QPSK）的敘述，下列何者錯誤？
①QPSK 的傳輸速度比較快
②QPSK 所需要的傳輸頻寬較大
③BPSK 抗雜訊的能力較高
④BPSK 較容易實作
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 BPSK 每次波形改變傳遞 1 bit；QPSK 有四種相位變化，每次波形改變可傳遞 2 bits。本題要選出「錯誤」的敘述。 【各選項解析】
  • ❌ ①QPSK 的傳輸速度比較快：正確敘述。一次傳 2 bits，速度自然比 BPSK (一次 1 bit) 快。
  • ⭕ ②QPSK 所需要的傳輸頻寬較大：錯誤敘述！因為 QPSK 的「頻譜效率」較高，在傳輸相同資料量的情況下，QPSK 所需的頻寬反而比 BPSK 來得「小」。因此選此項。
  • ❌ ③BPSK 抗雜訊的能力較高：正確敘述。BPSK 只有 0 度與 180 度兩種相位，差距大，較不易受雜訊干擾誤判。
  • ❌ ④BPSK 較容易實作：正確敘述。只需辨識兩種相位，硬體電路設計較簡單。
82. 下列何種設備提供 LAN 的邏輯區隔？
①路由器（Router）
②橋接器（Bridge）
③交換器（Switch）
④集線器（Hub）
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 「邏輯區隔」指的是在 IP 網路層 (Layer 3) 將網路切割成不同的子網路 (Subnet) 或廣播網域 (Broadcast Domain)。 【各選項解析】
  • ⭕ ①路由器（Router）：運作於 Layer 3，各個介面屬於不同的邏輯網段，完美提供邏輯區隔與阻擋廣播。
  • ❌ ②橋接器（Bridge）：運作於 Layer 2，只能切割「實體碰撞區」，無法進行 IP 邏輯區隔。
  • ❌ ③交換器（Switch）：基本等同多埠橋接器，無法阻隔廣播，除非具備 Layer 3 或 VLAN 功能(但一般泛指 Layer 2)。
  • ❌ ④集線器（Hub）：運作於 Layer 1，什麼都無法區隔，全網域共享。
83. 區域網路中，下列何者不是採用 Layer 3 設備的目的？
①允許 LAN 區隔出子網路
②允許與 WAN 連接
③提供網路的邏輯結構
④增加 LAN 的大小
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 Layer 3 設備（如路由器）造價昂貴，通常是用來處理「智慧型」的路由任務。本題要選出「不是」其主要目的之選項。 【各選項解析】
  • ❌ ①允許 LAN 區隔出子網路：這是 L3 設備的核心目的。
  • ❌ ②允許與 WAN 連接：連接外部網路(WAN)必須靠具備路由功能的 L3 設備。
  • ❌ ③提供網路的邏輯結構：透過 IP 規劃建立層次化網路，亦是 L3 目的。
  • ⭕ ④增加 LAN 的大小：如果單純只是要「增加區域網路的實體涵蓋範圍或增加電腦數量」，只需要買便宜的 Layer 2 交換器 (Switch) 或串接即可，不需要動用到 Layer 3 設備。
84. 下列何種設備可阻隔網路廣播（Broadcast）？
①集線器（Hub）
②橋接器（Bridge）
③Layer 2 交換器
④路由器（Router）
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 廣播封包 (目的 MAC 為 FF-FF-FF-FF-FF-FF) 預設會在同一個區域網路內四處流竄。要擋下它，必須使用第三層的設備。 【各選項解析】
  • ❌ ①集線器（Hub）：收到訊號就向所有洞口廣播，毫無阻隔能力。
  • ❌ ②橋接器（Bridge）：會阻隔單播碰撞，但一看到廣播封包依然會放行通過。
  • ❌ ③Layer 2 交換器：跟橋接器一樣，預設會將廣播封包從所有其他連接埠送出。
  • ⭕ ④路由器（Router）：路由器天生會「終結」廣播封包，絕對不會將廣播封包轉發到其他網段，藉此避免廣播風暴。
85. 下列何種設備無法劃分不同碰撞區（Collision domain）？
①路由器（Router）
②Layer 2 交換器
③集線器（Hub）
④橋接器（Bridge）
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 碰撞區是指「當兩台電腦同時發送信號時，會發生信號碰撞的網路區域」。能夠讀取 MAC 位址以上的設備都能劃分碰撞區。 【各選項解析】
  • ❌ ①路由器：L3 設備，每個埠口都是獨立的碰撞區與廣播區。
  • ❌ ②Layer 2 交換器：L2 設備，每個埠口都是獨立的碰撞區。
  • ⭕ ③集線器（Hub）：L1 設備，內部只是實體線路的串接，所有連接在同一台 Hub 上的電腦都處於「同一個」大碰撞區內，無法劃分。
  • ❌ ④橋接器：L2 設備，每個埠口都是獨立的碰撞區。
86. IP 位址為 172.16.30.56 時，預設網路 ID（Network ID）為何？
①172
②172.16
③172.16.30
④172.16.30.56
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 首先判斷 172 開頭屬於 Class B 網路 (範圍 128~191)。Class B 的預設子網路遮罩是 255.255.0.0。 【各選項解析】
  • ❌ ①172：這是 Class A (遮罩 255.0.0.0) 的預設網路 ID 格式。
  • ⭕ ②172.16：正確。Class B 的前兩個位元組(16 bits)是用來辨識網路區段 (Network ID)。
  • ❌ ③172.16.30：這是 Class C (遮罩 255.255.255.0) 的預設網路 ID 格式。
  • ❌ ④172.16.30.56：這是包含主機 ID 的完整 IP 位址。
87. IP 位址為 172.16.30.56 時，預設節點 ID（Node ID）為何？
①172.16.30.56
②16.30.56
③30.56
④56
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 承上題，172 開頭為 Class B 網路，前兩個位元組是網路 ID (172.16)，那麼剩下的後兩個位元組就是保留給設備使用的節點 (主機) ID。 【各選項解析】
  • ❌ ①172.16.30.56：完整 IP，未區分網段與主機。
  • ❌ ②16.30.56：這是如果該 IP 為 Class A 時的主機 ID。
  • ⭕ ③30.56：正確。扣除掉 172.16 後，剩下的 30.56 即為 Node ID。
  • ❌ ④56：這是如果該 IP 為 Class C 時的主機 ID。
88. IP 位址第 1 個位元組為 11010111 時，屬於下列哪個級別（Class）？
①Class A
②Class B
③Class C
④Class D
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 IPv4 是依據第一組數字的二進位開頭來分類。11010111 明顯是「110」開頭，對應到十進位是 215。 【各選項解析】
  • ❌ ①Class A：二進位必須是「0」開頭 (0~127)。
  • ❌ ②Class B：二進位必須是「10」開頭 (128~191)。
  • ⭕ ③Class C：二進位必須是「110」開頭 (192~223)。本題符合。
  • ❌ ④Class D：二進位必須是「1110」開頭 (224~239)，保留作多播用。
89. IP 位址第 1 個位元組為下列何者時，屬於 Class B 網路位址？
①01XXXXXX
②0XXXXXXX
③10XXXXXX
④110XXXXX
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 測驗 IP 網段分類的基本定義。Class B 的設計規定第一組位元組的最高兩位必須固定為 10。 【各選項解析】
  • ❌ ①01XXXXXX：屬於 Class A 的一半範圍 (64~127)。
  • ❌ ②0XXXXXXX：這是完整的 Class A 網段定義 (0開頭)。
  • ⭕ ③10XXXXXX：正確。固定 10 開頭，使得十進位範圍落在 128~191。
  • ❌ ④110XXXXX：這是 Class C 網段的定義。
90. 網路位址為 172.160.0.0，子網路遮罩為 255.255.255.128，可切割出多少個子網路（Subnets）？
①1024
②64
③128
④512
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 1. 172.160.0.0 屬於 Class B，預設網路遮罩為 255.255.0.0 (長度 16 bits)。
2. 題目給的遮罩是 255.255.255.128，轉換為連續的 1 是 8+8+8+1 = 25 個 bits (/25)。
3. 借用的位元數 (Subnet bits) = 25 - 16 = 9 bits。
4. 可切割出的子網路數 = 2 的 9 次方 = 512。 【各選項解析】
  • ❌ ①1024：要借用 10 bits 才會是 1024 (遮罩為 255.255.255.192)。
  • ❌ ②64：要借用 6 bits 才會是 64 (遮罩為 255.255.252.0)。
  • ❌ ③128：要借用 7 bits 才會是 128 (遮罩為 255.255.254.0)。
  • ⭕ ④512：正確。借用 9 bits，2^9 = 512 個網段。
91. 兩個路由器之 WAN 端介面對接，其個別 IP 可設定為
①192.168.1.32/27，192.168.1.33/27
②172.16.18.255/22，172.16.19.1/22
③192.168.3.6/30，192.168.3.7/30
④172.16.19.255/22，172.16.20.1/22
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 路由器介面對接必須確保兩端 IP 落在「同一個合法且可用的網段內」(不能是 Network ID 或 Broadcast)。 【各選項解析】
  • ❌ ①192.168.1.32/27, 33/27：/27 切塊為 32。32 剛好是該網段的 Network ID，不可指派給介面。
  • ⭕ ②172.16.18.255/22, 19.1/22：/22 在第三區塊切塊為 4。包含的網段為 172.16.16.0 ~ 172.16.19.255。此網段的廣播是 19.255，而 18.255 只是中間的一個合法 IP，與 19.1 同屬此網段，完美對接。
  • ❌ ③192.168.3.6/30, 7/30：/30 切塊為 4。網段為 4,5,6,7。其中 6 是可用 IP，但 7 是該網段的 Broadcast，不可指派。
  • ❌ ④172.16.19.255/22, 20.1/22：19.255 是 16~19 網段的廣播位址；而 20.1 是 20~23 下一個網段的 IP，兩者不在同網段。
92. RIP（Routing Information Protocol）路由協定，預設每隔多久會送出完整的路由表給所有介面？
①10 秒
②20 秒
③30 秒
④40 秒
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 RIP 是一個相對古老的距離向量 (Distance Vector) 協定。它的缺點之一就是相當耗費頻寬，因為它不管網路有沒有變動，都會「定時」廣播整份路由表給鄰居。 【各選項解析】
  • ❌ ①10 秒：這是 OSPF 協定預設發送 Hello 封包 (確認存活) 的間隔時間。
  • ❌ ②20 秒：並非常見路由協定的預設廣播時間。
  • ⭕ ③30 秒：正確。RIP 預設的 Update Timer 就是 30 秒。
  • ❌ ④40 秒：錯誤時間設定。
93. RIP（Routing Information Protocol）路由協定，定義最長的 Hop count 為
①5
②10
③15
④20
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【綜合解析】 RIP 協定使用「經過了幾台路由器 (Hop count)」來計算距離。為了避免路由迴圈導致封包永無止境地在網路中繞圈圈，它規定了最大跳數的限制。 【各選項解析】
  • ❌ ①5 / ②10 / ④20：皆非 RIP 協定定義的限制值。
  • ⭕ ③15：正確。RIP 最大有效跳數為 15，當計數達到 16 時，系統會視為該目標網路無法到達 (Unreachable) 或產生無窮大。
94. 為防止網路產生迴圈（Loop），網路交換器（Switch）應採用下列何種 IEEE 標準？
①802.1D
②802.1Q
③802.1G
④802.1X
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 為提升網路可靠度，網管通常會在 Switch 之間接多條備援線路，但這會產生實體迴圈引發廣播風暴。IEEE 制定了 STP 協定來自動封鎖多餘線路，斷線時再自動啟用。 【各選項解析】
  • ⭕ ①802.1D：正確。此為擴張樹協定 (Spanning Tree Protocol, STP) 的 IEEE 標準編號。
  • ❌ ②802.1Q：這是虛擬區域網路 (VLAN) 的封包標籤標準。
  • ❌ ③802.1G：早期的遠端 MAC 橋接標準，現在幾乎無人使用。
  • ❌ ④802.1X：這是以連接埠為基礎的網路存取控制 (身分認證) 標準。
95. 為限制網路廣播封包範圍，可在網路交換器（Switch）採用 VLAN（Virtual LAN）阻隔廣播封包，其 IEEE 標準為下列何者？
①802.1D
②802.1Q
③802.1G
④802.1X
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 要在 Layer 2 交換器上切割出不同的廣播網域 (VLAN)，並讓這些 VLAN 資訊能在不同交換器間傳遞(Trunking)，必須幫封包打上標籤。 【各選項解析】
  • ❌ ①802.1D：STP 防止迴圈標準。
  • ⭕ ②802.1Q：正確。常被簡稱為 dot1q，是 VLAN 標籤化 (Tagging) 的業界標準。
  • ❌ ③802.1G：遠端橋接標準。
  • ❌ ④802.1X：網路存取身分認證標準。
96. 依 ANSI/TIA/EIA-568-B3 規範，62.5/125 μm 多模光纖在 850nm 波長下，最大衰減值為何？
①3.5 dB/km
②1.5 dB/km
③1 dB/km
④2.5 dB/km
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 光纖傳輸時光信號會隨距離衰減。依照 EIA-568 標準，多模光纖在使用波長較短的 850nm 時，光散射損耗較嚴重，因此規範允許的最大衰減值較寬鬆。 【各選項解析】
  • ⭕ ①3.5 dB/km：正確。850nm 波長下的衰減標準就是 3.5 分貝/公里。
  • ❌ ②1.5 dB/km：這是 1300nm 較長波長時的衰減標準 (損耗較低)。
  • ❌ ③1 dB/km / ④2.5 dB/km：皆為非標準之干擾數據。
97. 依 ANSI/TIA/EIA-568-B3 規範，62.5/125 μm 多模光纖在 1300nm 波長下，最大衰減值為何？
①3.5 dB/km
②1.5 dB/km
③1 dB/km
④2.5 dB/km
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 承上題觀念，若同樣是多模光纖，但改用波長較長 (1300nm) 的光源傳輸，光波在纖芯中的折射與散射情況較輕微，訊號衰減變小，因此規範標準會比較嚴格(數值小)。 【各選項解析】
  • ❌ ①3.5 dB/km：是 850nm 時的衰減標準。
  • ⭕ ②1.5 dB/km：正確。1300nm 波長下的衰減標準值。
  • ❌ ③1 dB/km / ④2.5 dB/km：非標準規定值。
98. 依據「建築物屋內外電信設備設置技術規範」規定，光資訊插座盒所收容之光纖，其彎曲半徑應依製造廠之規定，如無建議值時，不得少於多少毫米？
①30 mm
②40 mm
③50 mm
④60 mm
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 光纖由玻璃或塑膠製成，最忌諱過度折彎，這會導致光信號嚴重流失甚至直接斷芯。在狹小的資訊插座盒內理線收容時，有最小彎曲半徑的安全規定。 【各選項解析】
  • ⭕ ①30 mm：正確。規範中明定，若原廠無特別指示，插座內終端收容的彎曲半徑不得小於 3公分 (30 mm)。
  • ❌ ②40 mm / ③50 mm / ④60 mm：皆不符合該規範明文記載之最低下限。
99. 依據「建築物屋內外電信設備設置技術規範」規定，屋內光纜之彎曲半徑應符合製造廠之規定，如無建議值時，在施工完畢後，於使用時或在無拉力狀態時，須保持不可小於光纜外徑的幾倍？
①10 倍
②15 倍
③20 倍
④25 倍
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 屋內光纜佈放完成並固定在線槽內後，屬於「靜態、無拉力狀態」。這時候的彎曲限制會比施工拖拉時來得寬鬆。 【各選項解析】
  • ⭕ ①10 倍：正確。無外加拉力的靜態佈放，彎曲半徑只需維持大於光纜本身外徑的 10 倍即可。
  • ❌ ②15 倍：這是「施工中」承受拉力時的動態標準。
  • ❌ ③20 倍：通常指屋外較硬光纜在承受拉力時的標準。
  • ❌ ④25 倍：非規範數值。
100. 依據「建築物屋內外電信設備設置技術規範」規定，屋內光纜之彎曲半徑應符合製造廠之規定，如無建議值時，佈放施工時不可小於光纜外徑的幾倍？
①10 倍
②15 倍
③20 倍
④25 倍
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【綜合解析】 在「佈放施工」的過程中，工程人員會拉扯光纜，光纜處於承受應力的「動態」狀況。為了保護內部光纖不被拉斷，法規對於施工時的彎曲角度限制得比平時更嚴格(半徑要更大)。 【各選項解析】
  • ❌ ①10 倍：這是靜態、佈放完成後的標準。
  • ⭕ ②15 倍：正確。施工時因帶有拉力，不可小於外徑的 15 倍。
  • ❌ ③20 倍 / ④25 倍：對屋內光纜而言並非標準規定。
101. 依 ANSI/TIA/EIA-568-B3 規範，單模光纖轉接器或面板的顏色為何？
①米黃色
②紅色
③綠色
④藍色
💡 點擊展開解答與全選項解析
✅ 正確答案：④
【綜合解析】 為了讓機房維運人員一眼就能分辨不同種類的光纖，避免插錯導致嚴重光衰減，TIA/EIA 標準賦予了光纖接頭/面板不同的顏色管理系統。 【各選項解析】
  • ❌ ①米黃色：一般用來標示 多模光纖 (Multi-mode Fiber)。
  • ❌ ②紅色：非標準用來區分單模/多模的主流顏色。
  • ❌ ③綠色：通常用來標示經過特殊斜角研磨 (APC) 的單模接頭，非一般通用顏色。
  • ⭕ ④藍色：正確。標準的 單模光纖 (Single-mode Fiber, UPC 研磨) 轉接器與面板統一使用藍色。
