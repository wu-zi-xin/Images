工作項目03：網路架設佈線 (第01 - 25題)

主題：子網路切割
1. 一 Class C 網路以網路遮罩 255.255.255.224 切割成子網路，可切成幾個網路區段？
① 16
② 8
③ 4
④ 2
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

Class C 的預設子網路遮罩為 255.255.255.0。此處使用 255.255.255.224，其最後一個位元組 224 轉換為二進位是 11100000。因為借了左邊 3 個位元（1），所以可以切割的子網路數量為 2 的 3 次方（2³ = 8）。

【各選項解析】
  • ① 16：需借用 4 個位元（2⁴ = 16，遮罩為 240）才符合。
  • ② 8：正確，借用 3 個位元切割出 8 個區段。
  • ③ 4：需借用 2 個位元（2² = 4，遮罩為 192）才符合。
  • ④ 2：需借用 1 個位元（2¹ = 2，遮罩為 128）才符合。
主題：可用 IP 範圍計算
2. 下列何者為 216.35.12.98/26 所處之子網路的可用 IP 範圍？
① 216.35.12.1~216.35.12.127
② 216.35.12.66~216.35.12.127
③ 216.35.12.65~216.35.12.126
④ 216.35.12.129~216.35.12.254
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

/26 代表子網路遮罩為 255.255.255.192，借用 2 個主機位元，共切出 4 個區段。每個區段包含 64 個 IP（256 - 192 = 64）。網段依序為 0, 64, 128, 192。IP 位址 98 落在「64 網段」內（範圍 64~127）。其中 64 為網路位址，127 為廣播位址，故扣除頭尾後，可用 IP 範圍為 65~126。

【各選項解析】
  • ① 216.35.12.1~127：這跨越了 0 網段與 64 網段，且 127 屬於廣播位址，不可當作主機 IP。
  • ② 216.35.12.66~127：結尾的 127 為廣播位址不可用，且起點應為 65。
  • ③ 216.35.12.65~126：正確。64 網段的有效可用範圍正是 65 到 126。
  • ④ 216.35.12.129~254：這屬於後面的網段範圍，而非 98 所在的網段。
主題：網路線材規格
3. Cat 5e UTP 線中有幾對雙絞線？
① 1
② 2
③ 4
④ 8
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

無遮蔽雙絞線（UTP, Unshielded Twisted Pair）規格中，如 Cat 5, Cat 5e, Cat 6 等網路線材，內部皆標準配有 8 根芯線，兩兩互相絞繞，因此組成了 4 對雙絞線。

【各選項解析】
  • ① 1：常見為電話線規格（有些單對或兩對）。
  • ② 2：某些早期或降級規格的以太網（如百兆僅需2對傳輸），但線材本體還是4對。
  • ③ 4：正確。標準網路線內有橙、綠、藍、棕四種顏色共 4 對線。
  • ④ 8：8 指的是「芯數」，題目問的是「幾對」，因此是 4 對而非 8 對。
主題：子網路位址判斷
4. 下列何者為 221.35.12.200/26 所處之子網路的網路位址？
① 221.35.12.192
② 221.35.12.128
③ 221.35.12.40
④ 221.35.12.0
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

/26 的子網路遮罩代表借用 2 個位元，網段區間（Block size）為 64（即 256 - 192 = 64）。其所切出的網段依序為 0, 64, 128, 192。IP 位址的尾數 200，落在 192~255 這個區段。因此該網段的網路位址（起點）即為 192。

【各選項解析】
  • ① 221.35.12.192：正確，尾數 200 落在起點為 192 的網段。
  • ② 221.35.12.128：這是前一個網段的網路位址（範圍 128~191）。
  • ③ 221.35.12.40：這是一個主機 IP，不具備網路位址特性。
  • ④ 221.35.12.0：這是第一個網段的網路位址。
主題：無線傳輸標準
5. IEEE 802.11 未定義哪個傳輸技術？
① 紅外線
② 藍牙
③ 跳頻式展頻
④ 直接序列展頻
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

IEEE 802.11 屬於無線區域網路（WLAN）的標準，初期的 802.11 標準中定義了三種實體層傳輸技術：紅外線（IR）、跳頻展頻（FHSS）與直接序列展頻（DSSS）。藍牙技術（Bluetooth）則是由 IEEE 802.15.1 標準所定義的無線個人區域網路（WPAN）。

【各選項解析】
  • ① 紅外線：屬於 IEEE 802.11 定義的初期實體層傳輸方式之一。
  • ② 藍牙：正確。藍牙屬於 IEEE 802.15 標準，並非 802.11。
  • ③ 跳頻式展頻：FHSS 屬於 IEEE 802.11 所定義的技術。
  • ④ 直接序列展頻：DSSS 同樣屬於 IEEE 802.11 定義的核心技術。
主題：訊號處理設備
6. 能濾除高頻載波訊號，再透過低通濾波器平滑訊號，以提取出原始調變訊號的峰值，是下列哪一種裝置？
① 路由器
② 交換器
③ 包絡檢波器
④ 數據機
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

包絡檢波器（Envelope detector）是一種電子電路裝置，主要應用在振幅調變（AM）的訊號解調過程中。它的功能就是濾除高頻的載波，然後利用低通濾波器取得訊號外圍的「包絡（Envelope）」，還原出最初的低頻原始訊號。

【各選項解析】
  • ① 路由器：屬於 OSI 第三層設備，用於封包交換及路徑選擇。
  • ② 交換器：屬於 OSI 第二層設備，用於同一區域網路內的訊框轉送。
  • ③ 包絡檢波器：正確。負責從高頻調幅訊號中提取低頻包絡線。
  • ④ 數據機：負責數位訊號與類比訊號間的轉換（調變與解調），非特指「提取峰值的檢波器」的專有名詞。
主題：子網路遮罩判斷
7. 下列何者不可能是網路遮罩值？
① 255.255.240.0
② 255.255.242.0
③ 255.255.255.128
④ 255.255.255.192
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

標準的子網路遮罩轉換為二進位時，必須是前面全部為連續的「1」，後面全部為連續的「0」，不能有 1 和 0 交錯出現的情況。選項中的數字轉換為二進位：
240 = 11110000（合法）
242 = 11110010（不合法，中間混了 0 後面又有 1）
128 = 10000000（合法）
192 = 11000000（合法）

【各選項解析】
  • ① 255.255.240.0：合法，對應 CIDR 為 /20。
  • ② 255.255.242.0：正確。二進制包含交錯的 1 與 0，違反遮罩規則。
  • ③ 255.255.255.128：合法，對應 CIDR 為 /25。
  • ④ 255.255.255.192：合法，對應 CIDR 為 /26。
主題：區域網路標準
8. 下列何種 IEEE 標準協定使用 CSMA/CD？
① 802.3
② 802.4
③ 802.5
④ 802.11
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

CSMA/CD（載波感測多重存取/碰撞偵測）是乙太網路（Ethernet）所使用的媒體存取控制方式，避免多台設備在同時傳送資料時造成訊號碰撞。IEEE 定義乙太網路的標準即為 IEEE 802.3。

【各選項解析】
  • ① 802.3：正確。此為乙太網路標準，採用 CSMA/CD。
  • ② 802.4：此為權杖匯流排（Token Bus）標準。
  • ③ 802.5：此為權杖環（Token Ring）標準。
  • ④ 802.11：此為無線區域網路標準（WLAN），採用的是 CSMA/CA 碰撞避免機制。
主題：MAC 位址長度
9. 乙太網路封包位址的長度是多少位元？
① 128
② 32
③ 48
④ 可變動
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

乙太網路的「實體封包位址」指的就是 MAC 位址（Media Access Control address）。全球唯一的 MAC 位址由 6 個位元組（Bytes）組成，每個位元組 8 位元，因此長度固定為 48 位元（bits）。

【各選項解析】
  • ① 128：這是 IPv6 網路位址的長度。
  • ② 32：這是 IPv4 網路位址的長度。
  • ③ 48：正確。MAC 位址長度固定為 48 bits。
  • ④ 可變動：MAC 位址為固定長度，不可變動。
主題：路由表知識
10. 路由表中，預設路由之網路位址及遮罩各為何？
① 0.0.0.0 及 0.0.0.0
② 0.0.0.0 及 255.255.255.255
③ 255.255.255.255 及 0.0.0.0
④ 255.255.255.255 及 255.255.255.255
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

預設路由（Default Route）是在路由器找不到明確的目的地路徑時所採用的「最後依靠」。它代表「所有的網路位址」，在路由表中設定為 IP 位址 0.0.0.0，且子網路遮罩也是 0.0.0.0（表示不需要匹配任何位元）。

【各選項解析】
  • ① 0.0.0.0 及 0.0.0.0：正確。這表示所有未知的目的網段。
  • ② 0.0.0.0 及 255.255.255.255：此組合沒有意義。
  • ③ 255.255.255.255 及 0.0.0.0：廣播位址配上無效遮罩。
  • ④ 255.255.255.255 及 255.255.255.255：這特指廣播封包的絕對位址。
主題：超網路切割 (CIDR)
11. 若要使用 CIDR 整合 16 組 Class C 之 IP 位址 199.1.16.0~199.1.31.0 成單一網路，則超網路遮罩（Supernet Mask）為何？
① 255.255.248.0
② 255.255.252.0
③ 255.255.240.0
④ 255.255.255.248
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

標準的 Class C 遮罩為 /24。要把 16 個 Class C 網段整合為一個超網路（Supernetting），等同於反向「借用主機位元給網路端」，需要釋放 4 個網路位元（2⁴ = 16）。原本 /24 減去 4 就變成了 /20。
/20 的二進制為前 20 個 1，即：11111111.11111111.11110000.00000000，轉成十進位為 255.255.240.0。

【各選項解析】
  • ① 255.255.248.0：對應 /21 遮罩，只能整合 8 個 Class C 網路。
  • ② 255.255.252.0：對應 /22 遮罩，只能整合 4 個 Class C 網路。
  • ③ 255.255.240.0：正確。對應 /20 遮罩，完美整合 16 個 Class C 網路。
  • ④ 255.255.255.248：對應 /29 遮罩，這是子網路分割而非超網路整合。
主題：廣播位址概念
12. 由網路外要送封包給 Class C 200.119.101.0 中所有 host，則封包之目的地位址應為何？
① 255.255.255.255
② 200.119.101.255
③ 200.119.101.0
④ 0.0.0.0
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

由「網路外」傳送廣播封包給某個「特定網段」的所有主機，這種行為稱為直接廣播（Directed Broadcast）。Class C 網路的直接廣播位址算法，是將該網段的主機部分（Host ID）全部填滿 1，因此 200.119.101.0 網段的廣播位址即為 200.119.101.255。

【各選項解析】
  • ① 255.255.255.255：此為受限廣播（Limited Broadcast），僅限本機所在網段內廣播，路由器預設不會轉送跨網段。
  • ② 200.119.101.255：正確。這是針對特定網段（200.119.101.0）的直接廣播位址。
  • ③ 200.119.101.0：此為該網段的網路位址，不能作為目的地。
  • ④ 0.0.0.0：表示預設路由或未知網路。
主題：廣播位址概念
13. 200.119.101.5 要送封包給同一網路中所有 host，則封包之目的地位址應為何？
① 200.119.101.255
② 255.255.255.255
③ 0.0.0.0
④ 200.119.101.0
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

當主機要在「同一個實體網段內」送封包給所有其他主機時，最標準及廣泛使用的做法是發送「受限廣播（Limited Broadcast）」，其目的 IP 位址皆設定為 255.255.255.255。此封包不會跨越路由器，只會在廣播網域內傳遞。

【各選項解析】
  • ① 200.119.101.255：直接廣播也能達到效果，但在協定設計中，同網段廣播的首選和通用設定為全 1（即255.255.255.255）。官方解答認定 ②。
  • ② 255.255.255.255：正確。受限廣播位址專供本網段內廣播使用。
  • ③ 0.0.0.0：不具意義的發送目的地。
  • ④ 200.119.101.0：為網路位址，無法作為封包目的地。
主題：ARP 協定運作
14. 就傳播方式（單播、群播、廣播）而言，ARP request 及 ARP reply 分別使用何種方式？
① 廣播，單播
② 單播，廣播
③ 廣播，廣播
④ 單播，單播
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

位址解析協定（ARP）的功能是將 IP 位址轉換為實體的 MAC 位址。當主機不知道目標 MAC 位址時，會送出 ARP Request，因為不知道對象在哪，所以要「大聲喊（廣播 Broadcast）」。而目標主機收到請求後，因為已經從封包知道來源是誰，就會私底下偷偷回應，採用「一對一（單播 Unicast）」回傳 ARP Reply。

【各選項解析】
  • ① 廣播，單播：正確。請求用廣播，回應採單播。
  • ② 單播，廣播：順序完全顛倒。
  • ③ 廣播，廣播：回應不需要廣播，會浪費網路頻寬。
  • ④ 單播，單播：尚未取得 MAC 位址前，無法進行單播請求。
主題：乙太網路標準參數
15. 在 Gigabit 乙太網路規格定義訊框與訊框之間的間隔時間為何？
① 96 Bit Time
② 128 Bit Time
③ 86 Bit Time
④ 48 Bit Time
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在 IEEE 802.3 的乙太網路標準中（涵蓋 10M, 100M 甚至 Gigabit），為了讓接收端設備的網路介面卡有時間處理剛收到的訊框並準備接收下一個，定義了「訊框間隔（Interpacket Gap, IPG）」。這個間隔時間統一規範為 96 個位元時間（96 Bit Time）。

【各選項解析】
  • ① 96 Bit Time：正確。這是乙太網路設計的標準訊框間隔。
  • ② 128 Bit Time：非標準定義。
  • ③ 86 Bit Time：錯誤數據。
  • ④ 48 Bit Time：這是 MAC 位址的長度數字，而非時間間隔。
主題：建築電信法規
16. 「建築物屋內外電信設備設置技術規範」關於宅內配線箱之設置規定，下列何者不正確？
① 應離地面 30 cm以上
② 箱門應具備空氣對流功能之通風設計
③ 箱內須有 110V 電源裝置
④ 從宅內配線箱至宅內各廳室出線匣之配線方式應以環狀為之，並設置資訊插座
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

根據建築物電信設備設計規範，宅內配線箱（宅內弱電箱）分歧至各個房間資訊插座的實體線路，皆應採用「星狀配線（Star Topology）」，這樣單一線路故障時不會影響其他房間，而非「環狀配線」。

【各選項解析】
  • ① 離地 30 cm：正確規定，防潮且方便施作。
  • ② 空氣對流設計：正確規定，有助於內部設備如集線器/分享器散熱。
  • ③ 箱內 110V 電源：正確規定，提供弱電設備(如 Switch)電源插座。
  • ④ 環狀為之：錯誤描述。應採用「星狀配線」。
主題：OSI 模型與位址
17. 當與 MAC 位址運作時屬於 OSI 中哪一層？
① 資料鏈路層
② 網路層
③ 表示層
④ 應用層
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在 OSI 七層模型中，設備硬體的實體位址（MAC Address, 媒體存取控制位址）是定義在第二層「資料鏈路層（Data Link Layer）」；而 IP 位址則定義在第三層網路層。

【各選項解析】
  • ① 資料鏈路層：正確。MAC 位址運作於此層的 MAC 子層。
  • ② 網路層：運作的是邏輯位址，例如 IP 位址。
  • ③ 表示層：負責資料格式轉換、加解密。
  • ④ 應用層：提供使用者與網路間的介面（如 HTTP, FTP）。
主題：調變技術
18. 使用兩個相位狀態表示二進位資料中的 0 和 1 的調變技術是下列哪一種？
① 二進位相位鍵控（Binary Phase-Shift Keying, BPSK）
② 四相相位鍵控（Quadrature Phase-Shift Keying, QPSK）
③ 偏移四相相移鍵控（Offset-QPSK）
④ 八相相位鍵控（8 Phase Shift Keying, 8PSK）
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

相位鍵控（PSK）是利用改變載波的相位來傳送數位資料。題目中提到「使用『兩個』相位狀態」來分別表示 0 與 1，這種最基礎的雙相位切換稱為二進位相位鍵控（BPSK）。

【各選項解析】
  • ① BPSK：正確。雙相位（通常差180度）來表示 1 bit (0或1)。
  • ② QPSK：使用四個不同的相位，每個狀態可表示 2 bits (如 00, 01, 10, 11)。
  • ③ Offset-QPSK：屬於 QPSK 的變體，同樣表示 2 bits。
  • ④ 8PSK：使用八個不同的相位，每個狀態可表示 3 bits。
主題：OSI 模型功能
19. OSI 哪一層負責訊框定序（Frame sequencing）？
① 實體層
② 傳輸層
③ 資料鏈路層
④ 應用層
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

OSI 各層有專屬的傳輸單元（PDU），在第二層「資料鏈路層」處理的單位稱作「訊框（Frame）」。因此，關於訊框的定序、錯誤偵測（FCS）、MAC定址等，都是由資料鏈路層負責。傳輸層負責的是「區段（Segment）」的定序。

【各選項解析】
  • ① 實體層：負責實體媒介的 Bit (位元) 傳輸，不懂訊框結構。
  • ② 傳輸層：負責 Segment (區段) 等級的流量控制與定序。
  • ③ 資料鏈路層：正確。負責 Frame (訊框) 的建立與定序作業。
  • ④ 應用層：負責應用協定，與封裝細節無關。
主題：通訊埠號碼
20. POP3 在 TCP/IP 的埠號為何？
① UDP Port 21
② TCP Port 23
③ UDP Port 25
④ TCP Port 110
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

POP3（Post Office Protocol version 3）是電子郵件的收信協定，由於收信需要可靠的傳輸連線，所以底層走 TCP 協定，並且國際標準分配的預設通訊埠號（Port Number）是 110。

【各選項解析】
  • ① UDP Port 21：21 為 FTP (TCP) 控制連線使用的埠。
  • ② TCP Port 23：23 為 Telnet 遠端登入的預設埠。
  • ③ UDP Port 25：25 為 SMTP (TCP) 電子郵件寄信使用的埠。
  • ④ TCP Port 110：正確。POP3 使用 TCP Port 110 收信。
主題：IEEE 網路標準
21. CSMA/CD 是屬於 IEEE 802 中哪一項標準？
① 802.1
② 802.2
③ 802.3
④ 802.5
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

IEEE 802 委員會制定了一系列的區域網路標準，其中 IEEE 802.3 是專門規範「乙太網路（Ethernet）」的運作方式。而早期乙太網路在共用媒介上解決多台主機同時傳輸問題的核心碰撞偵測機制，就是 CSMA/CD（載波感測多重存取與碰撞偵測）。

【各選項解析】
  • ① 802.1：負責網路架構與跨網段連接（如 VLAN, Spanning Tree）。
  • ② 802.2：負責邏輯鏈路控制（LLC）子層。
  • ③ 802.3：正確。乙太網路標準與 CSMA/CD 技術歸屬此規範。
  • ④ 802.5：定義的是權杖環網（Token Ring）架構。
主題：路由器運作原理
22. 路由器採用以下哪種資訊判斷封包之目的地網路 ID？
① IP 標頭長度
② 子網路遮罩
③ 位址類別
④ MAC 位址
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

路由器在進行路徑判斷時，會讀取封包中的「目的 IP 位址」，將其與路由表裡紀錄的「子網路遮罩（Subnet Mask）」進行二進位的 AND（交集）邏輯運算。這個運算過程可以濾除主機位元，精準得到「目的地網路 ID」，接著再尋找最佳輸出路徑送出封包。

【各選項解析】
  • ① IP 標頭長度：僅用來確認標頭大小（有無包含選項欄位），不涉網段判斷。
  • ② 子網路遮罩：正確。IP 位址 AND 子網路遮罩 = 網路 ID。
  • ③ 位址類別：雖然可判斷網路區段，但在無等級(CIDR)路由下失效，現代路由需依賴遮罩。
  • ④ MAC 位址：此為 Layer 2 交換器判斷轉發路徑的依據，路由器看的是 IP。
主題：IP 位址類別
23. 下列哪個 IP 位址是 Class C 位址？
① 10.20.30.40
② 140.30.50.65
③ 230.20.35.14
④ 200.17.45.15
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

判斷 IPv4 的 Class（類別），主要是看第一組數字（第一個 Byte）的範圍：
• Class A: 1 ~ 126
• Class B: 128 ~ 191
• Class C: 192 ~ 223
• Class D: 224 ~ 239
選項中的「200.17.45.15」，第一個數字 200 落在 192~223 的區間，因此它是 Class C。

【各選項解析】
  • ① 10.20.30.40：10 在 1~126 間，屬於 Class A。
  • ② 140.30.50.65：140 在 128~191 間，屬於 Class B。
  • ③ 230.20.35.14：230 在 224~239 間，屬於 Class D（群播專用）。
  • ④ 200.17.45.15：正確。200 屬於 Class C 的規範範圍內。
主題：多播 (Multicast)
24. 哪個 Class 的 IP 位址可進行多播（Multicast）傳輸？
① Class A
② Class E
③ Class B
④ Class D
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

IPv4 位址的五大分類中，Class A、B、C 主要是用來分配給一般主機通訊使用（單播 Unicast）。
Class D 網段（範圍 224.0.0.0 到 239.255.255.255）則是被設計並保留作為「多播（群播，Multicast）」用途，例如常見的 OSPF 或 RIPv2 路由更新交換、視訊串流等都會使用 Class D。
Class E 則是保留供未來實驗用途。

【各選項解析】
  • ① Class A：屬於單播位址。
  • ② Class E：保留供未來實驗使用，不發放。
  • ③ Class B：屬於單播位址。
  • ④ Class D：正確。被專門指定為群組通訊(Multicast)使用。
主題：子網路切割位元算法
25. 從主機 IP 位址之 hostid 部分使用多少位元可建立 40 個 subnet？
① 10bit
② 6bit
③ 4bit
④ 8bit
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

要從原本的 Host ID (主機位址部分) 借位來當作網路位元切割出子網路，其產生的子網路數量公式為 2 的 n 次方（n 為借用的位元數）。
題目要求至少要能建立 40 個 subnet：
如果借 5 bit，2⁵ = 32（不夠 40 個）。
如果借 6 bit，2⁶ = 64（大於 40 個，足以分配）。
因此，最少需要借用 6 個 bit。

【各選項解析】
  • ① 10bit：2¹⁰ = 1024，雖然大於 40，但並不是「能滿足 40 個的最小剛好位元需求」，且過度浪費主機位元。
  • ② 6bit：正確。2⁶ = 64，剛剛好足夠建立 40 個子網路。
  • ③ 4bit：2⁴ = 16 個，數量不夠 40 個。
  • ④ 8bit：2⁸ = 256，需求僅為 40 個，借 8 個位元不符經濟效益與題目常規。
