Shell Scripting 核心教學指南

涵蓋條件判斷、函式、迴圈與陣列亂數的完整實戰範例

動作目的

用來進行多選一的條件判斷，比起多重 if-else，能讓程式碼架構更清晰易讀 [1, 2]。

執行步驟 & 指令解釋

  • 開頭使用 case，並以反向拼寫的 esac 結尾，確保結構有頭有尾 [1, 3]。
  • ;;：兩個分號代表執行區塊結束，務必加上，否則程式會無視條件繼續往下執行 [1, 4]。
  • *：用來捕捉所有「不符合前面條件」的輸入，常作為預設的提示 (usage) 訊息 [2, 4]。

實戰範例

透過判斷外部傳入的第一個參數（$1），給予不同的回應 [1, 4]：

case $1 in
    hello)
        echo "Hello, how are you?" 
        ;;
    "")
        echo "You must input parameters" 
        ;;
    *)
        echo "Usage: $0 hello" 
        ;;
esac

動作目的

將會重複使用到的功能定義為函式（副程式），藉此簡化腳本架構並提高重用性 [5]。

執行步驟 & 指令解釋

  • echo -n：印出文字後「不換行」，讓後續的輸出能接續顯示在同一行 [5, 6]。
  • tr 'a-z' 'A-Z'：利用管線傳遞字串，將小寫英文字母轉換為大寫 [3, 6]。
  • $1 的作用域差異：在 function 內部，它代表「呼叫函式時傳給該函式的第一個參數」；在函式外部，它代表「執行腳本時傳入的第一個參數」 [7-9]。

實戰範例

定義函式印出不換行的提示語，並透過 tr 將參數轉大寫 [3, 5, 6]：

function printit {
    echo -n "Your choice is "
}

case $1 in
    one)
        printit
        echo $1 | tr 'a-z' 'A-Z' 
        ;;
    *)
        echo "Usage: $0 {one|two|three}" 
        ;;
esac

動作目的

根據條件成立與否來重複執行區塊。利用笛摩根定理，可以將 while 和 until 互相改寫 [10-12]。

執行步驟 & 指令解釋

  • while：當條件為「成立 (True)」時不斷執行，直到條件不成立才停止 [10]。
  • until：當條件為「不成立 (False)」時不斷執行，直到條件滿足為止（一直等待到條件發生） [11]。

實戰範例

要求使用者輸入全小寫或全大寫的 yes，兩種寫法效果完全相同 [10, 11, 13]：

# while 版本 (輸入不為 yes 且 不為 YES 時，繼續執行)
while [ "$yn" != "yes" -a "$yn" != "YES" ]
do
    read -p "Please input yes/YES to stop: " yn
done
echo "OK, you input correct answer"

# until 版本 (直到輸入為 yes 或 為 YES 時，才停止)
until [ "$yn" == "yes" -o "$yn" == "YES" ]
do
    read -p "Please input yes/YES to stop: " yn
done
echo "OK, you input correct answer"

動作目的

將字串列表或外部指令的執行結果，逐一帶入變數中重複操作 [14, 15]。

執行步驟 & 指令解釋

  • $(cut -d: -f1 /etc/passwd)：以冒號切割系統檔案，取出第一欄的所有帳號清單 [15, 16]。
  • ping -c 1 -w 1：進行網路測試，-c 1 偵測 1 次，-w 1 最多等待 1 秒鐘以加快速度 [17-19]。
  • > /dev/null：將多餘輸出丟棄，讓畫面保持整潔 [19]。回傳值 $? 為 0 代表通訊成功 [20]。

實戰範例

運用 seq 產生從 90 到 100 的數字陣列，進行網段 Ping 測試 [17, 19, 20]：

for i in $(seq 90 100)
do
    ping -c 1 -w 1 192.168.99.$i > /dev/null
    if [ $? == 0 ]; then
        echo "192.168.99.$i is UP"
    else
        echo "192.168.99.$i is DOWN"
    fi
done

動作目的

處理包含初始值、明確條件限制以及固定步進值（等差數值）的數值運算迴圈 [21, 22]。

執行步驟 & 指令解釋

  • 寫法為 for (( 初始值; 條件限制; 每次變動 ))，並將變數包在 $(( )) 中進行數學總和運算 [21]。

實戰範例

讓使用者輸入一個數字，並計算從 1 累加到該數字的總和 [21, 22]：

s=0
read -p "Please input a number, I will count for you: " num

for (( i=1; i<=$num; i++ ))
do
    s=$(( $s + $i ))
done

echo "The result from 1 to $num is $s"

動作目的

利用系統隨機數字結合陣列結構，來實作抽籤程式或機率驗證 [23, 24]。

執行步驟 & 指令解釋

  • $RANDOM 搭配取餘數運算，如 % 9 + 1 即可最有效率地取得 1 到 9 的亂數 [23]。
  • 陣列的索引值是從 0 開始計算的（如 12 星座的索引是 0 到 11） [24]。

實戰範例

定義 12 星座陣列，透過亂數除以 12 取餘數 (0-11) 來抽取本日幸運星座 [23-25]：

# 定義 12 星座陣列 (索引從 0 開始)
constellations=("白羊座" "金牛座" "雙子座" "巨蟹座" "獅子座" "處女座" "天秤座" "天蠍座" "射手座" "摩羯座" "水瓶座" "雙魚座")

# 取得 0 到 11 的亂數當作索引
idx=$(( $RANDOM % 12 ))

# 依據索引從陣列中取出對應星座
echo "本日最幸運的星座是：${constellations[$idx]}"
