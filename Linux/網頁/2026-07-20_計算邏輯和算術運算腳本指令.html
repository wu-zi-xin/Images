主題一：架設多個 FTP 伺服器 (綁定不同 IP)

動作目的

在同一台主機上，利用多個不同的 IP 位址（例如 .91 與 .93）架設各自獨立的 FTP 伺服器，並提供不同的專屬登入畫面以利辨識連線狀態 [cite: 1, 2]。

執行步驟與指令範例

步驟 1：修改設定檔並指定 IP
為了讓 FTP 伺服器綁定特定 IP，需修改 vsftpd.conf，設定 listen=YES 並關閉 IPv6 監聽。最關鍵的是使用 listen_address 指定 IPv4 的專屬 IP 位址 [cite: 3]。
修改設定檔並指定監聽 IP
listen=YES
listen_ipv6=NO
listen_address=192.168.1.91
步驟 2：設定專屬歡迎詞 (Banner)
透過 banner_file 指令，將登入畫面指向特定的純文字檔（例如 ban5.txt），讓使用者一登入就能看見該 IP 專屬的文字，確認是否連對伺服器 [cite: 3, 4]。
設定專屬歡迎詞檔案路徑
banner_file=/etc/vsftpd/ban5.txt
步驟 3：使用個別設定檔啟動服務
若之前曾用預設的 systemctl 啟動過，必須先將其完全停止，否則直接用個別設定檔啟動時會發生衝突而失敗。停止後，再呼叫個別的設定檔啟動對應的 FTP 服務 [cite: 5, 6]。
停用預設的全局啟動
systemctl stop vsftpd
以個別的設定檔啟動專屬的 FTP 伺服器
# /usr/sbin/vsftpd /etc/vsftpd/vsftpd.conf
systemctl stop vsftpd@vsftpd

# /usr/sbin/vsftpd /etc/vsftpd/vsftpd2.conf
systemctl stop vsftpd@vsftpd2
停用這些個別啟動的服務
systemctl stop vsftpd@vsftpd
systemctl stop vsftpd@vsftpd2

主題二：Shell Script 基礎與 read 對談式輸入

動作目的

撰寫互動式腳本，學習如何在螢幕輸出反斜線特殊字元，以及透過問答的方式等待使用者輸入，並將資料存入變數中進行後續處理 。

執行步驟與指令範例

步驟 1：使用 echo 處理特殊字元
指令 echo -e 允許解析字串中的反斜線特殊符號。例如 \n 代表換行。若不加 -e，系統會將其當作純文字直接印出，不會產生換行效果 [cite: 7]。
加上 -e 讓 \n 生效產生換行
echo -e "Hello World\n"
步驟 2：賦予腳本執行權限
剛建立的腳本預設是沒有執行權限的。需使用 chmod u+x 給予擁有者執行權限，檔案變色後即可透過 ./ 的方式來執行腳本 。
賦予權限並執行腳本
chmod u+x script.sh
./script.sh
步驟 3：使用 read 製作互動輸入
指令 read -p 會在螢幕印出提示 (prompt)，使用者輸入內容並按下 Enter 後，系統會將資料存入指定的變數 (如 fname)，後續可利用變數組合輸出結果 。
詢問名字與姓氏並分別存入變數
read -p "Please input your first name: " fname
read -p "Please input your last name: " lname
組合變數輸出
echo -e "Your full name is: ${fname} ${lname}"

主題三：數學算術運算

動作目的

讓 Shell Script 具備處理加法 (+)、減法 (-)、乘法 (*)、除法取商數 (/) 與除法取餘數 (%) 的計算能力 。

執行步驟與指令範例

步驟 1：使用算術運算語法 $(( ))
在 Shell 中，變數預設都會被當作「純字串」。要進行數學運算，必須將算式用前置號加兩對小括號 $(( 算式 )) 完整包覆。若漏掉括號，系統只會印出字串（例如 "8*3"） 。
輸入兩數並進行相乘運算
read -p "First number: " first
read -p "Second number: " second

total=$(($first * $second))
echo "Result: $first * $second = $total"
步驟 2：執行多重算術運算 (商數與餘數)
除法運算中，使用 / 會取得「商數」，而使用 % (百分比符號) 則會取得「餘數」。可以將這些運算符號連續應用在變數上以實現計算機功能 。
取得除法的商數與餘數
quotient=$(($first / $second))
remainder=$(($first % $second))

echo "商數為: $quotient , 餘數為: $remainder"

主題四：檔案屬性測試與權限判斷 (test)

動作目的

檢查特定檔案或目錄的存在狀態與類型，並檢測其所擁有的讀、寫、執行權限以及特殊權限 (SUID/SGID/Sticky Bit) 。

執行步驟與指令範例

步驟 1：檢查變數是否為空字串 (-z)
指令 test -z (zero) 用來檢查變數長度是否為空。這常作為防呆機制，當使用者沒有輸入檔名直接按下 Enter 時，捕捉該狀態並提早結束程式 。
檢查變數是否為空字串並防呆離開
read -p "Input file name: " filename
test -z "$filename" && echo "You must input file name!" && exit 0
步驟 2：檢查檔案是否存在 (! -e) 與類型 (-f / -d)
-e (exist) 檢查檔案是否存在，加上驚嘆號 ! -e 代表「不存在」。存在後，可利用 -f 判斷是否為一般檔案，或利用 -d 判斷是否為目錄 。
檢查檔案是否存在與檔案類型
test ! -e "$filename" && echo "File does not exist" && exit 0

test -f "$filename" && filetype="regular file"
test -d "$filename" && filetype="directory"
echo "This is a $filetype"
步驟 3：測試基本與特殊權限
除了用 -r、-w、-x 檢查基本權限外，也可檢查特權：-u (測 SUID)、-g (測 SGID)、-k (測 Sticky Bit) 。
測試基本與特殊權限
test -r "$filename" && perm="readable"
test -u "$filename" && perm="$perm SUID"

echo "Permissions: $perm"

主題五：接收外部參數與 if 條件判斷

動作目的

讓腳本能接收執行時從外部指令列傳入的參數，並透過 if-elif-else 進行多重條件分支的邏輯判斷處理 。

執行步驟與指令範例

步驟 1：接收與計算外部參數
腳本內建變數處理參數：$0 代表腳本檔名，$1 代表第一個參數。$# 代表參數的總數量，$@ 則代表所有參數的完整集合 。
接收與計算外部參數 (執行範例：./script.sh A B)
echo "Script 名稱是: $0"
echo "總共傳入了 $# 個參數"
echo "第一個參數是 $1，完整參數為: $@"
步驟 2：使用中括號 [ ] 與邏輯 OR (-o)
使用中括號 [ ] 包覆判斷條件時，內側必須保留空白字元。-o 代表邏輯 OR (或)，只要其中一個條件成立即視為成立 。
使用中括號與邏輯 OR 判斷輸入
read -p "Continue? (Y/N): " yn
if [ "$yn" == "Y" -o "$yn" == "y" ]; then
    echo "OK, continue"
fi
步驟 3：if-elif-else 多重判斷結構
依序檢查多個條件。若 if 不成立，檢查 elif；若皆不成立則執行 else。結構必須以 fi (if 倒寫) 作為結尾 。
if-elif-else 多重判斷結構範例
if [ "$1" == "hello" ]; then
    echo "Hello, how are you"
elif [ -z "$1" ]; then
    echo "You must input a parameter"
else
    echo "See you later, goodbye"
fi

主題六：網路服務偵測與 Alias (別名) 設定

動作目的

利用指令偵測系統開啟的網路服務 (如 HTTP、FTP)，並透過自訂別名 (Alias) 將長串的檢測與啟動指令簡化為極短的自訂字元 。

執行步驟與指令範例

步驟 1：使用 netstat 偵測 Port 號
指令 netstat -tuln 用來偵測網路狀態。常見的 Port 包括 21(FTP)、22(SSH)、25(SMTP)、53(DNS)、80(HTTP) 。
查看目前系統中正在監聽的所有 TCP/UDP Port 號
netstat -tuln
步驟 2：利用轉存 (>) 與過濾 (grep) 自動判斷
將 netstat 的輸出利用 > 轉存至文字檔。接著利用 $() 執行 grep 搜尋特定 Port 號 (如 :80)，藉此自動判斷服務是否啟動 。
將結果轉存並搜尋 Port 狀態
netstat -tuln > testfile

testing=$(grep ":80 " testfile)
if [ "$testing" != "" ]; then
    echo "WWW is running in your system"
fi
步驟 3：設定 Alias 別名
將簡化指令寫入隱藏檔 ~/.bashrc 中。修改後需重啟分頁才能生效。可使用分號 ; 將多個指令串聯（例如啟動後立刻檢測） 。
編輯 ~/.bashrc 寫入 Alias (完成後需開新分頁)
alias A1='sh /root/W9/netstate.sh'
alias A2='systemctl start httpd; A1'
alias A7='systemctl stop httpd'
