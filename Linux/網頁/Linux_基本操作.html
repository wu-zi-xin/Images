一、目錄導覽與檢視

動作目的

動作目的：在 Linux 環境中，因為沒有圖形化介面，我們必須學會如何確認自己目前所在的位置，切換到其他資料夾，以及查看資料夾內有哪些檔案，這是所有操作的基礎。

執行步驟與指令範例

步驟 1：顯示目前所在目錄 (pwd)
pwd 指令的意思是 Print Working Directory。當你迷失在系統目錄堆中時，輸入這個指令可以立刻印出你當前的完整絕對路徑。
顯示目前所在位置
pwd
輸出範例
/home/vbird/documents
步驟 2：切換目錄 (cd)
cd 指令是 Change Directory。可以用來移動到目標資料夾。輸入 cd ~ 可以快速回到使用者的家目錄，而 cd .. 則是回到上一層目錄。
切換到 /var/log 目錄
cd /var/log
回到上一層目錄
cd ..
快速回到家目錄
cd ~
步驟 3：列出目錄內容 (ls)
ls 指令用來列出檔案清單 (List)。這是用來確認當前資料夾底下有哪些項目的最基本指令。
列出當下目錄的檔案
ls

二、檔案與目錄建立

動作目的

動作目的：學會如何在系統中無中生有，建立用來存放資料的全新資料夾，或是建立空白檔案以供後續的文字編輯與程式開發使用。

執行步驟與指令範例

步驟 1：建立新目錄 (mkdir)
mkdir (Make Directory) 用於建立資料夾。若要一次建立多層不存在的父目錄，可以加上 -p 參數，避免系統報錯。
建立名為 test_folder 的新目錄
mkdir test_folder
建立多層目錄 (如果 project 目錄不存在，也會一併自動建立)
mkdir -p project/2026/report
步驟 2：建立空白檔案 (touch)
touch 原本的用途是修改檔案的時間戳記，但如果指定的檔案不存在，它就會幫你創造一個全新的 0 byte 空白檔案，非常實用。
建立一個名為 newfile.txt 的空白檔案
touch newfile.txt
一次建立多個空白檔案
touch file1.txt file2.txt file3.txt

三、檔案複製與移動

動作目的

動作目的：在管理伺服器時，經常需要備份設定檔或重新整理檔案位置。熟悉複製與移動指令，能讓我們安全、快速地轉移檔案資源。

執行步驟與指令範例

步驟 1：複製檔案或目錄 (cp)
cp (Copy) 用來複製檔案。如果是要複製「整個資料夾」及其底下的所有內容，必須加上 -r (recursive) 遞迴參數才能成功。
將檔案 config.txt 複製一份並命名為 config_backup.txt
cp config.txt config_backup.txt
將整個 test_folder 資料夾複製到 /tmp 目錄下
cp -r test_folder /tmp/
步驟 2：移動或重新命名檔案 (mv)
mv (Move) 不僅可以把檔案搬移到別的地方，當你將檔案在「同一個目錄下」移動並給予新名稱時，它就達成了「重新命名」的效果。
將檔案移動到 /opt 目錄底下
mv newfile.txt /opt/
重新命名檔案 (將 oldname.txt 改名為 newname.txt)
mv oldname.txt newname.txt

四、檔案刪除與清理

動作目的

動作目的：Linux 中通常沒有「資源回收桶」的概念，刪除指令一下檔案就會立刻消失，因此在使用刪除相關的指令時必須非常謹慎。

執行步驟與指令範例

步驟 1：刪除檔案與目錄 (rm)
rm (Remove) 用於刪除檔案。如果要刪除整個資料夾，需要加上 -r 參數。加上 -f (force) 則會強制刪除，不會再跳出確認提示。
刪除單一檔案
rm useless_file.txt
強制刪除整個資料夾及其內容 (極其危險，請小心使用)
rm -rf old_project_folder/
步驟 2：清除終端機畫面 (clear)
當終端機上塞滿了先前執行的指令與輸出結果，讓人眼花撩亂時，使用 clear 可以瞬間將畫面淨空，將游標推回第一行。
清除當前終端機畫面顯示
clear
如果想要暫時畫面乾淨，但還是可以往上查找
Ctrl+L

五、檔案內容查閱

動作目的

動作目的：不需透過編輯器打開檔案，直接在終端機畫面上讀取文字檔內容。這對於快速查閱系統日誌 (Log) 或設定檔內容非常有效率。

執行步驟與指令範例

步驟 1：一次性印出所有內容 (cat)
cat 指令會把整個檔案的內容從頭到尾一次印在終端機上。如果檔案內容很短，這是最方便快速的檢視方式。
檢視系統的網路設定資訊
cat /etc/resolv.conf
步驟 2：分頁檢視長篇文件 (less)
當檔案內容極長（例如幾萬行的日誌）時，用 less 可以一頁一頁看。進入後可用上下鍵捲動，按 q 離開。
以分頁模式閱讀龐大的系統日誌檔案
less /var/log/messages
步驟 3：只看頭尾幾行 (head / tail)
head 預設顯示前 10 行；tail 預設顯示最後 10 行。最常用的應用是加上 tail -f 來「即時追蹤」日誌檔的最新寫入狀況。
即時持續追蹤安全連線紀錄的最新狀態 (按 Ctrl+C 結束)
tail -f /var/log/secure

六、歷史指令管理 (history)

動作目的

動作目的：在終端機中，我們經常需要重複執行很長或很複雜的指令。透過呼叫歷史紀錄，並搭配 ! (驚嘆號) 捷徑，能大幅提升操作效率，省去重新打字的麻煩。

執行步驟與指令範例

步驟 1：檢視過去下過的指令 (history)
直接輸入 history 會印出所有最近執行過的指令清單，並且每一行前面都會帶有一個「編號」。
查看所有的歷史指令
history
輸出範例
112  cd /var/log
113  tail -f secure
步驟 2：執行特定編號的歷史指令 (!編號)
當你從 history 列表中看到某個想再次執行的指令（例如編號 113），只需輸入 !113，系統就會直接幫你帶出並執行該指令。
執行歷史紀錄中第 113 號的指令
!113
系統會自動轉化並執行
tail -f secure
步驟 3：快速重複特定指令 (!! 或 !字母)
想「再執行一次剛剛下過的指令」，可以輸入 !!。想執行最近一次以特定字母開頭的指令，可以使用 !字母。
重複執行上一次的指令
!!
執行歷史紀錄中，最近一次以 "sys" 開頭的指令
!sys

七、隱藏檔與詳細列出 (ls -a / ll)

動作目的

動作目的：單純使用 ls 只能看到普通檔案的檔名。透過加上參數或是使用捷徑指令 ll，可以讓我們看透檔案的權限、擁有者、大小，甚至揪出系統中的隱藏設定檔。

執行步驟與指令範例

步驟 1：列出所有隱藏檔 (ls -a)
在 Linux 中，只要檔名是以 . (小數點) 開頭的檔案就是「隱藏檔」（例如 .bashrc）。必須加上 -a (all) 參數才能讓它們現形。
列出包含隱藏檔的所有檔案名稱
ls -a
輸出範例
.  ..  .bash_profile  .bashrc  normal_file.txt
步驟 2：使用長格式列表檢視詳細屬性 (ll)
ll 其實是 ls -l 的捷徑別名。它會以「長格式」顯示，列出檔案的屬性權限、擁有者帳號、群組、檔案大小(Byte)與最後修改時間。
顯示檔案詳細資訊 (最常用的指令)
ll
如果要同時看詳細資訊 + 隱藏檔，可以組合參數
ls -al 或 ll -a

八、檔案權限判讀 (rwx)

動作目的

動作目的：當我們輸入 ll 後，最左邊會出現如 -rwxr-xr-- 的十個字元。學會拆解這十個字元，就能知道哪些人可以讀取、修改或執行這個檔案。

執行步驟與指令範例

步驟 1：辨識第 1 個字元 (檔案類型)
這十個字元的第一個字元代表「檔案的種類」。
- 代表一般檔案 (File)
d 代表目錄 (Directory)
l 代表捷徑連結檔 (Link)
觀察 ll 輸出的最左側
-rw-r--r--. 1 root root  123 Jan 1 12:00 file.txt
^
# 開頭為 -，表示這是一個「一般檔案」
步驟 2：辨識後 9 個字元 (擁有者/群組/其他人)
後面的 9 個字元以「三個為一組」分為三組：分別代表「擁有者」、「所屬群組」、「其他人」的權限。
r (Read, 讀取) / w (Write, 寫入) / x (eXecute, 執行) / - (無此權限)
拆解範例： -rwxr-xr--
# 擁有者權限: rwx (可讀、可寫、可執行)
# 群組權限: r-x (可讀、不可寫、可執行)
# 其他人權限: r-- (僅可讀取，不可寫不可執行)

九、終端機中檔案顏色的代表意義

動作目的

動作目的：在多數現代 Linux 系統下，執行 ls 時系統會依據檔案的「類型與權限」賦予不同的顯示顏色。記住這些顏色，能幫助我們在一秒內看出畫面上哪些是資料夾，哪些是執行檔。

執行步驟與指令範例

步驟 1：最常見的基礎三色 (藍 / 白黑 / 綠)
🔵 深藍色 (Blue)： 目錄資料夾 (Directory)。
⚪ 白色或黑色 (White/Black)： 一般的普通檔案 (文字檔、設定檔)。
🟢 綠色 (Green)： 具備「可執行權限 (x)」的檔案 (如程式或腳本檔)。
畫面顯示示意
# my_script.sh (顯示為綠色) -> 程式
# /etc         (顯示為藍色) -> 目錄
# readme.txt   (顯示為白色) -> 文字檔
步驟 2：進階特殊顏色 (淺藍 / 紅 / 黃黑)
🩵 淺藍色 (Cyan)： 符號連結檔 (Symbolic Link)，類似捷徑。
🔴 紅色 (Red)： 壓縮檔 (如 .tar.gz, .zip)。
🟡 黃底黑字： 設備檔案 (通常在 /dev 目錄下)。
畫面顯示示意
# backup.zip   (顯示為紅色) -> 壓縮檔
# shortcut     (顯示為淺藍色) -> 捷徑
