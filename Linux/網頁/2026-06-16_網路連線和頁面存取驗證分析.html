主題一：基礎網路設定與 Apache 伺服器安裝

動作目的：
為確保系統能連接外部網路下載套件，需先將虛擬機網路設為 NAT 並透過 DHCP 自動取得 IP (如 10.0.2.15)。接著使用新一代套件管理員 DNF 自動解決相依性問題，完成 Apache (httpd) 伺服器的安裝，並利用 systemd 程式啟動 Web 服務[cite: 1, 2]。

執行步驟與指令範例

步驟 1：安裝 Apache (HTTPD) 伺服器
確認網路對外連通後，使用 dnf install 指令安裝軟體包。DNF 比早期的 YUM 更聰明，會自動處理安裝順序與所需套件[cite: 1]。
透過 DNF 安裝 httpd 伺服器
dnf install httpd
步驟 2：啟動 Apache 服務
安裝完成後，服務不會自動執行。必須透過系統與服務管理程式 systemctl 啟動。預設的首頁資料夾位於 /var/www/html[cite: 2]。
啟動 httpd 服務
systemctl start httpd

主題二：啟用 HTTPS 與防火牆設定

動作目的：
預設的 HTTP (Port 80) 採明碼傳輸，若輸入帳號密碼極易遭到監聽。透過額外安裝 SSL 模組，讓伺服器支援具有加密功能的 HTTPS 協定。同時，也必須在伺服器端防火牆放行對應的封包，外部電腦才能順利連線。

執行步驟與指令範例

步驟 1：安裝 SSL 模組並重新啟動
安裝 mod_ssl 模組以支援 TLS/SSL。安裝後必須使用 restart 重啟服務，只有「關掉再開」才能真正套用新的模組設定。
安裝 SSL 模組
dnf install mod_ssl
重新啟動 httpd 服務以套用設定
systemctl restart httpd
步驟 2：防火牆放行 HTTPS 服務
外部設備連線預設會被本機防火牆擋住，需使用 firewall-cmd 工具新增開放 https 服務。
開放 HTTPS 通訊協定 (允許加密連線穿透防火牆)
firewall-cmd --add-service=https

主題三：自訂連接埠 (Port)

動作目的：
為提高網站隱密性，可將預設的 Port 80 更改為未被註冊佔用的動態 Port (建議為 50000 以上，如 50099)。由於不再使用預設服務協定，防火牆必須改用具體指定 TCP Port 的方式放行。

執行步驟與指令範例

步驟 1：修改主要設定檔 (httpd.conf)
設定檔位於 /etc/httpd/conf/httpd.conf。尋找 Listen 參數，將原本的 80 修改為自訂的連接埠號碼。修改完成必須重啟服務。
使用 Vim 編輯設定檔
vim /etc/httpd/conf/httpd.conf
內部修改：將 Listen 80 改為自訂 Port (以 50099 為例)
Listen 50099
存檔後重啟服務
systemctl restart httpd
步驟 2：防火牆開放指定 Port
自訂 Port 不是已知的服務名稱，因此防火牆參數需從 --add-service 改為 --add-port，並註明為 TCP 協定。
防火牆開放特定的 TCP 連接埠 (50099)
firewall-cmd --add-port=50099/tcp

主題四：建置個人網頁 (User Directory)

動作目的：
允許特定使用者擁有其專屬網頁空間。必須先啟用 userdir.conf，並在使用者家目錄下建立 public_html 放首頁。關鍵在於賦予資料夾「執行權限(x)」與關閉 SELinux 核心防護機制，避免出現 Forbidden 阻擋。

執行步驟與指令範例

步驟 1：啟用個人網頁設定檔
編輯 /etc/httpd/conf.d/userdir.conf，將 UserDir disabled 加上註解使其失效，並將 UserDir public_html 註解移除以啟用功能。
編輯 userdir 設定檔
vim /etc/httpd/conf.d/userdir.conf
內部修改內容 (加上註解停用、移除註解啟用)
#UserDir disabled
UserDir public_html
儲存後重啟服務
systemctl restart httpd
步驟 2：建立首頁與配置資料夾權限
在家目錄中建立資料夾，最重要的是必須為使用者的「家目錄」加上 x (執行) 權限，網頁伺服器才能切換進去讀取資料。
在指定使用者(如 u41)家目錄下建立網頁資料夾
mkdir /home/u41/public_html
賦予家目錄其他使用者執行(x)權限，允許進入目錄
chmod +x /home/u41
步驟 3：解除 SELinux 防護阻擋
實務或檢定測試中，為避免美國國安局開發的 SELinux 機制強制攔截，可使用 setenforce 0 暫時關閉，使其變為 Permissive (寬容) 模式。
暫時將 SELinux 設為寬容模式 (關閉強制阻擋)
setenforce 0
(選用) 檢查 SELinux 目前狀態是否為 Permissive
getenforce

主題五：IP 存取控制 (鎖 IP)

動作目的：
限制伺服器上的特定資料夾，僅讓特定的 IP 網段或主機存取 (例如僅允許 IP 42，其餘皆出現 Forbidden 拒絕)。此防護機制設定於 httpd.conf 中，利用 Order deny,allow 邏輯嚴格把關。

執行步驟與指令範例

步驟 1：修改設定檔套用鎖定規則
進入主要設定檔，針對需要保護的資料夾 (例如 /var/www/html/p) 加上 <Directory> 標籤。邏輯必須是「先拒絕全世界，再允許指定 IP」。
編輯主要設定檔
vim /etc/httpd/conf/httpd.conf
在檔案底部加入控制區塊
<Directory /var/www/html/p>
    Order deny,allow
    Deny from all
    Allow from 192.168.x.42
</Directory>
儲存後套用設定
systemctl restart httpd
