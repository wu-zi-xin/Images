主題一：系統基礎與快捷操作

動作目的：
掌握 Linux 的系統開機指令，學會善用手冊查詢指令功能，並熟悉能大幅提升工作效率的終端機快捷鍵，降低重複輸入的麻煩 [1-4]。
步驟 1：重新啟動系統
使用 reboot 指令可以直接將 Linux 系統重新開機 (boot 意為開機，reboot 為重開機) [1]。 
# 重新啟動 Linux 系統
reboot
步驟 2：查詢系統說明手冊
使用 man (manual) 可以查閱指令的使用手冊；使用 apropos 可以用「關鍵字」在手冊資料庫中進行全域搜尋。初次使用前必須先用 mandb 建立資料庫 [2, 4-6]。 
# 1. 更新或建立手冊資料庫 (需 Root 權限)
mandb

# 2. 用關鍵字搜尋與 user 相關的指令
apropos user

# 3. 查詢 useradd 指令的詳細手冊 (按 Q 離開)
man useradd
步驟 3：終端機高效率快捷鍵
利用 Tab 自動補齊指令；用 history 查詢指令紀錄；用 Ctrl + L 清空畫面；按下 ESC 再按 . 可以直接貼上前一個指令的最後一個參數 [3, 7-9]。 
# 顯示過去所有執行過的指令歷史紀錄
history

# 鍵盤按下：Ctrl + L

# 自動帶入前一個指令的最後參數 (快捷鍵)
# 鍵盤按下：ESC 接著按 .

主題二：目錄、檔案與權限

動作目的：
理解 Linux 單一根目錄 (/) 結構，學會切換目錄、列出目錄與檔案權限詳細資訊，並利用管線結合搜尋功能精準找到所需資料 [10-15]。
步驟 1：目錄切換與顯示當前路徑
使用 pwd (print working directory) 顯示目前所在絕對路徑。使用 cd (change directory) 切換到目標目錄 [12, 16, 17]。 
# 切換到根目錄下的 home 目錄 (存放所有使用者家目錄的地方)
cd /home

# 顯示目前所在的絕對路徑，確認是否成功切換
pwd
步驟 2：查看詳細檔案清單與權限
ll 是 ls -l 的別名 (alias)。可用來詳細列出檔案資訊，最左邊的 d 代表目錄，後方九碼分別代表擁有者、群組、其他人的讀 (r)、寫 (w)、執行 (x) 權限 [13-15]。 
# 查詢目前系統設定的所有指令別名 (綽號)
alias

# 顯示當前目錄下的詳細檔案與權限清單 (等同於 ls -l)
ll
步驟 3：讀取檔案與管線搜尋
使用 cat 將檔案內容印出在螢幕上。配合管線符號 | 可以將輸出結果丟給 grep 進行特定字串的搜尋 [10, 11, 18, 19]。 
# 讀取系統帳號檔，並過濾出包含 "n11" 的資料行
cat /etc/passwd | grep n11

主題三：帳號與密碼管理

動作目的：
學會以系統管理員身分新增、徹底刪除使用者，掌握變更密碼的權限差異與限制，以及如何正確地切換使用者並套用其環境設定 [2, 6, 20-22]。
步驟 1：新增與刪除帳號
使用 useradd 新增帳號 (系統會自動在 /home 建立專屬家目錄)。刪除時使用 userdel，若要連同家目錄一起徹地刪除，必須加上 -r (remove) 參數 [2, 6, 19, 21, 23, 24]。 
# 新增一個名為 n11 的使用者帳號
useradd n11

# 刪除帳號 n11，並且連同其專屬家目錄一併徹底移除
userdel -r n11
步驟 2：設定與修改密碼
使用 passwd 設定密碼。Root 修改密碼無需舊密碼且無複雜度限制；一般使用者需先驗證舊密碼，且新密碼長度需滿8碼、不能太簡單或與舊密碼相同 [9, 21, 22, 25]。 
# Root 幫使用者 n16 設定密碼 (不須舊密碼，不受複雜度限制)
passwd n16

# 一般使用者登入後幫自己修改密碼
passwd
步驟 3：切換使用者與登出
使用 su - [帳號] 切換身分。務必加上減號 -，這樣不僅會切換身分，還會套用該帳號的環境，並自動跳轉至該使用者的家目錄 (以 ~ 符號表示)。登出則使用 exit [16, 17, 20, 24, 26]。 
# 切換至使用者 n11，並套用其環境與進入家目錄
su - n11

# 從目前的帳號登出，退回上一個使用者狀態
exit

主題四：遠端登入與安全設定

動作目的：
學習如何透過 SSH (Secure Shell) 加密協定跨設備遠端操控伺服器，並透過修改系統設定檔，改變預設阻擋 Root 遠端登入的安全性限制 [27-37]。
步驟 1：一般帳號遠端登入
利用 ssh 進行遠端連線。您可以利用 -l 參數指定帳號，或者使用類似 Email (帳號@IP) 的格式進行連線。基於安全，SSH 預設拒絕 root 直接遠端登入 [27-30]。 
# 語法一：使用 -l 參數指定帳號 (以 n17 登入 192.168.x.11)
ssh -l n17 192.168.x.11

# 語法二：使用 Email 格式指定帳號
ssh n17@192.168.x.11
步驟 2：修改 SSH 允許 Root 登入
透過 vi 編輯器修改 /etc/ssh/sshd_config。利用 /Root 搜尋，按 i 進入插入模式，將 #PermitRootLogin 刪除註解符號 # 並將值改為 yes，最後按 ESC 離開插入，輸入 :wq 存檔 [32-35]。 
# 使用 vi 編輯器開啟 SSH 伺服器主要設定檔
vi /etc/ssh/sshd_config

# 於檔案內部搜尋並修改成如下：
PermitRootLogin yes
步驟 3：重啟 SSH 服務套用設定
修改設定檔後不會立即生效，必須使用系統控制指令 systemctl 針對 sshd (SSH 伺服器服務) 執行 restart 重啟，Root 才能成功遠端連線 [36, 37]。 
# 重新啟動 SSH 服務，使新設定檔強制生效
systemctl restart sshd

# 從另一台機器測試 Root 是否能成功遠端登入
ssh root@192.168.x.11
