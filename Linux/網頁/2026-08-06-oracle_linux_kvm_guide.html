階段一：KVM 主機環境建置 (Host Setup)

架構說明與目的

本實作是在「實體 Linux 主機 (Host)」的底層安裝 KVM (Kernel-based Virtual Machine) 虛擬化技術，使其具備分配資源並運行「子虛擬機 (Guest VM)」的能力。

為了方便管理，我們將一併安裝 Cockpit 網頁管理介面與 cockpit-machines 擴充套件，讓系統管理員可以直接透過瀏覽器遠端建立與監控虛擬機，而無須全程依賴文字指令。

執行步驟與指令範例

步驟 1：檢查硬體虛擬化支援
確保實體機的 CPU 有開啟硬體虛擬化 (Intel VT-x 或 AMD-V) 功能。
確認 CPU 廠牌與虛擬化標記 (Intel 顯示 vmx)
grep -e 'vendor_id' /proc/cpuinfo
grep -e 'vmx' /proc/cpuinfo
步驟 2：安裝 KVM 核心與管理工具
透過 dnf 安裝虛擬化群組套件以及 Cockpit 的虛擬機管理模組。
安裝虛擬化群組與 QEMU 相關元件
dnf group install "Virtualization Host" -y
dnf install qemu-kvm virt-install virt-viewer -y
檢查虛擬化環境是否就緒
virt-host-validate qemu
啟動虛擬化背景服務 (libvirtd)
systemctl enable --now libvirtd.service
步驟 3：安裝並開放 Cockpit 網頁管理介面
安裝 Cockpit 機管理套件，並設定防火牆允許外部連線進入。
安裝 cockpit-machines 與啟動 Socket
dnf install cockpit-machines -y
systemctl enable --now cockpit.socket
防火牆放行 Cockpit 服務 (預設 port 9090)
firewall-cmd --add-service=cockpit --permanent
firewall-cmd --reload
步驟 4：建立具有 sudo 權限的管理員帳號
建立帳號 (例如 ne99-111) 以便後續登入 Cockpit，並賦予 sudo 權限。
新增帳號並編輯 sudoers
useradd ne99-111
passwd ne99-111
visudo
💡 在 visudo 中加入： ne99-111 ALL=(ALL) ALL

階段二：在實體機上透過 Cockpit 部署虛擬機

動作目的

實體機的虛擬化環境準備就緒後，接下來將從其他電腦的瀏覽器登入實體機的 Cockpit 介面 (Port 9090)。
透過圖形化介面掛載 ISO 映像檔，分配記憶體與硬碟資源，建立出獨立運作的「子虛擬機」。

執行步驟

步驟 1：登入 Cockpit 管理介面
開啟瀏覽器，輸入 https://<實體機的 IP>:9090。忽略憑證警告後，使用剛才建立的 ne99-111 (或 root) 帳號登入，並勾選「Reuse my password for privileged tasks」開啟管理權限。
步驟 2：建立虛擬機器 (Create VM)
在左側選單點擊 Virtual Machines，點選右上方 Create VM 按鈕。依據要求輸入以下參數：
  • Name (名稱): OL99-您的驗收號碼
  • Installation type: Local install media (選擇實體機內的 ISO 檔)
  • Installation source: /tmp/OL_OracleLinux-R10-U1-x86_64-dvd.iso (請確認 ISO 存在)
  • Memory (記憶體): 2 GiB
  • Storage limit (硬碟空間): 10 GiB
設定完成後點擊 Create and run，虛擬機會開始建立並開機。
步驟 3：安裝子作業系統並截圖驗收
點擊虛擬機進入詳細頁面，切換至 Console (主控台) 分頁，此時會看到系統安裝畫面。依序完成 Oracle Linux 作業系統安裝。
安裝完畢後，在主控台登入 root 帳號。
⚠️ 驗收要求 (題目三)：進入子虛擬機的命令列登入畫面後，將該畫面截圖上傳。

階段三：虛擬機網路連線與網頁伺服器驗證

動作目的

確保建立出來的虛擬機能夠透過虛擬網路卡 (通常是橋接 bridge 或 NAT 模式) 與其他虛擬機及外部網路通訊。並測試是否能存取特定虛擬機上所架設的 HTTPS 網頁。

執行步驟與指令範例

步驟 1：測試內部連線與對外連線
在新建的虛擬機內，使用 ping 測試另一台已知虛擬機 (例如 IP 為 192.168.122.252) 的連通性，並測試是否能存取網際網路。
Ping 測試指令
ping 192.168.122.252
ping 8.8.8.8
步驟 2：測試 HTTPS 網頁存取
開啟虛擬機的瀏覽器 (例如 Firefox)，在網址列輸入目標虛擬機的 IP 位址。
在瀏覽器輸入位址
https://192.168.122.252
⚠️ 驗收要求 (題目二)：略過安全憑證警告 (Accept the Risk and Continue)，進入顯示「歡迎光臨...於 KVM 建構的網站...」的測試網頁後，將畫面（須包含上方 IP 網址列）截圖上傳。

階段四：自動配發 IP - Kea DHCP 伺服器建置

動作目的

在 Oracle Linux 10 環境中，預設的 DHCP 伺服器套件已經從傳統的 dhcpd 轉換為 Kea 系統。本步驟將示範如何安裝與啟動 Kea 的 IPv4 服務，作為網域內自動分配 IP 的核心元件。

執行步驟與指令範例

步驟 1：安裝 Kea 套件
透過 dnf 工具將 Kea 安裝至系統。
安裝指令
dnf install kea -y
步驟 2：啟動 Kea IPv4 服務
安裝完成後，需手動啟動服務。Kea 針對 v4 和 v6 有獨立的服務，此處啟動 kea-dhcp4。
啟動服務
systemctl start kea-dhcp4
⚠️ 驗收要求 (題目一)：將成功啟動 kea-dhcp4 的終端機指令與輸出結果截圖上傳。
