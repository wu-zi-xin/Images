主題一：case 多重條件判斷

動作目的：
在 Shell Script 中，利用 case 來進行多選一的條件判斷。比起撰寫多重 if-else，case 的結構能讓程式碼架構更為清晰、易讀[1, 2]。
執行步驟與指令範例
步驟 1：建立基礎架構與條件比對
寫法必須「有頭有尾」。開頭必須使用 case 關鍵字，而結尾則是將其反向拼寫為 esac 作為整個判斷結構的結束[1]。 
# 讀取腳本的第一個參數 ($1) 進行比對
case $1 in
    hello)
        echo "Hello, how are you?" 
esac
步驟 2：加入執行區塊的結束符號
當條件吻合時，會執行相應的動作。請注意，每個獨立的動作區塊最後，**務必要以兩個分號 ;; 結尾**。否則程式會無視條件繼續往下執行後續動作[1, 3]。 
case $1 in
    "one")
        echo "ONE"
        ;; # 務必加上雙分號結尾
    "two")
        echo "TWO"
        ;;
esac
步驟 3：設定預設動作 (捕捉例外)
可以利用星號 * 來捕捉所有「不符合前面任何條件」的輸入。這通常被用來提示使用者正確的參數用法 (Usage)[2, 3]。 
case $1 in
    hello)
        echo "Hello, how are you?" 
        ;;
    *) # 捕捉所有不符合的情況
        echo "Usage: $0 hello" 
        ;;
esac

主題二：function 函式定義與變數範圍

動作目的：
當腳本中有些功能會被重複使用時，可以將其定義為函式（副程式），呼叫時即可執行特定動作，這能有效簡化腳本架構並提高重用性[4]。
執行步驟與指令範例
步驟 1：定義副程式與不換行輸出
使用 function 關鍵字定義。echo -n 可以在印出文字後「不換行」，讓後續的輸出能接續顯示在同一行[4]。 
function printit {
    # 加上 -n 參數，游標會停留在同行不換行
    echo -n "Your choice is "
}
步驟 2：利用管線轉換大小寫
利用管線 | 將文字傳遞給 tr 'a-z' 'A-Z' 指令，可以輕鬆將字串中的小寫英文字母全面轉換為大寫[5]。 
case $1 in
    one)
        printit
        # 將變數 $1 透過 tr 轉換成大寫後接續輸出
        echo $1 | tr 'a-z' 'A-Z' 
        ;;
esac
步驟 3：理解變數 $1 的有效範圍
變數有作用域差異：若在函式「內部」出現 $1，代表的是傳給該函式的第一個參數；若在函式「外部」，則代表從終端機執行腳本時傳入的第一個參數[6, 7]。 
function print_param {
    # 這裡的 $1 是 function 的第一個參數 (亦即下方的 1)
    echo "Function param is: " $1
}

case $1 in # 這裡的 $1 是終端機傳入的腳本參數
    one)
        # 呼叫函式並傳入數字 1 作為參數
        print_param 1 
        ;;
esac

主題三：while 與 until 條件迴圈

動作目的：
根據設定條件的成立與否，決定是否重複執行迴圈內的動作。利用「笛摩根定理」，可以將 while 與 until 的邏輯互相反向轉換[8-10]。
執行步驟與指令範例
步驟 1：使用 while 迴圈 (條件成立時執行)
只要設定的條件為「成立 (True)」，就會不斷執行，直到條件不成立才停止。以下範例為：當輸入的值「不為 yes 且 (-a) 不為 YES」時，繼續詢問[8]。 
while [ "$yn" != "yes" -a "$yn" != "YES" ]
do
    read -p "Please input yes/YES to stop: " yn
done
echo "OK, you input correct answer"
步驟 2：使用 until 迴圈 (條件不成立時執行)
條件為「不成立 (False)」時不斷執行，直到條件滿足為止 (類似一直等待直到下午5點發生)。利用邏輯反轉，以下 until 寫法與上述 while 效果完全相同[9, 11]。 
until [ "$yn" == "yes" -o "$yn" == "YES" ]
do
    read -p "Please input yes/YES to stop: " yn
done
echo "OK, you input correct answer"

主題四：for 迴圈 (一) 列表與指令應用

動作目的：
將一連串的字串清單，或是外部指令執行出的結果，逐一帶入變數中重複操作[12, 13]。
執行步驟與指令範例
步驟 1：直接讀取列表迭代
直接將清單字串放在 for 迴圈後方迭代，每次迴圈會將清單項目依序放入變數中執行[12]。 
for animal in dog cat elephant
do
    echo "There are $animals"
done
步驟 2：結合外部切割指令
利用 $() 將指令餵給迴圈。例如用 cut -d: -f1 以冒號切割檔案，並只取出第一欄的帳號清單，逐一進行權限檢查[13, 14]。 
for username in $(cut -d: -f1 /etc/passwd)
do
    # 查詢每一個切割出來帳號的權限 (UID, GID)
    id $username
done
步驟 3：網段 Ping 測試 (丟棄雜訊與狀態判定)
使用 seq 產生連續數字。Ping 搭配 -c 1 (測1次) 與 -w 1 (等1秒)。使用 > /dev/null 丟棄雜訊，並用 $? 判斷回傳值是否為0 (通訊成功)[15-17]。 
for i in $(seq 90 100)
do
    ping -c 1 -w 1 192.168.99.$i > /dev/null
    if [ $? == 0 ]; then
        echo "192.168.99.$i is UP"
    else
        echo "192.168.99.$i is DOWN"
    fi
done

主題五：for 迴圈 (二) 算術寫法

動作目的：
處理包含初始值、明確條件限制以及固定步進值（等差數值）的迴圈運算，寫法類似 C 語言[18]。
執行步驟與指令範例
步驟 1：定義雙括號迴圈與算術加總
使用 for (( 初始值; 條件限制; 每次變動 )) 來設定迴圈參數，並將變數包在 $(( )) 中進行數學總和運算[18, 19]。 
s=0
read -p "Please input a number: " num

for (( i=1; i<=$num; i++ ))
do
    # 在前字號加上雙小括號內進行數學運算
    s=$(( $s + $i ))
done
echo "1+...+ $num = $s"
步驟 2：利用外部參數動態決定範圍與步進
可透過外部傳入三個參數 ($1 起始, $2 結束, $3 等差步進)，動態計算自訂範圍與跳躍值的總和[20]。 
s=0
# $1: 從哪裡開始加
# $2: 加到哪裡結束
# $3: 等差數值 (每次加多少)

for (( i=$1; i<=$2; i+=$3 ))
do
    s=$(( $s + $i ))
done
echo "The total sum is $s"

主題六：陣列與亂數實戰

動作目的：
結合系統隨機數字與陣列結構，實作如抽籤程式或亂數分布的機率驗證統計[21, 22]。
執行步驟與指令範例
步驟 1：有效取得限制範圍的亂數
系統變數 $RANDOM 會產生隨機數字，最有效率的範圍限制法是「取餘數」。例如要取 0 到 11 的亂數，只需寫 % 12[21]。 
# 取得 0 到 11 之間的亂數
idx=$(( $RANDOM % 12 ))
echo "Random Index is: $idx"
步驟 2：從陣列提取對應資料 (從零開始)
定義陣列時，項目會從索引 0 開始計算。將剛剛取出的亂數當作索引值，即可隨機抽出幸運星座[22]。 
# 定義陣列索引 0 到 11
constellations=("白羊" "金牛" "雙子" "巨蟹" "獅子" "處女" "天秤" "天蠍" "射手" "摩羯" "水瓶" "雙魚")

idx=$(( $RANDOM % 12 ))
echo "本日幸運星座：${constellations[$idx]}"
步驟 3：陣列計數與機率驗證
將取亂數的動作重複執行極高次數 (如 24 萬次)，並將出現的次數存回陣列中累加，可驗證系統亂數的分布具備平均性 (約各兩萬次)[23, 24]。 
# 執行 24 萬次驗證亂數分佈
for (( i=1; i<=240000; i++ ))
do
    idx=$(( $RANDOM % 12 ))
    # 將陣列特定索引的計數加一並存回
    arr[$idx]=$(( ${arr[$idx]} + 1 ))
done

# 印出結果驗證
echo "0 出現次數：${arr}"
