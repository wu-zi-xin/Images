主題一：模式切換與游標移動

動作目的

動作目的：了解 Vim 最核心的三種工作模式（一般模式、編輯模式、指令列模式），並學會不依賴滑鼠而在檔案內迅速精準地移動游標，這是掌握 Vim 的基本功。

執行步驟與指令範例

步驟1：進入與退出編輯模式
Vim 剛啟動時處於「一般模式」，不允許直接輸入文字。您需要按下 i 鍵切換到「編輯模式」才能打字。編輯完成後，按 Esc 鍵退回一般模式。
在一般模式下，按下 i 鍵，左下角會顯示 -- INSERT --
i
完成輸入文字後，按下 Esc 鍵退回一般模式
Esc
步驟2：使用鍵盤移動游標
在一般模式下，與其使用方向鍵，Vim 高手習慣使用 h、j、k、l 來進行左、下、上、右的游標移動，這樣手不用離開主鍵盤區。
向左移動一個字元
h
向下移動一行
j
向上移動一行
k
向右移動一個字元
l

主題二：檔案的儲存與離開

動作目的

動作目的：確保所有編輯的內容能夠被正確寫入磁碟中，或者在操作失誤時，能夠強制放棄變更並安全地關閉 Vim 編輯器。

執行步驟與指令範例

步驟1：儲存並離開
在一般模式下輸入冒號 : 進入指令列模式，接著輸入 wq 可以同時執行寫入（Write）與離開（Quit）的動作。
確認處於一般模式，輸入以下指令儲存並離開
:wq
步驟2：強制放棄變更並離開
如果改錯了程式碼不想存檔，輸入 :q! 可強制結束編輯，並捨棄從上次存檔以來的所有變更。
不儲存任何變更，強制退出 Vim
:q!

主題三：文字的編輯與刪除

動作目的

動作目的：在不進入編輯模式的情況下，透過快捷鍵瞬間刪除不需要的單字或整行程式碼，並在出錯時快速「復原」上一步操作。

執行步驟與指令範例

步驟1：刪除單字與整行文字
按 x 可刪除游標所在處的一個字元；連續按兩次 dd 則能直接刪除游標所在的整行文字。
刪除游標所在的一個字元（類似 Delete 鍵）
x
刪除游標所在的整行
dd
刪除游標下方的 3 行文字（加上數字）
3dd
步驟2：復原與重做
若不小心誤刪了資料，按下 u 鍵 (Undo) 可以復原上一個動作；若想取消剛才的復原，按下 Ctrl + r 即可重做 (Redo)。
復原上一個動作
u
取消復原（重做）
Ctrl + r

主題四：複製、剪下與貼上

動作目的

動作目的：善用 Vim 內建的暫存器與快捷鍵，進行大範圍文字或程式碼的搬遷，無須透過滑鼠選取就能達到高效的複製貼上作業。

執行步驟與指令範例

步驟1：複製與剪下整行
使用 yy 進行複製 (Yank)；而前面的刪除指令 dd 在 Vim 裡的實質意義其實是「剪下」，被刪除的內容會被保存在暫存區中。
複製游標所在的整行
yy
複製游標所在的該行及往下的總共 4 行
4yy
剪下（刪除）游標所在的整行
dd
步驟2：將內容貼上
執行完複製或剪下後，將游標移動到目標位置，按下 p 即可將內容貼在游標的「下一行」；大寫的 P 則是貼在游標的「上一行」。
將複製/剪下的內容貼到游標所在的下一行
p
將複製/剪下的內容貼到游標所在的上一行
P

主題五：全文搜尋與替換

動作目的

動作目的：在設定檔或大篇幅的程式碼中，快速定位關鍵字，甚至使用取代功能進行批次修改，大幅節省逐行尋找的時間。

執行步驟與指令範例

步驟1：搜尋關鍵字
在一般模式下按下斜線 / 開啟搜尋模式並輸入字串，按下 Enter 後會跳轉到第一個結果。按 n 找下一個，N 找上一個。
搜尋文件中的 "error" 關鍵字
/error
跳至下一個匹配的搜尋結果
n
跳至上一個匹配的搜尋結果
N
步驟2：批次字串替換
利用 :%s/舊字串/新字串/g 的語法，可以一次將整份文件裡符合條件的文字全部替換。
將整份檔案中的 "apple" 全部替換為 "banana"
:%s/apple/banana/g
替換前先詢問確認 (加入 c 參數)
:%s/apple/banana/gc
