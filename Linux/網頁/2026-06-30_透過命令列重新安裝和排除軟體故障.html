主題一：網路與虛擬機基礎設定

動作目的

設定多台虛擬機之間的內部網路配置，給予專屬的 IP 位址（如 61、62、63），並驗證網路連通狀態，確保後續網頁伺服器連線測試不會因實體網路或虛擬機網路隔絕而失敗 [1, 2]。

執行步驟與指令範例

步驟 1：設定 IP 位址與網路連通測試
確保虛擬機網卡設為「內部網路」。透過指令設定網卡 IP，並使用 ping 測試其他虛擬機（例如 62 與 63）是否有回應 [1, 2]。 
# 檢視當前 IP 狀態
ip a

# 測試與 62 號主機的連通性
ping 192.168.x.62

# 測試與 63 號主機的連通性
ping 192.168.x.63
步驟 2：修改虛擬機開機順序
若開機時一直卡在光碟安裝畫面，必須將系統立即關機，並在系統設定中取消「軟碟/光碟開機」，強制由硬碟開機 [3]。 
# 強制且立即關機 (接著至 VM 介面移除光碟開機優先權)
shutdown -h now

主題二：Apache 網頁伺服器與個人網頁設定

動作目的

在 Apache 伺服器上建置使用者專屬的個人網頁，並開放 HTTPS 通訊協定。同時為該網頁加上「帳號密碼保護」及精細的「IP 存取限制」，以強化網站的訪問安全 [2, 4-6]。

執行步驟與指令範例

步驟 1：建立個人網頁與開放目錄權限
透過 useradd 建立帳號，在其家目錄下新增 public_html 以放置網頁。必須給予其他使用者 x 權限，並暫時關閉 SELinux 才能讓網頁被看見 [2, 7]。 
# 建立使用者帳號與個人網頁資料夾 (登入該帳號操作)
useradd N1x-61
mkdir public_html

# 賦予其他使用者進入目錄的權限
chmod o+x /home/N1x-61

# 切換為 root 權限，暫時關閉 SELinux 保護
setenforce 0
步驟 2：啟動服務與 HTTPS 防火牆放行
重新啟動 Apache 伺服器服務，並將防火牆放行 HTTPS 封包，讓客戶端瀏覽器能以安全協定存取伺服器 [4, 7]。 
# 啟動 Apache (httpd) 伺服器
systemctl restart httpd

# 防火牆放行 HTTPS 協定
firewall-cmd --add-service=https
步驟 3：建立帳號密碼保護 (.htaccess)
確認設定檔具有 AllowOverride AuthConfig 後，在欲保護的資料夾中建立 .htaccess。使用 htpasswd 建立密碼檔，首次建立時必須加上 -c 參數 [5, 8, 9]。 
# 第一次建立密碼檔並為使用者設定密碼 (-c 表示新建)
htpasswd -c /var/www/html/P2/htpasswd N1x-61

# 若檔案已存在要為其他使用者新增密碼 (不加 -c，以免覆寫)
htpasswd /var/www/html/P2/htpasswd N1x-62
步驟 4：設定 IP 存取限制 (拒絕特定主機)
於設定檔中修改存取順序。若希望「僅拒絕特定 IP（如 63 主機），其餘皆允許」，順序必須設定為先允許 (Allow) 再拒絕 (Deny) [6]。 
# 編輯設定檔，加入以下規則 (先允許全部，再拒絕特定 IP)
Order allow,deny
Allow from all
Deny from 192.168.x.63

# 設定完成後務必重啟服務套用設定
systemctl restart httpd

主題三：軟體套件管理 (RPM 與 DNF)

動作目的

掛載系統安裝光碟並利用其檔案做為離線軟體庫。學會使用基層指令 RPM 進行單一套件的查詢與安裝；並透過修改設定檔建立本地 DNF 來源，解決複雜的套件相依性問題 [10-12]。

執行步驟與指令範例

步驟 1：使用 RPM 安裝單一套件
掛載光碟後，切換到套件存放目錄。使用 rpm 配合 -i (安裝)、-v (顯示詳細過程) 及 -h (顯示進度條) 來安裝套件，如 tree 指令 [10, 13, 14]。 
# 查詢套件是否已安裝
rpm -q tree

# 安裝 tree 套件，並顯示詳細過程與井字號進度條
rpm -ivh tree-x.x.x.rpm

# 若要移除該套件
rpm -e tree
步驟 2：修改 DNF 來源為本地端光碟
針對無法連網的環境，進入 /etc/yum.repos.d/ 修改設定檔，將網路來源註解掉，改為透過 file:/// 指向已掛載的本地端光碟路徑 (BaseOS 與 AppStream) [12, 15, 16]。 
# 編輯設定檔，將原本的 baseurl 註解，改為本機光碟路徑
vim /etc/yum.repos.d/local.repo

# 修改範例 (指向光碟下的 BaseOS 與 AppStream 目錄)：
baseurl=file:///run/media/root/10.1/BaseOS
baseurl=file:///run/media/root/10.1/AppStream
步驟 3：使用 DNF 解決相依性安裝
設定完本地來源後，即便中斷對外網路，依然可透過 dnf install 自動抓取所需的相依套件並順利安裝 [11, 16]。 
# 測試在無網路環境下，透過 DNF 自動解決相依性並安裝 PHP-FPM
dnf install php-fpm

主題四：PHP 網頁支援與測試

動作目的

為 Apache 網站伺服器擴充功能，使其能夠解析與執行動態的 PHP 網頁程式碼。透過建立基礎測試檔，跨設備驗證 PHP 是否成功運作 [17]。

執行步驟與指令範例

步驟 1：安裝 PHP 套件並建立測試檔
在伺服器端安裝 php-fpm 套件，隨後在網頁伺服器根目錄建立 hello.php 檔案寫入測試語法 [11, 17]。 
# 透過本地端 DNF 安裝 PHP 相關模組
dnf install php-fpm

# 建立 hello.php，寫入基本 PHP 程式碼
vim /var/www/html/hello.php

# 在檔案內寫入：
<?php
  echo "my first PHP script";
?>
步驟 2：重啟服務並以客端瀏覽器驗證
完成修改後，必須重啟 Apache 服務。接著從另一台機器（如 62 號機）透過 HTTPS 瀏覽此頁面，確認是否能看到解析後的內容 [17]。 
# 伺服器端重啟 HTTPD 服務
systemctl restart httpd

# 於客戶端 (62機) 開啟瀏覽器或用 curl 測試：
curl -k https://192.168.x.61/hello.php

主題五：MariaDB 資料庫安裝與操作

動作目的

建立功能完整的 MariaDB 資料庫服務，進行基礎安全性設定（設定 root 密碼），並學習如何透過共用資料夾，將外部準備好的 SQL 資料庫結構與內容匯入至系統中供查詢 [18-20]。

執行步驟與指令範例

步驟 1：安裝並啟動 MariaDB 服務
使用 DNF 搜尋並安裝 mariadb-server 套件，安裝完畢後必須啟動服務才能進行後續初始化 [18, 19]。 
# 安裝資料庫伺服器套件
dnf install mariadb-server

# 啟動 MariaDB 資料庫服務
systemctl start mariadb
步驟 2：資料庫安全初始化
執行 mysql_secure_installation 指令，按照引導設定 root 密碼（示範為 123456），並移除不安全的匿名權限設定 [19, 21]。 
# 執行初始化安全設定腳本
mysql_secure_installation

# 根據提示：無密碼按 Enter，設定新密碼為 123456，後續皆按 Enter 同意預設值
步驟 3：匯入 SQL 檔並查詢資料表
登入資料庫後，使用 source 指令匯入外部提供的 nation.sql 範例庫。接著使用 show tables 檢視資料表，與 select 語法查詢各洲資料 [20-22]。 
# 使用 root 身分登入資料庫 (需輸入剛才設定的密碼)
mysql -u root -p

# 在資料庫提示字元下，匯入外部 SQL 檔案
MariaDB> source /root/nation.sql;

# 檢視所有匯入的資料表
MariaDB> show tables;

# 查詢表格內所有資料 (務必加上分號結尾)
MariaDB> select * from continents;
