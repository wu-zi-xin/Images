主題一：系統基礎連線

動作目的：
學習在 Linux 環境中使用超級管理員 (root) 登入系統以獲取完整的控制權限，並且檢視系統當下的網路 IP 遮罩狀態。同時練習利用 ICMP 協定封包測試伺服器之間的網路連線狀態，最後運用指令歷史紀錄來快速重新執行系統關機等操作。
步驟 1：檢視網路與測試連線
目的： 使用 ip address 或簡寫 ip a 能夠確認伺服器的 IP 位置（例如斜線 24 代表子網路遮罩 255.255.255.0）；而 ping 指令會向遠端機器發送封包，當出現 run time 數據就代表兩機網路通暢，並可用 Ctrl + C 中斷。
指令： ip a (查詢網路) / ping (測試連通) 
# 查詢網路卡設定
ip a

# 測試與 21 號機器的網路連線
ping 192.168.x.21
# (測試成功後按下 Ctrl + C 終止)
步驟 2：歷史紀錄與系統關機
目的： 使用 history 查閱過去下過的所有指令。透過驚嘆號加上歷史編號 !編號 或字母 !字母 能夠迅速重複該動作，例如直接呼叫先前的 shutdown 立刻進行關機 (-h 代表 halt, 0 代表時間為 0)。
指令： history (查閱紀錄) / shutdown (關閉系統) 
# 檢視所有的歷史指令
history

# 重複執行上一筆以 sh 開頭的指令
!sh

# 系統立刻關機
shutdown -h 0

主題二：帳號與群組管理

動作目的：
除了系統預設在建立帳號時會一併產生同名的群組外，管理員可以自行透過指令手動建立自訂的新群組，並能彈性地把某個帳號同時指派加入到多個不同的群組之中，藉此達到嚴謹且細緻的權限控管。
步驟 1：新增與檢視群組
目的： 使用 groupadd 手動建立新的群組，再透過 cat 讀取 /etc/group 檔案來確認群組是否成功建立於系統之中。
指令： groupadd (新增群組) / cat (查看檔案) 
# 手動建立一個名為 G-21 的群組
groupadd G-21

# 查看系統目前所有的群組清單
cat /etc/group
步驟 2：修改使用者所屬群組
目的： 透過 usermod -G 來修改使用者附加的群組。若想要讓該帳號同時隸屬於多個群組，僅需要在群組名稱之間使用逗點 ( , ) 隔開即可，不需要加入空白。
指令： usermod (修改帳號) 
# 將帳號 user21 加入至單一群組 G-21
usermod -G G-21 user21

# 將帳號 user21 同時指派到 G-21 與 G-22 兩個群組
usermod -G G-21,G-22 user21
步驟 3：移除群組與過濾搜尋
目的： 當不需要該群組時，可以使用 groupdel 將其移除。同時在看大量資料時，可利用管道及 grep 搭配關鍵字過濾出我們需要的群組資訊行數。
指令： groupdel (刪除群組) / grep (過濾字串) 
# 刪除已建置的偶數群組 G-22
groupdel G-22

# 只顯示含有特定關鍵字 G-21 的群組資料行
cat /etc/group | grep G-21

主題三：目錄與檔案操作

動作目的：
學習最頻繁使用的建立資料夾與新建空檔案操作，並利用 dd 指令快速產生用於測試容量限制的特定大小檔案；此外，也結合文字編輯器實作編輯與內容儲存。
步驟 1：建立空檔與目錄切換
目的： 使用 mkdir 來建立新的資料夾；touch 可以一口氣建立多個空檔案，若檔案已存在則會將時間戳記 (Timestamp) 更新為當下時間。透過 cd 進入資料夾，單獨下 cd 則會直接跳回家目錄。
指令： mkdir (建目錄) / touch (建空檔) / cd (切換路徑) 
# 建立目錄 D1
mkdir D1

# 進入 D1 目錄
cd D1

# 一次建立 F1, F2, F3 三個空檔案
touch F1 F2 F3
步驟 2：dd 產生特定容量測試檔
目的： dd 指令非常適合用來建立固定空間的假檔案，透過 if=/dev/zero 提供無限的空資料來源，並指定 bs (區塊大小) 與 count (數量) 就可以產出精準的檔案。
指令： dd (資料轉換與拷貝) 
# 產生一個容量精準為 1KB 的測試檔 (檔名為 1K)
dd if=/dev/zero of=1K bs=1K count=1

# 產生一個容量精準為 4KB 的測試檔 (檔名為 4K)
dd if=/dev/zero of=4K bs=1K count=4
步驟 3：VIM 編輯器操作
目的： 利用系統最強大的 vim 進入檔案編輯，按下 i 鍵進入插入模式後便能輸入文字，打字完成後按 ESC 鍵退出編輯模式，最後透過 :wq 寫入並離開。
指令： vim (文字編輯) 
# 使用 vim 打開並編輯檔案
vim F-211

# 1. 進入後按下 i 鍵切換至 Insert 插入模式
# 2. 隨意輸入您的文字內容
# 3. 按下 ESC 鍵退出插入模式
# 4. 輸入 :wq 存檔並離開

主題四：清單檢視與排序

動作目的：
熟悉能檢視所有隱藏檔案以及遞迴呈現深層資料夾結構的 ls 工具，並學會藉由檔案建立時間以及容量大小，動態正向或反向排序我們的目錄結果。
步驟 1：顯示隱藏檔與遞迴層級
目的： 加上 -a 參數可以看到系統中所有以「點」開頭的隱藏檔；加上大寫的 -R (Recursive) 則會將資料夾內所有的子層目錄一併展開顯示。
指令： ls -a / ls -R 
# 顯示包含隱藏檔在內的所有內容
ls -a

# 遞迴展開顯示目錄及所有的子資料夾內容
ls -R
步驟 2：長列表與檔案大小排序
目的： 使用 -l 能以長列表形式詳列權限與擁有者。配上 -S 會依據容量排序；若加入小寫的 -r (Reverse) 將會顛倒預設順序，例如變成由小到大排列。
指令： ls -lS (大小排序) / ls -lSr (大小反向排序) 
# 以長列表顯示，並依檔案容量由大到小排序
ls -lS

# 加上 r 反向排列，依檔案容量由小到大排序
ls -lSr
步驟 3：依據時間戳記排序
目的： 參數 -t 能夠將檔案依照最後建立或修改的時間 (Timestamp) 排序，最新的排在最上方。如果配上 -r 反向排序，則會將最新建立的檔案排在畫面的最下方。
指令： ls -lt (時間排序) / ls -ltr (時間反向排序) 
# 依據時間排序，最新修改的排在最上方
ls -lt

# 反向時間排序，將最新修改的檔案排在清單最底部
ls -ltr

主題五：搬移複製與刪除

動作目的：
完全掌握資料夾與檔案的生命週期管理，包含拷貝複雜的整個資料夾層級、在同個目錄下透過搬移指令達成改名效果，以及利用強制指令手段一次性清除過於複雜的垃圾資料夾。
步驟 1：遞迴複製目錄結構
目的： 單純的 cp 只能拷貝檔案，但若要在複製的同時將來源資料夾內的所有子目錄及檔案「一併」包裝拷貝走，必須加上 -r (Recursive) 參數。
指令： cp -r (遞迴複製) 
# 將 D1 整個資料夾及其內含的所有內容複製一份，命名為 D2
cp -r D1 D2
步驟 2：重新命名與搬移操作
目的： mv 負責搬移檔案與目錄。如果在同一個路徑下將檔案 A 移至檔案 B，Linux 會直接將其視為「更改檔案名稱」；如果是指定到另一個目錄，則是將其整包搬移。
指令： mv (搬移或重命名) 
# 將 F9 重新命名為 F999
mv F9 F999

# 將資料夾 D9 整包搬移至資料夾 D8 的內部
mv D9 D8
步驟 3：強制打掉重練 (刪除)
目的： 面對極度錯綜複雜的目錄，可以使用 rm 進行刪除。參數 -r 用於針對目錄，參數 -f 代表不逐一詢問確認 (Force)，而星號 * 則代表目錄下所有的東西，為危險指令請謹慎使用。
指令： rm -rf (強制遞迴刪除) 
# 刪除單一檔案 F1
rm F1

# 強制無提示刪除該層目錄底下的所有檔案與資料夾
rm -rf *
