主題一：基礎檔案開啟與退出

動作目的： 在 Linux 作業系統的終端機中，利用 nano 編輯器快速開啟既有檔案進行修改，或是建立一個全新的文字檔。完成編寫後，能夠安全地進行存檔並將編輯器正確關閉返回命令列。
步驟1：開啟或建立新檔案
在終端機中輸入 nano 指令，後方加上欲編輯的檔案名稱。如果該檔案不存在，系統會直接建立一個同名的新檔案；如果存在，則會讀取內容進入編輯模式。 
# 開啟或建立名稱為 config.txt 的檔案
nano config.txt
步驟2：儲存檔案 (Write Out)
完成文字修改後，按下快捷鍵 Ctrl + O (英文字母 O) 以寫入檔案。系統會在底端提示要儲存的檔案名稱，此時只要按下 Enter 鍵確認即可完成存檔動作。 
# 儲存目前的編輯內容
Ctrl + O 
# 接著按下 Enter 鍵以確認檔案名稱
步驟3：退出編輯器 (Exit)
確定存檔完畢或是想要離開程式，請按下 Ctrl + X。如果檔案已經被修改但尚未存檔，系統會提示詢問「Save modified buffer? (Y/N)」，按 Y 儲存，按 N 則放棄儲存直接離開。 
# 退出 nano 編輯器
Ctrl + X

主題二：游標移動與快速導覽

動作目的： 幫助使用者在篇幅較長、行數較多的設定檔或程式碼中，不需要一直按方向鍵，而是利用快捷鍵快速將游標跳轉到行首、行尾或是特定行數，大幅提升編輯效率。
步驟1：游標移至行首與行尾
當您編輯一長串文字需要修改開頭或結尾時，不必長按左右鍵。按下 Ctrl + A 游標會立刻跳到行首，按下 Ctrl + E 則會立刻跳到行尾。 
# 游標移至目前所在行的最前面
Ctrl + A

# 游標移至目前所在行的最後面
Ctrl + E
步驟2：快速翻頁功能 (Page Up/Down)
對於內容超出螢幕的檔案，您可以使用 Ctrl + Y 來往上翻一頁 (Page Up)，或是使用 Ctrl + V 往下翻一頁 (Page Down)，這樣能夠非常快速地瀏覽檔案。 
# 往上一頁
Ctrl + Y

# 往下一頁
Ctrl + V
步驟3：跳躍至指定的行數 (Go To Line)
若是系統報錯提示第幾行有問題，按下 Ctrl + _（通常為組合鍵 Ctrl + Shift + 減號），底部會提示輸入行號，輸入數字後按下 Enter 即可精準空降。 
# 跳躍至特定行
Ctrl + _
# 例如輸入 55，然後按下 Enter，游標便會停在第 55 行

主題三：剪下與複製貼上

動作目的： 在無法使用實體滑鼠右鍵的純文字終端機環境中，利用鍵盤快捷鍵針對特定行數或是標記區塊進行剪裁、拷貝與貼上，用於文字重構與版面搬移。
步驟1：剪下整行文字 (Cut Text)
將游標停留在想要刪除或剪下的該行文字上，按下 Ctrl + K。這不僅會將該行刪除，還會將它存入 nano 的內部剪貼簿中。 
# 剪下當前游標所在的整行文字
Ctrl + K
步驟2：貼上文字 (Uncut Text)
將剛剛使用 Ctrl + K 剪下的內容（或複製的內容），移動游標到想要放置的目標行數位置，接著按下 Ctrl + U 即可將文字釋放貼上。 
# 貼上剪貼簿中的文字內容
Ctrl + U
步驟3：標記區塊並進行複製 (Copy Text)
若不想剪下而是想「複製」，可以先在起點按 Ctrl + 6 (或 Alt + A) 進行「標記」，移動游標選取範圍後，按下 Alt + 6 即可將所選區塊複製起來。接著一樣使用 Ctrl + U 貼上。 
# 1. 設置起點標記
Ctrl + 6

# (接著透過方向鍵反白選取文字)

# 2. 複製反白的區域
Alt + 6

主題四：關鍵字搜尋與替換

動作目的： 當需要在龐大的系統日誌或伺服器設定檔中尋找特定參數或字串時，可透過強大的搜尋功能精確定位，同時支援將舊設定值全域替換成新的值。
步驟1：搜尋特定關鍵字 (Where Is)
按下 Ctrl + W，底部會出現搜尋提示列。輸入您想找的字串後按 Enter，游標便會跳至第一個符合的結果。若要找下一個相同的字詞，請按 Alt + W。 
# 啟動搜尋功能
Ctrl + W
# (輸入要尋找的字眼並按 Enter)

# 跳至下一個搜尋結果
Alt + W
步驟2：搜尋字串並進行替換 (Replace)
按下 Ctrl + \ (反斜線)，系統會先要求輸入要被替換的「目標字串」，Enter 後接著輸入「新字串」。系統會逐一尋找並詢問是否替換（Y 為單次替換，N 為跳過，A 為全部替換）。 
# 啟動替換功能
Ctrl + \ 

# 操作流程示範：
# 1. 輸入 "old_text" -> Enter
# 2. 輸入 "new_text" -> Enter
# 3. 系統詢問 Replace this instance? (Y/N/A) -> 按 A 進行全域替換

主題五：多檔案同時編輯與切換

動作目的： 在不需要關閉當前編輯器的情況下，同時開啟多個檔案，並在檔案之間快速切換，方便進行內容對照與複製貼上。
步驟1：命令列同時開啟多檔
在啟動 nano 時，可以接連輸入多個檔案名稱。 
# 同時開啟 file1.txt 與 file2.txt
nano file1.txt file2.txt
步驟2：在檔案間進行切換
開啟多檔後，可以使用快捷鍵在不同檔案間循環切換。
- Alt + > (或 Alt + . )：切換至下一個檔案。
- Alt + < (或 Alt + , )：切換至上一個檔案。 
# 切換至下一個檔案
Alt + >

# 切換至上一個檔案
Alt + <

主題六：Nano 編輯器進階設定 (.nanorc)

動作目的： 透過建立個人化的設定檔，讓 nano 預設顯示行號、自動縮排與關閉繁瑣的換行提示，打造更符合開發習慣的終端機編輯環境。
步驟1：建立與編輯設定檔
在使用者家目錄下建立名為 .nanorc 的隱藏設定檔，並在其中寫入實用的參數。 
# 在家目錄建立並編輯設定檔
nano ~/.nanorc

# 建議寫入的常用設定參數：
set linenumbers      # 永久顯示行號
set tabsize 4        # 設定 Tab 鍵大小為 4 個空格
set autoindent       # 自動對齊縮排
set smooth           # 平滑滾動畫面（非整頁跳動）
