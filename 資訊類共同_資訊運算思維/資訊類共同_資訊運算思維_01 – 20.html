4. 下列流程圖所對應的 C/C++程式為何？
(圖示說明：菱形判斷 X>3，若為真則 PRINT A，若為假則 PRINT B，接著匯流執行 X=X+1)
① X>3? cout<<B:cout<<A; X=X+1;
② if (X>3) cout<<A; else cout<<B; X=X+1;
③ switch(X) { case 1: cout<<A; default: cout<<B; }
④ while (X>3) cout<<A; cout<<B; X=X+1;
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

這是一個標準的條件分支，判斷條件為 (X > 3)，為真(True)印出 A，為假(False)印出 B。不論走哪條路，最終都會執行 X = X + 1，因此最符合的結構為 if-else 敘述。

【各選項解析】
  • ① X>3? ...：錯誤，三元運算子中的順序顛倒了，若是 X>3 應該先輸出 A 才對。
  • ② if (X>3)...：正確，符合真印A、假印B，然後統一做 X=X+1 的流程。
  • ③ switch(X)：錯誤，此語法不適用於範圍比較判斷，且無 X=X+1。
  • ④ while (X>3)：錯誤，原圖並無迴圈折返線。
主題：程式邏輯判斷
5. 下列 C/C++程式片段之敘述，何者正確？
int a,b,c; cin>>a; cin>>b; c=a; if(b>c) c=b; cout<<"the output is:"<
① 輸入三個變數
② 找出輸入數值最小值
③ 找出輸入數值最大值
④ 輸出結果為 the output is:c
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

程式先從使用者輸入取得 `a` 與 `b` 的值。接著將 `a` 賦值給 `c` 當作基準。如果 `b` 的值大於基準 `c` (也就是 `a`)，就把 `b` 放進 `c` 裡面。這套邏輯的目的是為了篩選出 `a` 與 `b` 之中的最大值並保存在 `c` 中再印出。

【各選項解析】
  • ① 輸入三個變數：錯誤，只有輸入 a 和 b，宣告了三個變數。
  • ② 找出輸入數值最小值：錯誤，判斷式是用 `b>c` 來取代，這是找最大值的邏輯。
  • ③ 找出輸入數值最大值：正確。
  • ④ 輸出結果為 the output is:c：錯誤，最後輸出的是變數 c 所儲存的值，而不是字元 'c'。

主題：C/C++ 語法規則
9. 下列 C/C++程式片段，何者敘述正確？
While (sum <= 1000) sum = sum + 30;
① 小括號應該改成大括號
② sum = sum +30; 必須使用大括號括起來
③ While 應該改成 while
④ While ( sum<=1000 )之後應該要有分號
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

C/C++ 是嚴格區分字母大小寫 (Case-sensitive) 的程式語言，所有的保留字 (Keywords) 例如 while, for, if 等，都必須使用小寫字母。

【各選項解析】
  • ① 小括號是包裝判斷條件用的，不可改成大括號。
  • ② 當迴圈主體只有一行指令時，大括號是可省略的，不必須。
  • ③ 正確，While 開頭大寫會被視為未宣告的變數或函式，應改為小寫 while。
  • ④ while(條件) 後面若直接加分號，代表該迴圈為空迴圈，後方的程式碼就不是迴圈內部了，不符合原意。
主題：結構控制與邏輯運算
10. 有關 C/C++語言結構控制語法，下列何者正確？
① while (x>0) do {y=5;}
② for (x<10) { y=5;}
③ while (x>0 || x<5) { y=5;}
④ do (x>0) { y=5 } while (x<1)
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

判斷迴圈寫法是否符合 C/C++ 標準。while() 條件區塊中，可以使用邏輯運算子 (如 AND `&&`、OR `||`) 來串接多個條件。

【各選項解析】
  • ① 語法錯誤，沒有 `while(條件) do { }` 這種寫法。
  • ② for 迴圈括號內必須用分號區隔出三個區段 (初始值; 條件; 增量)，不能只放一個判斷式。
  • ③ 正確，使用 `||` (OR) 連接條件，語法完全合法。
  • ④ do-while 的 do 後面不加條件括號，正確語法為 `do { } while(條件);`。

主題：陣列與指標運算
13. 下列 C/C++程式片段，輸出結果何者正確？
int x = 3; int a[] = {1,2,3,4}; int *z; z = a; z = z + x; cout << *z << "\n";
① 1
② 2
③ 3
④ 4
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

1. 陣列 `a` 宣告了 4 個元素：a=1, a[1]=2, a[2]=3, a[3]=4。
2. `z = a;` 使得指標 z 指向陣列的第一個元素 (也就是 a)。
3. 接著指標作加法運算 `z = z + x;`，因 `x = 3`，這代表指標往後移動 3 個單位的空間，現在 z 指向 `a[3]`。
4. 輸出 `*z` 即取出 z 所指位置的值，也就是 a[3] 的值，答案為 4。

【各選項解析】
  • ① 1：這是未加 x 時 a 的值。
  • ② 2：這是 a[1] 的值。
  • ③ 3：這是 x 的值或 a[2] 的值。
  • ④ 4：正確，是指標往後移三步後 a[3] 的值。

主題：邏輯運算與三元運算子
15. 下列 C/C++程式片段，若 x = 2，則 y 值為何？
int y = !(12 < 5 || 3 <= 5 && 3 > x) ? 7 : 9;
① 2
② 3
③ 7
④ 9
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

判斷式拆解：
1. AND `&&` 優先權高於 OR `||`，先算 `3 <= 5 && 3 > 2`。
2. (3 <= 5) 為真 (True)，(3 > 2) 也為真 (True)，所以 `True && True` 結果為 True。
3. 接著算 `||` 左邊的 (12 < 5)，此為假 (False)。
4. 結合起來：`False || True` 結果為 True。
5. 括號外有 NOT 運算子 `!`，將 True 反轉為 False。
6. 三元運算子 `條件 ? 值1 : 值2`，既然條件為 False，就回傳冒號後面的數值 9。

【各選項解析】
  • ① 2：錯，非三元運算結果。
  • ② 3：錯。
  • ③ 7：錯，若條件為 True 才會是 7。
  • ④ 9：正確，條件經計算後為 False，所以 y = 9。
主題：邏輯運算與短路特性
16. 下列 C/C++程式片段，其 x 之輸出結果何者正確？
int x; x = (5 <= 3 && 'A' < 'F') ? 3 : 4;
① 2
② 3
③ 4
④ 5
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

條件判斷式 `(5 <= 3 && 'A' < 'F')`。
因為 5 並不小於等於 3，左側條件即為 False。在 C/C++ 邏輯 AND (`&&`) 運算中存在「短路 (short-circuit)」特性，只要左側為 False，整句結果就必定是 False，不會再去檢查右邊。因為條件為 False，三元運算子會傳回冒號右邊的值 4，故 x = 4。

【各選項解析】
  • ① 2：錯誤。
  • ② 3：錯誤，只有條件為真才會回傳 3。
  • ③ 4：正確。
  • ④ 5：錯誤。
主題：比較運算與布林值轉換
17. 下列 C/C++程式片段，執行後 x 值為何？
int a=0, b=0, c=0; int x=(a<b+4);

② 1
③ 2
④ 3

✅ 正確答案：②

加法運算子優先權高於關係運算子。程式執行 `b+4` 得到 0+4 = 4。接著判斷 `a < 4`，因為 `0 < 4` 是成立的，故這個表達式的布林結果為 True。在 C/C++ 裡面，把 True 賦值給整數變數，其值會被自動轉換為整數的 1。

【各選項解析】
  • ① 0：錯誤，0 代表 False。
  • ② 1：正確，代表 True 轉整數。
  • ③ 2：錯誤。
  • ④ 3：錯誤。
主題：遞迴函式
18. 下列 C/C++程式片段，f(8, 3)輸出為何？
int f(int x, int y) { if (x == y) return 0; else return f(x-1, y) + 1; }
① 3
② 5
③ 8
④ 11
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

此為一個典型的遞迴函式。每次呼叫若 `x` 不等於 `y`，就會回傳下一次遞迴(將 `x` 減去 1)的結果再加 1。
運算過程如下：
f(8,3) -> f(7,3) + 1
f(7,3) -> f(6,3) + 1
f(6,3) -> f(5,3) + 1
f(5,3) -> f(4,3) + 1
f(4,3) -> f(3,3) + 1
f(3,3) -> x==y 成立，回傳 0。
總計遞迴疊加了 5 次的 1，故結果為 0 + 1 + 1 + 1 + 1 + 1 = 5。這函式本質上在計算 x 與 y 的差值 (即 x - y)。

【各選項解析】
  • ① 3：錯誤。
  • ② 5：正確，8 - 3 = 5。
  • ③ 8：錯誤。
  • ④ 11：錯誤，這不是相加。
主題：陣列迴圈運算
19. 對於下列 C/C++程式，何者敘述正確？
for (i=0; i<=m-1; i++){ for (j=0; j<=p-1; j++){ c[i][j]=0; for (k=0; k<=n-1; k++){ c[i][j]=c[i][j]+a[i][k]*b[k][j]; } } }
① 將 a 及 b 兩矩陣相加後，儲存至 c 矩陣
② 若 a[2]={{1, 2}, {3, 4}}及 b[2]= {{1,0},{2,-3}}，執行結束後 c[2]= {{5,6}, {11,12}}
③ 若 a 及 b 均為 2x2 矩陣，最內層 for 迴圈執行 8 次
④ 若 a 及 b 均為 2x2 矩陣，最外層 for 迴圈執行 4 次
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

此程式碼為經典的「矩陣相乘」演算法，計算矩陣 A (m x n) 乘以矩陣 B (n x p) 並存入矩陣 C (m x p)。若 A、B 都是 2x2 矩陣，則 m=2, n=2, p=2。
迴圈執行次數計算：最外層 i 會跑 2 次 (0 到 1)，中間層 j 會跑 2 次，最內層 k 會跑 2 次。因此最內層 `c[i][j] = c[i][j] + ...` 語句總共被執行的次數 = m × p × n = 2 × 2 × 2 = 8 次。

【各選項解析】
  • ① 錯誤，內層是用相乘後累加 `a[i][k]*b[k][j]`，這是矩陣相乘，非相加。
  • ② 錯誤，若真執行矩陣相乘，c = 1*1 + 2*2 = 5；c[1] = 1*0 + 2*(-3) = -6。結果與該選項所述不同。
  • ③ 正確，2x2矩陣的最內層迴圈確實會執行 2*2*2 = 8 次。
  • ④ 錯誤，最外層迴圈 (i) 執行次數由 m 決定，只會執行 2 次。

20. 對於下列 C/C++程式片段，何者敘述有誤？
x1=2; y1=4; x2=6; y2=8; a=y2-y1; b=x2-x1; c=-a*x1+b*y1; cout<<a<<"x+"<<-b<<"y+"<<c<<"=0";
① 程式輸出為 4x+-4y+8=0
② 若(x1,x2)及(y1,y2)視為兩個二維平面座標，程式功能為計算直線方程式
③ 若(x1,x2)及(y1,y2)視為兩個二維平面座標，則直線方程式的斜率為 -4/3
④ 若(x1,x2),(y1,y2)及(3,5)視為三個二維平面座標，則會構成一個直角三角形
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

將數值代入：
a = 8 - 4 = 4
b = 6 - 2 = 4
c = -4*2 + 4*4 = -8 + 16 = 8
輸出：`4x+-4y+8=0`
這條直線方程式為 `4x - 4y + 8 = 0` (化簡為 x - y + 2 = 0)。一元一次直線的斜率 m = -(X係數)/(Y係數) = -4/-4 = 1。
因為斜率是 1，選項③說斜率為 -4/3 是錯誤的，故此選項為「有誤」的敘述。

【各選項解析】
  • ① 敘述正確(非答案)，算式結果確實印出 4x+-4y+8=0。
  • ② 敘述正確(非答案)，這個程式區塊就是在透過兩點求直線的一般式 `ax + by + c = 0`。
  • ③ 敘述錯誤(是本題答案)，該直線斜率應為 1，並非 -4/3。
  • ④ 選項內容敘述了另一個數學特性。題目要找出「有誤」的敘述，③已明確有誤。
