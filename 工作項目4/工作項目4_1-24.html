9. 200.12.34.53/29 所在的網路中，第一個可指定給設備使用之 IP 位址為何？
①200.12.34.1
②200.12.34.49
③200.12.34.17
④200.12.34.53
💡 點擊展開解答與全選項解析
✅ 正確答案：②
【運算解析】 步驟1：分析遮罩 /29。這代表主機位元有 32 - 29 = 3 bits。因此每個子網路大小 (Block Size) 為 2³ = 8。
步驟2：找出 53 落在哪個區塊。53 除以 8 = 6...餘5。代表它落在第 6 個區塊 (6 * 8 = 48)。
步驟3：所以這個子網路的「網路位址 (Network ID)」是 200.12.34.48。
步驟4：題目問「第一個可用 IP」，就是網路位址 + 1。
200.12.34.48 + 1 = 200.12.34.49

13. 若要將 IP 位址為 56.78.0.0/20 之網路分成 8 個子網路，其子網路遮罩為何？
①255.255.255.224
②255.255.224.0
③255.255.254.0
④255.255.248.0
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【運算解析】 步驟1：要分成 8 個子網路，需要借用多少 bit？因為 2³ = 8，所以要向主機部分「借 3 個 bits」。
步驟2：原本的遮罩是 /20，加上借來的 3 bits，新的遮罩變成 /23。
步驟3：將 /23 轉換為十進位。前兩個位元組是 255.255。第三個位元組有 7 個 1 (11111110)，即 128+64+32+16+8+4+2 = 254。
最終遮罩為：255.255.254.0

18. 若將子網路遮罩為 255.255.252.0 之網路再分成 16 個子網路，其子網路遮罩為何？

③255.255.255.224
④255.255.255.240

✅ 正確答案：②
【運算解析】 步驟1：先將原本的 255.255.252.0 轉成 CIDR。第三個位元組 252 二進位是 11111100 (有 6 個 1)，所以原本是 /22。

21. 下列何種 Class 之網路可指定給設備使用之 IP 位址數量最多？
①Class A
②Class B
③Class C
④Class D
💡 點擊展開解答與全選項解析
✅ 正確答案：①
【綜合解析】 IPv4 的分類中，配發給主機 (Host) 的位元數越多，可用的 IP 數量就越多。
- Class A：留 24 bits 給主機 (超過 1677 萬個 IP)。
- Class B：留 16 bits 給主機 (約 6.5 萬個 IP)。
- Class C：留 8 bits 給主機 (254 個 IP)。
- Class D：為群播 (Multicast) 用途，不指定給單一主機設備使用。
因此，可分配數量最多的絕對是 Class A。
22. 下列何種 Class 之網路數量最多？
①Class A
②Class B
③Class C
④Class D
💡 點擊展開解答與全選項解析
✅ 正確答案：③
【運算解析】 IPv4 的分類中，用於定義「網路 ID (Network ID)」的位元數越多，能切割出來的「網路數量」就越多：
- Class A：網路 ID 佔 8 bits (實際變化 7 bits)，網路數量為 2⁷ 個。
- Class B：網路 ID 佔 16 bits (實際變化 14 bits)，網路數量為 2¹⁴ 個。
- Class C：網路 ID 佔 24 bits (實際變化 21 bits)，網路數量為 2²¹ 個。
因此，Class C 能提供最多的「網路段數量」。
23. Class A 之網路數量共有幾個？
