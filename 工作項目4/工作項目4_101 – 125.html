101. DHCP 用戶端，在開機時使用下列哪一種方式請求分配 IP？
① 傳送要求 IP 訊息給路由器
② 於網路中廣播要求 IP 訊息
③ 直接傳送要求 IP 訊息給 DHCP 伺服器
④ 傳送要求 IP 訊息給另一個 DHCP 用戶端
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

DHCP（Dynamic Host Configuration Protocol）用戶端在剛開機時尚未獲取自己的 IP 位址，也還不知道 DHCP 伺服器的所在位置。因此，它會使用「廣播」（Broadcast，發送 DHCPDISCOVER 封包）的方式，在區域網路內尋找可用的 DHCP 伺服器來請求分配 IP [1][2]。

【各選項解析】
  • ① 錯誤。DHCP 請求並非專門發給路由器，而是發給區網內所有的設備以尋找 DHCP 伺服器。
  • ② 正確。在網路上進行廣播，尋找能配發 IP 的 DHCP 伺服器。
  • ③ 錯誤。此時用戶端還不知道 DHCP 伺服器的位址，無法使用單播「直接傳送」。
  • ④ 錯誤。另一台 DHCP 用戶端並沒有配發 IP 位址的權限。

102. IEEE 802.1X 使用下列哪一種協定？
① WEP
② SCP
③ EAP
④ RTP
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

IEEE 802.1X 是一種基於通訊埠的網路存取控制（Port-based Network Access Control）標準。它負責控制存取權限，並透過封裝 EAP（Extensible Authentication Protocol，可延伸認證協定）來進行實際的身分驗證訊息傳輸 [1]。

【各選項解析】
  • ① 錯誤。WEP 是一種老舊且易被破解的無線網路加密協定。
  • ② 錯誤。SCP 是基於 SSH 的安全檔案複製協定。
  • ③ 正確。802.1X 使用 EAP 作為傳遞認證資訊的協定。
  • ④ 錯誤。RTP 是用於網際網路上針對多媒體（音訊、視訊）資料的即時傳輸協定。

103. 下列 CentOS Linux 指令，何者可用來判斷是否已經安裝 Apache 伺服器？
① rpm -i httpd
② rpm -e httpd
③ rpm -q httpd
④ rpm -v httpd
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

在 CentOS 系統中，Apache 伺服器的套件名稱為 `httpd`。若要確認某個套件是否已經安裝，可使用 `rpm` 指令的 `-q` 參數（Query，查詢）來查詢該套件的狀態 [1]。

【各選項解析】
  • ① 錯誤。-i 代表 Install，用於安裝套件。
  • ② 錯誤。-e 代表 Erase，用於解除安裝（移除）套件。
  • ③ 正確。-q 代表 Query，用以查詢該軟體套件是否安裝及版本資訊。
  • ④ 錯誤。-v 代表 Verbose，用於顯示詳細指令執行過程，不會單獨用於查詢是否安裝。

105. 下列 CentOS Linux 指令，何者可用來啟動 Apache 伺服器？
① systemctl restart vsftpd
② systemctl restart httpd

④ systemctl start httpd

在較新的 CentOS 系統中，管理後台服務通常透過 `systemctl` 工具。若要「啟動」服務，應使用 `start` 參數；而 Apache 的服務名稱即為 `httpd` [1]。

【各選項解析】
  • ① 錯誤。這是用來重新啟動 FTP (vsftpd) 服務。
  • ② 錯誤。restart 是用來重新啟動已在執行的服務，題目問的是啟動。
  • ③ 錯誤。這是用來啟動 FTP (vsftpd) 服務。
  • ④ 正確。使用 start 參數搭配 httpd，可啟動 Apache 服務。

  • ③ 錯誤。套件與設定檔名稱應為 httpd，而不是 http。
  • ④ 錯誤。目錄層次與套件名稱皆有誤。

109. CentOS Linux 系統中，修改完 Apache 伺服器的 httpd.conf 設定檔後，何時會套用新的設定？
① 修改後，即會直接套用新的設定
② 修改後，需執行 systemctl restart vsftpd，才會套用新的設定
③ 修改後，需執行 systemctl restart httpd，才會套用新的設定
④ 修改後，需執行 systemctl restart http，才會套用新的設定
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

所有的 Linux 後台伺服器服務在啟動時會讀取設定檔至記憶體中。若修改了實體設定檔，必須手動要求服務程式重新讀取（重新啟動 restart 或是重新載入 reload），新設定才會生效 [3][4]。

【各選項解析】
  • ① 錯誤。設定檔修改後不會即時生效，必須重啟服務。
  • ② 錯誤。vsftpd 是用於 FTP 的服務，與 Apache 無關。
  • ③ 正確。重啟 httpd 服務（systemctl restart httpd）後才能套用新設定。
  • ④ 錯誤。服務的名稱是 httpd，而不是 http。

110. CentOS Linux 系統中，Apache 伺服器預設的本機首頁是放在下列哪一目錄下？
① /etc/html/www
② /etc/www/html
③ /var/www/html
④ /var/html/www
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

在基於 Red Hat 家族的 Linux 發行版中，Apache 伺服器的 `DocumentRoot`（也就是對外提供網站首頁、HTML 檔案存取的預設根目錄）預設是設定在 `/var/www/html` 底下 [3][4]。

【各選項解析】
  • ① 錯誤。/etc 用於存放系統設定檔，非對外網頁檔案目錄。
  • ② 錯誤。/etc 不用於存放網頁檔案。
  • ③ 正確。/var/www/html 為 Apache 的預設網頁根目錄。
  • ④ 錯誤。目錄順序有誤，www 應在 html 上層。
