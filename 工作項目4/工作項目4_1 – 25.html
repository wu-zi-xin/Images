主題：網路定址與私有 IP 範圍
1. 下列何者是 IANA 保留供私人（Private）使用之 IP 位址？
① 172.32.1.34
② 172.15.2.43
③ 172.20.23.186
④ 192.169.0.1
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

根據 RFC 1918 規範，IANA 保留給內部區域網路免費使用的私有 IP (Private IP) 範圍有三個區段：
Class A：10.0.0.0 ~ 10.255.255.255
Class B：172.16.0.0 ~ 172.31.255.255
Class C：192.168.0.0 ~ 192.168.255.255

【各選項解析】
  • ① 172.32.1.34：錯誤。172.32 已超出 Class B 私有 IP 的上限 (172.31)，此為公有 IP。
  • ② 172.15.2.43：錯誤。172.15 低於 Class B 私有 IP 的下限 (172.16)，此為公有 IP。
  • ③ 172.20.23.186：正確。此位址落在 Class B 的 172.16.0.0 ~ 172.31.255.255 範圍內，是合法的私有 IP。
  • ④ 192.169.0.1：錯誤。192.169 已超出 Class C 私有 IP 的上限 (192.168)，此為公有 IP。
主題：網路定址與私有 IP 範圍
2. 下列何者不是 IANA 保留供私人（Private）使用之 IP 位址？
① 10.23.123.54
② 192.168.0.34
③ 172.18.168.23
④ 172.32.45.127
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

私有 IP 僅限於內部區域網路使用，無法直接路由上網際網路。判斷時請牢記三大私有 IP 區段：10.x.x.x、172.16.x.x~172.31.x.x、以及 192.168.x.x。只要不在這些範圍內的 IP 就是需要在網際網路上註冊的公有 IP。

【各選項解析】
  • ① 10.23.123.54：屬於 Class A 私有 IP。
  • ② 192.168.0.34：屬於 Class C 私有 IP。
  • ③ 172.18.168.23：屬於 Class B 私有 IP。
  • ④ 172.32.45.127：正確。172.32.x.x 超出了 Class B 私有 IP (172.16~172.31) 的範圍，屬於需要在網際網路上使用的「公有 IP」。
主題：Class B 私有 IP 範圍
3. IANA 保留 Class B 供私人使用之 IP 位址範圍為何？
① 172.1.0.0~172.31.255.255
② 172.16.0.0~172.31.255.255
③ 172.32.0.0~172.63.255.255
④ 172.16.0.0~172.32.255.255
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

根據 IANA (網際網路號碼分配局) 的規定，Class B 的私有 IP 網段是從 172.16.0.0 開始，一直到 172.31.255.255 結束，這是網管人員必須背誦的基礎常識。

【各選項解析】
  • ① 172.1.0.0~：錯誤。起點不正確，172.1 屬於公有 IP。
  • ② 172.16.0.0~172.31.255.255：正確。此為標準 Class B 私有 IP 的精確範圍。
  • ③ 172.32.0.0~：錯誤。起點與終點皆不正確，這段全數為公有 IP。
  • ④ ~172.32.255.255：錯誤。終點多算了 172.32 網段。
主題：Class C 私有 IP 範圍
4. IANA 保留 Class C 供私人使用之 IP 位址範圍為何？
① 192.168.1.0~192.168.1.254
② 192.168.0.0~192.168.0.255
③ 192.168.0.0~192.168.255.255
④ 192.168.10.0~192.168.10.255
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

Class C 的私有 IP 網段是大家最常在家庭路由器或辦公室區域網路中看到的。其保留範圍是從 192.168.0.0 一直到 192.168.255.255，共有 256 個連續的 C 級網路可供使用。

【各選項解析】
  • ① 192.168.1.0~：錯誤。這只是其中的「一個」子網路，並非完整保留區段。
  • ② 192.168.0.0~0.255：錯誤。這同樣也只是一個 C 級網段。
  • ③ 192.168.0.0~192.168.255.255：正確。此為標準 Class C 私有 IP 的完整範圍。
  • ④ 192.168.10.0~：錯誤。這只涵蓋了單一子網路。
主題：Class A 私有 IP 範圍
5. IANA 保留 Class A 供私人使用之 IP 位址範圍為何？
① 10.0.0.0~10.0.255.255
② 10.10.0.0~10.10.255.255
③ 100.0.0.0~100.100.255.255
④ 10.0.0.0~10.255.255.255
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

Class A 的私有 IP 是保留給大型企業架設內部網路使用的，它僅佔用一個完整的 A 級網段，也就是網路 ID 固定為 10，後面的三個位元組 (24 bits) 皆可供主機自由分配。

【各選項解析】
  • ① 10.0.0.0~10.0.255.255：錯誤。範圍太小，只涵蓋了部分網段。
  • ② 10.10.0.0~：錯誤。範圍太小，這只是其中的子網段。
  • ③ 100.0.0.0~：錯誤。100.x.x.x 屬於公有網際網路 IP 範圍。
  • ④ 10.0.0.0~10.255.255.255：正確。這涵蓋了整個 10.x.x.x 網段，是完整的 Class A 私有位址空間。

9. 200.12.34.53/29 所在的網路中，第一個可指定給設備使用之 IP 位址為何？
① 200.12.34.1
② 200.12.34.49
③ 200.12.34.17
④ 200.12.34.53
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

計算步驟如下：
1. /29 的遮罩對應的區塊大小為 2³ = 8 個 IP。
2. 觀察來源 IP 的第四區段 .53。尋找能被 8 整除且最接近 53 的起點數字：48。
3. 因此該子網路的範圍是從 .48 到 .55 (48+8-1)。
4. .48 是代表整個網段的網路位址 (Network IP) 不可指派給主機。所以「第一個」可用的主機 IP 是 48 + 1 = .49。

【各選項解析】
  • ① .1：錯誤。這是 .0~.7 網段的第一個 IP。
  • ② .49：正確。網段 .48~.55 中的第一個可用 IP 即為 49。
  • ③ .17：錯誤。這是 .16~.23 網段的第一個 IP。
  • ④ .53：錯誤。這是目前主機正在使用的 IP，並非該區段的「第一個」IP。

13. 若要將 IP 位址為 56.78.5.34/20 之網路分成 8 個子網路，其子網路遮罩為何？
① 255.255.248.0
② 255.255.254.0
③ 255.255.252.0
④ 255.255.224.0
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

這是一題標準的子網路切割題：
1. 原始網路為 /20。要將其進一步切割為 8 個子網路，需要借用主機位元。
2. 因為 2³ = 8，所以必須向右方「借用 3 個位元」來作為新的子網路 ID。
3. 新的網路首碼將變成 20 + 3 = /23。
4. 將 /23 轉換為十進位：前兩個 Byte 為 255.255，第三個 Byte 有 7 個 1 (128+64+32+16+8+4+2 = 254)。因此新遮罩為 255.255.254.0。

【各選項解析】
  • ① 255.255.248.0：錯誤。這是 /21 的遮罩 (只分成 2 個子網路)。
  • ② 255.255.254.0：正確。此為 /23 的對應十進位遮罩。
  • ③ 255.255.252.0：錯誤。這是 /22 的遮罩 (分成 4 個子網路)。
  • ④ 255.255.224.0：錯誤。這是 /19 的遮罩。

16. 若要將 IP 位址為 25.178.10.34/20 之網路分成 8 個子網路，其每個子網路中共有幾個 IP 位址可指定給設備使用？
① 512
② 511
③ 510
④ 509
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

這是一題單純的可用主機數量計算：
1. 原始為 /20，切成 8 (2³) 個子網路代表要向主機位元借 3 個 bit，因此新網路的遮罩變成了 /23。
2. 總共 32 位元減掉網路位元 23，剩餘的「主機位元」為 9 個。
3. 該網段的總 IP 數為 2⁹ = 512。
4. 「可指定給設備使用」的 IP 必須扣除頭尾 (即網路位址與廣播位址)，因此為 512 - 2 = 510 個。

【各選項解析】
  • ① 512：錯誤。這是總 IP 數量，忘記扣除頭尾不可用的保留位址。
  • ② 511：錯誤。只扣除了一個。
  • ③ 510：正確。512 減去 2 等於 510。
  • ④ 509：錯誤。

17. 若要將 IP 位址為 65.8.20.34/20 所在之網路分成 16 個子網路，其每個子網路中共有幾個 IP 位址可指定給設備使用？
① 252
② 254
③ 255
④ 256
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

計算方式如同上題：
1. 原始為 /20，切割為 16 (2⁴) 個子網路，代表要借 4 個位元。新遮罩變成 20 + 4 = /24。
2. 新的網路其主機位元剩下 32 - 24 = 8 個 bit。
3. 該網段總 IP 數為 2⁸ = 256 個。
4. 扣掉網路位址與廣播位址後，可用主機數為 256 - 2 = 254 個。

【各選項解析】
  • ① 252：錯誤。
  • ② 254：正確。256 減去 2 即得 254。
  • ③ 255：錯誤。
  • ④ 256：錯誤。這是未扣除頭尾的總數量。
主題：子網路遮罩延伸切割
18. 若要將子網路遮罩為 255.255.252.0 之網路再分成 16 個子網路，其子網路遮罩為何？
① 255.255.255.0
② 255.255.255.192
③ 255.255.255.224
④ 255.255.255.240
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

1. 先將原始十進位遮罩轉為 CIDR：255.255.252.0 中，252 對應 6 個 1 (128+64+32+16+8+4)。因此原始遮罩為 8+8+6 = /22。
2. 欲分成 16 (2⁴) 個子網路，必須向右再借 4 個 bit。
3. 新的遮罩將成為 22 + 4 = /26。
4. 將 /26 轉換回十進位：前三個 Byte 皆為 255，第四個 Byte 借了 2 個位元 (128+64 = 192)。故答案為 255.255.255.192。

【各選項解析】
  • ① 255.255.255.0：錯誤。這是 /24 遮罩，只分成 4 個子網路。
  • ② 255.255.255.192：正確。此即為精確計算後的 /26 新遮罩。
  • ③ 255.255.255.224：錯誤。這是 /27 遮罩。
  • ④ 255.255.255.240：錯誤。這是 /28 遮罩。

① 128
② 256
③ 512
④ 64
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

標準的 Class A 網路預設遮罩是 /8 (只有第一個 Byte 是網路 ID)。而標準的 Class B 網路預設遮罩是 /16 (前兩個 Byte 是網路 ID)。
要把 A 級網路切成 B 級的大小，等於要將網路遮罩從 /8 擴張到 /16。這中間向主機借用的位元數為 16 - 8 = 8 個 bits。

  • ① 128：錯誤。算成 2⁷ 了。

  • ③ 512：錯誤。
  • ④ 64：錯誤。

23. Class A 之網路數量共有幾個？
① 2⁸
② 2⁷
③ 2⁶
④ 2⁹
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

在 IPv4 標準中，Class A 網段的特徵是：
1. 網路 ID 佔用第一個 Byte (共 8 個 bits)。
2. 但規定其「最左邊的第一個位元」必須永遠固定為 0。
既然有 1 個位元被固定綁死了，代表真正可以自由變動來產生不同網路 ID 的位元數只剩下 8 - 1 = 7 個 bits。因此，Class A 網路的理論總數為 2⁷ = 128 個 (實務上需保留全0與全1，但考題通常以理論公式值為主)。

【各選項解析】
  • ① 2⁸：錯誤。這未將 Class A 強制固定為 0 的首位元扣除。
  • ② 2⁷：正確。扣除 1 個固定位元後，剩餘組合為 2⁷ 個。
  • ③ 2⁶：錯誤。
  • ④ 2⁹：錯誤。

① 2¹⁶
② 2¹⁵
③ 2¹⁴
④ 2¹³
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

如同上一題的邏輯，Class B 網段的特徵是：
1. 網路 ID 佔用前兩個 Byte (共 16 個 bits)。
2. 規定其「最左邊的前兩個位元」必須永遠固定為 10。
16 個位元中扣除 2 個固定不動的位元後，真正可自由變化的剩餘位元數為 16 - 2 = 14 個 bits。因此，Class B 網路的理論總數為 2¹⁴ 個。

  • ④ 2¹³：錯誤。

【各選項解析】

  • ③ 2²²：錯誤。計算位元有誤。
  • ④ 2²¹：正確。精確扣除 3 個固定首位元後得到的結果。
