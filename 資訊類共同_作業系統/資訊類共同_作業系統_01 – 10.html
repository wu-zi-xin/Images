資訊相關職類共用工作項目

工作項目 03：作業系統 (第01 - 10題)

主題：程式語言翻譯
1. 有關使用直譯程式(Interpreter)將程式翻譯成機器語言之敘述，下列何者正確？
①直譯程式(Interpreter)與編譯程式(Compiler)翻譯方式一樣
②直譯程式每次轉譯一行指令後即執行
③直譯程式先執行再翻譯成目的程式
④直譯程式先翻譯成目的程式，再執行之
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

直譯程式（Interpreter）會將高階語言的原始碼逐行翻譯，並立刻執行，不會產生目的程式（Object file）。編譯程式（Compiler）則是將全部原始碼翻譯成目的程式後再一次性執行，兩者運作方式截然不同。

【各選項解析】
  • ①直譯程式(Interpreter)與編譯程式(Compiler)翻譯方式一樣：錯誤，直譯與編譯方式不同。
  • ②直譯程式每次轉譯一行指令後即執行：正確，這是直譯程式的核心運作原理 [1-3]。
  • ③直譯程式先執行再翻譯成目的程式：錯誤，必須先翻譯成機器語言才能執行。
  • ④直譯程式先翻譯成目的程式，再執行之：錯誤，這是編譯程式（Compiler）的特徵。
主題：程式編譯與連結
2. 編譯程式(Compiler)將高階語言翻譯至可執行的過程中，下列何者是連結程式(Linker)負責連結的標的？
①目的程式與所需之副程式
②原始程式與目的程式
③副程式與可執行程式
④原始程式與可執行程式
💡 點擊展開解答與解析
✅ 正確答案：①
【綜合解析】

在程式編譯的過程中，編譯器先將高階原始碼翻譯為目的程式（Object file）。接著，連結程式（Linker）的任務就是將這個目的程式與其他預先編譯好的系統資源、函數庫（副程式）進行連結，最終整合成一個可執行程式。

【各選項解析】
  • ①目的程式與所需之副程式：正確，連結程式負責將目的檔和函數庫進行連結 [1, 2]。
  • ②原始程式與目的程式：錯誤，原始程式已被編譯器轉為目的程式。
  • ③副程式與可執行程式：錯誤，連結副程式是為了「產生」可執行程式，不是連結可執行程式。
  • ④原始程式與可執行程式：錯誤，原始程式並不參與連結階段。
主題：作業系統類型
3. Linux 是屬何種系統？
①應用系統(Application Systems)
②作業系統(Operation Systems)
③資料庫系統(Database Systems)
④編輯系統(Editor Systems)
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

Linux 是一套免費且開源的類 Unix 作業系統。它負責控制與管理電腦硬體資源，為各種應用軟體提供運作平台，因此屬於系統軟體中的作業系統（Operation Systems）。

【各選項解析】
  • ①應用系統(Application Systems)：錯誤，Linux 並非特定應用的軟體。
  • ②作業系統(Operation Systems)：正確，Linux 本身就是著名的作業系統核心 [1, 2, 4]。
  • ③資料庫系統(Database Systems)：錯誤，如 MySQL 或 Oracle 才是資料庫。
  • ④編輯系統(Editor Systems)：錯誤，如 Vim 或 Word 才是編輯系統。
主題：作業系統介面
4. 下列何種作業系統沒有圖形使用者操作介面？
①Linux
②Windows Server
③Mac OS
④MS-DOS
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

圖形使用者介面（GUI）能讓使用者透過滑鼠與圖示來操作電腦。早期的微軟作業系統 MS-DOS 是單純的文字命令列介面（CLI），使用者必須手動輸入指令來操作，原生並不提供圖形介面。

【各選項解析】
  • ①Linux：錯誤，Linux 雖支援文字介面，但也能安裝 X-Window 擁有強大的圖形介面。
  • ②Windows Server：錯誤，微軟的伺服器版本具備視窗圖形介面。
  • ③Mac OS：錯誤，蘋果的 Mac OS 內建精緻的圖形使用者介面。
  • ④MS-DOS：正確，MS-DOS 是純文字命令列系統，沒有圖形介面 [1, 2]。
主題：作業系統特性
5. 下列何者「不是」多人多工之作業系統？
①Linux
②Solaris
③MS-DOS
④Windows Server
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

「多人多工」代表可以有多位使用者同時登入作業系統，並且在同一時間執行多個應用程式。MS-DOS 屬於早期的「單人單工」系統，同一時間只能讓一名使用者執行一個程式。

【各選項解析】
  • ①Linux：錯誤，是典型的高效能多人多工作業系統。
  • ②Solaris：錯誤，Unix 的分支，也是多人多工作業系統。
  • ③MS-DOS：正確，MS-DOS 屬於單人單工作業系統 [1, 2]。
  • ④Windows Server：錯誤，專為伺服器設計，支援多人多工。
主題：系統帳號管理
6. 下列何者為 Linux 作業系統之「系統管理者」的預設帳號？
①administrator
②manager
③root
④supervisor
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

不同作業系統會有不同的預設最高權限帳號。在 Linux 及 Unix-like 系統中，超級使用者（superuser）或系統管理者的預設帳號名稱固定為 root。而 Windows 的預設最高權限帳號則是 Administrator。

【各選項解析】
  • ①administrator：錯誤，這是 Windows 系統的預設管理者帳號。
  • ②manager：錯誤，一般無此預設高權限帳號。
  • ③root：正確，這是 Linux 系統管理者的預設帳號 [1, 2]。
  • ④supervisor：錯誤，通常是其他特定應用軟體的最高權限角色稱呼。
主題：系統登入機制
7. Windows 登入時，若鍵入的密碼其「大小寫不正確」會導致下列何種結果？
①仍可以進入 Windows
②進入 Windows 的安全模式
③要求重新輸入密碼
④Windows 將先關閉，並重新開機
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

Windows 作業系統在進行使用者驗證時，密碼是嚴格區分大小寫的（Case-sensitive）。如果輸入的英文字母大小寫錯誤，系統會視為密碼不符，拒絕登入，並提示使用者重新輸入正確的密碼。

【各選項解析】
  • ①仍可以進入 Windows：錯誤，基於安全機制，密碼錯誤無法登入。
  • ②進入 Windows 的安全模式：錯誤，安全模式需透過特殊開機選項進入，與密碼錯誤無關。
  • ③要求重新輸入密碼：正確，系統會提示密碼錯誤並讓你重試 [4, 5]。
  • ④Windows 將先關閉，並重新開機：錯誤，不會因為密碼打錯就導致電腦重啟。
主題：記憶體管理
8. 下列何種技術是利用硬碟空間來解決主記憶體空間之不足？
①分時技術(Time Sharing)
②同步記憶體 (Concurrent Memory)
③虛擬記憶體 (Virtual Memory)
④多工技術 (Multitasking)
💡 點擊展開解答與解析
✅ 正確答案：③
【綜合解析】

當電腦在執行較大型的程式，主記憶體（RAM）容量不夠時，作業系統會使用「虛擬記憶體（Virtual Memory）」技術，劃分出部分硬碟空間當作暫存記憶體使用。這可以騙過應用程式，讓它們以為有充足的主記憶體可以使用。

【各選項解析】
  • ①分時技術(Time Sharing)：錯誤，這是 CPU 切割時間給不同程式使用的技術。
  • ②同步記憶體 (Concurrent Memory)：錯誤，無此用於解決記憶體不足的標準名詞。
  • ③虛擬記憶體 (Virtual Memory)：正確，利用硬碟空間擴充主記憶體容量 [4-7]。
  • ④多工技術 (Multitasking)：錯誤，這是指 CPU 表面上同時執行多個程式的技術。
主題：系統軟體概念
9. 電腦中負責資源管理的軟體是下列何種？
①編譯程式 (Compiler)
②公用程式 (Utility)
③應用程式 (Application)
④作業系統 (Operating System)
💡 點擊展開解答與解析
✅ 正確答案：④
【綜合解析】

作業系統（Operating System, OS）是電腦最基礎的系統軟體。它的主要功能是作為使用者與硬體之間的橋樑，負責管理包含 CPU 排程、記憶體分配、檔案系統以及周邊輸入輸出裝置等所有電腦資源。

【各選項解析】
  • ①編譯程式 (Compiler)：錯誤，用於將高階語言翻譯為目的碼的工具。
  • ②公用程式 (Utility)：錯誤，用來執行維護電腦、掃毒或備份等輔助功能。
  • ③應用程式 (Application)：錯誤，滿足使用者特定需求（如文書處理、上網）的軟體。
  • ④作業系統 (Operating System)：正確，負責統一管理系統各項資源 [4, 5]。
主題：檔案系統
10. 下列何者為 Linux 系統所採用的檔案系統？
①NTFS
②XFS
③HTFS
④vms
💡 點擊展開解答與解析
✅ 正確答案：②
【綜合解析】

檔案系統決定了資料在磁碟中如何被存儲和管理。Linux 常見支援的檔案系統包含了 ext 系列（ext2, ext3, ext4）以及高效能的日誌檔案系統如 XFS。相對的，NTFS 則是微軟 Windows 系統的核心檔案系統。

【各選項解析】
  • ①NTFS：錯誤，這是 Windows NT 核心（Windows 2000, XP, 10, 11等）採用的檔案系統。
  • ②XFS：正確，這是一個由 SGI 創建的檔案系統，現廣泛應用於多數 Linux 發行版中 [4, 5]。
  • ③HTFS：錯誤，並非主流知名的標準檔案系統。
  • ④vms：錯誤，OpenVMS 是一套作業系統的名稱，並非 Linux 檔案系統。
